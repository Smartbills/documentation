---
title: "Update Location"
api: "PUT https://api.smartbills.io/v1/locations/{id}"
description: "Update an existing location's information"
---

## Overview

Update the details of an existing business location. All fields in the request body will replace the existing values.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Required Scopes

- `locations.write`

## Path Parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the location to update
</ParamField>

## Request Body

<ParamField body="name" type="string" required>
  Name of the location
</ParamField>

<ParamField body="address" type="object" required>
  Complete address object (all fields required)
</ParamField>

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 400 | INVALID_PARAMETER | Invalid parameter value |
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions |
| 404 | NOT_FOUND | Location not found |
| 409 | DUPLICATE_LOCATION | Address already used by another location |
| 429 | RATE_LIMIT_EXCEEDED | Too many requests |

<Warning>
  **Full Replacement**: The update operation replaces all fields. Include all required fields in your request.
</Warning>

## Best Practices

<AccordionGroup>
  <Accordion title="Fetch Before Update" icon="arrows-rotate">
    Always fetch the current location data before updating to avoid overwriting fields.
    
    ```javascript
    const current = await client.locations.get(12345);
    const updated = await client.locations.update(12345, {
      ...current,
      name: "New Name"
    });
    ```
  </Accordion>

  <Accordion title="Validate Address Changes" icon="location-dot">
    Ensure address uniqueness when updating to prevent conflicts.
  </Accordion>
</AccordionGroup>
