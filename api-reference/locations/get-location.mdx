title: "Get Location"
api: "GET https://api.smartbills.io/v1/locations/{id}"
description: "Retrieve a location by ID"
---

## Overview

Retrieve detailed information about a specific business location using its unique identifier.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Required Scopes

- `locations.read`

## Path Parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the location to retrieve
</ParamField>

<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.smartbills.io/v1/locations/12345 \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: 'YOUR_API_KEY' });

const location = await client.locations.get(12345);
console.log('Location:', location);
```

```python Python
from smartbills import Smartbills

client = Smartbills(api_key='YOUR_API_KEY')

location = client.locations.get(12345)
print('Location:', location)
```

```csharp C#
using Smartbills.NET;

var client = new SBClient("YOUR_API_KEY");

var location = await client.Locations.GetAsync(12345);
Console.WriteLine($"Location: {location.Name}");
```

</RequestExample>

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions |
| 404 | NOT_FOUND | Location not found |
| 429 | RATE_LIMIT_EXCEEDED | Too many requests |
