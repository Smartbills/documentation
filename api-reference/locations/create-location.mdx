## Overview

Create a new location for your business. Locations represent physical or virtual places where your business operates and can be used to organize receipts and transactions.

<Info>
  **Core Principle**: A location should be unique by address to avoid duplicates.
</Info>

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Required Scopes

- `locations.write`

## Request Body

<ParamField body="name" type="string" required>
  Name of the location (e.g., "Downtown Store", "Main Office")
</ParamField>

<ParamField body="address" type="object" required>
  Physical address of the location
  
  <Expandable title="Address Object">
    <ParamField body="street" type="string" required>
      Street address
    </ParamField>
    
    <ParamField body="city" type="string" required>
      City name
    </ParamField>
    
    <ParamField body="state" type="string" required>
      State or province name
    </ParamField>
    
    <ParamField body="stateCode" type="string" required>
      Two-letter state/province code
    </ParamField>
    
    <ParamField body="country" type="string" required>
      Country name
    </ParamField>
    
    <ParamField body="countryCode" type="string" required>
      Two-letter ISO country code
    </ParamField>
    
    <ParamField body="postalCode" type="string" required>
      Postal or ZIP code
    </ParamField>
    
    <ParamField body="location" type="object">
      Geographic coordinates
      
      <Expandable title="Coordinates">
        <ParamField body="latitude" type="number" required>
          Latitude
        </ParamField>
        
        <ParamField body="longitude" type="number" required>
          Longitude
        </ParamField>
      </Expandable>
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="merchantCategoryCode" type="string" required>
  MCC (Merchant Category Code) - 4-digit code classifying the business type
</ParamField>

<ParamField body="currency" type="string">
  Three-letter ISO currency code (e.g., USD, CAD, EUR)
</ParamField>

<ParamField body="timezone" type="string">
  IANA timezone identifier (e.g., "America/New_York")
</ParamField>

<ParamField body="phoneNumber" type="string">
  Phone number of the location
</ParamField>

<ParamField body="email" type="string">
  Email address for the location
</ParamField>

<ParamField body="website" type="string">
  Website URL
</ParamField>

<ParamField body="description" type="string">
  Description of the location
</ParamField>

<ParamField body="locale" type="string">
  Locale code (e.g., "en-US", "fr-CA")
</ParamField>

<ParamField body="isActive" type="boolean" default="true">
  Whether the location is currently active
</ParamField>

<ParamField body="logo" type="string">

## Merchant Category Codes (MCC)

Common MCC codes for different business types:

| MCC | Business Type |
|-----|---------------|
| 5411 | Grocery Stores, Supermarkets |
| 5812 | Eating Places, Restaurants |
| 5814 | Fast Food Restaurants |
| 5912 | Drug Stores, Pharmacies |
| 5999 | Miscellaneous and Specialty Retail |
| 7011 | Hotels, Motels, Resorts |
| 7230 | Beauty and Barber Shops |
| 7832 | Motion Picture Theaters |
| 7995 | Gambling, Casinos |

[View complete MCC list](https://www.citibank.com/tts/solutions/commercial-cards/assets/docs/govt/Merchant-Category-Codes.pdf)
