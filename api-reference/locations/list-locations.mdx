---
title: "List Locations"
api: "GET https://api.smartbills.io/v1/locations"
description: "Retrieve a paginated list of locations"
---

## Overview

Retrieve a list of all business locations in your account with pagination, sorting, and filtering options.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Required Scopes

- `locations.read`

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number for pagination (starts at 1)
</ParamField>

<ParamField query="pageSize" type="integer" default="100">
  Number of items per page (max: 100)
</ParamField>

<ParamField query="orderBy" type="string" default="createdAt">
  Field to sort by. Options: `id`, `name`, `createdAt`, `updatedAt`
</ParamField>

<ParamField query="sortOrder" type="string" default="desc">
  Sort order. Options: `asc`, `desc`
</ParamField>

<ParamField query="search" type="string">
  Search locations by name, city, or address
</ParamField>

<ParamField query="isActive" type="boolean">
  Filter by active status
</ParamField>

<ParamField query="city" type="string">
  Filter by city name
</ParamField>

<ParamField query="state" type="string">
  Filter by state or province
</ParamField>

<ParamField query="country" type="string">
  Filter by country
</ParamField>

<ParamField query="merchantCategoryCode" type="string">
  Filter by MCC code
</ParamField>

## Response

<ResponseField name="data" type="array">
  Array of location objects
</ResponseField>

<ResponseField name="metadata" type="object">
  Pagination metadata
  
  <Expandable title="Metadata Object">
    <ResponseField name="page" type="integer">
      Current page number
    </ResponseField>
    
    <ResponseField name="pageSize" type="integer">
      Number of items per page
    </ResponseField>
    
    <ResponseField name="totalPages" type="integer">
      Total number of pages
    </ResponseField>
    
    <ResponseField name="count" type="integer">
      Total number of locations
    </ResponseField>
  </Expandable>
</ResponseField>


```javascript JavaScript
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: 'YOUR_API_KEY' });

const response = await client.locations.list({
  page: 1,
  pageSize: 20,
  isActive: true,
  orderBy: 'name',
  sortOrder: 'asc'
});

console.log(`Found ${response.metadata.count} locations`);
console.log('Locations:', response.data);
```

```python Python
from smartbills import Smartbills

client = Smartbills(api_key='YOUR_API_KEY')

response = client.locations.list(
    page=1,
    page_size=20,
    is_active=True,
    order_by='name',
    sort_order='asc'
)

print(f"Found {response.metadata.count} locations")
print('Locations:', response.data)
```

```csharp C#
using Smartbills.NET;

var client = new SBClient("YOUR_API_KEY");

var response = await client.Locations.ListAsync(new LocationListRequest
{
    Page = 1,
    PageSize = 20,
    IsActive = true,
    OrderBy = "name",
    SortOrder = "asc"
});

Console.WriteLine($"Found {response.Metadata.Count} locations");
foreach (var location in response.Data)
{
    Console.WriteLine($"- {location.Name}");
}
```

## Filtering Examples

### Search by Name or Address

```bash
GET /v1/locations?search=downtown
```

### Filter by City

```bash
GET /v1/locations?city=New York
```

### Filter Active Locations Only

```bash
GET /v1/locations?isActive=true
```

### Combine Filters

```bash
GET /v1/locations?city=New York&isActive=true&orderBy=name&sortOrder=asc
```
