---

## Overview

Retrieve a list of all customers in your account with pagination, sorting, and filtering options.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Required Scopes

- `customers.read`

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number for pagination
</ParamField>

<ParamField query="pageSize" type="integer" default="100">
  Number of items per page (max: 100)
</ParamField>

<ParamField query="orderBy" type="string" default="createdAt">
  Field to sort by: `id`, `firstName`, `lastName`, `email`, `createdAt`, `updatedAt`, `totalSpent`
</ParamField>

<ParamField query="sortOrder" type="string" default="desc">
  Sort order: `asc`, `desc`
</ParamField>

<ParamField query="search" type="string">
  Search by name or email
</ParamField>

<ParamField query="email" type="string">
  Filter by exact email address
</ParamField>

<ParamField query="taxExempt" type="boolean">
  Filter by tax exempt status
</ParamField>

<ParamField query="acceptsMarketing" type="boolean">
  Filter by marketing acceptance
</ParamField>

<ParamField query="tags" type="string">
  Filter by tags (comma-separated)
</ParamField>

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.smartbills.io/v1/customers?page=1&pageSize=20&orderBy=totalSpent&sortOrder=desc' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: 'YOUR_API_KEY' });

const response = await client.customers.list({
  page: 1,
  pageSize: 20,
  orderBy: 'totalSpent',
  sortOrder: 'desc'
});

console.log(`Found ${response.metadata.count} customers`);
```

```python Python
from smartbills import SmartBills

client = SmartBills(api_key='YOUR_API_KEY')

response = client.customers.list(
    page=1,
    page_size=20,
    order_by='totalSpent',
    sort_order='desc'
)

print(f"Found {response.metadata.count} customers")
```

```csharp C#
using Smartbills.NET;

var client = new SBClient("YOUR_API_KEY");

var response = await client.Customers.ListAsync(new CustomerListRequest
{
    Page = 1,
    PageSize = 20,
    OrderBy = "totalSpent",
    SortOrder = "desc"
});

Console.WriteLine($"Found {response.Metadata.Count} customers");
```

## Filtering Examples

### Search by Name or Email

```bash
GET /v1/customers?search=john
```

### Filter by Tag

```bash
GET /v1/customers?tags=vip
```

### Filter Marketing Opt-ins

```bash
GET /v1/customers?acceptsMarketing=true
```

### Get Top Spenders

```bash
GET /v1/customers?orderBy=totalSpent&sortOrder=desc&pageSize=10
```
