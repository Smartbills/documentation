## Overview

Create a new customer to track receipts and transactions. Customers represent individuals or businesses that purchase from your business.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Required Scopes

- `customers.write`

## Request Body

<ParamField body="firstName" type="string" required>
  Customer's first name
</ParamField>

<ParamField body="lastName" type="string" required>
  Customer's last name
</ParamField>

<ParamField body="email" type="string">
  Email address (required if no phone provided)
</ParamField>

<ParamField body="phone" type="string">
  Phone number (required if no email provided)
</ParamField>

<ParamField body="locale" type="string" required>
  Locale code (e.g., "en-US", "fr-CA")
</ParamField>

<ParamField body="taxExempt" type="boolean" default="false">
  Whether the customer is tax exempt
</ParamField>

<ParamField body="acceptsMarketing" type="boolean" default="false">
  Whether the customer accepts marketing communications
</ParamField>

<ParamField body="address" type="object">
  Customer's address
  
  <Expandable title="Address Object">
    <ParamField body="line1" type="string">
      First line of address
    </ParamField>
    
    <ParamField body="line2" type="string">
      Second line of address
    </ParamField>
    
    <ParamField body="city" type="string">
      City name
    </ParamField>
    
    <ParamField body="state" type="string">
      State or province
    </ParamField>
    
    <ParamField body="stateCode" type="string">
      Two-letter state/province code
    </ParamField>
    
    <ParamField body="country" type="string">
      Country name
    </ParamField>
    
    <ParamField body="countryCode" type="string">
      Two-letter ISO country code
    </ParamField>
    
    <ParamField body="postalCode" type="string">
      Postal or ZIP code
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="notes" type="string">
  Additional notes about the customer
</ParamField>

<ParamField body="tags" type="array">
  Array of tag strings for categorization
</ParamField>

<ParamField body="metadata" type="object">
  Custom metadata key-value pairs
</ParamField>

var client = new SBClient("YOUR_API_KEY");

var customer = await client.Customers.CreateAsync(new CustomerCreateRequest

    FirstName = "John",

    Email = "john.doe@example.com",
    Phone = "+1-555-123-4567",
    Locale = "en-US",
    TaxExempt = false,
    AcceptsMarketing = true,
    Address = new AddressRequest
    {

        City = "New York",
        State = "New York",
        StateCode = "NY",
        Country = "United States",
        CountryCode = "US",
        PostalCode = "10001"
    },
    Tags = new[] { "vip", "premium" },
    Metadata = new Dictionary<string, string>
    {
        { "customer_segment", "enterprise" },
        { "account_manager", "Jane Smith" }
    }
});

Console.WriteLine($"Created customer: {customer.Id}");

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 400 | INVALID_PARAMETER | Invalid parameter value |
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions |
| 409 | DUPLICATE_CUSTOMER | Customer with this email already exists |
| 429 | RATE_LIMIT_EXCEEDED | Too many requests |

## Best Practices

<AccordionGroup>
  <Accordion title="Check for Duplicates" icon="copy">
    Check if a customer already exists before creating a new one.
    
    ```javascript
    const existing = await client.customers.list({ email: 'john.doe@example.com' });
    if (existing.data.length === 0) {
      await client.customers.create({ email: 'john.doe@example.com', ... });
    }
    ```
  </Accordion>

  <Accordion title="Use Metadata" icon="tag">
    Use metadata to store custom information about customers for your business needs.
  </Accordion>

  <Accordion title="Tag Customers" icon="tags">
    Use tags to categorize customers (e.g., "vip", "wholesale", "retail").
  </Accordion>

  <Accordion title="Respect Marketing Preferences" icon="envelope">
    Always respect the `acceptsMarketing` flag when sending communications.
  </Accordion>
</AccordionGroup>
