---

## Overview

Retrieve a list of all employees in your account with pagination, sorting, and filtering options.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Required Scopes

- `employees.read`

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number for pagination
</ParamField>

<ParamField query="pageSize" type="integer" default="100">
  Number of items per page (max: 100)
</ParamField>

<ParamField query="orderBy" type="string" default="createdAt">
  Field to sort by: `id`, `firstName`, `lastName`, `createdAt`, `totalSales`
</ParamField>

<ParamField query="sortOrder" type="string" default="desc">
  Sort order: `asc`, `desc`
</ParamField>

<ParamField query="search" type="string">
  Search by name or email
</ParamField>

<ParamField query="department" type="string">
  Filter by department
</ParamField>

<ParamField query="isActive" type="boolean">
  Filter by active status
</ParamField>

<ParamField query="employeeNumber" type="string">
  Filter by employee number
</ParamField>

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.smartbills.io/v1/employees?page=1&pageSize=20&isActive=true' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: 'YOUR_API_KEY' });

const response = await client.employees.list({
  page: 1,
  pageSize: 20,
  isActive: true,
  orderBy: 'totalSales',
  sortOrder: 'desc'
});

console.log(`Found ${response.metadata.count} employees`);
```

```python Python
from smartbills import Smartbills

client = Smartbills(api_key='YOUR_API_KEY')

response = client.employees.list(
    page=1,
    page_size=20,
    is_active=True,
    order_by='totalSales',
    sort_order='desc'
)

print(f"Found {response.metadata.count} employees")
```

```csharp C#
using Smartbills.NET;

var client = new SBClient("YOUR_API_KEY");

var response = await client.Employees.ListAsync(new EmployeeListRequest
{
    Page = 1,
    PageSize = 20,
    IsActive = true,
    OrderBy = "totalSales",
    SortOrder = "desc"
});

Console.WriteLine($"Found {response.Metadata.Count} employees");
```

## Filtering Examples

### Get Top Performers

```bash
GET /v1/employees?orderBy=totalSales&sortOrder=desc&pageSize=10
```

### Filter by Department

```bash
GET /v1/employees?department=Sales
```

### Active Employees Only

```bash
GET /v1/employees?isActive=true
```
