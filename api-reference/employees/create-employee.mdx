## Overview

Create a new employee to track sales and customer interactions. Employees are customer-facing staff members that generate sales and can be associated with receipts for detailed analytics.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Required Scopes

- `employees.write`

## Request Body

<ParamField body="firstName" type="string" required>
  Employee's first name
</ParamField>

<ParamField body="lastName" type="string">
  Employee's last name
</ParamField>

<ParamField body="email" type="string">
  Email address
</ParamField>

<ParamField body="locale" type="string">
  Locale code (e.g., "en-US", "fr-CA")
</ParamField>

<ParamField body="birthDate" type="string">
  Birth date in ISO 8601 format (YYYY-MM-DD)
</ParamField>

<ParamField body="phoneNumber" type="string">
  Phone number
</ParamField>

<ParamField body="employeeNumber" type="string">
  Internal employee number or ID
</ParamField>

<ParamField body="department" type="string">
  Department name
</ParamField>

<ParamField body="position" type="string">
  Job position or title
</ParamField>

<ParamField body="hireDate" type="string">
  Hire date in ISO 8601 format (YYYY-MM-DD)
</ParamField>

<ParamField body="isActive" type="boolean" default="true">
  Whether the employee is currently active
</ParamField>

<ParamField body="metadata" type="object">
  Custom metadata key-value pairs
</ParamField>

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 400 | INVALID_PARAMETER | Invalid parameter value |
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions |
| 409 | DUPLICATE_EMPLOYEE | Employee with this email or employee number already exists |
| 429 | RATE_LIMIT_EXCEEDED | Too many requests |
