---
title: "Get Employee"
api: "GET https://api.smartbills.io/v1/employees/{id}"
description: "Retrieve an employee by ID"
---

## Overview

Retrieve detailed information about a specific employee using their unique identifier.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Required Scopes

- `employees.read`

## Path Parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the employee to retrieve
</ParamField>

<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.smartbills.io/v1/employees/12345 \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: 'YOUR_API_KEY' });

const employee = await client.employees.get(12345);
console.log('Employee:', employee);
```

```python Python
from smartbills import SmartBills

client = SmartBills(api_key='YOUR_API_KEY')

employee = client.employees.get(12345)
print('Employee:', employee)
```

```csharp C#
using Smartbills.NET;

var client = new SBClient("YOUR_API_KEY");

var employee = await client.Employees.GetAsync(12345);
Console.WriteLine($"Employee: {employee.FirstName} {employee.LastName}");
```

</RequestExample>
