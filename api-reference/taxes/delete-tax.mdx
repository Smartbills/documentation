---
title: "Delete Tax"
api: "DELETE https://api.smartbills.io/v1/taxes/{id}"
description: "Delete a tax from your account"
---

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication
</ParamField>

## Required Scopes

- `taxes.write`

## Path Parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the tax to delete
</ParamField>

<Warning>
  **Destructive Action**: Deleting a tax is permanent. Consider deactivating instead.
</Warning>

<RequestExample>

```bash cURL
curl --request DELETE \
  --url https://api.smartbills.io/v1/taxes/12345 \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
const deleted = await client.taxes.delete(12345);
```

```python Python
deleted = client.taxes.delete(12345)
```

```csharp C#
var deleted = await client.Taxes.DeleteAsync(12345);
```

</RequestExample>

<ResponseExample>

```json Response
{
  "id": 12345,
  "name": "GST",
  "deletedAt": "2024-01-20T16:00:00Z"
}
```

</ResponseExample>
