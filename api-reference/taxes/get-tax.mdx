---
title: "Get Tax"
api: "GET https://api.smartbills.io/v1/taxes/{id}"
description: "Retrieve a tax by ID"
---

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication
</ParamField>

## Required Scopes

- `taxes.read`

## Path Parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the tax
</ParamField>

<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.smartbills.io/v1/taxes/12345 \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
const tax = await client.taxes.get(12345);
```

```python Python
tax = client.taxes.get(12345)
```

```csharp C#
var tax = await client.Taxes.GetAsync(12345);
```

</RequestExample>
