---

## Overview

Create a new tax rate for your business transactions.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication
</ParamField>

## Required Scopes

- `taxes.write`

## Request Body

<ParamField body="name" type="string" required>
  Tax name (e.g., "GST", "VAT", "Sales Tax")
</ParamField>

<ParamField body="rate" type="number" required>
  Tax rate as a percentage (e.g., 5.0 for 5%)
</ParamField>

<ParamField body="type" type="string" required>
  Tax type: `sales`, `vat`, `gst`, `hst`, `pst`, `other`
</ParamField>

<ParamField body="region" type="string">
  Geographic region where tax applies
</ParamField>

<ParamField body="isCompound" type="boolean" default="false">
  Whether this tax is compounded on other taxes
</ParamField>

<ParamField body="isActive" type="boolean" default="true">
  Whether the tax is currently active
</ParamField>

<ParamField body="metadata" type="object">
  Custom metadata
</ParamField>

<RequestExample>

```bash cURL
    "name": "GST",
    "rate": 5.0,
    "type": "gst",
    "region": "Canada",
    "isCompound": false,
    "isActive": true
  }'
```

## Tax Types

| Type | Description |
|------|-------------|
| `sales` | Sales tax |
| `vat` | Value Added Tax |
| `gst` | Goods and Services Tax |
| `hst` | Harmonized Sales Tax |
| `pst` | Provincial Sales Tax |
| `other` | Other tax types |
