---

## Overview

Retrieve a list of all products in your catalog with pagination, sorting, and filtering options.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Required Scopes

- `products.read`

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number for pagination
</ParamField>

<ParamField query="pageSize" type="integer" default="100">
  Number of items per page (max: 100)
</ParamField>

<ParamField query="orderBy" type="string" default="createdAt">
  Field to sort by: `id`, `name`, `createdAt`, `updatedAt`, `publishedAt`
</ParamField>

<ParamField query="sortOrder" type="string" default="desc">
  Sort order: `asc`, `desc`
</ParamField>

<ParamField query="search" type="string">
  Search by product name or description
</ParamField>

<ParamField query="category" type="string">
  Filter by category
</ParamField>

<ParamField query="tags" type="string">
  Filter by tags (comma-separated)
</ParamField>

<ParamField query="vendorId" type="integer">
  Filter by vendor ID
</ParamField>

<ParamField query="published" type="boolean">
  Filter by published status
</ParamField>

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.smartbills.io/v1/products?page=1&pageSize=20&category=Beverages' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: 'YOUR_API_KEY' });

const response = await client.products.list({
  page: 1,
  pageSize: 20,
  category: 'Beverages',
  orderBy: 'name',
  sortOrder: 'asc'
});

console.log(`Found ${response.metadata.count} products`);
```

```python Python
from smartbills import Smartbills

client = Smartbills(api_key='YOUR_API_KEY')

response = client.products.list(
    page=1,
    page_size=20,
    category='Beverages',
    order_by='name',
    sort_order='asc'
)

print(f"Found {response.metadata.count} products")
```

```csharp C#
using Smartbills.NET;

var client = new SBClient("YOUR_API_KEY");

var response = await client.Products.ListAsync(new ProductListRequest
{
    Page = 1,
    PageSize = 20,
    Category = "Beverages",
    OrderBy = "name",
    SortOrder = "asc"
});

Console.WriteLine($"Found {response.Metadata.Count} products");
```

## Filtering Examples

### Search Products

```bash
GET /v1/products?search=coffee
```

### Filter by Category

```bash
GET /v1/products?category=Beverages
```

### Filter by Tags

```bash
GET /v1/products?tags=organic,premium
```

### Published Products Only

```bash
GET /v1/products?published=true
```
