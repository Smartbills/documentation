---
title: "Get Product"
api: "GET https://api.smartbills.io/v1/products/{id}"
description: "Retrieve a product by ID"
---

## Overview

Retrieve detailed information about a specific product including all variants and images.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Required Scopes

- `products.read`

## Path Parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the product to retrieve
</ParamField>

<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.smartbills.io/v1/products/12345 \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: 'YOUR_API_KEY' });

const product = await client.products.get(12345);
console.log('Product:', product);
```

```python Python
from smartbills import SmartBills

client = SmartBills(api_key='YOUR_API_KEY')

product = client.products.get(12345)
print('Product:', product)
```

```csharp C#
using Smartbills.NET;

var client = new SBClient("YOUR_API_KEY");

var product = await client.Products.GetAsync(12345);
Console.WriteLine($"Product: {product.Name}");
```

</RequestExample>

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions |
| 404 | NOT_FOUND | Product not found |
| 429 | RATE_LIMIT_EXCEEDED | Too many requests |
