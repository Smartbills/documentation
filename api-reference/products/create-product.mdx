## Overview

Create a new product to manage items sold through Smartbills. Products can have multiple variants, images, and be organized by categories and tags.

<Info>
  **Core Principle**: A product should be unique by name within a merchant context.
</Info>

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Required Scopes

- `products.write`

## Request Body

<ParamField body="name" type="string" required>
  Product name
</ParamField>

<ParamField body="description" type="string">
  Product description
</ParamField>

<ParamField body="slug" type="string">
  URL-friendly slug (auto-generated if not provided)
</ParamField>

<ParamField body="vendorId" type="integer">
  ID of the vendor/supplier
</ParamField>

<ParamField body="category" type="string">
  Product category
</ParamField>

<ParamField body="tags" type="array">
  Array of tag strings for categorization
</ParamField>

<ParamField body="publishedAt" type="string">
  Publication date in ISO 8601 format
</ParamField>

<ParamField body="locale" type="string">
  Locale code (e.g., "en-US", "fr-CA")
</ParamField>

<ParamField body="images" type="array">
  Array of product images
  
  <Expandable title="Image Object">
    <ParamField body="url" type="string" required>
      Image URL
    </ParamField>
    
    <ParamField body="alt" type="string">
      Alt text for accessibility
    </ParamField>
    
    <ParamField body="position" type="integer">
      Display order (0-based)
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="variants" type="array">
  Array of product variants (sizes, colors, etc.)
  
  <Expandable title="Variant Object">
    <ParamField body="title" type="string" required>
      Variant title
    </ParamField>
    
    <ParamField body="sku" type="string">
      Stock Keeping Unit
    </ParamField>
    
    <ParamField body="price" type="object" required>
      Price object with amount and currency
    </ParamField>
    
    <ParamField body="compareAtPrice" type="object">
      Original price for showing discounts
    </ParamField>
    
    <ParamField body="inventoryQuantity" type="integer">
      Available quantity
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="metadata" type="object">
  Custom metadata key-value pairs
</ParamField>

```csharp C#
using Smartbills.NET;

var client = new SBClient("YOUR_API_KEY");

var product = await client.Products.CreateAsync(new ProductCreateRequest
{
    Name = "Premium Coffee Beans",
    Description = "Organic single-origin coffee beans from Colombia",
    Slug = "premium-coffee-beans",
    Category = "Beverages",
    Tags = new[] { "coffee", "organic", "premium" },
    Locale = "en-US",
    Images = new[]
    {
        new ProductImage
        {
            Url = "https://example.com/coffee-front.jpg",
            Alt = "Premium Coffee Beans - Front View",
            Position = 0
        }
    },
    Variants = new[]
    {
        new ProductVariantCreateRequest
        {
            Title = "250g Bag",
            Sku = "COFFEE-250G",
            Price = new Money { Amount = 15.99m, Currency = "USD" },
            InventoryQuantity = 100
        },
        new ProductVariantCreateRequest
        {
            Title = "500g Bag",
            Sku = "COFFEE-500G",
            Price = new Money { Amount = 28.99m, Currency = "USD" },
            InventoryQuantity = 75
        }
    }
});

Console.WriteLine($"Created product: {product.Id}");
```

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 400 | INVALID_PARAMETER | Invalid parameter value |
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions |
| 409 | DUPLICATE_PRODUCT | Product with this name or slug already exists |
| 429 | RATE_LIMIT_EXCEEDED | Too many requests |
