---

## Overview

Create a new department for a business. Departments allow you to organize employees and track expenses by organizational unit. Each department can have a cost center and a default approver for expense reports.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token. Format: `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Business ID for multi-tenant context
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

## Request Body

<ParamField body="name" type="string" required>
  Department name. Must be unique within the business.
</ParamField>

<ParamField body="code" type="string">
  Short department code for internal reference (e.g., `ENG`, `MKT`, `SLS`)
</ParamField>

<ParamField body="costCenter" type="string">
  Cost center identifier for accounting integration
</ParamField>

<ParamField body="defaultApproverId" type="integer">
  ID of the user who should be the default approver for expense reports from this department
</ParamField>

## Response

Returns the newly created department object.

<ResponseField name="id" type="integer">
  Unique department identifier
</ResponseField>

<ResponseField name="name" type="string">
  Department name
</ResponseField>

<ResponseField name="code" type="string">
  Department code
</ResponseField>

<ResponseField name="costCenter" type="string">
  Cost center identifier
</ResponseField>

<ResponseField name="defaultApproverId" type="integer">
  ID of the default approver
</ResponseField>

<ResponseField name="enabled" type="boolean">
  Whether the department is active (defaults to `true`)
</ResponseField>

<ResponseField name="createdAt" type="string">
  Timestamp when the department was created (ISO 8601)
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Timestamp of last update (ISO 8601)
</ResponseField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.smartbills.io/v1/businesses/456/departments \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --header 'x-tenant-id: 456' \
  --data '{
    "name": "Engineering",
    "code": "ENG",
    "costCenter": "CC-100",
    "defaultApproverId": 501
  }'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const department = await client.departments.create({
  name: "Engineering",
  code: "ENG",
  costCenter: "CC-100",
  defaultApproverId: 501
});

console.log(`Created department: ${department.id}`);
```

```python Python SDK
from smartbills import Smartbills
from smartbills.types import DepartmentCreateRequest

client = Smartbills(api_key="YOUR_API_KEY")

department = await client.departments.create(
    DepartmentCreateRequest(
        name="Engineering",
        code="ENG",
        cost_center="CC-100",
        default_approver_id=501
    )
)

print(f"Created department: {department.id}")
```

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 400 | VALIDATION_ERROR | Missing required fields or invalid values |
| 400 | DUPLICATE_NAME | A department with this name already exists |
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions to manage departments |
| 404 | BUSINESS_NOT_FOUND | Business ID does not exist |
| 404 | APPROVER_NOT_FOUND | The specified default approver ID does not exist |
| 429 | RATE_LIMIT_EXCEEDED | Too many requests |
