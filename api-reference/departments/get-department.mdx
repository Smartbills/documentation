---
title: "Get Department"
description: "Retrieve a single department by ID"
api: "GET https://api.smartbills.io/v1/businesses/{businessId}/departments/{departmentId}"
---

## Overview

Retrieve the full details of a single department by its unique identifier.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token. Format: `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Business ID for multi-tenant context
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

<ParamField path="departmentId" type="integer" required>
  The unique identifier of the department
</ParamField>

## Response

<ResponseField name="id" type="integer">
  Unique department identifier
</ResponseField>

<ResponseField name="name" type="string">
  Department name
</ResponseField>

<ResponseField name="code" type="string">
  Department code for internal reference
</ResponseField>

<ResponseField name="costCenter" type="string">
  Cost center identifier for accounting
</ResponseField>

<ResponseField name="defaultApproverId" type="integer">
  ID of the default approver for this department
</ResponseField>

<ResponseField name="enabled" type="boolean">
  Whether the department is active
</ResponseField>

<ResponseField name="createdAt" type="string">
  Timestamp when the department was created (ISO 8601)
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Timestamp of last update (ISO 8601)
</ResponseField>

<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.smartbills.io/v1/businesses/456/departments/1 \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'x-tenant-id: 456'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const department = await client.departments.getById(1);

console.log(department.name);
console.log(department.costCenter);
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

department = await client.departments.get(department_id=1)

print(f"{department.name} ({department.code}) - Cost Center: {department.cost_center}")
```

</RequestExample>

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions to access this business |
| 404 | DEPARTMENT_NOT_FOUND | Department ID does not exist |
| 404 | BUSINESS_NOT_FOUND | Business ID does not exist |
| 429 | RATE_LIMIT_EXCEEDED | Too many requests |
