---
title: "Download Multiple Attachments"
api: "POST https://api.smartbills.io/v1/expenses/attachments/download"
description: "Download multiple expense receipts as a ZIP file"
---

## Request Body

<ParamField body="expenseIds" type="array" required>
  Array of expense IDs to download
</ParamField>

<ParamField body="fileNameTemplate" type="string">
  Custom filename template for individual files
  
  Available placeholders:
  - `{MERCHANT}` - Merchant name
  - `{YYYY}` - Year (4 digits)
  - `{MM}` - Month (2 digits)
  - `{DD}` - Day (2 digits)
  - `{AMOUNT}` - Expense amount
  - `{ID}` - Expense ID
</ParamField>

<ParamField body="zipFileName" type="string">
  Custom name for the ZIP file (default: "expenses.zip")
</ParamField>

## Response

Returns a ZIP file containing all requested expense attachments.

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.smartbills.io/v1/expenses/attachments/download \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "expenseIds": [12345, 12346, 12347],
    "fileNameTemplate": "{MERCHANT}_{YYYY}_{MM}_{DD}",
    "zipFileName": "january_expenses.zip"
  }' \
  --output expenses.zip
```

```javascript JavaScript
const response = await fetch(
  'https://api.smartbills.io/v1/expenses/attachments/download',
  {
    method: 'POST',
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      expenseIds: [12345, 12346, 12347],
      fileNameTemplate: '{MERCHANT}_{YYYY}_{MM}_{DD}',
      zipFileName: 'january_expenses.zip'
    })
  }
);

const blob = await response.blob();
const url = window.URL.createObjectURL(blob);
const a = document.createElement('a');
a.href = url;
a.download = 'january_expenses.zip';
a.click();
```

```python Python
import requests

url = 'https://api.smartbills.io/v1/expenses/attachments/download'
headers = {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
}
data = {
    'expenseIds': [12345, 12346, 12347],
    'fileNameTemplate': '{MERCHANT}_{YYYY}_{MM}_{DD}',
    'zipFileName': 'january_expenses.zip'
}

response = requests.post(url, headers=headers, json=data)
with open('january_expenses.zip', 'wb') as f:
    f.write(response.content)
```
