## Request Body

<ParamField body="file" type="file" required>
  The receipt or invoice file (PDF, JPG, PNG, HEIC)
  
  Maximum file size: 10MB
</ParamField>

<ParamField body="mergeFiles" type="boolean" default="false">
  If true, merge multiple files into a single expense
</ParamField>

## Content Type

This endpoint accepts `multipart/form-data` for file uploads.

</ResponseField>

<ResponseField name="amount" type="number">

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.smartbills.io/v1/expenses/upload \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: multipart/form-data' \
  --form 'file=@/path/to/receipt.pdf'
```

```javascript JavaScript
const formData = new FormData();
formData.append('file', fileInput.files[0]);

const response = await fetch(
  'https://api.smartbills.io/v1/expenses/upload',
  {
    method: 'POST',
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY'
    },
```

```python Python
import requests

url = 'https://api.smartbills.io/v1/expenses/upload'
headers = {
    'Authorization': 'Bearer YOUR_API_KEY'
}
files = {
    'file': open('/path/to/receipt.pdf', 'rb')
}

response = requests.post(url, headers=headers, files=files)
expense = response.json()
print(expense)
```

```php PHP
<?php
$ch = curl_init();

$file = new CURLFile('/path/to/receipt.pdf');
$data = array('file' => $file);

curl_setopt($ch, CURLOPT_URL, 'https://api.smartbills.io/v1/expenses/upload');
curl_setopt($ch, CURLOPT_POST, 1);
curl_setopt($ch, CURLOPT_POSTFIELDS, $data);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, 1);
curl_setopt($ch, CURLOPT_HTTPHEADER, array(
    'Authorization: Bearer YOUR_API_KEY'
));

$result = curl_exec($ch);
curl_close($ch);

$expense = json_decode($result, true);
print_r($expense);
?>
```

## Supported File Types

- **PDF** - Portable Document Format
- **JPG/JPEG** - Joint Photographic Experts Group
- **PNG** - Portable Network Graphics
- **HEIC** - High Efficiency Image Container
- **TIFF** - Tagged Image File Format

## OCR Processing

SmartBills automatically extracts the following information from receipts:

- **Amount** - Total transaction amount
- **Merchant** - Business name
- **Date** - Transaction date
- **Tax** - Tax amount (if available)
- **Line Items** - Individual items purchased
- **Payment Method** - Card type or payment method
- **Currency** - Transaction currency

## Tips for Best Results

1. **Image Quality** - Use high-resolution images (minimum 300 DPI)
2. **Lighting** - Ensure good lighting without glare
3. **Alignment** - Keep the receipt straight and centered
4. **Complete** - Capture the entire receipt including header and footer
5. **Format** - PDF files typically provide best OCR results

## Validation

After upload, review and correct any extracted information if needed using the [Update Expense](/api-reference/expenses/update-expense) endpoint.

<Tip>
  The `confidence` score indicates how accurate the OCR extraction is. Scores below 0.7 may require manual review.
</Tip>
