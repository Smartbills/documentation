---
title: "Download Expense Attachment"
api: "GET https://api.smartbills.io/v1/expenses/{expenseId}/attachments/download"
description: "Download a single expense receipt or invoice"
---

## Path Parameters

<ParamField path="expenseId" type="integer" required>
  The unique identifier of the expense
</ParamField>

## Query Parameters

<ParamField query="fileNameTemplate" type="string">
  Custom filename template for the download
  
  Available placeholders:
  - `{MERCHANT}` - Merchant name
  - `{YYYY}` - Year (4 digits)
  - `{MM}` - Month (2 digits)
  - `{DD}` - Day (2 digits)
  - `{AMOUNT}` - Expense amount
  - `{ID}` - Expense ID
  
  Default: `{MERCHANT}_{YYYY}_{MM}_{DD}`
</ParamField>

## Response

Returns the file as a binary stream with appropriate content-type header.

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.smartbills.io/v1/expenses/12345/attachments/download?fileNameTemplate={MERCHANT}_{YYYY}_{MM}_{DD}' \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --output receipt.pdf
```

```javascript JavaScript
const response = await fetch(
  'https://api.smartbills.io/v1/expenses/12345/attachments/download?fileNameTemplate={MERCHANT}_{YYYY}_{MM}_{DD}',
  {
    method: 'GET',
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY'
    }
  }
);

const blob = await response.blob();
const url = window.URL.createObjectURL(blob);
const a = document.createElement('a');
a.href = url;
a.download = 'receipt.pdf';
a.click();
```

```python Python
import requests

url = 'https://api.smartbills.io/v1/expenses/12345/attachments/download'
headers = {
    'Authorization': 'Bearer YOUR_API_KEY'
}
params = {
    'fileNameTemplate': '{MERCHANT}_{YYYY}_{MM}_{DD}'
}

response = requests.get(url, headers=headers, params=params)
with open('receipt.pdf', 'wb') as f:
    f.write(response.content)
```
