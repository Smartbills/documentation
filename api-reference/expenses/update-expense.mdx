---
title: "Update Expense"
api: "PUT https://api.smartbills.io/v1/expenses/{expenseId}"
description: "Update an existing expense"
---

## Path Parameters

<ParamField path="expenseId" type="integer" required>
  The unique identifier of the expense to update
</ParamField>

## Request Body

<ParamField body="amount" type="number">
  Expense amount
</ParamField>

<ParamField body="currency" type="string">
  ISO 4217 currency code (e.g., USD, CAD, EUR)
</ParamField>

<ParamField body="date" type="string">
  Transaction date in ISO 8601 format
</ParamField>

<ParamField body="merchant" type="string">
  Merchant or vendor name
</ParamField>

<ParamField body="category" type="string">
  Expense category
</ParamField>

<ParamField body="description" type="string">
  Expense description or notes
</ParamField>

<ParamField body="tags" type="array">
  Array of tags to associate with the expense
</ParamField>

<ParamField body="metadata" type="object">
  Custom metadata object
</ParamField>

## Response

Returns the updated expense object.

<RequestExample>

```bash cURL
curl --request PUT \
  --url https://api.smartbills.io/v1/expenses/12345 \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "amount": 54.99,
    "merchant": "Office Depot Store #123",
    "description": "Updated description with more details",
    "tags": ["office", "supplies", "urgent"]
  }'
```

```javascript JavaScript
const response = await fetch(
  'https://api.smartbills.io/v1/expenses/12345',
  {
    method: 'PUT',
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      amount: 54.99,
      merchant: 'Office Depot Store #123',
      description: 'Updated description with more details',
      tags: ['office', 'supplies', 'urgent']
    })
  }
);

const expense = await response.json();
console.log(expense);
```

```python Python
import requests

url = 'https://api.smartbills.io/v1/expenses/12345'
headers = {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
}
data = {
    'amount': 54.99,
    'merchant': 'Office Depot Store #123',
    'description': 'Updated description with more details',
    'tags': ['office', 'supplies', 'urgent']
}

response = requests.put(url, headers=headers, json=data)
expense = response.json()
print(expense)
```
