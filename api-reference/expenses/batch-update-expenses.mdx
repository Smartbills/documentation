---
title: "Batch Update Expenses"
api: "PUT https://api.smartbills.io/v1/expenses"
description: "Update multiple expenses in a single request"
---

## Request Body

<ParamField body="updates" type="array" required>
  Array of expense updates

  <Expandable title="Update Object">
    <ParamField body="id" type="integer" required>
      Expense ID to update
    </ParamField>

    <ParamField body="amount" type="number">
      Updated amount
    </ParamField>

    <ParamField body="merchant" type="string">
      Updated merchant name
    </ParamField>

    <ParamField body="category" type="string">
      Updated category
    </ParamField>

    <ParamField body="description" type="string">
      Updated description
    </ParamField>

    <ParamField body="tags" type="array">
      Updated tags
    </ParamField>

    <ParamField body="metadata" type="object">
      Updated metadata
    </ParamField>
  </Expandable>
</ParamField>

## Response

Returns an array of updated expense objects.

<RequestExample>

```bash cURL
curl --request PUT \
  --url https://api.smartbills.io/v1/expenses \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '[
    {
      "id": 12345,
      "category": "Office Supplies",
      "tags": ["office", "supplies"]
    },
    {
      "id": 12346,
      "category": "Software",
      "tags": ["software", "recurring"]
    }
  ]'
```

```javascript JavaScript
const response = await fetch(
  'https://api.smartbills.io/v1/expenses',
  {
    method: 'PUT',
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify([
      {
        id: 12345,
        category: 'Office Supplies',
        tags: ['office', 'supplies']
      },
      {
        id: 12346,
        category: 'Software',
        tags: ['software', 'recurring']
      }
    ])
  }
);

const expenses = await response.json();
console.log(expenses);
```

```python Python
import requests

url = 'https://api.smartbills.io/v1/expenses'
headers = {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
}
data = [
    {
        'id': 12345,
        'category': 'Office Supplies',
        'tags': ['office', 'supplies']
    },
    {
        'id': 12346,
        'category': 'Software',
        'tags': ['software', 'recurring']
    }
]

response = requests.put(url, headers=headers, json=data)
expenses = response.json()
print(expenses)
```
