---

## Overview

This endpoint returns a list of expenses for the authenticated user. You can filter, sort, and paginate the results to find exactly what you need.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number for pagination (starts at 1)
</ParamField>

<ParamField query="pageSize" type="integer" default="20">
  Number of items per page (max: 100)
</ParamField>

<ParamField query="businessId" type="integer">
  Filter expenses by business ID
</ParamField>

<ParamField query="status" type="string">
  Filter by expense status. Options: `pending`, `approved`, `rejected`, `submitted`
</ParamField>

<ParamField query="categoryId" type="integer">
  Filter by expense category ID
</ParamField>

<ParamField query="minAmount" type="number">
  Minimum expense amount (inclusive)
</ParamField>

<ParamField query="maxAmount" type="number">
  Maximum expense amount (inclusive)
</ParamField>

<ParamField query="startDate" type="string">
  Filter expenses from this date (ISO 8601 format: YYYY-MM-DD)
</ParamField>

<ParamField query="endDate" type="string">
  Filter expenses until this date (ISO 8601 format: YYYY-MM-DD)
</ParamField>

<ParamField query="merchant" type="string">
  Filter by merchant name (partial match)
</ParamField>

<ParamField query="tags" type="string">
  Filter by tags (comma-separated for multiple tags)
</ParamField>

<ParamField query="paymentMethod" type="string">
  Filter by payment method: `cash`, `credit_card`, `debit_card`, `bank_transfer`
</ParamField>

<ParamField query="hasReceipt" type="boolean">
  Filter expenses with or without receipts. `true` or `false`
</ParamField>

<ParamField query="reportId" type="integer">
  Filter expenses belonging to a specific report
</ParamField>

<ParamField query="sortBy" type="string" default="date">
  Field to sort by. Options: `date`, `amount`, `merchant`, `createdAt`, `updatedAt`
</ParamField>

<ParamField query="sortOrder" type="string" default="desc">
  Sort order. Options: `asc`, `desc`
</ParamField>

<ParamField query="search" type="string">
  Search across merchant name, notes, and other text fields
</ParamField>

## Filtering Examples

### Filter by Date Range

Get expenses from a specific month:

```bash
GET /v1/expenses?startDate=2024-01-01&endDate=2024-01-31
```

### Filter by Amount Range

Get expenses between $50 and $500:

```bash
GET /v1/expenses?minAmount=50&maxAmount=500
```

### Multiple Filters

Combine filters to narrow results:

```bash
GET /v1/expenses?businessId=100&status=pending&hasReceipt=true&startDate=2024-01-01
```

### Search

Search across multiple text fields:

```bash
GET /v1/expenses?search=coffee
```

## Best Practices

<AccordionGroup>
  <Accordion title="Use Pagination" icon="page">
    Always use pagination for better performance. Don't request more than you need.
    
    ```javascript
    // Good: Paginate results
    const params = { page: 1, pageSize: 20 };
    
    // Avoid: Requesting too many items at once
    const params = { pageSize: 1000 };
    ```
  </Accordion>

  <Accordion title="Filter Server-Side" icon="filter">
    Use query parameters to filter on the server rather than fetching all data and filtering client-side.
    
    ```javascript
    // Good: Filter on server
    GET /v1/expenses?status=pending&startDate=2024-01-01
    
    // Avoid: Fetch all and filter locally
    GET /v1/expenses (then filter in your code)
    ```
  </Accordion>

  <Accordion title="Cache When Possible" icon="database">
    Cache results when appropriate to reduce API calls. Use `updatedAt` timestamps to detect changes.
  </Accordion>

  <Accordion title="Handle Pagination" icon="arrows-rotate">
    Implement proper pagination handling to fetch all results when needed.
    
    ```javascript
    async function getAllExpenses() {
      let allExpenses = [];
      let page = 1;
      let hasNext = true;
      
      while (hasNext) {
        const response = await fetch(
          `https://api.smartbills.io/v1/expenses?page=${page}`,
          { headers: { Authorization: 'Bearer YOUR_API_KEY' } }
        );
        const data = await response.json();
        
        allExpenses = allExpenses.concat(data.data);
        hasNext = data.pagination.hasNext;
        page++;
      }
      
      return allExpenses;
    }
    ```
  </Accordion>
</AccordionGroup>
