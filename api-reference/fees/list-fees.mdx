---
title: "List Fees"
api: "GET https://api.smartbills.io/v1/fees"
description: "Retrieve a paginated list of fees"
---

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication
</ParamField>

## Required Scopes

- `fees.read`

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number
</ParamField>

<ParamField query="pageSize" type="integer" default="100">
  Items per page (max: 100)
</ParamField>

<ParamField query="category" type="string">
  Filter by category
</ParamField>

<ParamField query="type" type="string">
  Filter by type
</ParamField>

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.smartbills.io/v1/fees?page=1&pageSize=20' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
const response = await client.fees.list({
  page: 1,
  pageSize: 20
});
```

```python Python
response = client.fees.list(page=1, page_size=20)
```

```csharp C#
var response = await client.Fees.ListAsync(new FeeListRequest
{
    Page = 1,
    PageSize = 20
});
```

</RequestExample>
