---
title: "Delete Fee"
api: "DELETE https://api.smartbills.io/v1/fees/{id}"
description: "Delete a fee from your account"
---

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication
</ParamField>

## Required Scopes

- `fees.write`

## Path Parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the fee to delete
</ParamField>

<Warning>
  **Destructive Action**: Deleting a fee is permanent and cannot be undone.
</Warning>

<RequestExample>

```bash cURL
curl --request DELETE \
  --url https://api.smartbills.io/v1/fees/12345 \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
const deletedFee = await client.fees.delete(12345);
```

```python Python
deleted_fee = client.fees.delete(12345)
```

```csharp C#
var deletedFee = await client.Fees.DeleteAsync(12345);
```

</RequestExample>

<ResponseExample>

```json Response
{
  "id": 12345,
  "name": "Service Fee",
  "deletedAt": "2024-01-20T16:00:00Z"
}
```

</ResponseExample>
