---
title: "Update Fee"
api: "PUT https://api.smartbills.io/v1/fees/{id}"
description: "Update an existing fee"
---

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication
</ParamField>

## Required Scopes

- `fees.write`

## Path Parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the fee to update
</ParamField>

<RequestExample>

```bash cURL
curl --request PUT \
  --url https://api.smartbills.io/v1/fees/12345 \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "name": "Updated Service Fee",
    "amount": {
      "value": 3.00,
      "currency": "USD"
    }
  }'
```

```javascript JavaScript
const updatedFee = await client.fees.update(12345, {
  name: "Updated Service Fee",
  amount: {
    value: 3.00,
    currency: "USD"
  }
});
```

```python Python
updated_fee = client.fees.update(
    12345,
    name="Updated Service Fee",
    amount={"value": 3.00, "currency": "USD"}
)
```

```csharp C#
var updatedFee = await client.Fees.UpdateAsync(12345, new FeeUpdateRequest
{
    Name = "Updated Service Fee",
    Amount = new Money { Value = 3.00m, Currency = "USD" }
});
```

</RequestExample>

<ResponseExample>

```json Response
{
  "id": 12345,
  "name": "Updated Service Fee",
  "amount": {
    "value": 3.00,
    "currency": "USD"
  },
  "updatedAt": "2024-01-20T16:45:00Z"
}
```

</ResponseExample>
