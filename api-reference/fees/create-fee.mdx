## Overview

Create a new fee to represent service charges, commissions, or other fees associated with transactions or products.

<Info>
  **Core Principle**: A fee must be unique by name.
</Info>

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Required Scopes

- `fees.write`

## Request Body

<ParamField body="name" type="string" required>
  Name of the fee
</ParamField>

<ParamField body="description" type="string">
  Description of the fee
</ParamField>

<ParamField body="amount" type="object" required>
  Fee amount
  
  <Expandable title="Amount Object">
    <ParamField body="value" type="number" required>
      Monetary value
    </ParamField>
    
    <ParamField body="currency" type="string" required>
      Three-letter ISO currency code
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="type" type="string">
  Fee type: `fixed`, `percentage`, `variable`
</ParamField>

<ParamField body="category" type="string">
  Fee category: `service`, `delivery`, `processing`, `convenience`, `other`
</ParamField>

<ParamField body="percentage" type="number">
  Percentage value (if type is `percentage`)
</ParamField>

<ParamField body="locale" type="string">
  Locale code (e.g., "en-US", "fr-CA")
</ParamField>

<ParamField body="translations" type="array">
  Array of translations for different locales
</ParamField>

<ParamField body="metadata" type="object">
  Custom metadata key-value pairs
</ParamField>

```javascript JavaScript

  locale: "en-US"
```

```python Python
from smartbills import SmartBills

client = SmartBills(api_key='YOUR_API_KEY')

fee = client.fees.create(
    name="Service Fee",
    description="Standard service fee for all transactions",
    amount={
        "value": 2.50,
        "currency": "USD"
    },
    type="fixed",
    category="service",
    locale="en-US"
)

print('Created fee:', fee)
```

```csharp C#
using Smartbills.NET;

var client = new SBClient("YOUR_API_KEY");

var fee = await client.Fees.CreateAsync(new FeeCreateRequest
{
    Name = "Service Fee",
    Description = "Standard service fee for all transactions",
    Amount = new Money { Value = 2.50m, Currency = "USD" },
    Type = "fixed",
    Category = "service",
    Locale = "en-US"
});

Console.WriteLine($"Created fee: {fee.Id}");
```

## Fee Types

| Type | Description | Example |
|------|-------------|---------|
| `fixed` | Fixed amount fee | $2.50 service fee |
| `percentage` | Percentage-based fee | 3% processing fee |
| `variable` | Variable fee based on conditions | Dynamic delivery fee |

## Fee Categories

| Category | Description |
|----------|-------------|
| `service` | General service fees |
| `delivery` | Delivery and shipping fees |
| `processing` | Payment processing fees |
| `convenience` | Convenience fees |
| `other` | Other miscellaneous fees |

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 400 | INVALID_PARAMETER | Invalid parameter value |
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions |
| 409 | DUPLICATE_FEE | Fee with this name already exists |
| 429 | RATE_LIMIT_EXCEEDED | Too many requests |
