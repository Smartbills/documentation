---
title: "Get Fee"
api: "GET https://api.smartbills.io/v1/fees/{id}"
description: "Retrieve a fee by ID"
---

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication
</ParamField>

## Required Scopes

- `fees.read`

## Path Parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the fee
</ParamField>

<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.smartbills.io/v1/fees/12345 \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
const fee = await client.fees.get(12345);
```

```python Python
fee = client.fees.get(12345)
```

```csharp C#
var fee = await client.Fees.GetAsync(12345);
```

</RequestExample>
