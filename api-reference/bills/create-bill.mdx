---
title: "Create Bill"

---

## Overview

Create a new bill to track a vendor invoice. You can include line items and attach the original invoice document.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Request Body

<ParamField body="businessId" type="integer" required>
  ID of the business this bill belongs to
</ParamField>

<ParamField body="vendorId" type="integer" required>
  ID of the vendor issuing the bill
</ParamField>

<ParamField body="billNumber" type="string">
  Vendor's invoice or bill reference number
</ParamField>

<ParamField body="amount" type="number" required>
  Total bill amount
</ParamField>

<ParamField body="currency" type="string" required>
  ISO 4217 currency code (e.g., USD, CAD, EUR)
</ParamField>

<ParamField body="dueDate" type="string" required>
  Payment due date (ISO 8601 format: YYYY-MM-DD)
</ParamField>

<ParamField body="issueDate" type="string">
  Date the bill was issued (YYYY-MM-DD). Defaults to today.
</ParamField>

<ParamField body="notes" type="string">
  Notes or description for the bill
</ParamField>

<ParamField body="lineItems" type="array">
  Array of line items on the bill
  <Expandable title="Line Item Object">
    <ParamField body="description" type="string" required>
      Item description
    </ParamField>
    <ParamField body="quantity" type="number" required>
      Quantity
    </ParamField>
    <ParamField body="unitPrice" type="number" required>
      Price per unit
    </ParamField>
    <ParamField body="categoryId" type="integer">
      Category ID for this line item
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="taxAmount" type="number">
  Total tax amount
</ParamField>

<ParamField body="metadata" type="object">
  Custom metadata key-value pairs
</ParamField>

## Validation Rules

- `vendorId` must reference an existing vendor in the business
- `amount` must be a positive number
- `dueDate` must be a valid date
- Line item `quantity` and `unitPrice` must be positive numbers

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 400 | VALIDATION_FAILED | Invalid request data |
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions |
| 404 | VENDOR_NOT_FOUND | Vendor does not exist |
| 404 | BUSINESS_NOT_FOUND | Business does not exist |
