---
title: "Get Bill"
description: "Retrieve a specific bill by ID"
api: "GET https://api.smartbills.io/v1/bills/{billId}"
---

## Overview

Retrieve the full details of a specific bill, including line items, attachments, and vendor information.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Path Parameters

<ParamField path="billId" type="integer" required>
  The unique identifier of the bill
</ParamField>

## Response

<ResponseField name="id" type="integer">
  Unique bill identifier
</ResponseField>

<ResponseField name="businessId" type="integer">
  ID of the business
</ResponseField>

<ResponseField name="vendorId" type="integer">
  ID of the vendor
</ResponseField>

<ResponseField name="vendor" type="object">
  Vendor details
  <Expandable title="Vendor Object">
    <ResponseField name="id" type="integer">
      Vendor ID
    </ResponseField>
    <ResponseField name="name" type="string">
      Vendor name
    </ResponseField>
    <ResponseField name="email" type="string">
      Vendor contact email
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="billNumber" type="string">
  Vendor's invoice or bill number
</ResponseField>

<ResponseField name="amount" type="number">
  Total bill amount
</ResponseField>

<ResponseField name="currency" type="string">
  ISO 4217 currency code
</ResponseField>

<ResponseField name="dueDate" type="string">
  Payment due date (YYYY-MM-DD)
</ResponseField>

<ResponseField name="issueDate" type="string">
  Date the bill was issued (YYYY-MM-DD)
</ResponseField>

<ResponseField name="status" type="string">
  Bill status: `draft`, `pending`, `paid`, `overdue`, `cancelled`
</ResponseField>

<ResponseField name="notes" type="string">
  Bill notes or description
</ResponseField>

<ResponseField name="lineItems" type="array">
  Individual line items on the bill
  <Expandable title="Line Item Object">
    <ResponseField name="id" type="integer">
      Line item ID
    </ResponseField>
    <ResponseField name="description" type="string">
      Item description
    </ResponseField>
    <ResponseField name="quantity" type="number">
      Quantity
    </ResponseField>
    <ResponseField name="unitPrice" type="number">
      Price per unit
    </ResponseField>
    <ResponseField name="amount" type="number">
      Total for this line item
    </ResponseField>
    <ResponseField name="categoryId" type="integer">
      Category ID
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="attachments" type="array">
  Attached files (invoices, receipts)
  <Expandable title="Attachment Object">
    <ResponseField name="id" type="integer">
      Attachment ID
    </ResponseField>
    <ResponseField name="filename" type="string">
      Original filename
    </ResponseField>
    <ResponseField name="url" type="string">
      Download URL
    </ResponseField>
    <ResponseField name="contentType" type="string">
      MIME type
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="taxAmount" type="number">
  Total tax amount
</ResponseField>

<ResponseField name="subtotal" type="number">
  Subtotal before tax
</ResponseField>

<ResponseField name="paidAt" type="string">
  Timestamp when bill was paid (ISO 8601, null if unpaid)
</ResponseField>

<ResponseField name="createdAt" type="string">
  Timestamp when bill was created (ISO 8601)
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Timestamp of last update (ISO 8601)
</ResponseField>

<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.smartbills.io/v1/bills/3001 \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
const bill = await client.bills.getById(3001);
```

```python Python
bill = client.bills.get_by_id(bill_id=3001)
```

```csharp C#
var bill = await client.Bills.GetByIdAsync(3001);
```

</RequestExample>

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions |
| 404 | BILL_NOT_FOUND | Bill does not exist |
