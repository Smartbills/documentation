---
title: "Create Category"
description: "Create a new expense category"
api: "POST https://api.smartbills.io/v1/businesses/{businessId}/categories"
---

## Overview

Create a new expense category for a business. Categories are used to classify expenses and can be mapped to general ledger account codes for accounting integration.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token. Format: `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Business ID for multi-tenant context
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

## Request Body

<ParamField body="name" type="string" required>
  Category name. Must be unique within the business.
</ParamField>

<ParamField body="description" type="string">
  A description of what expenses belong in this category
</ParamField>

<ParamField body="glAccountCode" type="string">
  General ledger account code for accounting integration (e.g., `6200`)
</ParamField>

<ParamField body="color" type="string">
  Hex color code for display in the UI (e.g., `#4A90D9`)
</ParamField>

<ParamField body="enabled" type="boolean" default="true">
  Whether the category is active and available for use. Defaults to `true`.
</ParamField>

<ParamField body="displayOrder" type="integer">
  Sort position for display in dropdowns and lists. Lower numbers appear first.
</ParamField>

## Response

Returns the newly created category object.

<ResponseField name="id" type="integer">
  Unique category identifier
</ResponseField>

<ResponseField name="name" type="string">
  Category name
</ResponseField>

<ResponseField name="description" type="string">
  Category description
</ResponseField>

<ResponseField name="glAccountCode" type="string">
  General ledger account code
</ResponseField>

<ResponseField name="color" type="string">
  Hex color code
</ResponseField>

<ResponseField name="enabled" type="boolean">
  Whether the category is active
</ResponseField>

<ResponseField name="displayOrder" type="integer">
  Sort order for display
</ResponseField>

<ResponseField name="createdAt" type="string">
  Timestamp when the category was created (ISO 8601)
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Timestamp of last update (ISO 8601)
</ResponseField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.smartbills.io/v1/businesses/456/categories \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --header 'x-tenant-id: 456' \
  --data '{
    "name": "Travel",
    "description": "Business travel expenses including flights, hotels, and ground transportation",
    "glAccountCode": "6200",
    "color": "#4A90D9",
    "enabled": true,
    "displayOrder": 1
  }'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const category = await client.categories.create({
  name: "Travel",
  description: "Business travel expenses including flights, hotels, and ground transportation",
  glAccountCode: "6200",
  color: "#4A90D9",
  displayOrder: 1
});

console.log(`Created category: ${category.id}`);
```

```python Python SDK
from smartbills import Smartbills
from smartbills.types import CategoryCreateRequest

client = Smartbills(api_key="YOUR_API_KEY")

category = await client.categories.create(
    CategoryCreateRequest(
        name="Travel",
        description="Business travel expenses including flights, hotels, and ground transportation",
        gl_account_code="6200",
        color="#4A90D9",
        display_order=1
    )
)

print(f"Created category: {category.id}")
```

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 400 | VALIDATION_ERROR | Missing required fields or invalid values |
| 400 | DUPLICATE_NAME | A category with this name already exists |
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions to manage categories |
| 404 | BUSINESS_NOT_FOUND | Business ID does not exist |
| 429 | RATE_LIMIT_EXCEEDED | Too many requests |
