---
title: "Update Category"
description: "Update an existing expense category"
api: "PUT https://api.smartbills.io/v1/businesses/{businessId}/categories/{categoryId}"
---

## Overview

Update an existing expense category. All fields are optional -- only the fields you include in the request body will be modified.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token. Format: `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Business ID for multi-tenant context
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

<ParamField path="categoryId" type="integer" required>
  The unique identifier of the category to update
</ParamField>

## Request Body

All fields are optional. Only include the fields you want to change.

<ParamField body="name" type="string">
  Category name. Must be unique within the business.
</ParamField>

<ParamField body="description" type="string">
  A description of what expenses belong in this category
</ParamField>

<ParamField body="glAccountCode" type="string">
  General ledger account code for accounting integration
</ParamField>

<ParamField body="color" type="string">
  Hex color code for display in the UI (e.g., `#4A90D9`)
</ParamField>

<ParamField body="enabled" type="boolean">
  Whether the category is active and available for use. Setting to `false` hides the category from selection but does not affect existing expenses.
</ParamField>

<ParamField body="displayOrder" type="integer">
  Sort position for display in dropdowns and lists
</ParamField>

## Response

Returns the updated category object.

<ResponseField name="id" type="integer">
  Unique category identifier
</ResponseField>

<ResponseField name="name" type="string">
  Category name
</ResponseField>

<ResponseField name="description" type="string">
  Category description
</ResponseField>

<ResponseField name="glAccountCode" type="string">
  General ledger account code
</ResponseField>

<ResponseField name="color" type="string">
  Hex color code
</ResponseField>

<ResponseField name="enabled" type="boolean">
  Whether the category is active
</ResponseField>

<ResponseField name="displayOrder" type="integer">
  Sort order for display
</ResponseField>

<ResponseField name="createdAt" type="string">
  Timestamp when the category was created (ISO 8601)
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Timestamp of last update (ISO 8601)
</ResponseField>

<RequestExample>

```bash cURL

  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --header 'x-tenant-id: 456' \
  --data '{

    "color": "#2E86C1"
  }'
```

## Disabling a Category

To disable a category without deleting it, set `enabled` to `false`. Disabled categories are hidden from category selection dropdowns but existing expenses assigned to the category remain unchanged.

```bash
curl --request PUT \
  --url https://api.smartbills.io/v1/businesses/456/categories/1 \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --header 'x-tenant-id: 456' \
  --data '{ "enabled": false }'
```

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 400 | VALIDATION_ERROR | Invalid field values |
| 400 | DUPLICATE_NAME | A category with this name already exists |
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions to manage categories |
| 404 | CATEGORY_NOT_FOUND | Category ID does not exist |
| 404 | BUSINESS_NOT_FOUND | Business ID does not exist |
| 429 | RATE_LIMIT_EXCEEDED | Too many requests |
