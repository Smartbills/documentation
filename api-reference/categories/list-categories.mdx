---
title: "List Categories"
description: "Retrieve a paginated list of expense categories"
api: "GET https://api.smartbills.io/v1/businesses/{businessId}/categories"
---

## Overview

Retrieve a list of expense categories configured for a business. Categories help organize expenses into logical groups such as Travel, Meals, or Office Supplies. You can search by name and filter by enabled status.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token. Format: `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Business ID for multi-tenant context
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number for pagination (starts at 1)
</ParamField>

<ParamField query="pageSize" type="integer" default="20">
  Number of items per page (max: 100)
</ParamField>

<ParamField query="search" type="string">
  Search categories by name (partial match)
</ParamField>

<ParamField query="enabled" type="boolean">
  Filter by enabled status. `true` returns only active categories, `false` returns only disabled categories. Omit to return all.
</ParamField>

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.smartbills.io/v1/businesses/456/categories?page=1&pageSize=20&enabled=true' \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'x-tenant-id: 456'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const categories = await client.categories.list({
  search: "Travel",
  enabled: true,
  page: 1,
  pageSize: 20
});

console.log(`Found ${categories.pagination.totalCount} categories`);
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

categories = await client.categories.list()

for category in categories.data:
    print(f"{category.name} - {category.gl_account_code}")
```
