---
title: "Get Category"
description: "Retrieve a single expense category by ID"
api: "GET https://api.smartbills.io/v1/businesses/{businessId}/categories/{categoryId}"
---

## Overview

Retrieve the full details of a single expense category by its unique identifier.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token. Format: `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Business ID for multi-tenant context
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

<ParamField path="categoryId" type="integer" required>
  The unique identifier of the category
</ParamField>

## Response

<ResponseField name="id" type="integer">
  Unique category identifier
</ResponseField>

<ResponseField name="name" type="string">
  Category name
</ResponseField>

<ResponseField name="description" type="string">
  Category description
</ResponseField>

<ResponseField name="glAccountCode" type="string">
  General ledger account code for accounting integration
</ResponseField>

<ResponseField name="color" type="string">
  Hex color code used for display (e.g., `#4A90D9`)
</ResponseField>

<ResponseField name="enabled" type="boolean">
  Whether the category is active and available for use
</ResponseField>

<ResponseField name="displayOrder" type="integer">
  Sort order for display in dropdowns and lists
</ResponseField>

<ResponseField name="createdAt" type="string">
  Timestamp when the category was created (ISO 8601)
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Timestamp of last update (ISO 8601)
</ResponseField>

<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.smartbills.io/v1/businesses/456/categories/1 \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'x-tenant-id: 456'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const category = await client.categories.getById(1);

console.log(category.name);
console.log(category.glAccountCode);
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

category = await client.categories.get(category_id=1)

print(f"{category.name} - GL: {category.gl_account_code}")
```

</RequestExample>

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions to access this business |
| 404 | CATEGORY_NOT_FOUND | Category ID does not exist |
| 404 | BUSINESS_NOT_FOUND | Business ID does not exist |
| 429 | RATE_LIMIT_EXCEEDED | Too many requests |
