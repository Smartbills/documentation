---
title: "Reimburse Report"
description: "Fully reimburse an approved expense report"
api: "POST https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/{reportId}/payments/reimburse"
---

## Overview

Reimburse an approved expense report in full. This marks all expenses in the report as reimbursed and records the payment details. The report must be in `approved` status before it can be reimbursed.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

<ParamField path="reportId" type="integer" required>
  The unique identifier of the expense report to reimburse
</ParamField>

## Request Body

<ParamField body="reimbursedAmount" type="number">
  Total amount to reimburse. Defaults to the report's approved total if not specified.
</ParamField>

<ParamField body="reimbursementMethod" type="string">
  Payment method used for reimbursement. Options: `bank_transfer`, `check`, `cash`, `payroll`, `other`
</ParamField>

<ParamField body="reimbursementReference" type="string">
  External reference number for the reimbursement (e.g., check number, wire transfer ID)
</ParamField>

<ParamField body="reimbursementNotes" type="string">
  Notes about the reimbursement
</ParamField>

<ParamField body="reimbursedDate" type="string">
  Date the reimbursement was made (ISO 8601 format: YYYY-MM-DD). Defaults to today.
</ParamField>

## Response

<ResponseField name="id" type="integer">
  Reimbursement record ID
</ResponseField>

<ResponseField name="reportId" type="integer">
  ID of the reimbursed expense report
</ResponseField>

<ResponseField name="status" type="string">
  Report status after reimbursement: `reimbursed`
</ResponseField>

<ResponseField name="reimbursedAmount" type="number">
  Total amount reimbursed
</ResponseField>

<ResponseField name="reimbursementMethod" type="string">
  Payment method used
</ResponseField>

<ResponseField name="reimbursementReference" type="string">
  External payment reference
</ResponseField>

<ResponseField name="reimbursementNotes" type="string">
  Reimbursement notes
</ResponseField>

<ResponseField name="reimbursedDate" type="string">
  Date of reimbursement
</ResponseField>

<ResponseField name="reimbursedAt" type="string">
  Timestamp when the reimbursement was recorded (ISO 8601)
</ResponseField>

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 400 | REPORT_NOT_APPROVED | Report must be approved before reimbursement |
| 400 | ALREADY_REIMBURSED | Report has already been reimbursed |
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions |
| 404 | REPORT_NOT_FOUND | Report does not exist |
