---
title: "Partial Reimbursement"
description: "Partially reimburse specific expenses within an expense report"
api: "POST https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/{reportId}/payments/partial-reimburse"
---

## Overview

Reimburse specific expenses within an expense report individually, rather than reimbursing the entire report at once. This is useful when different expenses need to be reimbursed at different times or through different payment methods.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

<ParamField path="reportId" type="integer" required>
  The unique identifier of the expense report
</ParamField>

## Request Body

<ParamField body="expenseReimbursements" type="array" required>
  Array of individual expense reimbursement entries

  <Expandable title="Expense Reimbursement Object">
    <ParamField body="expenseReportExpenseId" type="integer" required>
      The ID of the expense report item to reimburse (from the report items list)
    </ParamField>

    <ParamField body="reimbursementAmount" type="number" required>
      Amount to reimburse for this specific expense
    </ParamField>

    <ParamField body="notes" type="string">
      Notes specific to this expense's reimbursement
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="reimbursementNotes" type="string">
  General notes about this partial reimbursement batch
</ParamField>

<ParamField body="reimbursementMethod" type="string">
  Payment method used. Options: `bank_transfer`, `check`, `cash`, `payroll`, `other`
</ParamField>

<ParamField body="reimbursementDate" type="string">
  Date the reimbursement was made (ISO 8601 format: YYYY-MM-DD). Defaults to today.
</ParamField>

## Response

<ResponseField name="id" type="integer">
  Partial reimbursement record ID
</ResponseField>

<ResponseField name="reportId" type="integer">
  ID of the expense report
</ResponseField>

<ResponseField name="status" type="string">
  Report status: `partially_reimbursed` or `reimbursed` (if all expenses are now reimbursed)
</ResponseField>

<ResponseField name="totalReimbursed" type="number">
  Total amount reimbursed in this batch
</ResponseField>

<ResponseField name="reimbursementMethod" type="string">
  Payment method used
</ResponseField>

<ResponseField name="reimbursementDate" type="string">
  Date of reimbursement
</ResponseField>

<ResponseField name="expenseReimbursements" type="array">
  Details of each expense reimbursement

  <Expandable title="Expense Reimbursement Result">
    <ResponseField name="expenseReportExpenseId" type="integer">
      Report item ID
    </ResponseField>
    <ResponseField name="reimbursementAmount" type="number">
      Amount reimbursed
    </ResponseField>
    <ResponseField name="notes" type="string">
      Reimbursement notes
    </ResponseField>
    <ResponseField name="status" type="string">
      Item reimbursement status: `reimbursed`
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="createdAt" type="string">
  Timestamp when the reimbursement was recorded (ISO 8601)
</ResponseField>

## Validation Rules

- The report must be in `approved` or `partially_reimbursed` status
- Each `expenseReportExpenseId` must reference a valid item in the report
- `reimbursementAmount` cannot exceed the approved amount for each expense
- Expenses that have already been reimbursed cannot be reimbursed again

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 400 | REPORT_NOT_APPROVED | Report must be approved first |
| 400 | EXPENSE_ALREADY_REIMBURSED | One or more expenses are already reimbursed |
| 400 | AMOUNT_EXCEEDS_APPROVED | Reimbursement amount exceeds approved amount |
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 404 | REPORT_NOT_FOUND | Report does not exist |
| 404 | EXPENSE_NOT_FOUND | Report item does not exist |
