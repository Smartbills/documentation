description: "Schedule a planned reimbursement date for an expense report"

---

## Overview

Schedule a planned reimbursement date for an approved expense report. This sets an expected payment date and notifies the employee when to expect reimbursement, without processing the actual payment.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

<ParamField path="reportId" type="integer" required>
  The unique identifier of the expense report
</ParamField>

## Request Body

<ParamField body="plannedDate" type="string" required>
  Planned reimbursement date (ISO 8601 format: YYYY-MM-DD). Must be a future date.
</ParamField>

<ParamField body="notes" type="string">
  Notes about the planned reimbursement (e.g., payment cycle details)
</ParamField>

## Response

<ResponseField name="id" type="integer">
  Planned reimbursement record ID
</ResponseField>

<ResponseField name="reportId" type="integer">
  ID of the expense report
</ResponseField>

<ResponseField name="plannedDate" type="string">
  Scheduled reimbursement date
</ResponseField>

<ResponseField name="notes" type="string">
  Planning notes
</ResponseField>

<ResponseField name="status" type="string">
  Report status: `reimbursement_planned`
</ResponseField>

<ResponseField name="createdAt" type="string">
  Timestamp when the plan was created (ISO 8601)
</ResponseField>

## Validation Rules

- The report must be in `approved` status
- `plannedDate` must be a future date
- Only one active planned reimbursement can exist per report

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 400 | REPORT_NOT_APPROVED | Report must be approved before planning reimbursement |
| 400 | INVALID_DATE | Planned date must be in the future |
| 400 | PLAN_ALREADY_EXISTS | A reimbursement plan already exists for this report |
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions |
| 404 | REPORT_NOT_FOUND | Report does not exist |
