## Expense Report

The Expense Report object represents a collection of expenses grouped together for submission, approval, and reimbursement. Reports follow a lifecycle from draft through submission, approval, and finally reimbursement.

## Properties

<ResponseField name="id" type="integer">
  Unique identifier for the expense report
</ResponseField>

<ResponseField name="businessId" type="integer">
  ID of the business this report belongs to
</ResponseField>

<ResponseField name="employeeId" type="integer">
  ID of the employee who created the report
</ResponseField>

<ResponseField name="reportNumber" type="string">
  Auto-generated report reference number (e.g., `ER-2024-0042`)
</ResponseField>

<ResponseField name="title" type="string">
  Descriptive title of the report
</ResponseField>

<ResponseField name="description" type="string">
  Detailed description of the report purpose
</ResponseField>

<ResponseField name="businessPurpose" type="string">
  Business justification for the expenses
</ResponseField>

<ResponseField name="status" type="string">
  Current report status. Possible values: `draft`, `submitted`, `approved`, `partially_approved`, `rejected`, `changes_requested`, `reimbursement_planned`, `partially_reimbursed`, `reimbursed`
</ResponseField>

<ResponseField name="totalAmount" type="number">
  Sum of all expense amounts in the report
</ResponseField>

<ResponseField name="currency" type="string">
  Primary currency for the report (ISO 4217)
</ResponseField>

<ResponseField name="approvedAmount" type="number">
  Total approved amount. May differ from `totalAmount` if partially approved. `null` if not yet approved.
</ResponseField>

<ResponseField name="expenses" type="array">
  Array of expenses included in the report
  <Expandable title="Expense Summary">
    <ResponseField name="id" type="integer">
      Expense ID
    </ResponseField>
    <ResponseField name="merchant" type="string">
      Merchant name
    </ResponseField>
    <ResponseField name="amount" type="number">
      Expense amount
    </ResponseField>
    <ResponseField name="currency" type="string">
      Currency code
    </ResponseField>
    <ResponseField name="date" type="string">
      Transaction date
    </ResponseField>
    <ResponseField name="category" type="string">
      Category name
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="submittedAt" type="string">
  Timestamp when the report was submitted for approval (ISO 8601). `null` if not submitted.
</ResponseField>

<ResponseField name="approvedAt" type="string">
  Timestamp when the report was approved (ISO 8601). `null` if not approved.
</ResponseField>

<ResponseField name="rejectedAt" type="string">
  Timestamp when the report was rejected (ISO 8601). `null` if not rejected.
</ResponseField>

<ResponseField name="reimbursedAt" type="string">
  Timestamp when the report was fully reimbursed (ISO 8601). `null` if not reimbursed.
</ResponseField>

<ResponseField name="createdAt" type="string">
  Timestamp when the report was created (ISO 8601)
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Timestamp when the report was last updated (ISO 8601)
</ResponseField>

## Status Lifecycle

```
draft -> submitted -> approved -> reimbursement_planned -> reimbursed
                   -> partially_approved -> reimbursed
                   -> rejected
                   -> changes_requested -> submitted (resubmit)
         approved -> partially_reimbursed -> reimbursed
```
