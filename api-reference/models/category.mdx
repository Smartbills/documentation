## Category

The Category object represents an expense category used to classify and organize expenses. Categories can be mapped to general ledger account codes for accounting integration.

## Properties

<ResponseField name="id" type="integer">
  Unique identifier for the category
</ResponseField>

<ResponseField name="businessId" type="integer">
  ID of the business this category belongs to
</ResponseField>

<ResponseField name="name" type="string">
  Display name of the category (e.g., "Travel - Airfare", "Office Supplies")
</ResponseField>

<ResponseField name="description" type="string">
  Detailed description of what expenses belong in this category
</ResponseField>

<ResponseField name="glAccountCode" type="string">
  General ledger account code for accounting system integration (e.g., "6200", "5100-01")
</ResponseField>

<ResponseField name="color" type="string">
  Hex color code for visual display in the UI (e.g., `#4A90D9`)
</ResponseField>

<ResponseField name="enabled" type="boolean">
  Whether the category is active and available for selection. Disabled categories are hidden from new expense creation but preserved on existing expenses.
</ResponseField>

<ResponseField name="displayOrder" type="integer">
  Sort position for display in category lists. Lower numbers appear first.
</ResponseField>

<ResponseField name="createdAt" type="string">
  Timestamp when the category was created (ISO 8601)
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Timestamp when the category was last updated (ISO 8601)
</ResponseField>

## Example

```json
{
  "id": 5,
  "businessId": 456,
  "name": "Office Supplies",
  "description": "Paper, pens, printer supplies, and other consumable office materials",
  "glAccountCode": "6200",
  "color": "#4A90D9",
  "enabled": true,
  "displayOrder": 3,
  "createdAt": "2023-01-15T10:00:00Z",
  "updatedAt": "2023-01-15T10:00:00Z"
}
```

## Default Categories

When a new business is created, the following default categories are provisioned:

| Name | GL Code |
|------|---------|
| Travel - Airfare | 6100 |
| Travel - Lodging | 6110 |
| Travel - Ground Transportation | 6120 |
| Meals & Entertainment | 6200 |
| Office Supplies | 6300 |
| Software & Subscriptions | 6400 |
| Professional Services | 6500 |
| Telecommunications | 6600 |
| Miscellaneous | 6900 |
