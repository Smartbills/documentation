## Employee

The Employee object represents a team member within a business. Employees can create expenses, submit expense reports, and be part of approval chains.

## Properties

<ResponseField name="id" type="integer">
  Unique identifier for the employee record
</ResponseField>

<ResponseField name="businessId" type="integer">
  ID of the business this employee belongs to
</ResponseField>

<ResponseField name="userId" type="integer">
  ID of the associated user account
</ResponseField>

<ResponseField name="firstName" type="string">
  Employee's first name
</ResponseField>

<ResponseField name="lastName" type="string">
  Employee's last name
</ResponseField>

<ResponseField name="email" type="string">
  Employee's email address
</ResponseField>

<ResponseField name="role" type="string">
  Employee's role within the organization. Possible values: `employee`, `manager`, `finance`, `admin`
</ResponseField>

<ResponseField name="department" type="string">
  Department the employee belongs to
</ResponseField>

<ResponseField name="managerId" type="integer">
  ID of the employee's direct manager. `null` for top-level employees. Used to determine the approval chain for expense reports.
</ResponseField>

<ResponseField name="status" type="string">
  Employee status. Possible values: `active`, `inactive`, `suspended`
</ResponseField>

<ResponseField name="createdAt" type="string">
  Timestamp when the employee record was created (ISO 8601)
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Timestamp when the employee record was last updated (ISO 8601)
</ResponseField>

## Example

```json
{
  "id": 500,
  "businessId": 456,
  "userId": 789,
  "firstName": "Jane",
  "lastName": "Smith",
  "email": "jane.smith@company.com",

  "department": "Marketing",
  "managerId": 400,
  "status": "active",
  "createdAt": "2023-06-01T09:00:00Z",
  "updatedAt": "2024-01-10T12:00:00Z"
}
```
