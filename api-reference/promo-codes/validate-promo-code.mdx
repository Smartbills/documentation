---

## Overview

Validate a promo code to check if it's valid, active, and can be applied to a purchase.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication
</ParamField>

## Required Scopes

- `promo-codes.read`

## Request Body

<ParamField body="code" type="string" required>
  The promo code to validate
</ParamField>

<ParamField body="customerId" type="integer">
  Customer ID (to check usage limits per customer)
</ParamField>

<ParamField body="purchaseAmount" type="number">
  Purchase amount (to check minimum purchase requirements)
</ParamField>

<ParamField body="currency" type="string">
  Currency code
</ParamField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.smartbills.io/v1/promo-codes/validate \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "code": "SUMMER2024",
    "customerId": 12345,
    "purchaseAmount": 75.00,
    "currency": "USD"
  }'
```

```javascript JavaScript
const validation = await client.promoCodes.validate({
  code: "SUMMER2024",
  customerId: 12345,
  purchaseAmount: 75.00,
  currency: "USD"
});
```

```python Python

```


</RequestExample>

<ResponseExample>

```json Success Response
{
  "valid": true,
  "promoCode": {
    "id": 12345,
    "code": "SUMMER2024",
    "discountType": "percentage",
    "discountValue": 20
  },
  "discountAmount": 15.00,
  "finalAmount": 60.00,
  "message": "Promo code applied successfully"
}
```

```json Invalid Response
{
  "valid": false,
  "reason": "expired",
  "message": "This promo code has expired"
}
```

```json Minimum Not Met Response
{
  "valid": false,
  "reason": "minimum_not_met",
  "message": "Minimum purchase of $50.00 required",
  "minimumPurchase": 50.00
}
```

</ResponseExample>

## Validation Reasons

| Reason | Description |
|--------|-------------|
| `expired` | Promo code has expired |
| `not_started` | Promo code not yet active |
| `usage_limit_reached` | Overall usage limit reached |
| `customer_limit_reached` | Customer has reached their usage limit |
| `minimum_not_met` | Purchase amount below minimum |
| `inactive` | Promo code is not active |
| `not_found` | Promo code does not exist |
