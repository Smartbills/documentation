---
title: "Update Promo Code"
api: "PUT https://api.smartbills.io/v1/promo-codes/{id}"
description: "Update an existing promo code"
---

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication
</ParamField>

## Required Scopes

- `promo-codes.write`

## Path Parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the promo code to update
</ParamField>

<RequestExample>

```bash cURL
curl --request PUT \
  --url https://api.smartbills.io/v1/promo-codes/12345 \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "description": "Extended summer sale - 25% off",
    "discountValue": 25,
    "expiresAt": "2024-09-30T23:59:59Z"
  }'
```

```javascript JavaScript
const updated = await client.promoCodes.update(12345, {
  description: "Extended summer sale - 25% off",
  discountValue: 25,
  expiresAt: "2024-09-30T23:59:59Z"
});
```

```python Python
updated = client.promo_codes.update(
    12345,
    description="Extended summer sale - 25% off",
    discount_value=25,
    expires_at="2024-09-30T23:59:59Z"
)
```

```csharp C#
var updated = await client.PromoCodes.UpdateAsync(12345, new PromoCodeUpdateRequest
{
    Description = "Extended summer sale - 25% off",
    DiscountValue = 25,
    ExpiresAt = "2024-09-30T23:59:59Z"
});
```

</RequestExample>

<ResponseExample>

```json Response
{
  "id": 12345,
  "code": "SUMMER2024",
  "description": "Extended summer sale - 25% off",
  "discountValue": 25,
  "expiresAt": "2024-09-30T23:59:59Z",
  "updatedAt": "2024-01-20T16:45:00Z"
}
```

</ResponseExample>
