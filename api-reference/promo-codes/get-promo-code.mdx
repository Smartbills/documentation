---
title: "Get Promo Code"
api: "GET https://api.smartbills.io/v1/promo-codes/{id}"
description: "Retrieve a promo code by ID"
---

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication
</ParamField>

## Required Scopes

- `promo-codes.read`

## Path Parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the promo code
</ParamField>

<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.smartbills.io/v1/promo-codes/12345 \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
const promoCode = await client.promoCodes.get(12345);
```

```python Python
promo_code = client.promo_codes.get(12345)
```

```csharp C#
var promoCode = await client.PromoCodes.GetAsync(12345);
```

</RequestExample>
