---
title: "Create Promo Code"
api: "POST https://api.smartbills.io/v1/promo-codes"
description: "Create a new promotional code"
---

## Overview

Create a new promo code for discounts and special offers.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication
</ParamField>

## Required Scopes

- `promo-codes.write`

## Request Body

<ParamField body="code" type="string" required>
  Promo code (e.g., "SUMMER2024")
</ParamField>

<ParamField body="description" type="string">
  Description of the promo code
</ParamField>

<ParamField body="discountType" type="string" required>
  Type: `percentage`, `fixed_amount`
</ParamField>

<ParamField body="discountValue" type="number" required>
  Discount value (percentage or amount)
</ParamField>

<ParamField body="currency" type="string">
  Currency (required if discountType is `fixed_amount`)
</ParamField>

<ParamField body="minimumPurchase" type="number">
  Minimum purchase amount required
</ParamField>

<ParamField body="maximumDiscount" type="number">
  Maximum discount amount (for percentage discounts)
</ParamField>

<ParamField body="usageLimit" type="integer">
  Maximum number of uses
</ParamField>

<ParamField body="usageLimitPerCustomer" type="integer">
  Maximum uses per customer
</ParamField>

<ParamField body="startsAt" type="string">
  Start date (ISO 8601)
</ParamField>

<ParamField body="expiresAt" type="string">
  Expiration date (ISO 8601)
</ParamField>

<ParamField body="isActive" type="boolean" default="true">
  Whether the promo code is active
</ParamField>
