---
title: "List Promo Codes"
api: "GET https://api.smartbills.io/v1/promo-codes"
description: "Retrieve a paginated list of promo codes"
---

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication
</ParamField>

## Required Scopes

- `promo-codes.read`

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number
</ParamField>

<ParamField query="pageSize" type="integer" default="100">
  Items per page (max: 100)
</ParamField>

<ParamField query="isActive" type="boolean">
  Filter by active status
</ParamField>

<ParamField query="search" type="string">
  Search by code or description
</ParamField>

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.smartbills.io/v1/promo-codes?isActive=true' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
const response = await client.promoCodes.list({
  isActive: true
});
```

```python Python
response = client.promo_codes.list(is_active=True)
```

```csharp C#
var response = await client.PromoCodes.ListAsync(new PromoCodeListRequest
{
    IsActive = true
});
```

</RequestExample>
