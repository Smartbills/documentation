---
title: "Delete Promo Code"
api: "DELETE https://api.smartbills.io/v1/promo-codes/{id}"
description: "Delete a promo code"
---

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication
</ParamField>

## Required Scopes

- `promo-codes.write`

## Path Parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the promo code to delete
</ParamField>

<Warning>
  **Destructive Action**: Deleting a promo code is permanent. Consider deactivating instead.
</Warning>

<RequestExample>

```bash cURL
curl --request DELETE \
  --url https://api.smartbills.io/v1/promo-codes/12345 \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
const deleted = await client.promoCodes.delete(12345);
```

```python Python
deleted = client.promo_codes.delete(12345)
```

```csharp C#
var deleted = await client.PromoCodes.DeleteAsync(12345);
```

</RequestExample>

<ResponseExample>

```json Response
{
  "id": 12345,
  "code": "SUMMER2024",
  "deletedAt": "2024-01-20T16:00:00Z"
}
```

</ResponseExample>
