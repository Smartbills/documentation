---
title: "Update Invoice"
api: "PUT https://api.smartbills.io/v1/invoices/{invoiceId}"
description: "Update an existing invoice"
---

## Path Parameters

<ParamField path="invoiceId" type="integer" required>
  The unique identifier of the invoice to update
</ParamField>

## Body Parameters

<ParamField body="invoiceNumber" type="string">
  Updated invoice number
</ParamField>

<ParamField body="dueDate" type="string">
  Updated due date (ISO 8601)
</ParamField>

<ParamField body="billingPeriodStartDate" type="string">
  Updated billing period start (ISO 8601)
</ParamField>

<ParamField body="billingPeriodEndDate" type="string">
  Updated billing period end (ISO 8601)
</ParamField>

<ParamField body="autoPaymentDate" type="string">
  Updated auto-payment date (ISO 8601)
</ParamField>

<ParamField body="paymentLinkUrl" type="string">
  Updated payment link URL
</ParamField>

<ParamField body="lineItems" type="array">
  <Expandable title="properties">
    <ParamField body="description" type="string">Line item description</ParamField>
    <ParamField body="quantity" type="number">Quantity</ParamField>
    <ParamField body="unitPrice" type="number">Price per unit</ParamField>
    <ParamField body="productId" type="integer">Associated product ID</ParamField>
  </Expandable>
</ParamField>

## Response

Returns the updated invoice object.

<RequestExample>

```bash cURL
curl --request PUT \
  --url https://api.smartbills.io/v1/invoices/1001 \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "dueDate": "2026-06-01T00:00:00Z",
    "lineItems": [
      {
        "description": "Web Development Services - Extended",
        "quantity": 15,
        "unitPrice": 150.00
      }
    ]
  }'
```

```javascript JavaScript
const invoice = await smartbills.invoices.update(1001, {
  dueDate: "2026-06-01T00:00:00Z",
  lineItems: [
    { description: "Web Development Services - Extended", quantity: 15, unitPrice: 150 }
  ]
});
```

```csharp C#
var invoice = await invoiceClient.UpdateAsync(1001, new InvoiceUpdateRequest
{
    DueDate = DateTimeOffset.Parse("2026-06-01"),
    LineItems = new List<InvoiceLineItemRequest>
    {
        new() { Description = "Web Development Services - Extended", Quantity = 15, UnitPrice = 150 }
    }
});
```

</RequestExample>
