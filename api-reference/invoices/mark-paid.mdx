---
title: "Mark Invoice as Paid"
api: "POST https://api.smartbills.io/v1/businesses/{businessId}/invoices/{invoiceId}/mark-paid"
description: "Manually mark an invoice as paid without processing a payment"
---

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

<ParamField path="invoiceId" type="integer" required>
  The unique identifier of the invoice
</ParamField>

## Response

Returns the updated invoice object with status set to `MarkedPaid`.

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.smartbills.io/v1/businesses/456/invoices/1001/mark-paid \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json'
```

```javascript JavaScript
const invoice = await smartbills.invoices.markPaid(1001);
```

```csharp C#
var invoice = await invoiceClient.MarkPaidAsync(1001,
    new SBRequestOptions { BusinessId = 456 });
```

</RequestExample>
