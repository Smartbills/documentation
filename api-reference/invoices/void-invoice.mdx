---
title: "Void Invoice"
api: "POST https://api.smartbills.io/v1/invoices/{invoiceId}/void"
description: "Void an invoice, marking it as cancelled and no longer payable"
---

## Path Parameters

<ParamField path="invoiceId" type="integer" required>
  The unique identifier of the invoice to void
</ParamField>

## Response

Returns the updated invoice object with `billStatus` set to `Void` and a `voidedAt` timestamp.

<Tip>
  Voiding an invoice disables the payment link and prevents any further payment collection. This action cannot be undone.
</Tip>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.smartbills.io/v1/invoices/1001/void \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json'
```

```javascript JavaScript
const invoice = await smartbills.invoices.void(1001);
```

```csharp C#
var invoice = await invoiceClient.VoidAsync(1001);
```

</RequestExample>
