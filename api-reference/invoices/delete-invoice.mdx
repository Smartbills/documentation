---
title: "Delete Invoice"
api: "DELETE https://api.smartbills.io/v1/invoices/{invoiceId}"
description: "Delete an invoice"
---

## Path Parameters

<ParamField path="invoiceId" type="integer" required>
  The unique identifier of the invoice to delete
</ParamField>

## Response

Returns the deleted invoice object.

<RequestExample>

```bash cURL
curl --request DELETE \
  --url https://api.smartbills.io/v1/invoices/1001 \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json'
```

```javascript JavaScript
const invoice = await smartbills.invoices.delete(1001);
```

```csharp C#
var invoice = await invoiceClient.DeleteAsync(1001);
```

</RequestExample>
