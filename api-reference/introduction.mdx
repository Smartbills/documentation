## Introduction

The Smartbills API is a RESTful API that allows you to programmatically manage expenses, reports, businesses, and more. Use this API to integrate expense management into your applications.

## Base URL

All API requests should be made to:

```
https://api.smartbills.io/v1
```

## Authentication

All API requests require authentication via an API key or OAuth 2.0 token.

### API Key

Include your API key in the `Authorization` header:

```bash
curl https://api.smartbills.io/v1/expenses \
  -H "Authorization: Bearer sk_live_xxxxx"
```

### OAuth 2.0

For user-facing applications, use OAuth 2.0:

```bash
curl https://api.smartbills.io/v1/expenses \
  -H "Authorization: Bearer oauth_token_xxxxx"
```

See [Authentication](/developer/authentication) for details.

## Request Format

### Headers

| Header | Value | Required |
|--------|-------|----------|
| `Authorization` | `Bearer {token}` | Yes |
| `Content-Type` | `application/json` | For POST/PUT |
| `Accept` | `application/json` | Recommended |

### JSON Body

For POST and PUT requests, send JSON in the request body:

```json
{
  "merchant": "Office Depot",
  "amount": 45.99,
  "currency": "USD",
  "date": "2025-01-15"
}
```

## Response Format

All responses are JSON:

### Success Response

```json
{
  "data": {
    "id": 12345,
    "merchant": "Office Depot",
    "amount": 45.99,
    "currency": "USD"
  }
}
```

### List Response

```json
{
  "data": [
    { "id": 1, ... },
    { "id": 2, ... }
  ],
  "page": 1,
  "pageSize": 20,
  "total": 150,
  "totalPages": 8
}
```

### Error Response

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Amount is required",
    "details": [
      {
        "field": "amount",
        "message": "Amount must be greater than 0"
      }
    ]
  }
}
```

## HTTP Status Codes

| Code | Description |
|------|-------------|
| `200` | Success |
| `201` | Created |
| `204` | No content (successful delete) |
| `400` | Bad request (validation error) |
| `401` | Unauthorized |
| `403` | Forbidden |
| `404` | Not found |
| `429` | Rate limited |
| `500` | Server error |

## Pagination

List endpoints support pagination:

| Parameter | Description | Default |
|-----------|-------------|---------|
| `page` | Page number (1-based) | 1 |
| `pageSize` | Items per page | 20 |
| `sort` | Sort field | `createdAt` |
| `order` | Sort direction (`asc`/`desc`) | `desc` |

Example:

```bash
GET /v1/expenses?page=2&pageSize=50&sort=date&order=desc
```

## Filtering

Many endpoints support filtering:

```bash
GET /v1/expenses?category=travel&status=approved&from=2025-01-01&to=2025-01-31
```

## Rate Limits

| Plan | Requests/minute |
|------|-----------------|
| Free | 60 |
| Starter | 300 |
| Business | 1,000 |
| Enterprise | Custom |

Rate limit headers:

```
X-RateLimit-Limit: 1000
X-RateLimit-Remaining: 999
X-RateLimit-Reset: 1706540400
```

## Versioning

The API version is included in the URL path:

```
https://api.smartbills.io/v1/expenses
```

We maintain backward compatibility within major versions.
