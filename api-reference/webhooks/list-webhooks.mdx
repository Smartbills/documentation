## List Webhooks

Retrieve all webhook endpoints for your account.

## Request

```bash
GET /v1/webhooks
```

### Query Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `page` | integer | Page number (default: 1) |
| `pageSize` | integer | Items per page (default: 20) |

### Example Request

```bash
curl https://api.smartbills.io/v1/webhooks \
  -H "Authorization: Bearer sk_live_xxxxx"
```
