## Create Webhook

Register a webhook to receive event notifications.

## Request

```bash
POST /v1/webhooks
```

### Body Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `url` | string | Yes | The URL to receive webhooks |
| `events` | array | Yes | Events to subscribe to |
| `description` | string | No | Description of webhook |
| `enabled` | boolean | No | Whether webhook is active (default: true) |

### Example Request

```bash
curl -X POST https://api.smartbills.io/v1/webhooks \
  -H "Authorization: Bearer sk_live_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://your-app.com/webhooks",
    "events": ["expense.created", "report.submitted"],
    "description": "Production webhook"
  }'
```

## Response

```json
{
  "data": {
    "id": "wh_abc123",
    "url": "https://your-app.com/webhooks",
    "events": ["expense.created", "report.submitted"],
    "description": "Production webhook",
    "enabled": true,
    "secret": "whsec_xxxxx",
    "createdAt": "2025-01-15T10:30:00Z"
  }
}
```

<Warning>
Save the `secret` securely. It's only returned once and is used to verify webhook signatures.
</Warning>
