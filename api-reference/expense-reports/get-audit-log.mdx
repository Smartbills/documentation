---
title: "Get Audit Log"
api: "GET https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/{reportId}/audit-log"
description: "Retrieve the complete audit log for an expense report"
---

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

<ParamField path="reportId" type="integer" required>
  The unique identifier of the expense report
</ParamField>

<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.smartbills.io/v1/businesses/456/expense-reports/1001/audit-log \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

</RequestExample>
