---
title: "Get Audit Log"
api: "GET https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/{reportId}/audit-log"
description: "Retrieve the complete audit log for an expense report with field-level change tracking"
---

## Overview

Retrieve the complete audit log for an expense report, showing every change made to the report with field-level detail. This provides a comprehensive trail of all modifications for compliance and review purposes.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token. Format: `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Business ID for multi-tenant context
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

<ParamField path="reportId" type="integer" required>
  The unique identifier of the expense report
</ParamField>

## Response

<ResponseField name="auditLog" type="array">
  Array of audit log entries in chronological order

  <Expandable title="Audit Log Entry">
    <ResponseField name="id" type="integer">
      Unique audit log entry identifier
    </ResponseField>

    <ResponseField name="action" type="string">
      Action performed: `CREATED`, `UPDATED`, `SUBMITTED`, `APPROVED`, `REJECTED`, `CHANGES_REQUESTED`, `RECALLED`, `COMMENT_ADDED`, `DELETED`
    </ResponseField>

    <ResponseField name="userId" type="integer">
      ID of the user who performed the action
    </ResponseField>

    <ResponseField name="userName" type="string">
      Name of the user who performed the action
    </ResponseField>

    <ResponseField name="changes" type="object">
      Object describing the fields that were changed. For updates, each changed field contains `before` and `after` values.
    </ResponseField>

    <ResponseField name="ipAddress" type="string">
      IP address of the user when the action was performed
    </ResponseField>

    <ResponseField name="timestamp" type="string">
      Timestamp when the action occurred (ISO 8601)
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.smartbills.io/v1/businesses/456/expense-reports/1001/audit-log \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'x-tenant-id: 456'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const auditLog = await client.expenseReports.getAuditLog(1001);

auditLog.auditLog.forEach(entry => {
  console.log(`${entry.timestamp}: ${entry.action} by ${entry.userName}`);
  if (entry.changes) {
    console.log("  Changes:", JSON.stringify(entry.changes));
  }
});
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

audit_log = client.expense_reports.get_audit_log(1001)

for entry in audit_log.audit_log:
    print(f"{entry.timestamp}: {entry.action} by {entry.user_name}")
    if entry.changes:
        print(f"  Changes: {entry.changes}")
```

</RequestExample>

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions to view this report's audit log |
| 404 | NOT_FOUND | Expense report not found |
| 429 | RATE_LIMIT_EXCEEDED | Too many requests |
