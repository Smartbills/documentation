---
title: "Delete Expense Report"
api: "DELETE https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/{reportId}"
description: "Delete an expense report in draft status"
---

## Overview

Delete an expense report. Only reports in `draft` status can be deleted. Transactions previously associated with the report will be unlinked but not deleted.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token. Format: `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Business ID for multi-tenant context
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

<ParamField path="reportId" type="integer" required>
  The unique identifier of the expense report to delete
</ParamField>

## Response

Returns a `204 No Content` response on successful deletion.

<RequestExample>

```bash cURL
curl --request DELETE \
  --url https://api.smartbills.io/v1/businesses/456/expense-reports/1001 \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'x-tenant-id: 456'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

await client.expenseReports.delete(1001);

console.log("Report deleted successfully");
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

client.expense_reports.delete(1001)

print("Report deleted successfully")
```

</RequestExample>

<ResponseExample>

```json Response
// 204 No Content
```

</ResponseExample>

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions to delete this report |
| 404 | NOT_FOUND | Expense report not found |
| 409 | INVALID_STATUS | Report is not in `draft` status and cannot be deleted. Submitted or approved reports must be recalled first. |
| 429 | RATE_LIMIT_EXCEEDED | Too many requests |
