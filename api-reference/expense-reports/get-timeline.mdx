---
title: "Get Report Timeline"
api: "GET https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/{reportId}/timeline"
description: "Retrieve the chronological timeline of events for an expense report"
---

## Overview

Retrieve the timeline of events for an expense report, showing all status changes, comments, and actions in chronological order. This provides a clear overview of the report's lifecycle from creation through approval.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token. Format: `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Business ID for multi-tenant context
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

<ParamField path="reportId" type="integer" required>
  The unique identifier of the expense report
</ParamField>

## Response

<ResponseField name="events" type="array">
  Array of timeline event objects in chronological order

  <Expandable title="Timeline Event Object">
    <ResponseField name="id" type="integer">
      Unique event identifier
    </ResponseField>

    <ResponseField name="type" type="string">
      Event type: `created`, `updated`, `submitted`, `approved`, `partially_approved`, `rejected`, `changes_required`, `recalled`, `comment_added`, `expense_added`, `expense_removed`
    </ResponseField>

    <ResponseField name="userId" type="integer">
      ID of the user who triggered the event
    </ResponseField>

    <ResponseField name="userName" type="string">
      Name of the user who triggered the event
    </ResponseField>

    <ResponseField name="description" type="string">
      Human-readable description of the event
    </ResponseField>

    <ResponseField name="metadata" type="object">
      Additional event-specific data (e.g., rejection reason, approval notes, comment text)
    </ResponseField>

    <ResponseField name="timestamp" type="string">
      Timestamp when the event occurred (ISO 8601)
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.smartbills.io/v1/businesses/456/expense-reports/1001/timeline \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'x-tenant-id: 456'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const timeline = await client.expenseReports.getTimeline(1001);

timeline.events.forEach(event => {
  console.log(`${event.timestamp}: ${event.type} by ${event.userName}`);
});
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

timeline = client.expense_reports.get_timeline(1001)

for event in timeline.events:
    print(f"{event.timestamp}: {event.type} by {event.user_name}")
```

</RequestExample>

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions to view this report's timeline |
| 404 | NOT_FOUND | Expense report not found |
| 429 | RATE_LIMIT_EXCEEDED | Too many requests |
