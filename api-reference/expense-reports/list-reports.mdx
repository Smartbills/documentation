---
title: "List Expense Reports"
api: "GET https://api.smartbills.io/v1/businesses/{businessId}/expense-reports"
description: "Retrieve a paginated list of expense reports with filtering and sorting options"
---

## Overview

Retrieve a list of expense reports for a business. You can filter by status, employee, date range, and search terms, and sort results by various fields.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token. Format: `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Business ID for multi-tenant context
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

## Query Parameters

<ParamField query="status" type="string">
  Filter by report status. Options: `draft`, `submitted`, `approved`, `partially_approved`, `rejected`, `changes_required`, `reimbursed`
</ParamField>

<ParamField query="employeeId" type="integer">
  Filter reports by employee ID (the submitter)
</ParamField>

<ParamField query="startDate" type="string">
  Filter reports with period starting from this date (ISO 8601 format: YYYY-MM-DD)
</ParamField>

<ParamField query="endDate" type="string">
  Filter reports with period ending before this date (ISO 8601 format: YYYY-MM-DD)
</ParamField>

<ParamField query="search" type="string">
  Search across report title, description, and business purpose
</ParamField>

<ParamField query="sortBy" type="string" default="createdAt">
  Field to sort by. Options: `createdAt`, `updatedAt`, `totalAmount`, `title`, `status`
</ParamField>

<ParamField query="sortDescending" type="boolean" default="true">
  Sort in descending order when `true`, ascending when `false`
</ParamField>

<ParamField query="page" type="integer" default="1">
  Page number for pagination (starts at 1)
</ParamField>

<ParamField query="pageSize" type="integer" default="20">
  Number of items per page (max: 100)
</ParamField>

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.smartbills.io/v1/businesses/456/expense-reports?status=submitted&sortBy=createdAt&sortDescending=true&page=1&pageSize=20' \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'x-tenant-id: 456'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const response = await client.expenseReports.list({
  businessId: 456,
  status: "submitted",
  sortBy: "createdAt",
  sortDescending: true,
  page: 1,
  pageSize: 20
});

console.log(`Found ${response.pagination.totalCount} reports`);
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

response = client.expense_reports.list({
    "business_id": 456,
    "status": "submitted",
    "sort_by": "createdAt",
    "sort_descending": True,
    "page": 1,
    "page_size": 20
})

print(f"Found {response.pagination.total_count} reports")
```

## Filtering Examples

### Filter by Status

Get all submitted reports awaiting approval:

```bash
GET /v1/businesses/456/expense-reports?status=submitted
```

### Filter by Employee

Get all reports from a specific employee:

```bash
GET /v1/businesses/456/expense-reports?employeeId=789
```

### Filter by Date Range

Get reports for a specific period:

```bash
GET /v1/businesses/456/expense-reports?startDate=2025-01-01&endDate=2025-03-31
```

### Search Reports

Search across report titles and descriptions:

```bash
GET /v1/businesses/456/expense-reports?search=travel
```
