---
title: "Reject Expense Report"
api: "POST https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/{reportId}/reject"
description: "Reject a submitted expense report with a reason"
---

## Overview

Reject a submitted expense report. The report status changes to `rejected`, and the submitter is notified with the provided reason. The submitter can then create a new report or modify and resubmit.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token. Format: `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Business ID for multi-tenant context
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

<ParamField path="reportId" type="integer" required>
  The unique identifier of the expense report to reject
</ParamField>

## Request Body

<ParamField body="reason" type="string" required>
  The reason for rejecting the report. This will be visible to the submitter.

  Example: `"Missing receipts for hotel expenses. Policy requires receipts for all expenses over $25."`
</ParamField>

## Response

Returns the updated expense report with status changed to `rejected`.

<ResponseField name="id" type="integer">
  Unique expense report identifier
</ResponseField>

<ResponseField name="title" type="string">
  Report title
</ResponseField>

<ResponseField name="status" type="string">
  Report status (will be `rejected`)
</ResponseField>

<ResponseField name="totalAmount" type="number">
  Total amount of the report
</ResponseField>

<ResponseField name="reportCurrency" type="string">
  Currency code
</ResponseField>

<ResponseField name="rejectedBy" type="integer">
  User ID of the person who rejected the report
</ResponseField>

<ResponseField name="rejectedAt" type="string">
  Timestamp when the report was rejected (ISO 8601)
</ResponseField>

<ResponseField name="rejectionReason" type="string">
  The reason provided for the rejection
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Timestamp of last update (ISO 8601)
</ResponseField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.smartbills.io/v1/businesses/456/expense-reports/1001/reject \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --header 'x-tenant-id: 456' \
  --data '{
    "reason": "Missing receipts for hotel expenses. Policy requires receipts for all expenses over $25."
  }'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const report = await client.expenseReports.reject(1001, {
  reason: "Missing receipts for hotel expenses. Policy requires receipts for all expenses over $25."
});

console.log("Report rejected:", report.status);
console.log("Reason:", report.rejectionReason);
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

report = client.expense_reports.reject(1001, {
    "reason": "Missing receipts for hotel expenses. Policy requires receipts for all expenses over $25."
})

print(f"Report rejected: {report.status}")
print(f"Reason: {report.rejection_reason}")
```

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 400 | VALIDATION_FAILED | Missing or empty rejection reason |
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | User is not authorized to reject this report |
| 404 | NOT_FOUND | Expense report not found |
| 409 | INVALID_STATUS | Report is not in `submitted` status |
| 429 | RATE_LIMIT_EXCEEDED | Too many requests |
