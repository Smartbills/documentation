---
title: "Approve Expense Report"
api: "POST https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/{reportId}/approve"
description: "Approve a submitted expense report with optional per-expense approval details"
---

## Overview

Approve a submitted expense report. You can approve the full report amount, or provide a different approved amount along with per-expense approval details for partial approvals.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token. Format: `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Business ID for multi-tenant context
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

<ParamField path="reportId" type="integer" required>
  The unique identifier of the expense report to approve
</ParamField>

## Request Body

<ParamField body="approvedAmount" type="number">
  The approved total amount. If omitted, the full report amount is approved. Use a different value for partial approvals.
</ParamField>

<ParamField body="notes" type="string">
  Approval notes visible to the submitter

  Example: `"Approved. Please use corporate card for future hotel bookings."`
</ParamField>

<ParamField body="expenseApprovals" type="array">
  Array of per-expense approval details for granular control

  <Expandable title="Expense Approval Object">
    <ParamField body="expenseId" type="integer" required>
      The ID of the transaction being approved or adjusted
    </ParamField>

    <ParamField body="approvedAmount" type="number">
      The approved amount for this specific transaction
    </ParamField>

    <ParamField body="notes" type="string">
      Notes for this specific transaction
    </ParamField>
  </Expandable>
</ParamField>

## Response

Returns the updated expense report with approval details.

<ResponseField name="id" type="integer">
  Unique expense report identifier
</ResponseField>

<ResponseField name="title" type="string">
  Report title
</ResponseField>

<ResponseField name="status" type="string">
  Report status (will be `approved` or `partially_approved`)
</ResponseField>

<ResponseField name="totalAmount" type="number">
  Original total amount of the report
</ResponseField>

<ResponseField name="approvedAmount" type="number">
  Approved amount
</ResponseField>

<ResponseField name="reportCurrency" type="string">
  Currency code
</ResponseField>

<ResponseField name="approvedBy" type="integer">
  User ID of the approver
</ResponseField>

<ResponseField name="approvedAt" type="string">
  Timestamp when the report was approved (ISO 8601)
</ResponseField>

<ResponseField name="notes" type="string">
  Approval notes
</ResponseField>

<ResponseField name="expenseApprovals" type="array">
  Per-expense approval details

  <Expandable title="Expense Approval Object">
    <ResponseField name="expenseId" type="integer">
      Transaction ID
    </ResponseField>

    <ResponseField name="approvedAmount" type="number">
      Approved amount for this transaction
    </ResponseField>

    <ResponseField name="notes" type="string">
      Notes for this transaction
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Timestamp of last update (ISO 8601)
</ResponseField>

<RequestExample>

```bash cURL
# Full Approval
curl --request POST \
  --url https://api.smartbills.io/v1/businesses/456/expense-reports/1001/approve \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --header 'x-tenant-id: 456' \
  --data '{
    "notes": "Approved for reimbursement"
  }'

# Partial Approval with per-expense details
curl --request POST \
  --url https://api.smartbills.io/v1/businesses/456/expense-reports/1001/approve \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --header 'x-tenant-id: 456' \
  --data '{
    "approvedAmount": 1034.56,
    "notes": "Meal expense adjusted to policy limit",
    "expenseApprovals": [
      {
        "expenseId": 12345,
        "approvedAmount": 500.00
      },
      {
        "expenseId": 12346,
        "approvedAmount": 534.56
      },
      {
        "expenseId": 12347,
        "approvedAmount": 0,
        "notes": "Exceeds per-meal policy limit. Please resubmit with corrected amount."
      }
    ]
  }'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

// Full approval
const report = await client.expenseReports.approve(1001, {
  notes: "Approved for reimbursement"
});

// Partial approval
const partialReport = await client.expenseReports.approve(1001, {
  approvedAmount: 1034.56,
  notes: "Meal expense adjusted to policy limit",
  expenseApprovals: [
    { expenseId: 12345, approvedAmount: 500.00 },
    { expenseId: 12346, approvedAmount: 534.56 },
    { expenseId: 12347, approvedAmount: 0, notes: "Exceeds per-meal policy limit" }
  ]
});

console.log("Status:", partialReport.status);
console.log("Approved amount:", partialReport.approvedAmount);
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

# Full approval
report = client.expense_reports.approve(1001, {
    "notes": "Approved for reimbursement"
})

# Partial approval
partial_report = client.expense_reports.approve(1001, {
    "approved_amount": 1034.56,
    "notes": "Meal expense adjusted to policy limit",
    "expense_approvals": [
        {"expense_id": 12345, "approved_amount": 500.00},
        {"expense_id": 12346, "approved_amount": 534.56},
        {"expense_id": 12347, "approved_amount": 0, "notes": "Exceeds per-meal policy limit"}
    ]
})

print(f"Status: {partial_report.status}")
print(f"Approved amount: {partial_report.approved_amount}")
```

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 400 | VALIDATION_FAILED | Invalid request data |
| 400 | INVALID_EXPENSE_ID | An expense ID in `expenseApprovals` does not belong to this report |
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | User is not authorized to approve this report |
| 404 | NOT_FOUND | Expense report not found |
| 409 | INVALID_STATUS | Report is not in `submitted` status |
| 429 | RATE_LIMIT_EXCEEDED | Too many requests |
