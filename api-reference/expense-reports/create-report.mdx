---
title: "Create Expense Report"
api: "POST https://api.smartbills.io/v1/businesses/{businessId}/expense-reports"
description: "Create a new expense report to group transactions for submission and approval"
---

## Overview

Create a new expense report to organize and submit transactions for approval. You can create an empty report and add transactions later, or include transaction IDs during creation.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token. Format: `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Business ID for multi-tenant context
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

## Request Body

<ParamField body="title" type="string" required>
  Descriptive title for the expense report

  Example: `"January 2025 Travel Expenses"`
</ParamField>

<ParamField body="description" type="string">
  Detailed description of the report purpose

  Example: `"Business trip to NYC for client meetings"`
</ParamField>

<ParamField body="businessPurpose" type="string">
  Business justification for the expenses

  Example: `"Client acquisition and relationship building"`
</ParamField>

<ParamField body="startDate" type="string">
  Start date of the expense period (ISO 8601 format: YYYY-MM-DD)

  Example: `"2025-01-15"`
</ParamField>

<ParamField body="endDate" type="string">
  End date of the expense period (ISO 8601 format: YYYY-MM-DD)

  Example: `"2025-01-18"`
</ParamField>

<ParamField body="transactionIds" type="array">
  Array of transaction IDs to include in the report

  Example: `[12345, 12346, 12347]`
</ParamField>

<ParamField body="reportCurrency" type="string">
  Three-letter ISO currency code for the report (e.g., USD, CAD, EUR). Transactions in other currencies will be converted.

  Example: `"USD"`
</ParamField>

<ParamField body="employeeId" type="integer">
  ID of the employee this report is for. If omitted, defaults to the authenticated user. Managers can create reports on behalf of employees by specifying this field.
</ParamField>

```bash cURL
curl --request POST \
  --url https://api.smartbills.io/v1/businesses/456/expense-reports \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --header 'x-tenant-id: 456' \
  --data '{
    "title": "January 2025 Travel Expenses",
    "description": "Business trip to NYC for client meetings",
    "businessPurpose": "Client acquisition",
    "startDate": "2025-01-15",
    "endDate": "2025-01-18",
    "transactionIds": [12345, 12346, 12347],
    "reportCurrency": "USD"
  }'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const report = await client.expenseReports.create({
  businessId: 456,
  title: "January 2025 Travel Expenses",
  description: "Business trip to NYC for client meetings",
  businessPurpose: "Client acquisition",
  startDate: "2025-01-15",
  endDate: "2025-01-18",
  transactionIds: [12345, 12346, 12347],
  reportCurrency: "USD"
});

console.log("Report created:", report.id);
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

report = client.expense_reports.create({
    "business_id": 456,
    "title": "January 2025 Travel Expenses",
    "description": "Business trip to NYC for client meetings",
    "business_purpose": "Client acquisition",
    "start_date": "2025-01-15",
    "end_date": "2025-01-18",
    "transaction_ids": [12345, 12346, 12347],
    "report_currency": "USD"
})

print(f"Report created: {report.id}")
```

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 400 | VALIDATION_FAILED | Invalid request data |
| 400 | INVALID_DATE_RANGE | End date is before start date |
| 400 | TRANSACTION_NOT_FOUND | One or more transaction IDs do not exist |
| 400 | TRANSACTION_ALREADY_IN_REPORT | Transaction is already assigned to another report |
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | No access to the specified business |
| 404 | BUSINESS_NOT_FOUND | Business ID does not exist |
| 429 | RATE_LIMIT_EXCEEDED | Too many requests |
