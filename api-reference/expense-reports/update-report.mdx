---
title: "Update Expense Report"
api: "PUT https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/{reportId}"
description: "Update an existing expense report's details, date range, or transactions"
---

## Overview

Update an existing expense report. You can modify the title, description, business purpose, date range, transaction list, and currency. Only reports in `draft` or `changes_required` status can be updated.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token. Format: `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Business ID for multi-tenant context
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

<ParamField path="reportId" type="integer" required>
  The unique identifier of the expense report to update
</ParamField>

## Request Body

<ParamField body="title" type="string">
  Updated report title
</ParamField>

<ParamField body="description" type="string">
  Updated report description
</ParamField>

<ParamField body="businessPurpose" type="string">
  Updated business purpose
</ParamField>

<ParamField body="startDate" type="string">
  Updated start date of the expense period (ISO 8601 format: YYYY-MM-DD)
</ParamField>

<ParamField body="endDate" type="string">
  Updated end date of the expense period (ISO 8601 format: YYYY-MM-DD)
</ParamField>

<ParamField body="transactionIds" type="array">
  Updated array of transaction IDs. This replaces the existing list of transactions.
</ParamField>

<ParamField body="reportCurrency" type="string">
  Updated three-letter ISO currency code for the report
</ParamField>

## Response

Returns the updated expense report object.

  Unique expense report identifier

<ResponseField name="title" type="string">

<ResponseField name="description" type="string">

  Report status

<RequestExample>

```bash cURL
curl --request PUT \
  --url https://api.smartbills.io/v1/businesses/456/expense-reports/1001 \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --header 'x-tenant-id: 456' \
  --data '{
    "title": "January 2025 Business Trip - Updated",
    "description": "Updated with additional meals expenses",
    "transactionIds": [12345, 12346, 12347, 12348],
    "endDate": "2025-01-19"
  }'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const report = await client.expenseReports.update(1001, {
  title: "January 2025 Business Trip - Updated",
  description: "Updated with additional meals expenses",
  transactionIds: [12345, 12346, 12347, 12348],
  endDate: "2025-01-19"
});

console.log("Report updated:", report.title);
console.log("New total:", report.totalAmount);
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

report = client.expense_reports.update(1001, {
    "title": "January 2025 Business Trip - Updated",
    "description": "Updated with additional meals expenses",
    "transaction_ids": [12345, 12346, 12347, 12348],
    "end_date": "2025-01-19"
})

print(f"Report updated: {report.title}")
print(f"New total: {report.total_amount}")
```

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 400 | VALIDATION_FAILED | Invalid request data |
| 400 | INVALID_DATE_RANGE | End date is before start date |
| 400 | TRANSACTION_NOT_FOUND | One or more transaction IDs do not exist |
| 400 | TRANSACTION_ALREADY_IN_REPORT | Transaction is already assigned to another report |
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions to update this report |
| 404 | NOT_FOUND | Expense report not found |
| 409 | INVALID_STATUS | Report is not in an editable status (must be `draft` or `changes_required`) |
| 429 | RATE_LIMIT_EXCEEDED | Too many requests |
