---
title: "Get My Expense Reports"
api: "GET https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/me"
description: "Retrieve the current authenticated user's expense reports"
---

## Overview

Retrieve expense reports belonging to the currently authenticated user. This is a convenience endpoint that filters reports to only those owned by the caller, useful for employee self-service views.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token. Format: `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Business ID for multi-tenant context
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

## Query Parameters

<ParamField query="status" type="string">
  Filter by report status. Options: `draft`, `submitted`, `approved`, `partially_approved`, `rejected`, `changes_required`, `reimbursed`
</ParamField>

## Response

<ResponseField name="data" type="array">
  Array of the current user's expense report objects

  <Expandable title="Expense Report Object">
    <ResponseField name="id" type="integer">
      Unique expense report identifier
    </ResponseField>

    <ResponseField name="title" type="string">
      Report title
    </ResponseField>

    <ResponseField name="description" type="string">
      Report description
    </ResponseField>

    <ResponseField name="businessPurpose" type="string">
      Business purpose for the expenses
    </ResponseField>

    <ResponseField name="status" type="string">
      Report status: `draft`, `submitted`, `approved`, `partially_approved`, `rejected`, `changes_required`, `reimbursed`
    </ResponseField>

    <ResponseField name="totalAmount" type="number">
      Total amount of all transactions in the report
    </ResponseField>

    <ResponseField name="reportCurrency" type="string">
      Three-letter ISO currency code
    </ResponseField>

    <ResponseField name="expenseCount" type="integer">
      Number of transactions in the report
    </ResponseField>

    <ResponseField name="startDate" type="string">
      Expense period start date (YYYY-MM-DD)
    </ResponseField>

    <ResponseField name="endDate" type="string">
      Expense period end date (YYYY-MM-DD)
    </ResponseField>

    <ResponseField name="submittedAt" type="string">
      Timestamp when the report was submitted (ISO 8601)
    </ResponseField>

    <ResponseField name="createdAt" type="string">
      Timestamp when the report was created (ISO 8601)
    </ResponseField>

    <ResponseField name="updatedAt" type="string">
      Timestamp of last update (ISO 8601)
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.smartbills.io/v1/businesses/456/expense-reports/me?status=draft' \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'x-tenant-id: 456'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const myReports = await client.expenseReports.getMine({
  status: "draft"
});

console.log(`You have ${myReports.data.length} draft reports`);
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

my_reports = client.expense_reports.get_my_reports({
    "status": "draft"
})

print(f"You have {len(my_reports.data)} draft reports")
```

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions to access this business |
| 404 | BUSINESS_NOT_FOUND | Business ID does not exist |
| 429 | RATE_LIMIT_EXCEEDED | Too many requests |
