---
title: "Add Comment"
api: "POST https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/{reportId}/comments"
description: "Add a comment to an expense report for discussion between submitters and approvers"
---

## Overview

Add a comment to an expense report. Comments provide a communication channel between the report submitter and approvers to discuss expenses, clarify details, or provide additional context. Comments can be added to reports in any status.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token. Format: `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Business ID for multi-tenant context
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

<ParamField path="reportId" type="integer" required>
  The unique identifier of the expense report
</ParamField>

## Request Body

<ParamField body="comment" type="string" required>
  The comment text to add to the report

  Example: `"The hotel expense includes conference registration fees. See attached itemized receipt."`
</ParamField>

## Response

Returns the newly created comment object.

<ResponseField name="id" type="integer">
  Unique comment identifier
</ResponseField>

<ResponseField name="reportId" type="integer">
  ID of the expense report this comment belongs to
</ResponseField>

<ResponseField name="userId" type="integer">
  ID of the user who posted the comment
</ResponseField>

<ResponseField name="userName" type="string">
  Name of the user who posted the comment
</ResponseField>

<ResponseField name="comment" type="string">
  Comment text
</ResponseField>

<ResponseField name="createdAt" type="string">
  Timestamp when the comment was posted (ISO 8601)
</ResponseField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.smartbills.io/v1/businesses/456/expense-reports/1001/comments \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --header 'x-tenant-id: 456' \
  --data '{
    "comment": "The hotel expense includes conference registration fees. See attached itemized receipt."
  }'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const comment = await client.expenseReports.addComment(1001, {
  comment: "The hotel expense includes conference registration fees. See attached itemized receipt."
});

console.log("Comment added:", comment.id);
console.log("Posted at:", comment.createdAt);
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

comment = client.expense_reports.add_comment(1001, {
    "comment": "The hotel expense includes conference registration fees. See attached itemized receipt."
})

print(f"Comment added: {comment.id}")
print(f"Posted at: {comment.created_at}")
```

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 400 | VALIDATION_FAILED | Missing or empty comment text |
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions to comment on this report |
| 404 | NOT_FOUND | Expense report not found |
| 429 | RATE_LIMIT_EXCEEDED | Too many requests |
