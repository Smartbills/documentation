---
title: "Get Expense Report"
api: "GET https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/{reportId}"
description: "Retrieve a specific expense report"
---

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

<ParamField path="reportId" type="integer" required>
  The unique identifier of the expense report
</ParamField>

<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.smartbills.io/v1/businesses/456/expense-reports/1001 \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

</RequestExample>
