---
title: "Submit Expense Report"
api: "POST https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/{reportId}/submit"
description: "Submit an expense report for approval"
---

## Overview

Submit a draft expense report for approval. The report status changes from `draft` to `submitted`, and designated approvers are notified. The report must have at least one transaction before it can be submitted.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token. Format: `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Business ID for multi-tenant context
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

<ParamField path="reportId" type="integer" required>
  The unique identifier of the expense report to submit
</ParamField>

## Response

Returns the updated expense report with status changed to `submitted`.

<ResponseField name="id" type="integer">
  Unique expense report identifier
</ResponseField>

<ResponseField name="title" type="string">
  Report title
</ResponseField>

<ResponseField name="status" type="string">
  Report status (will be `submitted`)
</ResponseField>

<ResponseField name="totalAmount" type="number">
  Total amount of all transactions in the report
</ResponseField>

<ResponseField name="reportCurrency" type="string">
  Currency code
</ResponseField>

<ResponseField name="expenseCount" type="integer">
  Number of transactions in the report
</ResponseField>

<ResponseField name="submittedAt" type="string">
  Timestamp when the report was submitted (ISO 8601)
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Timestamp of last update (ISO 8601)
</ResponseField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.smartbills.io/v1/businesses/456/expense-reports/1001/submit \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'x-tenant-id: 456'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const report = await client.expenseReports.submit(1001);

console.log("Report submitted:", report.status);
console.log("Submitted at:", report.submittedAt);
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

report = client.expense_reports.submit(1001)

print(f"Report submitted: {report.status}")
print(f"Submitted at: {report.submitted_at}")
```

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 400 | EMPTY_REPORT | Report has no transactions and cannot be submitted |
| 400 | MISSING_RECEIPTS | One or more transactions are missing required receipts |
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions to submit this report |
| 404 | NOT_FOUND | Expense report not found |
| 409 | INVALID_STATUS | Report is not in `draft` or `changes_required` status |
| 429 | RATE_LIMIT_EXCEEDED | Too many requests |
