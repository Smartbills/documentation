---
title: "Get Receipt"
api: "GET https://api.smartbills.io/v1/receipts/{id}"
description: "Retrieve a receipt by ID"
---

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication
</ParamField>

## Required Scopes

- `receipts.read`

## Path Parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the receipt
</ParamField>

<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.smartbills.io/v1/receipts/12345 \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
const receipt = await client.receipts.get(12345);
```

```python Python
receipt = client.receipts.get(12345)
```

```csharp C#
var receipt = await client.Receipts.GetAsync(12345);
```

</RequestExample>
