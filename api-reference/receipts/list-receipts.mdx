---
title: "List Receipts"
api: "GET https://api.smartbills.io/v1/receipts"
description: "Retrieve a paginated list of receipts"
---

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication
</ParamField>

## Required Scopes

- `receipts.read`

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number
</ParamField>

<ParamField query="pageSize" type="integer" default="100">
  Items per page (max: 100)
</ParamField>

<ParamField query="merchantId" type="integer">
  Filter by merchant ID
</ParamField>

<ParamField query="locationId" type="integer">
  Filter by location ID
</ParamField>

<ParamField query="customerId" type="integer">
  Filter by customer ID
</ParamField>

<ParamField query="startDate" type="string">
  Filter receipts from this date (ISO 8601)
</ParamField>

<ParamField query="endDate" type="string">
  Filter receipts until this date (ISO 8601)
</ParamField>

<ParamField query="status" type="string">
  Filter by status: `completed`, `pending`, `cancelled`
</ParamField>

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.smartbills.io/v1/receipts?page=1&pageSize=20&status=completed' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```python Python
response = client.receipts.list(

```
