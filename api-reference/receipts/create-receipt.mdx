## Overview

Create a new receipt to track transactions. Smartbills can be easily implemented alongside your billing system, allowing you to continue operating as usual while providing consumers with their receipts in the Smartbills app.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Required Scopes

- `receipts.write`

## Distributing Receipts

### Known Client
If you know the client and they exist in your Smartbills database, provide:
- Smartbills Client ID
- Email address
- Phone number

### Unknown Client
If you don't know the client, provide payment method information:
- **Credit card**: BIN, last 4 digits, cardholder name, expiration date
- **Virtual credit card**: Same as credit card + wallet type
- **Bank account**: Institution number, transit number, account number

<Warning>
  If you do not know the client, it is not possible to guarantee that the receipt will end up in the client's Smartbills account.
</Warning>

    <ParamField body="email" type="string">
      Customer email
    </ParamField>
    
    <ParamField body="phone" type="string">
      Customer phone number
    </ParamField>
    
    <ParamField body="firstName" type="string">
      First name
    </ParamField>

      Last name

</ParamField>

  Unique receipt number
</ParamField>

<ParamField body="receiptDate" type="string" required>

</ParamField>

<ParamField body="subtotal" type="object" required>
  Subtotal amount before taxes

    <ParamField body="amount" type="number" required>

    <ParamField body="currency" type="string" required>
      Three-letter ISO currency code
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="total" type="object" required>
  Total amount including taxes
</ParamField>

<ParamField body="taxes" type="array">
  Array of tax line items
  
  <Expandable title="Tax Item">
    <ParamField body="name" type="string" required>
      Tax name
    </ParamField>
    
    <ParamField body="rate" type="number" required>
      Tax rate percentage
    </ParamField>
    
    <ParamField body="amount" type="object" required>
      Tax amount
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="lineItems" type="array">
  Array of line items on the receipt
  
  <Expandable title="Line Item">
    <ParamField body="description" type="string" required>
      Item description
    </ParamField>
    
    <ParamField body="quantity" type="number" required>
      Quantity
    </ParamField>
    
    <ParamField body="unitPrice" type="object" required>

    <ParamField body="sku" type="string">

    </ParamField>

    </ParamField>

    </ParamField>
    
    <ParamField body="cardBrand" type="string">
      Card brand (Visa, Mastercard, etc.)

  </Expandable>

</ParamField>

<ParamField body="notes" type="string">
  Additional notes
</ParamField>

  Custom metadata

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
