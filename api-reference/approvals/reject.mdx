---
title: "Reject Report"
description: "Reject a submitted expense report"
api: "POST https://api.smartbills.io/v1/businesses/{businessId}/approbations/{reportId}/reject"
---

## Overview

Reject an expense report that has been submitted for approval. A reason must be provided to inform the employee why the report was rejected. The report status changes to `rejected` and the employee can address the issues and resubmit.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

<ParamField path="reportId" type="integer" required>
  The unique identifier of the expense report to reject
</ParamField>

## Request Body

<ParamField body="reason" type="string" required>
  Reason for rejecting the report. This is visible to the submitting employee.
</ParamField>

## Response

<ResponseField name="reportId" type="integer">
  ID of the rejected report
</ResponseField>

<ResponseField name="status" type="string">
  Updated report status: `rejected`
</ResponseField>

<ResponseField name="rejectedBy" type="integer">
  ID of the user who rejected the report
</ResponseField>

<ResponseField name="rejectedAt" type="string">
  Timestamp of rejection (ISO 8601)
</ResponseField>

<ResponseField name="reason" type="string">
  Rejection reason
</ResponseField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.smartbills.io/v1/businesses/456/approbations/789/reject \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "reason": "Missing receipts for hotel and meal expenses. Please attach receipts and resubmit."
  }'
```

```javascript JavaScript
const result = await client.approbations.reject(789, {

});
```

```python Python

```

```csharp C#
});
```

</RequestExample>

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 400 | REPORT_NOT_SUBMITTED | Report has not been submitted for approval |
| 400 | REASON_REQUIRED | A rejection reason is required |
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | NOT_APPROVER | You are not an approver for this report |
| 404 | REPORT_NOT_FOUND | Report does not exist |
