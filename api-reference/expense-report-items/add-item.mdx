---

## Overview

Add an existing expense to an expense report. You can optionally specify an allocated amount (for split expenses), an exchange rate, and a category override.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

<ParamField path="reportId" type="integer" required>
  The unique identifier of the expense report
</ParamField>

## Request Body

<ParamField body="expenseId" type="integer" required>
  The ID of the expense to add to the report
</ParamField>

<ParamField body="allocatedAmount" type="number">
  Amount to allocate from this expense to the report. Defaults to the full expense amount. Use this for splitting an expense across multiple reports.
</ParamField>

<ParamField body="exchangeRate" type="number">
  Exchange rate to apply when the expense currency differs from the report currency. Defaults to `1.0`.
</ParamField>

<ParamField body="categoryId" type="integer">
  Override the expense category for this report. If not provided, the expense's original category is used.
</ParamField>

## Validation Rules

- The expense must exist and belong to the specified business
- The expense must not already be fully allocated to another report
- The report must be in `draft` status
- `allocatedAmount` cannot exceed the expense's remaining unallocated amount
- `exchangeRate` must be a positive number

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 400 | EXPENSE_ALREADY_IN_REPORT | Expense is already in this report |
| 400 | AMOUNT_EXCEEDS_EXPENSE | Allocated amount exceeds the expense total |
| 400 | REPORT_NOT_DRAFT | Report is not in draft status |
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 404 | EXPENSE_NOT_FOUND | Expense does not exist |
| 404 | REPORT_NOT_FOUND | Report does not exist |
