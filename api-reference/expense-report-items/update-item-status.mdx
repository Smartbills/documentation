title: "Edit Report Item"
description: "Edit an expense's details within an expense report"
api: "PUT https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/{reportId}/expenses/{expenseId}"
---

## Overview

Update the allocated amount, exchange rate, category, or notes for an expense within an expense report. This modifies the report-level properties of the expense without changing the original expense record.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

<ParamField path="reportId" type="integer" required>
  The unique identifier of the expense report
</ParamField>

<ParamField path="expenseId" type="integer" required>
  The unique identifier of the expense to edit
</ParamField>

## Request Body

<ParamField body="allocatedAmount" type="number">
  Updated amount to allocate from this expense to the report
</ParamField>

<ParamField body="exchangeRate" type="number">
  Updated exchange rate to apply
</ParamField>

<ParamField body="categoryId" type="integer">
  Updated category ID for this expense within the report
</ParamField>

<ParamField body="notes" type="string">
  Notes specific to this expense within the report
</ParamField>

## Validation Rules

- The report must be in `draft` status
- `allocatedAmount` cannot exceed the original expense amount
- `categoryId` must reference a valid category within the business
- `exchangeRate` must be a positive number

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 400 | REPORT_NOT_DRAFT | Report is not in draft status |
| 400 | AMOUNT_EXCEEDS_EXPENSE | Allocated amount exceeds the expense total |
| 400 | INVALID_CATEGORY | Category does not exist |
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 404 | EXPENSE_NOT_IN_REPORT | Expense is not part of this report |
| 404 | REPORT_NOT_FOUND | Report does not exist |
