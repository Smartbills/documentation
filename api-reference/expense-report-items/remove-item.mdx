---
title: "Remove Item from Report"
description: "Remove an expense from an expense report"
api: "DELETE https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/{reportId}/expenses/{expenseId}"
---

## Overview

Remove an expense from an expense report. The expense itself is not deleted -- it is simply detached from the report and can be added to a different report.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

<ParamField path="reportId" type="integer" required>
  The unique identifier of the expense report
</ParamField>

<ParamField path="expenseId" type="integer" required>
  The unique identifier of the expense to remove
</ParamField>

## Response

Returns a `200 OK` status on successful removal.

<ResponseField name="message" type="string">
  Confirmation message
</ResponseField>

<Warning>
  You can only remove expenses from reports that are in `draft` status. Submitted or approved reports cannot be modified.
</Warning>

<RequestExample>

```bash cURL
curl --request DELETE \
  --url https://api.smartbills.io/v1/businesses/456/expense-reports/789/expenses/12345 \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
await client.expenseReportExpenses.remove(789, 12345);
```

```python Python
client.expense_report_expenses.remove(report_id=789, expense_id=12345)
```

```csharp C#
await client.ExpenseReportExpenses.RemoveAsync(789, 12345);
```

</RequestExample>

<ResponseExample>

```json Response
{
  "message": "Expense removed from report successfully"
}
```

</ResponseExample>

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 400 | REPORT_NOT_DRAFT | Report is not in draft status |
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions |
| 404 | EXPENSE_NOT_IN_REPORT | Expense is not part of this report |
| 404 | REPORT_NOT_FOUND | Report does not exist |
