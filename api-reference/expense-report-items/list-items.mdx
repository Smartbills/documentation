---
title: "List Report Items"
description: "List all expenses in an expense report"
api: "GET https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/{reportId}/expenses"
---

## Overview

Retrieve all expenses that have been added to a specific expense report. The response includes each expense's allocated amount, exchange rate, and category assignment within the report context.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Path Parameters

<ParamField path="businessId" type="integer" required>
  The unique identifier of the business
</ParamField>

<ParamField path="reportId" type="integer" required>
  The unique identifier of the expense report
</ParamField>

## Response

<ResponseField name="data" type="array">
  Array of expense report item objects

  <Expandable title="Expense Report Item Object">
    <ResponseField name="id" type="integer">
      Unique identifier for the report item entry
    </ResponseField>

    <ResponseField name="expenseId" type="integer">
      ID of the linked expense
    </ResponseField>

    <ResponseField name="reportId" type="integer">
      ID of the parent expense report
    </ResponseField>

    <ResponseField name="allocatedAmount" type="number">
      Amount allocated to this report (may differ from the original expense amount for split expenses)
    </ResponseField>

    <ResponseField name="exchangeRate" type="number">
      Exchange rate applied when the expense currency differs from the report currency
    </ResponseField>

    <ResponseField name="categoryId" type="integer">
      Category ID assigned to this expense within the report
    </ResponseField>

    <ResponseField name="notes" type="string">
      Notes specific to this expense within the report
    </ResponseField>

    <ResponseField name="expense" type="object">
      The full expense object
      <Expandable title="Expense Object">
        <ResponseField name="id" type="integer">
          Expense ID
        </ResponseField>
        <ResponseField name="merchant" type="string">
          Merchant name
        </ResponseField>
        <ResponseField name="amount" type="number">
          Original expense amount
        </ResponseField>
        <ResponseField name="currency" type="string">
          ISO 4217 currency code
        </ResponseField>
        <ResponseField name="date" type="string">
          Transaction date (YYYY-MM-DD)
        </ResponseField>
        <ResponseField name="status" type="string">
          Expense status
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="createdAt" type="string">
      Timestamp when the item was added to the report (ISO 8601)
    </ResponseField>

    <ResponseField name="updatedAt" type="string">
      Timestamp of last update (ISO 8601)
    </ResponseField>
  </Expandable>
</ResponseField>

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions for this business |
| 404 | REPORT_NOT_FOUND | Expense report does not exist |
