## Overview

Create a new merchant to track receipts and transactions. A merchant represents a business entity that issues receipts to customers.

<Info>
  **Core Principle**: A merchant should be unique by website. Avoid creating duplicate merchants for the same business.
</Info>

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Required Scopes

- `merchants.write`

## Request Body

<ParamField body="name" type="string" required>
  Name of the merchant
</ParamField>

<ParamField body="website" type="string" required>
  Website URL of the merchant (must be unique)
</ParamField>

<ParamField body="currency" type="string" required>
  Three-letter ISO currency code (e.g., USD, CAD, EUR)
</ParamField>

<ParamField body="timezone" type="string" required>
  Timezone of the merchant (e.g., "America/New_York", "Europe/London")
</ParamField>

<ParamField body="phoneNumber" type="string" required>
  Phone number of the merchant
</ParamField>

<ParamField body="locale" type="string" required>
  Locale code (e.g., "en-US", "fr-CA")
</ParamField>

<ParamField body="logo" type="string">
  URL of the merchant's logo image
</ParamField>

<ParamField body="address" type="object" required>
  Physical address of the merchant
  
  <Expandable title="Address Object">
    <ParamField body="line1" type="string" required>
      First line of the address
    </ParamField>
    
    <ParamField body="line2" type="string">
      Second line of the address (optional)
    </ParamField>
    
    <ParamField body="city" type="string" required>
      City name
    </ParamField>
    
    <ParamField body="state" type="string" required>
      State or province name
    </ParamField>
    
    <ParamField body="stateCode" type="string" required>
      Two-letter state/province code
    </ParamField>
    
    <ParamField body="country" type="string" required>
      Country name
    </ParamField>
    
    <ParamField body="countryCode" type="string" required>
      Two-letter ISO country code
    </ParamField>
    
    <ParamField body="postalCode" type="string" required>
      Postal or ZIP code
    </ParamField>
    
    <ParamField body="location" type="object">
      Geographic coordinates
      
      <Expandable title="Location Object">
        <ParamField body="latitude" type="number" required>
          Latitude coordinate
        </ParamField>
        
        <ParamField body="longitude" type="number" required>
          Longitude coordinate
        </ParamField>
      </Expandable>
    </ParamField>
  </Expandable>
</ParamField>

| Status Code | Error Code | Description |
|------------|------------|-------------|

## Best Practices

<AccordionGroup>
  <Accordion title="Unique Websites" icon="globe">
    Ensure each merchant has a unique website URL. This prevents duplicate merchants and helps with data integrity.
    
    ```javascript
    // Good: Check if merchant exists first
    const existing = await client.merchants.list({ website: 'https://example.com' });
    if (existing.data.length === 0) {
      await client.merchants.create({ website: 'https://example.com', ... });
    }
    ```
  </Accordion>

  <Accordion title="Complete Address Information" icon="location-dot">
    Provide complete address information including coordinates for better mapping and location services.
  </Accordion>

  <Accordion title="Use Standard Formats" icon="check">
    - Use ISO currency codes (USD, CAD, EUR)
    - Use IANA timezone names (America/New_York)
    - Use ISO country codes (US, CA, GB)
    - Use standard locale codes (en-US, fr-CA)
  </Accordion>

  <Accordion title="Logo Images" icon="image">
    Provide high-quality logo images (PNG or SVG recommended). Ensure the URL is publicly accessible.
  </Accordion>
</AccordionGroup>
