## Overview

Permanently delete a merchant from your Smartbills account. This action cannot be undone.

<Warning>
  **Destructive Action**: Deleting a merchant is permanent and cannot be undone. Consider the impact on related receipts and transactions before proceeding.
</Warning>

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Required Scopes

- `merchants.write`

## Path Parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the merchant to delete
</ParamField>

## Response

Returns the deleted merchant object for confirmation.

<ResponseField name="id" type="integer">
  ID of the deleted merchant
</ResponseField>

<ResponseField name="name" type="string">
  Name of the deleted merchant
</ResponseField>

<ResponseField name="website" type="string">
  Website of the deleted merchant
</ResponseField>

<ResponseField name="deletedAt" type="string">
  ISO 8601 timestamp of when the merchant was deleted
</ResponseField>

## Important Considerations

<AccordionGroup>
  <Accordion title="Impact on Receipts" icon="receipt">
    Before deleting a merchant, consider what happens to associated receipts:
    
    - **Option 1**: Delete all associated receipts first
    - **Option 2**: Reassign receipts to another merchant
    - **Option 3**: Archive the merchant instead of deleting (if supported)
    
    ```javascript
    // Check for receipts before deleting
    const receipts = await client.receipts.list({ merchantId: 12345 });
    
    if (receipts.data.length > 0) {
      console.warn(`Merchant has ${receipts.data.length} receipts`);
      // Handle receipts before deletion
    } else {
      await client.merchants.delete(12345);
    }
    ```
  </Accordion>

  <Accordion title="Soft Delete Alternative" icon="archive">
    Consider implementing a soft delete pattern by marking merchants as inactive instead of permanently deleting them:
    
    ```javascript
    // Instead of deleting, mark as inactive
    await client.merchants.update(12345, {
      ...currentMerchant,
      metadata: {
        ...currentMerchant.metadata,
        status: 'inactive',
        deactivatedAt: new Date().toISOString()
      }
    });
    ```
  </Accordion>

  <Accordion title="Audit Trail" icon="clock-rotate-left">
    Log merchant deletions for audit purposes:
    
    ```javascript
    const merchant = await client.merchants.get(12345);
    
    // Log before deletion
    await logAuditEvent({
      action: 'merchant.delete',
      merchantId: merchant.id,
      merchantName: merchant.name,
      deletedBy: currentUser.id,
      timestamp: new Date().toISOString()
    });
    
    await client.merchants.delete(12345);
    ```
  </Accordion>

  <Accordion title="Confirmation Pattern" icon="triangle-exclamation">
    Always implement user confirmation before deletion:
    
    ```javascript
    async function deleteMerchantWithConfirmation(merchantId) {
      const merchant = await client.merchants.get(merchantId);
      
      const confirmed = await showConfirmDialog({
        title: 'Delete Merchant?',
        message: `Are you sure you want to delete "${merchant.name}"? This action cannot be undone.`,
        confirmText: 'Delete',
        cancelText: 'Cancel',
        type: 'destructive'
      });
      
      if (confirmed) {
        await client.merchants.delete(merchantId);
      }
    }
    ```
  </Accordion>
</AccordionGroup>

## Deletion Workflow Example

Here's a complete example of a safe deletion workflow:

```javascript
async function safeMerchantDeletion(merchantId) {
  try {
    // 1. Fetch merchant details
    const merchant = await client.merchants.get(merchantId);
    console.log(`Preparing to delete: ${merchant.name}`);
    
    // 2. Check for dependencies
    const receipts = await client.receipts.list({ 
      merchantId,
      pageSize: 1 
    });
    
    if (receipts.metadata.count > 0) {
      throw new Error(
        `Cannot delete merchant. ${receipts.metadata.count} receipts found. ` +
        `Please delete or reassign receipts first.`
      );
    }
    
    // 3. Confirm with user
    const confirmed = confirm(
      `Delete "${merchant.name}"? This cannot be undone.`
    );
    
    if (!confirmed) {
      console.log('Deletion cancelled');
      return null;
    }
    
    // 4. Perform deletion
    const deleted = await client.merchants.delete(merchantId);
    
    // 5. Log for audit
    console.log(`Successfully deleted merchant ${merchantId} at ${deleted.deletedAt}`);
    
    return deleted;
    
  } catch (error) {
    console.error('Failed to delete merchant:', error.message);
    throw error;
  }
}

// Usage
await safeMerchantDeletion(12345);
```
