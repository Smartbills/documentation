## Overview

Retrieve a list of all merchants in your account with pagination, sorting, and filtering options.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Required Scopes

- `merchants.read`

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number for pagination (starts at 1)
</ParamField>

<ParamField query="pageSize" type="integer" default="100">
  Number of items per page (max: 100)
</ParamField>

<ParamField query="orderBy" type="string" default="createdAt">
  Field to sort by. Options: `id`, `name`, `createdAt`, `updatedAt`
</ParamField>

<ParamField query="sortOrder" type="string" default="desc">
  Sort order. Options: `asc`, `desc`
</ParamField>

<ParamField query="search" type="string">
  Search merchants by name or website
</ParamField>

<ParamField query="currency" type="string">
  Filter by currency code (e.g., USD, CAD, EUR)
</ParamField>

## Filtering and Searching

### Search by Name or Website

```bash
GET /v1/merchants?search=coffee
```

This will return all merchants where the name or website contains "coffee".

### Filter by Currency

```bash
GET /v1/merchants?currency=USD
```

### Combine Filters

```bash
GET /v1/merchants?currency=USD&orderBy=name&sortOrder=asc&pageSize=50
```

## Pagination Example

To fetch all merchants, iterate through pages:

```javascript
async function getAllMerchants() {
  const allMerchants = [];
  let page = 1;
  let hasMore = true;
  
  while (hasMore) {
    const response = await client.merchants.list({ page, pageSize: 100 });
    allMerchants.push(...response.data);
    
    hasMore = page < response.metadata.totalPages;
    page++;
  }
  
  return allMerchants;
}
```

## Best Practices

<AccordionGroup>
  <Accordion title="Use Pagination" icon="list">
    Always use pagination for better performance. Don't request more than you need.
    
    ```javascript
    // Good: Reasonable page size
    const merchants = await client.merchants.list({ pageSize: 50 });
    
    // Avoid: Requesting maximum every time
    const merchants = await client.merchants.list({ pageSize: 100 });
    ```
  </Accordion>

  <Accordion title="Cache Results" icon="database">
    Cache merchant data when appropriate to reduce API calls. Merchants don't change frequently.
  </Accordion>

  <Accordion title="Use Search Efficiently" icon="magnifying-glass">
    Use the search parameter to filter results server-side rather than fetching all and filtering client-side.
  </Accordion>
</AccordionGroup>
