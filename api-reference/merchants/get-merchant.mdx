---
title: "Get Merchant"
api: "GET https://api.smartbills.io/v1/merchants/{id}"
description: "Retrieve a merchant by ID"
---

## Overview

Retrieve detailed information about a specific merchant using its unique identifier.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Required Scopes

- `merchants.read`

## Path Parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the merchant to retrieve
</ParamField>

## Response

<ResponseField name="id" type="integer">
  Unique identifier for the merchant
</ResponseField>

<ResponseField name="name" type="string">
  Name of the merchant
</ResponseField>

<ResponseField name="slug" type="string">
  URL-friendly slug generated from the merchant name
</ResponseField>

<ResponseField name="website" type="string">
  Website URL of the merchant
</ResponseField>

<ResponseField name="currency" type="string">

<ResponseField name="logo" type="string">

    <ResponseField name="country" type="string">

<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.smartbills.io/v1/merchants/12345 \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: 'YOUR_API_KEY' });

const merchant = await client.merchants.get(12345);

```

```python Python

```

var client = new SBClient("YOUR_API_KEY");

## Error Responses

| Status Code | Error Code | Description |
|------------|------------|-------------|
| 401 | UNAUTHORIZED | Missing or invalid API key |
| 403 | FORBIDDEN | Insufficient permissions (missing `merchants.read` scope) |
| 404 | NOT_FOUND | Merchant with the specified ID does not exist |
| 429 | RATE_LIMIT_EXCEEDED | Too many requests |
