---
title: "Update Merchant"
api: "PUT https://api.smartbills.io/v1/merchants/{id}"
description: "Update an existing merchant's information"
---

## Overview

Update the details of an existing merchant. All fields in the request body will replace the existing values.

## Authentication

<ParamField header="Authorization" type="string" required>
  Bearer token for authentication. Format: `Bearer YOUR_API_KEY`
</ParamField>

## Required Scopes

- `merchants.write`

## Path Parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the merchant to update
</ParamField>

## Request Body

<ParamField body="name" type="string" required>
  Name of the merchant
</ParamField>

<ParamField body="website" type="string" required>
  Website URL of the merchant (must be unique)
</ParamField>

<ParamField body="currency" type="string" required>
  Three-letter ISO currency code
</ParamField>

<ParamField body="timezone" type="string" required>
  IANA timezone identifier
</ParamField>

<ParamField body="phoneNumber" type="string" required>
  Phone number of the merchant
</ParamField>

<ParamField body="locale" type="string" required>
  Locale code (e.g., "en-US", "fr-CA")
</ParamField>

<ParamField body="logo" type="string">
  URL of the merchant's logo image
</ParamField>

<ParamField body="address" type="object" required>
  Physical address of the merchant (complete address object required)
</ParamField>

## Important Notes

<Warning>
  **Full Replacement**: The update operation replaces all fields. Make sure to include all required fields in your request, even if you're only changing one field.
</Warning>

<Info>
  **Slug Updates**: The slug is automatically regenerated based on the new name if the name changes.
</Info>

## Best Practices

<AccordionGroup>
  <Accordion title="Fetch Before Update" icon="arrows-rotate">
    Always fetch the current merchant data before updating to ensure you don't accidentally overwrite fields.
    
    ```javascript
    // Good: Fetch first, then update
    const current = await client.merchants.get(12345);
    const updated = await client.merchants.update(12345, {
      ...current,
      name: "New Name"  // Only change what you need
    });
    ```
  </Accordion>

  <Accordion title="Validate Website Uniqueness" icon="globe">
    If changing the website URL, ensure it's not already used by another merchant to avoid 409 errors.
  </Accordion>

  <Accordion title="Handle Concurrent Updates" icon="users">
    Implement optimistic locking or version checking if multiple users might update the same merchant.
  </Accordion>
</AccordionGroup>
