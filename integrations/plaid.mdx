## Overview

Use Plaid to securely connect employee bank accounts and corporate cards for automatic transaction import and expense matching.

## Features

| Feature | Description |
|---------|-------------|
| **Bank Connection** | Link checking/savings accounts |
| **Card Linking** | Connect credit/debit cards |
| **Auto-import** | Import transactions automatically |
| **Matching** | Match transactions to expenses |
| **Balance Check** | View account balances |

## Setup

### Connect Bank Account

<Steps>
  <Step title="Navigate to Banking">
    Go to **Settings > Banking** in Smartbills
  </Step>
  <Step title="Add Account">
    Click **Connect Bank Account**
  </Step>
  <Step title="Select Bank">
    Search and select your bank
  </Step>
  <Step title="Authenticate">
    Log in to your bank securely via Plaid
  </Step>
  <Step title="Select Accounts">
    Choose accounts to connect
  </Step>
</Steps>

## Configuration

### Transaction Import

| Setting | Options |
|---------|---------|
| Frequency | Real-time, Daily, Manual |
| History | 30, 60, 90 days |
| Categories | Filter by merchant category |

### Matching Rules

Automatically match transactions to expenses:

- Same amount and date
- Similar merchant name
- Within time window

## Security

### How Plaid Works

- Smartbills never sees your bank credentials
- Data encrypted end-to-end
- Bank-level security
- You control access

### Permissions

Smartbills can only:

- View transaction history
- View account balances
- Cannot move money

## Supported Banks

Plaid supports 11,000+ financial institutions including:

- Major banks (Chase, Bank of America, Wells Fargo)
- Credit unions
- Online banks
- Credit cards
