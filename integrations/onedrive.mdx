## Overview

Connect OneDrive to automatically archive expense receipts and documents to your Microsoft cloud storage.

## Features

| Feature | Description |
|---------|-------------|
| **Two-way Sync** | Import receipts from OneDrive and export from Smartbills |
| **Folder Selection** | Choose specific folders for import and export |
| **Custom Export Paths** | Template-based folder paths for exports |
| **Auto-sync** | Automatic receipt backup |
| **SharePoint** | Support for SharePoint sites |
| **Organization** | Structured folder hierarchy |
| **Per-Employee Folders** | Each employee can connect their own OneDrive |
| **Business Folders** | Admin-configured shared folders for the whole business |
| **Delta Sync** | Microsoft Graph delta API for efficient change detection |

## Setup

### Connect OneDrive

<Steps>
  <Step title="Navigate to Apps">
    Go to **Settings > Apps** in Smartbills
  </Step>
  <Step title="Find OneDrive">
    Search for OneDrive in the marketplace
  </Step>
  <Step title="Sign In">
    Sign in with Microsoft account
  </Step>
  <Step title="Grant Access">
    Authorize Smartbills access
  </Step>
  <Step title="Select Folder">
    Choose destination folder
  </Step>
</Steps>

## Configuration

### Folder Configuration

Add folders for import, export, or both:

| Direction | Description |
|-----------|-------------|
| **Import** | Watch folder for new receipt files to import into Smartbills |
| **Export** | Export Smartbills receipts to this folder |
| **Both** | Two-way sync - import new files and export receipts |

### Export Path Templates

Customize where exported receipts are saved:

| Variable | Description | Example |
|----------|-------------|---------|
| `{{year}}` | Current year | 2026 |
| `{{month}}` | Current month | 03 |
| `{{day}}` | Current day | 15 |
| `{{vendor}}` | Vendor name | Starbucks |
| `{{category}}` | Expense category | Travel |

### Folder Options

| Type | Description |
|------|-------------|
| Personal OneDrive | Your personal storage |
| OneDrive for Business | Company storage |
| SharePoint | Team site document library |

### Folder Structure

```
Smartbills Receipts/
├── 2026/
│   ├── Q1/
│   │   ├── January/
│   │   ├── February/
│   │   └── March/
│   └── Q2/
```
