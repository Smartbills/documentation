## Overview

Integrate with Stripe to process expense reimbursements and reconcile corporate card transactions.

## Features

| Feature | Description |
|---------|-------------|
| **Reimbursement Processing** | Pay employees via Stripe |
| **Card Reconciliation** | Match Stripe Issuing transactions |
| **Payment Tracking** | Track reimbursement status |
| **Automatic Matching** | Link Stripe charges to expenses |

## Setup

### Connect Stripe

<Steps>
  <Step title="Navigate to Apps">
    Go to **Settings > Apps** in Smartbills
  </Step>
  <Step title="Find Stripe">
    Search for Stripe in the marketplace
  </Step>
  <Step title="Connect Account">
    Click Connect and sign in to Stripe
  </Step>
  <Step title="Configure">
    Set up payment preferences
  </Step>
</Steps>

## Reimbursement Configuration

### Payment Methods

| Method | Speed | Fees |
|--------|-------|------|
| ACH Transfer | 3-5 days | Free |
| Instant | Same day | Fee applies |
| Card | Immediate | Fee applies |

### Automatic Payments

Configure automatic reimbursement:

1. Report approved
2. Payment initiated
3. Employee receives funds
4. Status updated

## Card Reconciliation

### Stripe Issuing

If using Stripe corporate cards:

- Transactions import automatically
- Match to expense receipts
- Auto-categorization
- Real-time sync

## Best Practices

<Tip>
**Use ACH for cost savings** - ACH transfers have no fees.
</Tip>

<Tip>
**Enable auto-pay** - Reduce manual processing.
</Tip>
