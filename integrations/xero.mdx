## Overview

Integrate Smartbills with Xero to automatically export approved expenses and keep your accounting in sync.

## Features

| Feature | Description |
|---------|-------------|
| **Expense Export** | Export expenses to Xero as bills (ACCPAY invoices) |
| **Expense Reports** | Sync reports as manual journal entries |
| **Reimbursements** | Track reimbursement payments |
| **Account Mapping** | Map categories to Xero accounts |
| **Contact Sync** | Sync vendors as Xero contacts |
| **Tax Rate Mapping** | Map GST, HST, PST, QST, VAT tax codes |
| **Tracking Categories** | Use Xero tracking for departments |
| **Receipt Attachments** | Attach receipt images to invoices |
| **Bidirectional Sync** | Import and export data both ways |

## Setup

### Prerequisites

- Xero account with Standard or Premium plan
- Smartbills Business plan or higher
- Admin access to both systems

### Connect Xero

<Steps>
  <Step title="Navigate to Apps">
    Go to **Settings > Apps** in Smartbills
  </Step>
  <Step title="Find Xero">
    Search for Xero in the marketplace
  </Step>
  <Step title="Click Connect">
    Click the **Connect** button
  </Step>
  <Step title="Authorize">
    Sign in to Xero and authorize access
  </Step>
  <Step title="Select Organization">
    Choose the Xero organization to connect
  </Step>
  <Step title="Configure">
    Set up account mapping
  </Step>
</Steps>

## Configuration

### Account Mapping

Map expense categories to Xero accounts:

| Smartbills | Xero Account |
|------------|--------------|
| Travel | 493 - Travel |
| Meals | 497 - Entertainment |
| Office | 473 - Office Expenses |

### Tax Mapping

| Smartbills | Xero Tax Rate |
|------------|---------------|
| Standard | GST on Expenses |
| Zero-rated | No GST |
| Exempt | BAS Excluded |

### Tracking Categories

Use Xero tracking for cost centers:

| Smartbills Department | Xero Tracking |
|-----------------------|---------------|
| Engineering | Engineering |
| Sales | Sales & Marketing |

## Sync Behavior

### What Gets Synced

| Smartbills Entity | Xero Entity |
|-------------------|-------------|
| Business Expense | Invoice (ACCPAY) |
| Expense Report | Manual Journal |
| Reimbursement | Payment |
| Vendor | Contact |
| Receipt | Attachment |

### Double-Entry Bookkeeping

Expense reports create proper manual journal entries:

| Debit | Credit |
|-------|--------|
| Expense Account (per line) | Accounts Payable |
| Tax Account (if applicable) | - |

### Sync Timing

| Trigger | Description |
|---------|-------------|
| On Approval | Automatically when approved |
| On Reimbursement | When payment is processed |
| Manual | Trigger from integration settings |
| Initial Sync | Full sync on first connection |

### Webhook Events

| Event | Action |
|-------|--------|
| `InvoiceCreated` | Import new expense from Xero |
| `InvoiceUpdated` | Update synced expense |
| `ContactCreated` | Import new vendor |

## Troubleshooting

### Common Issues

| Issue | Solution |
|-------|----------|
| Connection lost | Reconnect Xero |
| Wrong organization | Check selected org |
| Missing account | Update mapping |
