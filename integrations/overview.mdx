## How Integrations Work

### Connection Flow

<Steps>
  <Step title="Browse">
    Find the integration in the Apps marketplace
  </Step>
  <Step title="Connect">
    Authorize Smartbills to access the service
  </Step>
  <Step title="Configure">
    Set up mapping and sync preferences
  </Step>
  <Step title="Sync">
    Data flows automatically between systems
  </Step>
</Steps>

### Authorization Types

| Type | Security | Use Case |
|------|----------|----------|
| OAuth 2.0 | High | Most integrations |
| API Key | Medium | Developer tools |
| Webhook | Varies | Event notifications |

## Managing Integrations

### View Connected Apps

1. Go to **Settings > Apps**
2. See all connected integrations
3. View status and last sync time

### Configure Integration

1. Click on the integration
2. Adjust settings
3. Configure mapping
4. Test connection

### Disconnect Integration

1. Go to **Settings > Apps**
2. Click on the integration
3. Click **Disconnect**
4. Confirm disconnection

## Data Sync

### Sync Direction

| Direction | Description |
|-----------|-------------|
| One-way (import) | Data comes into Smartbills |
| One-way (export) | Data goes out to other app |
| Two-way | Bidirectional sync |

### Sync Frequency

| Type | Timing |
|------|--------|
| Real-time | Instant via webhooks |
| Scheduled | Every 15 min, hourly, daily |
| Manual | On-demand sync |

## Troubleshooting

### Connection Issues

| Issue | Solution |
|-------|----------|
| Authorization expired | Reconnect the integration |
| Sync failed | Check credentials, retry |
| Data mismatch | Review mapping settings |

- Check integration-specific documentation
- Contact Smartbills support
