## Overview

Connect Google Drive to automatically backup all your expense receipts and documents to your preferred Google Drive folder.

## Features

| Feature | Description |
|---------|-------------|
| **Two-way Sync** | Import receipts from Drive and export from Smartbills |
| **Folder Selection** | Choose specific folders for import and export |
| **Custom Export Paths** | Template-based folder paths for exports |
| **Auto-backup** | Automatic receipt archival |
| **Folder Organization** | Organize by date/category/vendor |
| **Shared Drives** | Support for team drives |
| **Per-Employee Folders** | Each employee can connect their own Drive |
| **Business Folders** | Admin-configured shared folders for the whole business |
| **Change Detection** | Webhooks detect new files in watched folders |

## Setup

### Connect Google Drive

<Steps>
  <Step title="Navigate to Apps">
    Go to **Settings > Apps** in Smartbills
  </Step>
  <Step title="Find Google Drive">
    Search for Google Drive in the marketplace
  </Step>
  <Step title="Sign In">
    Sign in with your Google account
  </Step>
  <Step title="Grant Access">
    Allow Smartbills to access Drive
  </Step>
  <Step title="Select Folder">
    Choose or create destination folder
  </Step>
</Steps>

## Configuration

### Folder Configuration

Add folders for import, export, or both:

| Direction | Description |
|-----------|-------------|
| **Import** | Watch folder for new receipt files to import into Smartbills |
| **Export** | Export Smartbills receipts to this folder |
| **Both** | Two-way sync - import new files and export receipts |

### Export Path Templates

Customize where exported receipts are saved using template variables:

| Variable | Description | Example |
|----------|-------------|---------|
| `{{year}}` | Current year | 2026 |
| `{{month}}` | Current month | 03 |
| `{{day}}` | Current day | 15 |
| `{{vendor}}` | Vendor name | Starbucks |
| `{{category}}` | Expense category | Travel |

Example path: `/Receipts/{{year}}/{{month}}/{{vendor}}_{{day}}.pdf`

### Folder Structure

Choose how exported files are organized:

| Structure | Example |
|-----------|---------|
| By Year/Month | `2026/03/receipt.jpg` |
| By Category | `Travel/receipt.jpg` |
| By Employee | `John Smith/receipt.jpg` |
| Flat | `receipt_12345.jpg` |

### File Naming

| Template | Result |
|----------|--------|
| `{date}_{merchant}` | `2026-03-15_Starbucks.jpg` |
| `{id}_{amount}` | `12345_$45.99.jpg` |
| `{category}_{merchant}_{date}` | `Travel_United_2026-03-15.jpg` |

## Sync Behavior

### When Files Upload

| Trigger | Timing |
|---------|--------|
| On expense creation | Immediately |
| On report approval | Batch upload |
| Scheduled | Daily at midnight |

### File Types

All receipt formats supported:

- Images (JPEG, PNG, HEIC)
- PDFs
- Documents

## Shared Drives

### Using Team Drives

1. Select Shared Drive during setup
2. Choose team folder
3. All team receipts sync to shared location

### Permissions

Smartbills needs:

- View files
- Create files
- Edit file metadata

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Files not uploading | Check Drive storage space |
| Permission denied | Re-authorize connection |
| Wrong folder | Update folder settings |
