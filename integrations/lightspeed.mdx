## Overview

Integrate with Lightspeed Retail or Restaurant to sync sales, inventory, and customer data.

## Supported Versions

| Product | Status |
|---------|--------|
| Lightspeed Retail (X-Series) | Supported |
| Lightspeed Retail (R-Series) | Supported |
| Lightspeed Restaurant | Coming Soon |

## Features

| Feature | Description |
|---------|-------------|
| **Sales Sync** | Import transactions |
| **Inventory** | Sync product catalog |
| **Customers** | Link customer data |
| **Multi-location** | All locations supported |
| **Registers** | Track by register |

## Setup

### Connect Lightspeed

<Steps>
  <Step title="Navigate to Apps">
    Go to **Settings > Apps** in Smartbills
  </Step>
  <Step title="Find Lightspeed">
    Search for Lightspeed in the marketplace
  </Step>
  <Step title="Select Product">
    Choose Retail or Restaurant
  </Step>
  <Step title="Authorize">
    Sign in to Lightspeed
  </Step>
  <Step title="Configure">
    Map locations and products
  </Step>
</Steps>

## Configuration

### Location Mapping

Map Lightspeed outlets to Smartbills locations for multi-location businesses.

### Product Sync

| Option | Description |
|--------|-------------|
| Full sync | Import all products |
| Selected categories | Sync specific categories |
| Manual | Map individually |

## Sync Behavior

### Data Flow

- Sales imported in real-time
- Inventory levels updated
- Customer profiles synced

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Connection issues | Re-authorize |
| Missing sales | Check date range |
| Products not syncing | Refresh catalog |
