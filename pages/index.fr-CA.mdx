# API Smartbills
Bienvenue dans la documentation de l'API Smartbills. Smartbills est une plateforme en ligne puissante permettant aux utilisateurs de recevoir leurs factures dans un seul compte en ligne.

L'API Smartbills est organisée autour de REST. Notre API dispose d'URL prévisibles orientées ressources, accepte les corps de requête codés sous forme de formulaire, renvoie des réponses codées JSON et utilise des codes de réponse HTTP, une authentification et des verbes standard.

Vous pouvez utiliser l'API Smartbills en mode test, ce qui n'affecte pas vos données de production. L'url que vous utilisez détermine si la demande est en mode production ou en mode test. Pour en savoir plus sur les différents environnements disponible, référez-vous à notre documentation sur les [environnements](/environments).
