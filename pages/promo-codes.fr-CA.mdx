# Codes Promo
Cet objet représente un code promo dans votre système. Utilisez-le pour gérer les réductions et les promotions.

`promo-codes.read`
`promo-codes.write`

## Principes de base

Un code promo doit être unique par son code.

## SBPromoCode

## Créer un code promo
Créer un nouveau code promo. Nécessite la portée `promo-codes.write`

`POST https://api.smartbills.io/v1/promo-codes`

#### Corps de la requête 
Nécessite un corps de type `PromoCodeCreateRequest`
| Paramètre  | Description | Type  | Requis |
|---|---|---|---|
| `name` | Nom du code promo | `string`  |  `requis` |
| `amount` | Montant du code promo | [`SBMoney`](/SBMoney)   |  `requis` |
| `percentage` | Pourcentage de réduction du code promo | `number`  |  `optionnel` |
| `type` | Type du code promo | `SBPromoCodeType`  |  `requis` |
| `isActive` | Si le code promo est actif | `boolean`  |  `requis` |

```json copy filename="PromoCodeCreateRequest"
{
  "name": "ETE21",
  "percentage": 20,
  "type": "percentage",
  "isActive": true
}
```

#### Réponse
Retourne un `SBPromoCodeResponse`
```json copy filename="SBPromoCodeResponse"
{
  "id": 0,
  "name": "ETE21",
  "type": "percentage",
  "percentage": 20,
  "createdAt": "2025-01-21T00:56:42.273Z",
  "updatedAt": "2025-01-21T00:56:42.273Z"
}
```

#### Exemple de code
 
<Tabs items={['JS', '.NET']}> 
    <Tabs.Tab>
	```js copy
	import { SBClient, SBPromoCode, PromoCodeCreateRequest } from "@smartbills/sdk"
	
	const client = new SBClient();
	const request = {
		"name": "ETE21",
		"percentage": 20,
		"type": "percentage",
		"isActive": true
	};

	const promoCode = await client.promoCodes.create(request);
	```
  </Tabs.Tab>
    <Tabs.Tab>


## Récupérer un code promo
Récupérer un code promo par ID. Nécessite la portée `promo-codes.read`

`GET https://api.smartbills.io/v1/promo-codes/:id`

#### Paramètres de chemin 

| Paramètre  | Description | Type  | Requis |
|---|---|---|---|
| `id` | ID du code promo à récupérer | `long`  |  `requis` |

#### Réponse
Retourne un `SBPromoCodeResponse`
```json copy filename="SBPromoCodeResponse"
{
  "id": 0,
  "name": "ETE21",
  "type": "amount",
  "amount": {
    "currency": "USD",
    "amount": 20
  },
  "createdAt": "2025-01-21T00:56:42.273Z",
  "updatedAt": "2025-01-21T00:56:42.273Z"
}
```

#### Exemple de code
 
<Tabs items={['JS', '.NET']}> 
    <Tabs.Tab>
	```js copy
	import { SBClient, SBPromoCode } from "@smartbills/sdk"
	
	const client = new SBClient();
	const promoCode = await client.promoCodes.getByIdAsync(1);
	```
  </Tabs.Tab>
</Tabs>

## Lister les codes promo
Récupérer une liste de codes promo. Nécessite la portée `promo-codes.read`

`GET https://api.smartbills.io/v1/promo-codes?page=1&pageSize=100`

#### Paramètres de requête 
Nécessite des paramètres de requête de type `PromoCodeListRequest`
| Paramètre  | Description | Type  | Requis | Par défaut|
|---|---|---|---|---|
| `page` | Page actuelle | `long`  |  `requis` | 1|
| `pageSize` | Nombre d'enregistrements à retourner | `long`  |  `requis` | 100|
| `orderBy` | Trier les résultats par une clé de SBPromoCode | `keyof SBPromoCode`  ||`createdAt` |
| `sortOrder` | Ordre du tri  | `asc` ou `desc`  || `desc`|

```json copy filename="PromoCodeListRequest"
{
    "page": 1,
    "pageSize": 100,
	"orderBy": "createdAt",
	"sortOrder": "desc",
}
```

#### Réponse
Retourne un `SBPromoCodeResponseSBList`
```json copy filename="SBPromoCodeResponseSBList"
{
    "data": [{
        "id": 0,
        "name": "ETE21",
        "type": "percentage",
        "percentage": 20,
        "createdAt": "2025-01-21T00:56:42.273Z",
        "updatedAt": "2025-01-21T00:56:42.273Z"
    }],
    "metadata": {
        "page": 1,
        "pageSize": 100,
        "totalPages": 1,
        "count": 1
    }
}
```

#### Exemple de code
 
<Tabs items={['JS', '.NET']}> 
    <Tabs.Tab>
	```js copy
	import { SBClient, SBPromoCode, SBList, PromoCodeListRequest } from "@smartbills/sdk"
	
	const client = new SBClient();
	const request = {
		"page": 1,
		"pageSize": 100,
		"orderBy": "createdAt",
		"sortOrder": "desc",
	};

	const promoCodes = await client.promoCodes.list(request);
	```
  </Tabs.Tab>
</Tabs>
