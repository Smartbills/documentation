# API Taxes
## Core principles
This object represents a tax applicable to your transactions. Use it to define and manage taxes to apply to products or services in your system.

## Scopes
`taxes.read`
`taxes.write`

## Create a tax
Allows you to create a tax in your system. Requires scope `taxes.write`.
<Tabs items={['HTTP']}>
  <Tabs.Tab>
`POST` `https://api.smartbills.io/v1/taxes`
  </Tabs.Tab>
</Tabs>

### Request
#### Request Body
You must provide a request body of type `TaxCreateRequest`.

| Parameter       | Description                              | Type        | Required    |
|-----------------|------------------------------------------|-------------|-------------|
| `name`          | Name of the tax                          | `string`    | `required`  |
| `rate`          | Tax rate in percentage                   | `decimal`   | `required`  |
| `description`   | Description of the tax                   | `string`    | `optional`  |

### Response

#### Response Body

[SBTax](/SBTax)

#### HTTP Status Codes
| Code  | Description                                  |
|-------|----------------------------------------------|
| `201` | The tax was successfully created             |
| `400` | The request sent is not valid                |

#### Code example

<Tabs items={['JS', '.NET']}>
  <Tabs.Tab>
  ```js copy
  import { SBClient, SBTax, TaxCreateRequest } from "@smartbills/sdk"
  
  const client = new SBClient();
  const request = {
    "name": "VAT",
    "rate": 15.0,
    "description": "Value Added Tax"
  };

  const tax = await client.taxes.create(request);
  ```
  </Tabs.Tab>
  <Tabs.Tab>
  ```c# copy
  using Smartbills.NET;
  
  var client = new SBClient();
  var request = new TaxCreateRequest
  {
    Name = "VAT",
    Rate = 15.0,
    Description = "Value Added Tax"
  };

  var tax = await client.Taxes.CreateAsync(request);
  ```
  </Tabs.Tab>
</Tabs>

## Retrieve a tax
Retrieve information about a tax in the system. Requires scope `taxes.read`.
<Tabs items={['HTTP']}>
  <Tabs.Tab>
`GET` `https://api.smartbills.io/v1/taxes/:id`
  </Tabs.Tab>
</Tabs>

### Path Parameter
| Parameter  | Description                                | Type      | Required    |
|------------|--------------------------------------------|-----------|-------------|
| `id`       | Unique identifier of the tax               | `long`    | `required`  |

### Response
[SBTax](/SBTax)

#### Code example

<Tabs items={['JS', '.NET']}>
  <Tabs.Tab>
  ```js copy
  import { SBClient, SBTax } from "@smartbills/sdk"
  
  const client = new SBClient();
  const tax = await client.taxes.getByIdAsync(1);
  ```
  </Tabs.Tab>
  <Tabs.Tab>
  ```c# copy
  using Smartbills.NET;
  
  var client = new SBClient();
  var tax = await client.Taxes.GetByIdAsync(1);
  ```
  </Tabs.Tab>
</Tabs>

## Retrieve a list of taxes
Retrieve a list of taxes registered in the system. Requires scope `taxes.read`.
<Tabs items={['HTTP']}>
  <Tabs.Tab>
`GET` `https://api.smartbills.io/v1/taxes`
  </Tabs.Tab>
</Tabs>

### Query Parameters
[`SBListRequest`](/pagination)
| Parameter   | Description                          | Type      | Required    |
|-------------|--------------------------------------|-----------|-------------|
| `page`      | Page number                          | `long`    | `required`  |
| `pageSize`  | Number of records to return          | `long`    | `required`  |

### Response
[SBTax](/SBTax)

#### Code example

<Tabs items={['JS', '.NET']}>
  <Tabs.Tab>
  ```js copy
  import { SBClient, SBTax, SBList, SBListRequest } from "@smartbills/sdk"
  
  const client = new SBClient();
  const request = {
    "page": 1,
    "pageSize": 100
  };

  const taxes = await client.taxes.list(request);
  ```
  </Tabs.Tab>
  <Tabs.Tab>
  ```c# copy
  using Smartbills.NET;
  
  var client = new SBClient();
  var request = new SBListRequest
  {
    Page = 1,
    PageSize = 100
  };

  var taxes = await client.Taxes.ListAsync(request);
  ```
  </Tabs.Tab>
</Tabs>

## Update a tax
Allows you to update information about a tax in the system. Requires scope `taxes.write`.
<Tabs items={['HTTP']}>
  <Tabs.Tab>
`PUT` `https://api.smartbills.io/v1/taxes/:id`
  </Tabs.Tab>
</Tabs>

### Path Parameter
| Parameter  | Description                                | Type      | Required    |
|------------|--------------------------------------------|-----------|-------------|
| `id`       | Unique identifier of the tax               | `long`    | `required`  |

### Request Body
You must provide a request body of type `TaxUpdateRequest`.

| Parameter       | Description                              | Type        | Required    |
|-----------------|------------------------------------------|-------------|-------------|
| `name`          | Name of the tax                          | `string`    | `required`  |
| `rate`          | Tax rate in percentage                   | `decimal`   | `required`  |
| `description`   | Description of the tax                   | `string`    | `optional`  |

### Response

#### HTTP Status Codes
| Code  | Description                                  |
|-------|----------------------------------------------|
| `200` | The tax was successfully updated             |
| `400` | The request sent is not valid                |
| `404` | No tax was found                             |

[SBTax](/SBTax)

#### Code example

<Tabs items={['JS', '.NET']}>
  <Tabs.Tab>
  ```js copy
  import { SBClient, SBTax, TaxUpdateRequest } from "@smartbills/sdk"
  
  const client = new SBClient();
  const request = {
    "name": "VAT Updated",
    "rate": 20.0,
    "description": "Updated Value Added Tax"
  };

  const tax = await client.taxes.updateAsync(1, request);
  ```
  </Tabs.Tab>
  <Tabs.Tab>
  ```c# copy
  using Smartbills.NET;
  
  var client = new SBClient();
  var request = new TaxUpdateRequest
  {
    Name = "VAT Updated",
    Rate = 20.0,
    Description = "Updated Value Added Tax"
  };

  var tax = await client.Taxes.UpdateAsync(1, request);
  ```
  </Tabs.Tab>
</Tabs>
