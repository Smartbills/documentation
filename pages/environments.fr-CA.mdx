# Environnements  
Smartbills offre plusieurs environnements enfin que vous puissez développer et tester vos applications avant de les déployer en production.

## Environnement Sandbox
L'environnement sandbox est un environnement identique à notre environnement de production, mais désigner spécifiquement pour tester les intégrations.

- `https://sandbox-api.smartbills.io/auth`

- `https://sandbox-api.smartbills.io`


## Environnement de production
Lorsque vous êtes en possession de vos clés de productions, vous pouvez modifier vos url pour les faires pointer vers ces addresses:

- `https://api.smartbills.io/auth`

- `https://api.smartbills.io`
