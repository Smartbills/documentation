## Erreurs
Smartbills utilise des codes de réponse HTTP conventionnels pour indiquer le succès ou l'échec d'une requête API. En général: les codes de la plage 2xx indiquent le succès. Les codes de la plage 4xx indiquent une erreur qui a échoué compte tenu des informations fournies (par exemple, un paramètre obligatoire a été omis, etc.). Les codes de l’ordre de 5xx indiquent une erreur avec les serveurs de Smartbills (ceux-ci sont rares).

Certaines erreurs 4xx qui pourraient être traitées par programme (par exemple, un mauvais résultat est refusé) incluent un code d'erreur qui explique brièvement l'erreur signalée.

## Code de status HTTP

| Paramètre  | Description|
|---|---|
| `400` | Vous nous avez envoyé une demande invalide. Lisez le corps de la réponse pour comprendre pourquoi votre demande a été refusée.
| `401` | Vous avez essayé d'accéder à une ressource API sans fournir d'authentification ou en fournissant une authentification non valide.
| `403` | Vous n'êtes pas autorisé à accéder à la ressource. Assurez-vous que votre jeton inclut les portées requises pour accéder à la ressource.
| `409` | Vous avez tenter de créé une nouvelle ressource, mais l'insertion de celle-ci causerait un conflict avec une données déjà présente dans la base de données.
| `500` | Erreur de serveur interne de notre côté. Veuillez nous contacter si vous avez rencontré cette erreur à support@smartbills.io


## SBException
Lorsque le serveur Smartbills retourne une erreur, un objet de type `SBException` est retourné. Cet objet contient les champs suivants:
| Paramètre  | Description| Type |
|---|---|---|
| `status` | Le status HTTP ci-dessus. | `number`
| `code` | Un code d'erreur associé au problème. | `string`
| `message` | Un message decrivant le problème. | `string`
| `errors` | Une liste d'erreurs associées au problème. Ce paramètre est souvent présent lors d'erreur de validation de la requête.| [`SBError[]`](#SBError)

## SBError
| Paramètre  | Description| Type |
|---|---|---|
| `code` | Un code d'erreur associé au problème. | `string`
| `message` | Un message decrivant le problème. | `string`
| `parameter` | Le chemin JSON, séparé par des points, vers la propriété causant le problème.| `string`
| `link` | Un lien d'aide vers la documentation de l'API.| `string`
