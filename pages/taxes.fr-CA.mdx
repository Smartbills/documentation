# API Taxes
## Principes de base
Cet objet représente une taxe applicable à vos transactions. Utilisez-le pour définir et gérer les taxes à appliquer aux produits ou services dans votre système.

## Portées
`taxes.read`
`taxes.write`

## Créer une taxe
Permet de créer une taxe dans votre système. Nécessite la portée `taxes.write`.
<Tabs items={['HTTP']}>
  <Tabs.Tab>
`POST` `https://api.smartbills.io/v1/taxes`
  </Tabs.Tab>
</Tabs>

### Requête
#### Corps de la requête
Vous devez fournir un corps de requête de type `TaxCreateRequest`.

| Attribut         | Descriptif                                | Type        | Obligatoire |
|------------------|-------------------------------------------|-------------|-------------|
| `name`           | Nom de la taxe                            | `string`    | `obligatoire`|
| `rate`           | Taux de la taxe en pourcentage            | `decimal`   | `obligatoire`|
| `description`    | Description de la taxe                    | `string`    | `facultatif` |

### Réponse

#### Corps de la réponse

[SBTax](/SBTax)

#### Code d'état HTTP
| Paramètre  | Description                                  |
|------------|----------------------------------------------|
| `201`      | La taxe a été créée avec succès              |
| `400`      | La requête envoyée n'est pas valide.         |

#### Exemple de code

<Tabs items={['JS', '.NET']}>
  <Tabs.Tab>
  ```js copy
  import { SBClient, SBTax, TaxCreateRequest } from "@smartbills/sdk"
  
  const client = new SBClient();
  const request = {
    "name": "TVA",
    "rate": 15.0,
    "description": "Taxe sur la valeur ajoutée"
  };

  const tax = await client.taxes.create(request);
  ```
  </Tabs.Tab>
  <Tabs.Tab>
  ```c# copy
  using Smartbills.NET;
  
  var client = new SBClient();
  var request = new TaxCreateRequest
  {
    Name = "TVA",
    Rate = 15.0,
    Description = "Taxe sur la valeur ajoutée"
  };

  var tax = await client.Taxes.CreateAsync(request);
  ```
  </Tabs.Tab>
</Tabs>

## Récupérer une taxe
Récupère les informations d'une taxe dans le système. Nécessite la portée `taxes.read`.
<Tabs items={['HTTP']}>
  <Tabs.Tab>
`GET` `https://api.smartbills.io/v1/taxes/:id`
  </Tabs.Tab>
</Tabs>

### Paramètre de route
| Attribut  | Descriptif                                | Type      | Obligatoire |
|-----------|-------------------------------------------|-----------|-------------|
| `id`      | Identifiant unique de la taxe             | `long`    | `obligatoire`|

### Réponse
[SBTax](/SBTax)

#### Exemple de code

<Tabs items={['JS', '.NET']}>
  <Tabs.Tab>
  ```js copy
  import { SBClient, SBTax } from "@smartbills/sdk"
  
  const client = new SBClient();
  const tax = await client.taxes.getByIdAsync(1);
  ```
  </Tabs.Tab>
  <Tabs.Tab>
  ```c# copy
  using Smartbills.NET;
  
  var client = new SBClient();
  var tax = await client.Taxes.GetByIdAsync(1);
  ```
  </Tabs.Tab>
</Tabs>

## Récupérer une liste de taxes
Récupère une liste de taxes enregistrées dans le système. Nécessite la portée `taxes.read`.
<Tabs items={['HTTP']}>
  <Tabs.Tab>
`GET` `https://api.smartbills.io/v1/taxes`
  </Tabs.Tab>
</Tabs>

### Paramètres de requête
[`SBListRequest`](/pagination)
| Attribut   | Descriptif                          | Type      | Obligatoire |
|------------|-------------------------------------|-----------|-------------|
| `page`     | Numéro de la page                   | `long`    | `obligatoire`|
| `pageSize` | Nombre d'enregistrements à retourner| `long`    | `obligatoire`|

### Réponse
[SBTax](/SBTax)

#### Exemple de code

<Tabs items={['JS', '.NET']}>
  <Tabs.Tab>
  ```js copy
  import { SBClient, SBTax, SBList, SBListRequest } from "@smartbills/sdk"
  
  const client = new SBClient();
  const request = {
    "page": 1,
    "pageSize": 100
  };

  const taxes = await client.taxes.list(request);
  ```
  </Tabs.Tab>
  <Tabs.Tab>
  ```c# copy
  using Smartbills.NET;
  
  var client = new SBClient();
  var request = new SBListRequest
  {
    Page = 1,
    PageSize = 100
  };

  var taxes = await client.Taxes.ListAsync(request);
  ```
  </Tabs.Tab>
</Tabs>

## Mettre à jour une taxe
Permet de mettre à jour les informations d'une taxe dans le système. Nécessite la portée `taxes.write`.
<Tabs items={['HTTP']}>
  <Tabs.Tab>
`PUT` `https://api.smartbills.io/v1/taxes/:id`
  </Tabs.Tab>
</Tabs>

### Paramètre de route
| Attribut  | Descriptif                                | Type      | Obligatoire |
|-----------|-------------------------------------------|-----------|-------------|
| `id`      | Identifiant unique de la taxe             | `long`    | `obligatoire`|

### Corps de la requête
Vous devez fournir un corps de requête de type `TaxUpdateRequest`.

| Attribut         | Descriptif                                | Type        | Obligatoire |
|------------------|-------------------------------------------|-------------|-------------|
| `name`           | Nom de la taxe                            | `string`    | `obligatoire`|
| `rate`           | Taux de la taxe en pourcentage            | `decimal`   | `obligatoire`|
| `description`    | Description de la taxe                    | `string`    | `facultatif` |

### Réponse

#### Code d'état HTTP
| Paramètre  | Description                                  |
|------------|----------------------------------------------|
| `200`      | La taxe a été mise à jour avec succès        |
| `400`      | La requête envoyée n'est pas valide          |
| `404`      | Aucune taxe n'a été trouvée                  |

[SBTax](/SBTax)

#### Exemple de code

<Tabs items={['JS', '.NET']}>
  <Tabs.Tab>
  ```js copy
  import { SBClient, SBTax, TaxUpdateRequest } from "@smartbills/sdk"
  
  const client = new SBClient();
  const request = {
    "name": "TVA Mise à jour",
    "rate": 20.0,
    "description": "Taxe sur la valeur ajoutée mise à jour"
  };

  const tax = await client.taxes.updateAsync(1, request);
  ```
  </Tabs.Tab>
  <Tabs.Tab>
  ```c# copy
  using Smartbills.NET;
  
  var client = new SBClient();
  var request = new TaxUpdateRequest
  {
    Name = "TVA Mise à jour",
    Rate = 20.0,
    Description = "Taxe sur la valeur ajoutée mise à jour"
  };

  var tax = await client.Taxes.UpdateAsync(1, request);
  ```
  </Tabs.Tab>
</Tabs>
