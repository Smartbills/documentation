## Welcome 
Welcome to [Smartbills](https://smartbills.io) API documentation. Smartbills API allows you to automatically deliver smart, digital receipts to your customers. Receipts sent through Smartbills are accessible to customers in a centralized account.

## Getting Started
To begin, you will need to create a Smartbills account and set up a developer profile on our [developer portal](https://developers.smartbills.io). Once your developer profile is created, you can create apps which will give you access to the pre-production environment. Production keys are only enabled once approved.
