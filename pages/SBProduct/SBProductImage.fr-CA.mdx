# SBProductImage
| Attribut                   | Description                                     | Type                    | Obligatoire |
|----------------------------|-------------------------------------------------|-------------------------|-------------|
| `id`                       | Identifiant unique de l'image                   | `integer`               | Oui         |
| `name`                     | Nom de l'image                                  | `string`                | Non         |
| `height`                   | Hauteur de l'image                              | `integer`               | Oui         |
| `width`                    | Largeur de l'image                              | `integer`               | Oui         |
| `productVariantIds`        | Identifiants des variantes de produit           | `array`                 | Non         |
| `url`                      | URL de l'image                                  | `string`                | Non         |
| `updatedAt`                | Date de mise à jour                             | `date`    | Non         |
| `createdAt`                | Date de création                                | `date`    | Oui         |
