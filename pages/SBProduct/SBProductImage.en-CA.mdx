# SBProductImage
| Attribute                   | Description                                     | Type                    | Required    |
|-----------------------------|-------------------------------------------------|-------------------------|-------------|
| `id`                        | Unique identifier of the image                  | `long`               | Yes         |
| `name`                      | Name of the image                               | `string`                | No          |
| `height`                    | Height of the image                             | `long`               | Yes         |
| `width`                     | Width of the image                              | `long`               | Yes         |
| `productVariantIds`         | Identifiers of product variants                 | `array`                 | No          |
| `url`                       | URL of the image                                | `string`                | No          |
| `updatedAt`                 | Update date                                     | `date`    | No          |
| `createdAt`                 | Creation date                                   | `date`    | Yes         |
