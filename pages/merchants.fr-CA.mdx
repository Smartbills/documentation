# Marchands
Cet objet représente un marchand de votre entreprise. Utilisez-le pour suivre les reçus appartenant au même marchand.

`merchants.read`
`merchants.write`

## Principes de base

Un marchand doit être unique par site web.

## SBMerchant

## Créer un marchand
Créer un nouveau marchand. Nécessite la portée `merchants.write`

`POST https://api.smartbills.io/v1/merchants`

#### Corps de la requête 
Nécessite un corps de type `MerchantCreateRequest`
| Paramètre  | Description | Type  | Obligatoire |
|---|---|---|---|
| `name` | Nom du marchand | `string`  |  `obligatoire` |
| `address` | Adresse du marchand | `AddressRequest`  |  `obligatoire` |
| `logo` | URL du logo du marchand | `string`  |  `obligatoire` |
| `timezone` | Fuseau horaire du marchand | `string`  |  `obligatoire` |
| `currency` | Devise utilisée par le marchand | `string`  |  `obligatoire` |
| `website` | Site web du marchand | `string`  |  `obligatoire` |
| `phoneNumber` | Numéro de téléphone du marchand | `string`  |  `obligatoire` |
| `locale` | Langue du marchand | `string`  |  `obligatoire` |

```json copy filename="MerchantCreateRequest"
{
  "name": "string",
  "address": {
    "line1": "string",
    "line2": "string",
    "city": "string",
    "state": "string",
    "country": "string",
    "stateCode": "string",
    "countryCode": "string",
    "postalCode": "string",
    "location": {
      "latitude": 43,
      "longitude": -73
    }
  },
  "logo": "string",
  "timezone": "string",
  "currency": "string",
  "website": "string",
  "phoneNumber": "string",
  "locale": "string"
}
```

Renvoie un `SBMerchant`
```json copy filename="SBMerchant"

  "name": "string",
```

## Lister les marchands
Récupérer une liste de marchands. Nécessite la portée `merchants.read`

`GET https://api.smartbills.io/v1/merchants?page=1&pageSize=100`

#### Paramètres de requête 
Nécessite des paramètres de requête de type `MerchantListRequest`
| Paramètre  | Description | Type  | Obligatoire | Par défaut|
|---|---|---|---|---|
| `page` | Page actuelle | `long`  |  `obligatoire` | 1|
| `pageSize` | Nombre d'enregistrements à retourner | `long`  |  `obligatoire` | 100|
| `orderBy` | Trier les résultats par une clé de SBMerchant | `keyof SBMerchant`  ||`createdAt` |
| `sortOrder` | Ordre du tri  | `asc` ou `desc`  || `desc`|

```json copy filename="MerchantListRequest"
{
    "page": 1,
    "pageSize": 100,
	"orderBy": "createdAt",
	"sortOrder": "desc",
}
```

#### Réponse
Renvoie un `SBList<SBMerchant>`
```json copy filename="SBList<SBMerchant>"
{
    "data": [{
        "id": 0,
        "name": "string",
        "address": {
            "line1": "string",
            "line2": "string",
            "city": "string",
            "state": "string",
            "stateCode": "string",
            "country": "string",
            "countryCode": "string",
            "postalCode": "string",
            "location": {
                "latitude": -43.532,
                "longitude": -73.154
            },
            "formattedAddress": "string"
        },
        "currency": "string",
        "slug": "string",
        "timezone": "string",
        "website": "string",
        "phoneNumber": "string",
        "logo": "string",
        "createdAt": "2025-01-21T00:56:42.273Z",
        "updatedAt": "2025-01-21T00:56:42.273Z"
    }],
    "metadata": {
        "page": 1,
        "pageSize": 100,
        "totalPages": 1,
        "count": 1
    }
}
```

#### Exemple de code
 
<Tabs items={['JS', '.NET']}>

    <Tabs.Tab>
    ```js copy
    import { SBClient, SBMerchant, SBList, MerchantListRequest} from "@smartbills/sdk"
    
    const client = new SBClient();
    const request = {
        page: 1,
        pageSize: 100,
        orderBy: "createdAt",
        sortOrder: "desc"
    };

    const merchants = await client.merchants.list(request);
    ```
    </Tabs.Tab>
    <Tabs.Tab>
    ```c# copy
    using Smartbills.NET;
    SBClient client = new SBClient();
    var request = new MerchantListRequest
    {
        Page = 1,
        PageSize = 100,
        OrderBy = "createdAt",
        SortOrder = "desc"
    };
    var merchants = await client.Merchants.ListAsync(request);
    ```
    </Tabs.Tab>
</Tabs>
