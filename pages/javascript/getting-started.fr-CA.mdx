# Commencer avec @smartbills/sdk

Ce guide vous aidera à démarrer avec le SDK JavaScript de Smartbills, `@smartbills/sdk`.

## Installation

Pour installer le SDK, utilisez npm ou yarn :

```bash
npm install @smartbills/sdk
```

ou

```bash
yarn add @smartbills/sdk
```

## Initialisation

Pour utiliser le SDK, vous devez initialiser le `SBClient` avec votre jeton d'accès JWT.

```js
import { SBClient } from '@smartbills/sdk';

const client = new SBClient({
  credentials: new SBAccessToken(token, refresh_token),
});
```

ou avec vos identifiants client.

```js
import { SBClient } from '@smartbills/sdk';

const client = new SBClient({
  credentials: new SBClientCredentials(client_id, client_secret, scopes),
});
```

Vous êtes maintenant prêt à effectuer des appels API à l'API Smartbills.
