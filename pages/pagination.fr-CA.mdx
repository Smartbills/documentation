# Pagination
Tous les ressources API de niveau supérieur prennent en charge les récupérations en masse via des méthodes API « liste ». Par exemple, vous pouvez lister les clients et lister les factures. Ces méthodes API de liste partagent une structure commune et acceptent, au minimum, les deux paramètres suivants : page, pageSize

### SBListRequest
| Parameters  | Description| type |
|---|---|---|
| `page` | La page . La page par défault est 1. | `long`
| `pageSize` | Le nombre d'éléments à récupérer. La valeur minimale est 1 et maximale est 100. La valeur par défault est 25. | `long`
```json copy filename="SBList<SBProduct>"
{
	"data": [{
		"id": 1,
		"firstName": "John",
		"lastName": "Doe",
		"email": "john.doe@smartbills.io",
		"taxExempt": true,
		"phone": "(555) 555-5555",
		"locale": "fr-CA",
		"acceptsMarketing": true,
	}],
	"metadata": {
		"page":1,
		"pageSize":100,
		"totalPages":1,
		"count":1,
	},
	
}
```
## Réponse de pagination
Lorsque Smartbills retourne une réponse paginée, celle-ci `SBList<T>` est un objet genérique retourné pour toutes les entités permettant la pagination.

### SBList
| Parameters  | Description| type |
|---|---|---|
| `data` | Les objets retournées | `T[]`
| `pagination` | Les métadonnées sur la pagination. | `SBPagination`

```json copy filename="SBList<T>"
{
	"data": [],
	"pagination": {
		"page":1,
		"pageSize":100,
		"totalPages":1,
		"count":1,
	},
}
```
### SBPagination
La ressource `SBPagination` contient les métadonnées par rapport à la pagination.  

| Parameters  | Description| type |
|---|---|---|
| `currentPage` | La page courante. | `long`
| `pageCount` | Le nombre de page disponible. | `long`
| `count` | Le nombre total d'entité | `long`
| `limit` | Le nombre d'entité retourné | `long`
```json copy filename="SBPagination"
{
 		"count": 2,
        "pageCount": 1,
        "currentPage": 1,
        "limit": 25
}
```
