# Employés
Cet objet représente un employé de votre entreprise qui interagit avec les clients et a des ventes associées à lui.

## Portées
`employees.read`
`employees.write`

## Principes de base
Les employés de Smartbills sont des employés en contact avec les clients qui génèrent des ventes. Vous pouvez associer des reçus aux employés. Cela permet des analyses approfondies sur vos employés et nous aide à générer des rapports détaillés sur la manière dont vos clients interagissent avec vos employés.

## Créer un employé
Créez un nouvel employé. Nécessite la portée `employees.write`

`POST https://api.smartbills.io/v1/employees`

#### Corps de la demande
Nécessite un corps de type « EmployeeCreateRequest »
| Paramètre | Descriptif | Type | Obligatoire |
|---|---|---|---|
| `firstName` | Prénom de l'employé | `string` | `obligatoire` |
| `lastName` | Nom de famille de l'employé | `string` | |
| `gender` | Genre de l'employé | `MALE`, `FEMALE`, `OTHER` | |
| `locale` | Localiser l'employé | `string` | |
| `email` | Email de l'employé | `string` | |
| `birthdate` | Date de naissance de l'employé | `date` | |

```json copy filename="EmployeeCreateRequest"
{
	"firstName": "Jean",
	"lastName": "Biche",
	"gender": "MALE",
	"email": "john.doe@smartbills.io",
	"locale": "fr-CA",
	"birthDate": "1990-01-01"
}
```

#### Réponse
Retourne un `SBEmployee`
```json copy filename="SBEmployee"
{
	"id": 1,
	"firstName": "Jean",
	"lastName": "Biche",
	"gender": "MALE",
	"email": "john.doe@smartbills.io",
	"locale": "fr-CA",
	"birthDate": "1990-01-01",
	"createdAt": "2023-01-01",
	"updatedAt": null
}
```

#### Exemple de code
<Tabs items={['JS', '.NET']}>
	<Tabs.Tab>
	```js copy
	import { SBClient, SBEmployee, EmployeeCreateRequest } from "@smartbills/sdk"

	const client = new SBClient();
	const request = {
		"firstName": "Jean",
		"lastName": "Biche",
		"gender": "MALE",
		"email": "john.doe@smartbills.io",
		"locale": "fr-CA",
		"birthDate": "1990-01-01"
	};

	const employee = await client.employees.create(request);
	```
	</Tabs.Tab>
	<Tabs.Tab>
	```c# copy
	using Smartbills.NET;
	SBClient client = new SBClient();
	var request = new EmployeeCreateRequest
	{
		FirstName = "Jean",
		LastName = "Biche",
		Gender = "MALE",
		Email = "john.doe@smartbills.io",
		Locale = "fr-CA",
		BirthDate = "1990-01-01"
	};
	var employee = await client.Employees.CreateAsync(request);
	```
	</Tabs.Tab>
</Tabs>

## Récupérer un employé
Récupérer un employé par ID. Nécessite la portée `employees.read`

`GET https://api.smartbills.io/v1/employees/:id`

#### Paramètres du chemin

| Paramètre | Descriptif | Type | Obligatoire |
|---|---|---|---|
| `id` | ID de l'employé à récupérer | `long` | `obligatoire` |

#### Réponse
Retourne un `SBEmployee`
```json copy filename="SBEmployee"
{
	"id": 1,
	"firstName": "Jean",
	"lastName": "Biche",
	"email": "john.doe@smartbills.io",
	"locale": "fr-CA",
	"birthDate": "1990-01-01",
	"createdAt": "2023-01-01",
	"updatedAt": "2023-01-06"
}
```

#### Exemple de code
<Tabs items={['JS', '.NET']}>
	<Tabs.Tab>
	```js copy

	const client = new SBClient();
	const employee = await client.employees.getByIdAsync(1);
	```
	</Tabs.Tab>
</Tabs>

## Liste des employés
Récupérez une liste d'employés. Nécessite la portée `employees.read`

`GET https://api.smartbills.io/v1/employees?page=1&pageSize=100`

#### Paramètres de requête
Nécessite des paramètres de requête de type « EmployeeListRequest »
| Paramètre | Descriptif | Type | Obligatoire | Par défaut |
|---|---|---|---|---|
| `page` | Page actuelle | `long` | `obligatoire` | 1 |
| `pageSize` | Nombre d'enregistrements à renvoyer | `long` | `obligatoire` | 100 |
| `orderBy` | Classez les résultats par une clé de SBEmployee | `keyof SBEmployee` | | `createdAt` |
| `sortOrder` | Ordre du tri | `asc` ou `desc` | | `desc` |

```json copy filename="EmployeeListRequest"
{
	"page": 1,
	"pageSize": 100,
	"orderBy": "createdAt",
	"sortOrder": "desc"
}
```

#### Réponse
Retourne une `SBList<SBEmployee>`
```json copy filename="SBList<SBEmployee>"
{
	"data": [{
		"id": 1,
		"firstName": "Jean",
		"lastName": "Biche",
		"email": "john.doe@smartbills.io",
		"locale": "fr-CA",
		"birthDate": "1990-01-01",
		"createdAt": "2023-01-01",
		"updatedAt": "2023-01-06"
	}],
	"metadata": {
		"page": 1,
		"pageSize": 100,
		"totalPages": 1,
		"count": 1
	}
}
```

#### Exemple de code
<Tabs items={['JS', '.NET']}>
	<Tabs.Tab>
	```js copy
	import { SBClient, SBEmployee, SBList, EmployeeListRequest } from "@smartbills/sdk"

	const client = new SBClient();
	const request = {
		"page": 1,
		"pageSize": 100,
		"orderBy": "createdAt",
		"sortOrder": "desc"
	};

	const employees = await client.employees.list(request);
	```
	</Tabs.Tab>
	<Tabs.Tab>
	```c# copy
	using Smartbills.NET;
	SBClient client = new SBClient();
	var request = new EmployeeListRequest
	{
		Page = 1,
		PageSize = 100,
		OrderBy = "createdAt",
		SortOrder = "desc"
	};
	var employees = await client.Employees.ListAsync(request);
	```
	</Tabs.Tab>
</Tabs>

## Mettre à jour un employé
Mettre à jour les informations d'un employé. Nécessite la portée `employees.write`

`PUT https://api.smartbills.io/v1/employees/:id`

#### Paramètres de route 

| Paramètre  | Description | Type  | Obligatoire |
|---|---|---|---|
| `id` | ID de l'employé à mettre à jour | `long`  |  `obligatoire` |

#### Paramètres du corps 
Nécessite un corps de type `EmployeeUpdateRequest`

| Paramètre  | Description | Type  | Obligatoire |
|---|---|---|---|
| `firstName` | Prénom de l'employé | `string`  |  `obligatoire` |
| `lastName` | Nom de famille de l'employé | `string`  |  `obligatoire` |

| `email` | Email de l'employé | `string`  |  `obligatoire` |
| `locale` | Localiser l'employé | `string`  |  `obligatoire` |
| `birthdate` | Date de naissance de l'employé | `date`  | |

```json copy filename="EmployeeUpdateRequest"
{
    "firstName": "Jean",
    "lastName": "Biche",
    "gender": "MALE",
    "email": "john.doe@smartbills.io",
	"locale": "fr-CA",
	"birthDate": "1990-01-01"
```

```json copy filename="SBEmployee"
{

    "firstName": "Jean",
```
