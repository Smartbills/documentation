# SBFee
| Attribut                    | Description                                     | Type                    | Obligatoire |
|-----------------------------|-------------------------------------------------|-------------------------|-------------|
| `id`                        | Identifiant unique du frais                     | `long`               | Oui         |
| `name`                      | Nom du frais                                    | `string`                | Oui         |
| `amount`                    | Montant du frais                                | `SBMoney`                | Oui         |
| `percentage`                | Pourcentage du frais                            | `decimal`                | Non         |
| `type`                      | Type du frais                                   | `string`                | Oui         |
| `category`                  | Catégorie du frais                              | `SBFeeCategory`         | Oui         |

## SBFeeCategory
Les catégories de frais disponibles sont :
- `SERVICE_FEE`
- `PAYMENT_PROCESSING_FEE`
- `SHIPPING_FEE`
- `CANCELLATION_FEE`
