# Variantes de produits
Cet objet représente une variante d'un produit de votre entreprise. Utilisez-le pour gérer différentes versions des produits (comme les tailles, couleurs, etc.).

## Portées
`products.read`
`products.write`

## Principes de base
Une variante appartient à un produit et peut avoir son propre prix, SKU et autres attributs.

## Créer une variante de produit
Créer une nouvelle variante pour un produit. Nécessite la portée `products.write`

<Tabs items={['HTTP']}>
  <Tabs.Tab>
`POST` `https://api.smartbills.io/v1/products/{productId}/variants`
  </Tabs.Tab>
</Tabs>

### Paramètres de route
| Paramètre  | Description        | Type   | Obligatoire |
|------------|-------------------|--------|-------------|
| `productId`| ID du produit     | `long` | `true`      |

### Corps de la requête
Nécessite un corps de type `ProductVariantCreateRequest`
| Paramètre     | Description           | Type      | Obligatoire |
|--------------|----------------------|-----------|-------------|
| `initialPrice`| Prix initial         | `decimal` | |
| `price`       | Prix actuel          | `decimal` | `true`      |
| `weightUnit`  | Unité de poids       | `string`  | |
| `weight`      | Valeur du poids      | `decimal` | |
| `taxable`     | Est taxable          | `boolean` | |
| `name`        | Nom de la variante   | `string`  | |
| `imageIds`    | Images associées     | `long[]`  | |
| `sku`         | SKU                  | `string`  | |
| `upc`         | Code UPC             | `string`  | |

```json copy filename="ProductVariantCreateRequest"
{
  "initialPrice": 0,
  "price": 0,
  "weightUnit": "string",
  "weight": 0,
  "taxable": true,
  "name": "string",
  "imageIds": [],
  "sku": "string",
  "upc": "string"
}
```

## Récupérer une variante de produit
Récupère une variante spécifique d'un produit. Nécessite la portée `products.read`

<Tabs items={['HTTP']}>
  <Tabs.Tab>
`GET` `https://api.smartbills.io/v1/products/{productId}/variants/{variantId}`
  </Tabs.Tab>
</Tabs>

### Paramètres de route
| Paramètre  | Description        | Type   | Obligatoire |
|------------|-------------------|--------|-------------|
| `productId`| ID du produit     | `long` | `true`      |
| `variantId`| ID de la variante | `long` | `true`      |

### Réponse
Retourne un objet `ProductVariantResponse`.

## Mettre à jour une variante de produit
Mettre à jour une variante de produit existante. Nécessite la portée `products.write`

<Tabs items={['HTTP']}>
  <Tabs.Tab>
`PUT` `https://api.smartbills.io/v1/products/{productId}/variants/{variantId}`
  </Tabs.Tab>
</Tabs>

### Paramètres de route
| Paramètre  | Description        | Type   | Obligatoire |
|------------|-------------------|--------|-------------|
| `productId`| ID du produit     | `long` | `true`      |
| `variantId`| ID de la variante | `long` | `true`      |

### Corps de la requête
Identique à la requête de création (`ProductVariantCreateRequest`)

## Supprimer une variante de produit
Supprimer une variante de produit. Nécessite la portée `products.write`

<Tabs items={['HTTP']}>
  <Tabs.Tab>
`DELETE` `https://api.smartbills.io/v1/products/{productId}/variants/{variantId}`
  </Tabs.Tab>
</Tabs>

### Paramètres de route
| Paramètre  | Description        | Type   | Obligatoire |
|------------|-------------------|--------|-------------|
| `productId`| ID du produit     | `long` | `true`      |
| `variantId`| ID de la variante | `long` | `true`      |

### Codes de réponse
| Code  | Description                            |
|-------|----------------------------------------|
| `200` | Variante supprimée avec succès         |
| `404` | Variante non trouvée                   |
