# Employés
Cet objet représente un employé de votre entreprise qui interagit avec les clients.

## Portées
`employees.read`
`employees.write`

## Principes de base
Les employés de Smartbills sont des employés en contact avec les clients qui génèrent des ventes. Vous pouvez associer des factures aux employés. Cela permet des analyses approfondies sur vos employés et nous aide à générer des rapports détaillés sur la manière dont vos clients interagissent avec vos employés.

## SBEmployé

```json copy filename="SBEmployee"
{
	"id": 1,
	"firstName": "Jean",
	"lastName": "Biche",
	"gender": "MALE",
	"email": "john.doe@smartbills.io",
	"locale": "fr-CA",
	"birthDate": "1990-01-01",
	"createdAt": "2023-01-01",
	"updatedAt": "2023-01-06"
}
```

| Attribut | Descriptif | Type |
|---|---|---|
| `id` | Smartbills id unique de l'employé | `long` |
| `firstName` | Prénom de l'employé. C'est ce que le client verra sur sa facture. | `string` |
| `lastName` | Nom de famille de l'employé | `string` |
| `gender` | Genre de l'employé | `MALE`, `FEMALE`, `OTHER` |
| `locale` | Localiser l'employé | `string` |
| `email` | Email de l'employé | `string` |
| `birthdate` | Date de naissance de l'employé | `date` |
| `createdAt` | L'heure à laquelle l'employé a été créé | `date` |
| `updatedAt` | L'heure à laquelle l'employé a été mis à jour | `date` |
