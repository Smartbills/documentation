# Smartbills API
Welcome to the Smartbills API documentation. Smartbills is a powerful online platform that enables users to receive their receipts in a single online account.

The Smartbills API is organized around REST. Our API uses resource-oriented, predictable URLs, accepts form-encoded request bodies, returns JSON-encoded responses, and leverages standard HTTP response codes, authentication, and verbs.

You can use the Smartbills API in test mode, which does not affect your production data. The URL you use determines whether the request is in production or test mode. For more information on the different environments available, refer to our [environments documentation](/environments).

## Developer Tools and SDKs
Get started quickly with our various SDKs. Our client libraries are open-source and available on our [Github](https://github.com/smartbills).
