## Bienvenue 
Bienvenue dans la documentation de l'API [Smartbills](https://smartbills.io). L'API Smartbills vous permet de livrer automatiquement des reçus numériques intelligents à vos clients. Les reçus envoyés via Smartbills sont accessibles aux clients dans un compte centralisé.

## Commencer
Pour commencer, vous devrez créer un compte Smartbills et configurer un profil développeur sur notre [portail développeur](https://developers.smartbills.io). Une fois votre profil développeur créé, vous pouvez créer des applications qui vous donneront accès à l'environnement de pré-production. Les clés de production ne sont activées qu'une fois approuvées.
