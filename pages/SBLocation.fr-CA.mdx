# SBLocation
Cet objet représente un emplacement physique associé à un marchand. Utilisez-le pour gérer les adresses physiques où les transactions peuvent avoir lieu.

| Attribut               | Description                                               | Type                     | Obligatoire |
|-----------------------|-----------------------------------------------------------|--------------------------|-------------|
| `id`                  | Identifiant unique de l'emplacement                       | `long`                   | `obligatoire` |
| `name`                | Nom de l'emplacement                                      | `string`                 | `obligatoire` |
| `address`             | Adresse de l'emplacement                                  | `AddressRequest`         | `obligatoire` |
| `longitude`           | Longitude de l'emplacement                                | `number`                 | `obligatoire` |
| `latitude`            | Latitude de l'emplacement                                 | `number`                 | `obligatoire` |
| `merchantCategoryCode`| Code de catégorie du marchand                             | `string`                 | `obligatoire` |
| `currency`            | Devise utilisée                                           | `string`                 | `facultatif` |
| `timezone`            | Fuseau horaire de l'emplacement                           | `string`                 | `facultatif` |
| `phoneNumber`         | Numéro de téléphone de l'emplacement                      | `string`                 | `facultatif` |
| `facebookUrl`         | URL de la page Facebook de l'emplacement                  | `string`                 | `facultatif` |
| `instagramUsername`   | Nom d'utilisateur Instagram de l'emplacement              | `string`                 | `facultatif` |
| `twitterUsername`     | Nom d'utilisateur Twitter de l'emplacement                | `string`                 | `facultatif` |
| `isActive`            | Indique si l'emplacement est actif                        | `bool`                   | `facultatif` |
| `locale`              | Langue de l'emplacement                                   | `string`                 | `facultatif` |
| `email`               | Adresse email de l'emplacement                            | `string`                 | `facultatif` |
| `logo`                | URL du logo de l'emplacement                              | `string`                 | `facultatif` |
| `images`              | Liste des images associées à l'emplacement                | `List<SBImage>`| `facultatif` |
