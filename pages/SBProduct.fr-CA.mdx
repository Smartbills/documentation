# SBProduct
Cet objet représente un produit dans votre entreprise. Utilisez-le pour gérer les produits vendus sur Smartbills.

| Attribut         | Description                                    | Type      | Obligatoire |
|-----------------|------------------------------------------------|-----------|-------------|
| `id`            | Identifiant unique du produit                  | `integer` | Oui         |
| `name`          | Nom du produit                                 | `string`  | Oui         |
| `description`   | Description du produit                         | `string`  | Non         |
| `slug`          | Identifiant compatible URL                     | `string`  | Non         |
| `vendorId`      | ID du fournisseur                              | `integer` | Non         |
| `category`      | Catégorie du produit                           | `string`  | Non         |
| `tags`          | Étiquettes associées au produit                | `string[]`| Non         |
| `publishedAt`   | Date de publication                            | `date`    | Non         |
| `locale`        | Locale du produit                              | `string`  | Non         |
| `images`        | Images du produit                              | `SBProductImage[]` | Non         |
| `variants`      | Variantes du produit                           | `SBProductVariant[]`| Non         |
| `createdAt`     | Date de création                               | `datetime`| Oui         |
| `updatedAt`     | Date de dernière mise à jour                   | `datetime`| Non         |
