## Aperçu

La page Image de marque vous permet de personnaliser l'apparence de votre expérience Smartbills. Téléchargez le logo de votre entreprise, définissez les couleurs de marque et personnalisez l'apparence des rapports exportés et des modèles de reçus. Une image de marque cohérente garantit que les rapports de dépenses et les documents reflètent l'identite de votre organisation.

Pour accéder aux paramètres d'image de marque, naviguez vers **Paramètres > Image de marque** dans la barre latérale gauche.

<Note>
  Seuls les utilisateurs ayant le rôle **Administrateur** ou **Propriétaire** peuvent modifier les paramètres d'image de marque.
</Note>

## Télécharger le Logo

Le logo de votre entreprise apparaît dans la barre latérale, les rapports exportés et les notifications par courriel. Pour télécharger ou remplacer votre logo :

1. Cliquez sur le bouton **Télécharger le logo** ou sur l'aperçu du logo existant
2. Sélectionnez un fichier image depuis votre ordinateur
3. Ajustez la zone de recadrage si nécessaire
4. Cliquez sur **Enregistrer**

Les formats pris en charge sont PNG, JPG et SVG. Pour de meilleurs résultats, utilisez une image carree d'au moins 256x256 pixels avec un fond transparent.

## Couleurs de Marque

Définissez les couleurs principales et secondaires de votre organisation. Ces couleurs sont appliquées à :

- Les rapports PDF exportés (en-têtes, lignes d'accent)
- Les modèles de notifications par courriel
- Les accents de l'interface Smartbills (optionnel)

<Steps>
  <Step title="Sélectionnez la Couleur Principale">
    Cliquez sur l'echantillon de couleur principale pour ouvrir le sélecteur de couleurs. Entrez un code hexadecimal ou utilisez le sélecteur visuel pour choisir la couleur principale de votre marque.

  </Step>

  <Step title="Sélectionnez la Couleur Secondaire">
    Définissez optionnellement une couleur secondaire utilisée pour les accents et les mises en évidence dans les documents exportés.

  </Step>

  <Step title="Previsualisez et Enregistrez">
    Un aperçu en direct montre comment vos couleurs apparaissent sur un exemple de rapport de dépenses. Lorsque vous êtes satisfait, cliquez sur **Enregistrer** pour appliquer.

  </Step>
</Steps>

## Personnaliser les Modèles de Reçus

Les modèles de reçus controlent la mise en page et les informations affichees sur les rapports de dépenses et les PDF de reçus exportés. Vous pouvez personnaliser :

- **En-tête**: Nom de l'entreprise, emplacement du logo et coordonnées
- **Pied de page**: Texte personnalisé tel que les mentions légales ou les références aux politiques
- **Champs**: Choisissez quels champs de dépense apparaissent sur le document exporté

Cliquez sur **Enregistrer** après avoir effectué des modifications. Toutes les futures exportations utiliseront le modèle mis à jour.

## Réinitialiser aux Valeurs par Défaut

Pour revenir à tous les paramètres d'image de marque par défaut de Smartbills, cliquez sur **Réinitialiser aux valeurs par défaut** en bas de la page. Cela supprime votre logo personnalisé, réinitialise les couleurs et restaure le modèle de reçu par défaut.
