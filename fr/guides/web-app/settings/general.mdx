## Aperçu

La page Paramètres généraux est l'endroit où vous configurez les détails fondamentaux de votre entreprise sur Smartbills. Ces paramètres affectent la facon dont le nom de votre organisation apparaît sur les rapports, quelle devise est utilisée pour le suivi des dépenses, et d'autres préférences de base.

Pour accéder aux paramètres généraux, naviguez vers **Paramètres > Général** dans la barre latérale gauche.

<Note>
  Seuls les utilisateurs ayant le role **Administrateur** ou **Proprietaire** peuvent modifier les paramètres généraux.
</Note>

## Informations de l'Entreprise

### Nom de l'Entreprise

Le nom de l'entreprise apparaît sur les rapports de dépenses, les factures et les invitations d'équipe. Entrez le nom d'exploitation de votre entreprise tel que vous souhaitez qu'il soit affiché dans Smartbills.

### Raison Sociale

La raison sociale est le nom de l'entite juridique enregistrée de votre organisation. Elle est utilisée sur les documents officiels et les exportations fiscales. Si votre raison sociale differe de votre nom d'exploitation, entrez les deux.

### Adresse de l'Entreprise

Entrez l'adresse principale de votre entreprise. Ces informations sont utilisees pour :

- Les en-tetes et pieds de page des rapports de dépenses
- La conformité fiscale et la localisation
- Les modèles de communication avec les fournisseurs

## Paramètres Regionaux

### Devise par Défaut

Sélectionnez la devise de reporting principale de votre organisation (ex. : USD, CAD, EUR, GBP). Les dépenses soumises dans d'autres devises sont converties au taux de changé actuel et affichees à côté du montant original.

### Fuseau Horaire

Le fuseau horaire détermine les horodatages sur les rapports, les journaux d'audit, les notifications et les opérations planifiees. Choisissez le fuseau horaire qui correspond à l'emplacement de votre bureau principal.

## Année Fiscale

Configurez le mois de debut de l'année fiscale de votre organisation. Cela affecte la facon dont les rapports annuels, les budgets et les résumés de dépenses sont calcules. La valeur par défaut est janvier (année civile), mais vous pouvez le définir à n'importe quel mois pour correspondre à votre période comptable.

## Logo

Téléchargez le logo de votre entreprise pour personnalisér l'experience Smartbills. Le logo apparaît sur :

- Le haut de la barre latérale
- Les rapports de dépenses et PDF exportes
- Les notifications par courriel envoyées à votre équipe

Cliquez sur **Télécharger le logo** pour sélectionner un fichier image. Les formats pris en charge sont PNG, JPG et SVG. Pour de meilleurs résultats, utilisez une image carree d'au moins 256x256 pixels.

## Enregistrer les Modifications

Après avoir modifié des paramètres sur cette page, cliquez sur **Enregistrer** en bas pour appliquer vos modifications. Les changements au nom de l'entreprise, à la devise et au logo prennent effet immédiatement sur toute la plateforme.
