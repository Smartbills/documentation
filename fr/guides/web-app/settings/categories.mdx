## Aperçu

Les catégories de dépenses sont des étiquettes qui classifient chaque dépense par type (ex. : Voyage, Repas, Fournitures de bureau). Les catégories sont essentielles pour des rapports financiers précis, le suivi des budgets et l'intégration comptable. Smartbills est livre avec un ensemble de catégories par défaut, et vous pouvez les personnaliser pour correspondre au plan comptable de votre organisation.

Pour gérer les catégories, naviguez vers **Paramètres > Catégories** dans la barre latérale gauche.

<Note>
  Seuls les utilisateurs ayant le rôle **Administrateur**, **Propriétaire** ou **Comptable** peuvent gérer les catégories.
</Note>

## Catégories par Défaut

Smartbills fournit un ensemble de catégories couramment utilisées, notamment :

- Voyage
- Repas et divertissements
- Fournitures de bureau
- Transport
- Logiciels et abonnements
- Services professionnels
- Services publics
- Divers

Vous pouvez modifier ces valeurs par défaut, désactiver celles dont vous n'avez pas besoin ou ajouter de nouvelles catégories personnalisées.

## Créer une Catégorie Personnalisée

<Steps>
  <Step title="Ouvrez les Paramètres de Catégories">
    Naviguez vers **Paramètres > Catégories**. La page affiche toutes les catégories existantes dans une liste réorganisable.

  </Step>

  <Step title="Cliquez sur Ajouter une Catégorie">
    Cliquez sur le bouton **Ajouter une catégorie** en haut de la liste.

  </Step>

  <Step title="Entrez les Détails de la Catégorie">
    Remplissez le formulaire de catégorie :

    - **Nom** (obligatoire), Le nom d'affichage de la catégorie (ex. : "Divertissement clients")
    - **Code de compte GL**: Le code de compte du grand livre pour l'intégration comptable (ex. : "6200")
    - **Description**: Une description optionnelle pour aider les employés à choisir la bonne catégorie

  </Step>

  <Step title="Enregistrez">
    Cliquez sur **Enregistrer** pour créer la catégorie. Elle apparaîtra dans la liste des catégories et sera disponible pour les employés lors de la soumission des dépenses.
  </Step>
</Steps>

## Modifier une Catégorie

Cliquez sur n'importe quelle catégorie dans la liste pour ouvrir son panneau de détails. Vous pouvez modifier le nom, le code de compte GL et la description. Cliquez sur **Enregistrer** pour appliquer vos modifications.

<Note>
  Renommer une catégorie la met à jour dans toutes les dépenses existantes qui l'utilisent. Les rapports historiques reflètent le nom mis à jour.
</Note>

## Définir les Codes de Compte GL

Les codes de compte GL (Grand Livre) relient vos catégories Smartbills à votre logiciel comptable. Lorsque vous exportez des dépenses, les codes GL sont inclus pour que votre équipe comptable ou votre intégration puisse associer les dépenses aux bons comptes.

Entrez le code GL dans le panneau de détails de la catégorie. Le format dépend de votre système comptable (ex. : "5000", "6200-01").

## Activer et Désactiver des Catégories

Pour empecher les employés d'utiliser une catégorie sans la supprimer :

1. Cliquez sur la catégorie dans la liste
2. Désactivez le commutateur **Active**
3. Cliquez sur **Enregistrer**

Les catégories désactivées sont masquées du menu déroulant lors de la soumission des dépenses mais restent visibles dans les données historiques et les rapports.

## Réorganiser les Catégories

Glissez et déposez les catégories dans la liste pour modifier leur ordre d'affichage. L'ordre que vous définissez ici détermine la séquence dans laquelle les catégories apparaissent dans les menus déroulants à travers Smartbills.
