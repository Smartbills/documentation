## Aperçu

La page Facturation vous permet de consulter votre plan d'abonnement actuel, de mettre à niveau ou de reclasser votre plan, de gérer votre mode de paiement et d'accéder à votre historique de facturation. Maintenez vos informations de facturation à jour pour garantir un accès ininterrompu aux fonctionnalités de Smartbills.

Pour accéder aux paramètres de facturation, naviguez vers **Paramètres > Facturation** dans la barre latérale gauche.

<Note>
  Seul le rôle **Propriétaire** peut gérer les paramètres de facturation et les modes de paiement.
</Note>

## Plan Actuel

Le haut de la page Facturation affiche votre plan d'abonnement actif ainsi que les détails clés :

- **Nom du plan**: Gratuit, Pro ou Entreprise
- **Cycle de facturation**: Mensuel ou Annuel
- **Prochaine date de facturation**: La date de votre prochain paiement
- **Sieges utilisés**: Le nombre de membres actifs par rapport à la limite de votre plan

## Mise à Niveau ou Reclassement

Pour changer de plan :

1. Cliquez sur **Changer de plan** sur la page Facturation
2. Examinez les plans disponibles et leurs fonctionnalités
3. Sélectionnez le plan vers lequel vous souhaitez migrer
4. Confirmez le changement

**La mise à niveau** prend effet immédiatement. Un montant au prorata vous est facture pour le reste du cycle de facturation en cours.

**Le reclassement** prend effet à la fin de votre cycle de facturation actuel. Vous conservez l'accès aux fonctionnalités de votre plan actuel jusque-la.

<Tip>
  Passer d'une facturation mensuelle à annuelle vous fait economiser jusqu'à 20 %. Cliquez sur **Passer à l'annuel** dans les détails du plan pour effectuer le changement.
</Tip>

## Mode de Paiement

### Consulter le Mode de Paiement

Votre mode de paiement actuel est affiché sur la page Facturation (ex. : "Visa se terminant par 4242"). Seuls les quatre derniers chiffres sont affichés pour des raisons de sécurité.

### Mettre à Jour le Mode de Paiement

1. Cliquez sur **Mettre à jour le mode de paiement**
2. Entrez les détails de votre nouvelle carte dans le formulaire sécurisé
3. Cliquez sur **Enregistrer**

Le nouveau mode de paiement sera utilisé pour tous les futurs paiements.

## Historique de Facturation

La section Historique de facturation liste toutes les factures passees avec :

- **Date**: La date de facturation
- **Montant**: Le montant facture
- **Statut**: Payé, En attente ou Échoué
- **Facture**: Un lien pour télécharger la facture en PDF

Cliquez sur n'importe quelle ligne de facture pour télécharger le PDF pour vos dossiers ou votre comptabilité.
