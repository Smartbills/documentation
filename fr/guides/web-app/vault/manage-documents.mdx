## Aperçu

Le Coffre-fort stocke vos documents financiers automatiquement, mais vous pouvez également télécharger des fichiers manuellement, les organiser avec des etiquettes, rechercher des enregistrements spécifiques et exporter des documents au besoin. Ce guide couvre les tâches principales de gestion documentaire.

## Consulter les Documents

<Steps>
  <Step title="Accéder au Coffre-fort">
    Cliquez sur **Coffre-fort** dans la barre latérale gauche pour ouvrir le coffre-fort de documents.

    <Frame>
      <img src="/images/guides/web-app/vault/navigate-to-vault.png" alt="Clic sur Coffre-fort dans la barre latérale" />
    </Frame>
  </Step>

  <Step title="Parcourir par Catégorie ou Date">
    Utilisez les onglets de filtre et le sélecteur de date en haut pour affiner la liste des documents :

    - Cliquez sur un onglet de **type de document** (Tous, Reçus, Rapports, Factures, Autres) pour filtrer par catégorie
    - Utilisez le sélecteur de **plage de dates** pour vous concentrer sur une periode spécifique
    - Triez par date, nom ou taille de fichier en utilisant les en-tetes de colonnes

    <Frame>
      <img src="/images/guides/web-app/vault/browse-documents.png" alt="Navigation dans les documents par catégorie et date" />
    </Frame>
  </Step>

  <Step title="Cliquer pour Aperçu ou Téléchargement">
    Cliquez sur n'importe quel document pour ouvrir le panneau d'aperçu. Depuis l'aperçu, vous pouvez :

    - Voir le document en taille reelle
    - Cliquer sur **Télécharger** pour enregistrer une copie sur votre ordinateur
    - Cliquer sur le lien vers la dépense, le rapport ou la facture associe
    - Consulter les metadonnées telles que la date de téléchargement, la taille du fichier et les etiquettes

    <Frame>
      <img src="/images/guides/web-app/vault/preview-download.png" alt="Aperçu du document avec bouton de téléchargement et metadonnées" />
    </Frame>
  </Step>
</Steps>

## Télécharger des Documents

Vous pouvez télécharger des fichiers directement dans le Coffre-fort pour les documents qui ne sont pas automatiquement captures via les dépenses ou les factures.

<Steps>
  <Step title="Cliquer sur Télécharger">
    Dans le Coffre-fort, cliquez sur le bouton **Télécharger** dans le coin supérieur droit.

    <Frame>
      <img src="/images/guides/web-app/vault/upload-button.png" alt="Bouton Télécharger dans le Coffre-fort" />
    </Frame>
  </Step>

  <Step title="Sélectionner les Fichiers">
    Glissez-deposez les fichiers sur la zone de téléchargement, ou cliquez sur **Parcourir** pour sélectionner des fichiers depuis votre ordinateur. Vous pouvez télécharger plusieurs fichiers à la fois.

    **Formats pris en charge :**
    - Documents PDF
    - Images (JPEG, PNG)
    - Tableurs (XLSX, CSV)
    - Autres formats de documents courants

    <Frame>
      <img src="/images/guides/web-app/vault/select-files.png" alt="Glisser-déposer ou parcourir pour sélectionner les fichiers à télécharger" />
    </Frame>
  </Step>

  <Step title="Ajouter des Etiquettes et une Description">
    Pour chaque fichier téléchargé, vous pouvez ajouter :

    - **Etiquettes** -- Mots-cles pour faciliter la recherche (p. ex., "contrat", "T1-2024", "fournisseur-acme")
    - **Description** -- Une breve note sur le contenu ou l'objectif du document
    - **Catégorie** -- Classifiez le type de document (reçu, facture, contrat, autre)

    <Frame>
      <img src="/images/guides/web-app/vault/add-tags-description.png" alt="Ajout d'etiquettes et de description aux documents téléchargés" />
    </Frame>
  </Step>

  <Step title="Enregistrer">
    Cliquez sur **Enregistrer** pour terminer le téléchargement. Les documents apparaissent immediatement dans le Coffre-fort et sont disponibles pour la recherche et le téléchargement.

    <Frame>
      <img src="/images/guides/web-app/vault/upload-complete.png" alt="Téléchargement termine avec les documents ajoutes au Coffre-fort" />
    </Frame>
  </Step>
</Steps>

## Rechercher des Documents

La barre de recherche du Coffre-fort vous aide à trouver rapidement des documents spécifiques.

### Recherche Simple

Saisissez un mot-cle dans la barre de recherche en haut du Coffre-fort. La recherche porte sur :

- Le nom du fichier
- Les etiquettes
- La description
- Le nom du fournisseur, de l'employé ou du rapport associe

<Frame>
  <img src="/images/guides/web-app/vault/search-bar.png" alt="Utilisation de la barre de recherche pour trouver des documents" />
</Frame>

### Filtrage Avance

Combinez la recherche avec les filtres pour des résultats plus précis :

1. Saisissez un terme de recherche
2. Appliquez une **plage de dates** pour restreindre la periode
3. Sélectionnez un **type de document** pour vous concentrer sur une catégorie
4. Filtrez par **employé** pour voir les documents d'une personne spécifique
5. Utilisez les **etiquettes** pour trouver les documents etiquetes

<Tip>
  **Astuce de recherche** : Utilisez des termes spécifiques pour de meilleurs résultats. Rechercher "acme facture mars" est plus efficace que rechercher "document".
</Tip>

## Exporter des Documents

Vous pouvez télécharger des documents individuels ou exporter plusieurs fichiers à la fois.

### Télécharger un Document Individuel

1. Cliquez sur le document pour ouvrir l'aperçu
2. Cliquez sur le bouton **Télécharger**
3. Le fichier est enregistre dans l'emplacement de téléchargement par défaut de votre ordinateur

### Export en Masse au Format ZIP

<Steps>
  <Step title="Sélectionner les Documents">
    Utilisez les cases à cocher à côté de chaque document pour sélectionner les fichiers que vous souhaitez exporter. Vous pouvez également utiliser **Tout Sélectionner** pour sélectionner tous les documents de la vue filtree actuelle.

    <Frame>
      <img src="/images/guides/web-app/vault/select-for-export.png" alt="Sélection de plusieurs documents pour l'export en masse" />
    </Frame>
  </Step>

  <Step title="Cliquer sur Télécharger">
    Avec les documents sélectionnes, cliquez sur le bouton **Télécharger** dans la barre d'outils. Si plusieurs fichiers sont sélectionnes, ils sont regroupes dans une archive ZIP.

    <Frame>
      <img src="/images/guides/web-app/vault/download-zip.png" alt="Téléchargement des documents sélectionnes sous forme d'archive ZIP" />
    </Frame>
  </Step>
</Steps>

<Note>
  **Exports volumineux** : Si vous sélectionnez un grand nombre de documents, la preparation du fichier ZIP peut prendre un moment. Un indicateur de progression affiche l'etat de l'export.
</Note>

## Modifier les Metadonnées d'un Document

Vous pouvez mettre à jour les etiquettes et la description de n'importe quel document dans le Coffre-fort :

1. Cliquez sur le document pour ouvrir l'aperçu
2. Cliquez sur **Modifier** à côté du champ des etiquettes ou de la description
3. Effectuez vos modifications
4. Cliquez sur **Enregistrer**

Cela ne modifié pas le fichier original -- uniquement les metadonnées qui lui sont associées.

## Supprimer des Documents

Les documents téléchargés manuellement peuvent être supprimes du Coffre-fort :

1. Ouvrez l'aperçu du document
2. Cliquez sur **Supprimer**
3. Confirmez la suppression

<Warning>
  **Documents auto-archives** (ceux lies aux dépenses, rapports ou factures) ne peuvent pas être supprimes du Coffre-fort tant que l'enregistrement associe existe. Cela garantit l'integrite des documents à des fins de conformité.
</Warning>
