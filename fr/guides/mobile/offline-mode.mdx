## Aperçu

L'application mobile Smartbills est conçue pour fonctionner meme sans connexion internet. Vous pouvez capturer des reçus, créer des dépenses et modifier les données de dépenses existantes hors ligne. Toutes les modifications sont enregistrées localement sur votre appareil et automatiquement synchronisées avec le serveur Smartbills lorsque votre connexion est retablie.

## Ce Qui Fonctionne Hors Ligne

Les actions suivantes sont entièrement disponibles sans connexion internet :

| Fonctionnalité | Comportement Hors Ligne |
|----------------|------------------------|
| **Numeriser des reçus** | Capturez des reçus avec votre appareil photo. Les images sont enregistrées localement et l'OCR s'execute à la reconnexion |
| **Créer des dépenses** | Créez manuellement de nouvelles dépenses avec tous les champs (commercant, montant, date, catégorie, notes) |
| **Modifier des dépenses** | Modifiez toute dépense éditable précédemment synchronisée sur votre appareil |
| **Consulter des dépenses** | Parcourez votre liste de dépenses et consultez les détails de toutes les dépenses précédemment chargées |
| **Joindre des photos** | Ajoutez des images supplémentaires aux dépenses existantes |
| **Consulter des rapports** | Accédez aux rapports de dépenses précédemment chargés |

<Tip>
  Ouvrez l'application Smartbills en Wi-Fi avant de voyager pour vous assurer que vos dépenses et rapports les plus recents sont mis en cache sur votre appareil.
</Tip>

## Ce Qui Necessite une Connexion

Certaines fonctionnalités nécessitent une communication avec le serveur Smartbills et ne sont pas disponibles hors ligne :

- **Soumettre des rapports de dépenses** -- Les rapports ne peuvent pas être soumis pour approbation hors ligne
- **Consulter la boîte de réception de l'entreprise** -- La boîte de réception partagée des Dépenses de l'Entreprise necessite une connexion en direct pour se charger
- **Approuver ou rejeter des rapports** -- Les actions d'approbation nécessitent une confirmation du serveur
- **Recevoir des notifications push** -- Les notifications sont livrees par internet
- **Rechercher dans toutes les dépenses** -- La recherche hors ligne est limitee aux dépenses mises en cache sur votre appareil
- **Accéder aux paramètres d'équipe ou d.administration** -- Les modifications de paramètres nécessitent une connexion au serveur

<Note>
  Si vous tentez une action qui necessite une connexion alors que vous etes hors ligne, l'application affiche un message expliquant que l'action sera disponible une fois reconnecte.
</Note>

## Fonctionnement de la Synchronisation Hors Ligne

### Enregistrement Local des Modifications

Lorsque vous etes hors ligne, chaque action que vous effectuez est enregistrée dans une file d'attente locale sur votre appareil. Chaque élément en file d'attente comprend un horodatage et les détails complets de la modification. Vous pouvez continuer à travailler normalement -- l'application ne vous empeche pas d'effectuer des actions supplémentaires pendant que des modifications précédentes sont en file d'attente.

### Synchronisation Automatique à la Reconnexion

Lorsque votre appareil retrouve une connexion internet, Smartbills commence automatiquement à traiter la file d'attente hors ligne. Les modifications sont téléchargées dans l'ordre de leur création. Vous n'avez pas besoin d'ouvrir l'application ni d'effectuer une action manuelle pour declencher la synchronisation.

### Indicateur de Synchronisation

L'application affiche un indicateur de synchronisation pour vous tenir informe de l'etat actuel :

| Indicateur | Signification |
|------------|--------------|
| **Coche verte** | Toutes les modifications sont synchronisées. Votre appareil est à jour |
| **Fleche orange (rotative)** | Synchronisation en cours. Les modifications sont en cours de téléchargement |
| **Point d'exclamation rouge** | Une ou plusieurs modifications n'ont pas pu être synchronisées. Appuyez pour les détails |
| **Nuage gris barre** | Vous etes actuellement hors ligne. Les modifications sont en file d'attente localement |

L'indicateur de synchronisation apparaît en haut de l'onglet Accueil et dans l'onglet Dépenses lorsqu'il y à des modifications en attente.

## Resolution des Conflits

Si la meme dépense est modifiée à la fois sur l'application mobile (en mode hors ligne) et sur le tableau de bord web (pendant que le telephone etait déconnecté), un conflit peut survenir. Smartbills utilise une strategie de **derniere ecriture gagne** pour resoudre les conflits :

- La modification la plus récente -- basee sur l'horodatage du moment où la modification à été effectuée -- à la priorite
- Si vous avez modifié le nom du commercant sur mobile à 14h15 et qu'un collegue à modifié la catégorie sur le web à 14h20, les deux modifications sont preservees car elles concernent des champs differents
- Si vous avez modifié le montant sur mobile à 14h15 et également modifié le montant sur le web à 14h20, la modification web (14h20) ecrase la modification mobile car elle etait plus récente

<Warning>
  Dans de rares cas ou le meme champ est modifié aux deux endroits, la modification la plus ancienne est perdue. Vérifiez vos dépenses après la reconnexion si vous soupconnez qu'un conflit à pu se produire.
</Warning>

## Gestion des Données Hors Ligne

### Stockage

Les données hors ligne sont stockees en toute sécurité sur votre appareil en utilisant un stockage local chiffre. Les images de reçus capturees hors ligne sont enregistrées en pleine resolution et téléchargées à la reconnexion. Soyez attentif à l'espace de stockage disponible sur votre appareil si vous capturez un grand nombre de reçus hors ligne.

### Vider la File d'Attente Hors Ligne

Dans des circonstances normales, vous ne devriez pas avoir besoin de vider manuellement la file d'attente hors ligne. Si vous rencontrez des erreurs de synchronisation persistantes :

1. Allez dans **Menu** > **Paramètres** > **Données et Stockage**
2. Appuyez sur **Voir la File de Synchronisation** pour voir toutes les modifications en attente
3. Vous pouvez réessayer les éléments échoués individuellement ou appuyer sur **Tout Réessayer**

<Note>
  Ne desinstallez pas l'application tant qu'il y à des modifications non synchronisées. La desinstallation supprime toutes les données locales, y compris les modifications hors ligne en file d'attente qui n'ont pas encore été téléchargées.
</Note>

## Bonnes Pratiques

- **Synchronisez avant les longs déplacéments** : Ouvrez l'application en Wi-Fi pour télécharger les dernieres données avant de voyager dans des zones avec une connectivite limitee
- **Vérifiez l'indicateur de synchronisation** : Après la reconnexion, confirmez que toutes les modifications hors ligne ont été téléchargées avec succès
- **Evitez de modifier la meme dépense sur plusieurs appareils** : Pour eviter les conflits, effectuez les modifications sur une seule plateforme à la fois
- **Gardez l'application à jour** : La derniere version de l'application inclut le moteur de synchronisation hors ligne le plus fiable
