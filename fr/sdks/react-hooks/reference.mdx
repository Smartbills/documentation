---
title: "Référence des Hooks"
description: "Référence complète de tous les hooks React Smartbills, organisés par domaine"
---

Tous les hooks sont importes depuis `@smartbills/react-hooks`. Les hooks de requête retournent les objets résultat standard de React Query. Les hooks de mutation retournent des résultats `useMutation` avec une fonction `mutate` / `mutateAsync`.

## Dépenses

| Hook | Type | Description |
|------|------|-------------|
| `useExpenses(params?)` | Requête (infinie) | Lister les dépenses de l'entreprise avec pagination |
| `useMyExpenses(params?)` | Requête (infinie) | Lister les dépenses de l'utilisateur courant |
| `useEmployéeExpenses(employéeId, params?)` | Requête (infinie) | Lister les dépenses d'un employé spécifique |
| `useUpdateExpense()` | Mutation | Mettre à jour une dépense : `{ expenseId, data }` |
| `useDeleteExpense()` | Mutation | Supprimer une dépense par ID |
| `useUploadExpenses()` | Mutation | Télécharger des fichiers de dépenses (FormData) |
| `useUploadMyExpenses()` | Mutation | Télécharger des fichiers de dépenses personnelles |
| `usePresignedUpload()` | Mutation | Upload présigné S3 avec confirmation automatique |
| `usePresignedEmployéeUpload(employéeId)` | Mutation | Upload présigné pour un employé spécifique |
| `useUpdateExpenseCategory()` | Mutation | Mettre à jour la catégorie : `{ expenseId, categoryId }` |
| `useUpdateExpenseNote()` | Mutation | Mettre à jour la note : `{ expenseId, note }` |
| `useUpdateExpenseReview()` | Mutation | Marquer comme revise : `{ expenseId, isReviewed }` |
| `useAssignExpenseToReport()` | Mutation | Assigner à un rapport : `{ expenseId, expenseReportId }` |
| `useSplitExpense()` | Mutation | Diviser une dépense : `{ expenseId, request }` |
| `useExportExpenses()` | Mutation | Exporter les dépenses en fichier (Blob) |
| `useExportExpensesWithFilename()` | Mutation | Exporter avec métadonnées du nom de fichier |
| `useDownloadExpenseAttachments()` | Mutation | Télécharger les pieces jointes en archive |
| `useDownloadExpenseAttachmentsWithFilename()` | Mutation | Télécharger les pieces jointes avec nom de fichier |
| `useDownloadSingleExpenseAttachment()` | Mutation | Télécharger une seule piece jointe |

### Opérations en Lot sur les Dépenses

| Hook | Type | Description |
|------|------|-------------|
| `useBulkAssignCategory()` | Mutation | Assigner une catégorie à plusieurs dépenses |
| `useBulkAssignPayerType()` | Mutation | Assigner un type de payeur à plusieurs dépenses |
| `useBulkAssignExpenseReport()` | Mutation | Assigner un rapport à plusieurs dépenses |
| `useBulkAssignVendor()` | Mutation | Assigner un fournisseur à plusieurs dépenses |
| `useBulkDeleteExpenses()` | Mutation | Supprimer plusieurs dépenses |
| `useBulkSetNote()` | Mutation | Définir la note sur plusieurs dépenses |

## Autres Domaines

Le SDK inclut également des hooks pour les domaines suivants. Chacun suit le meme patron de requête/mutation.

| Domaine | Fichier de Hook | Hooks Principaux |
|---------|----------------|------------------|
| **Pieces jointes** | `useAttachments` | Gérer les pieces jointes |
| **Expéditeurs autorises** | `useAuthorizedSenders` | Gérer les expéditeurs de transfert d'email |
| **Facturation** | `useBilling` | Gestion des abonnements et de la facturation |
| **Paiement** | `useCheckout` | Gestion des sessions de paiement |
| **Connexion** | `useConnect` | Flux de connexion OAuth |
| **Comptes connectés** | `useConnectedAccounts` | Gérer les comptes bancaires connectés |
| **Clients** | `useCustomers` | Gestion des clients |
| **Comptes email** | `useEmailAccounts` | Configuration des comptes email |
| **Transfert d'email** | `useEmailForwarding` | Règles de transfert d'email |
| **Tâches de dépenses** | `useExpenseJobs` | Statut des tâches en arriere-plan |
| **Dépenses de rapport** | `useExpenseReportExpenses` | Gérer les éléments d'un rapport |
| **Paiements de rapport** | `useExpenseReportPayments` | Suivi des paiements de rapport |
| **Intégrations** | `useIntégrations`, `useAppInstallations` | Intégration et marketplace |
| **Invitations** | `useInvitations` | Invitations d'équipe |
| **Paiements de factures** | `useInvoicePayments` | Suivi des paiements de factures |
| **Emplacements** | `useLocations` | Gestion des emplacements |
| **Fidelite** | `useLoyalty` | Gestion du programme de fidelite |
| **Adhesions** | `useMemberships` | Adhesions à l'organisation |
| **Notifications** | `useNotifications` | Préférences de notification |
| **Méthodes de paiement** | `usePaymentMethods` | Gestion des méthodes de paiement |
| **Versements** | `usePayouts` | Gestion des versements |
| **Produits** | `useProducts` | Gestion du catalogue de produits |
| **Codes promo** | `usePromoCodes` | Gestion des codes promotionnels |
| **Reçus** | `useReceipts` | Gestion des reçus numériques |
| **Rapports** | `useReporting` | Analytique et rapports |
| **Tableaux** | `useTables` | Configuration des tableaux de données |
| **Taxes** | `useTaxes` | Gestion des taux de taxe |
| **Transactions** | `useTransactions` | Gestion des transactions |
| **Utilisateurs** | `useUsers` | Gestion des comptes utilisateurs |
| **Flux de travail** | `useWorkflows` | Configuration des flux d'approbation |
