## Aperçu

Smartbills Budgets offre une visibilité sur les dépenses organisationnelles par rapport aux objectifs budgétaires définis. Configurez des budgets par département, projet ou tout regroupement personnalisé, puis suivez les dépenses réelles en temps réel.

### Fonctionnalités clés

- **Création de budgets** — Définir des budgets avec un nom, un montant total, une devise et une période.
- **Répartition par catégorie** — Diviser un budget en catégories pour un suivi plus granulaire des dépenses.
- **Suivi de l'utilisation** — Voir les montants réels, engagés, restants et le pourcentage d'utilisation en un coup d'œil.
- **Notifications** — Configurer des alertes basées sur des seuils (ex. : notifier à 75 %, 90 %, 100 %) pour anticiper les dépassements.

### Permissions

| Permission | Description |
|---|---|
| `BUDGETS_VIEW` | Voir les budgets et leur utilisation |
| `BUDGETS_MANAGE` | Créer, modifier et supprimer des budgets |

Les administrateurs et comptables ont les deux permissions par défaut.

### Points d'accès API

| Méthode | Point d'accès | Description |
|---|---|---|
| `GET` | `/v1/businesses/{businessId}/budgets` | Lister les budgets |
| `POST` | `/v1/businesses/{businessId}/budgets` | Créer un budget |
| `GET` | `/v1/businesses/{businessId}/budgets/{budgetId}` | Détails d'un budget |
| `PUT` | `/v1/businesses/{businessId}/budgets/{budgetId}` | Mettre à jour un budget |
| `DELETE` | `/v1/businesses/{businessId}/budgets/{budgetId}` | Supprimer un budget |
| `POST` | `/v1/businesses/{businessId}/budgets/{budgetId}/categories` | Ajouter une catégorie |
| `PUT` | `/v1/businesses/{businessId}/budgets/{budgetId}/categories/{categoryId}` | Mettre à jour une catégorie |
| `DELETE` | `/v1/businesses/{businessId}/budgets/{budgetId}/categories/{categoryId}` | Supprimer une catégorie |
| `POST` | `/v1/businesses/{businessId}/budgets/{budgetId}/notifications` | Créer une notification |
| `DELETE` | `/v1/businesses/{businessId}/budgets/{budgetId}/notifications/{notificationId}` | Supprimer une notification |
