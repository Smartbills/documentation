---
title: "Actions"
description: "Actions exécutées par les automatisations Smartbills"
---

Les actions sont les opérations effectuées lorsqu'une automatisation est déclenchée. Chaque flux peut inclure une ou plusieurs actions exécutées séquentiellement.

**Actions sur les dépenses** : modifier la catégorie, assigner au département, ajouter des étiquettes, envoyer pour approbation. **Notifications** : envoyer un courriel, une notification in-app ou push. **Rapports** : créer un rapport, ajouter une dépense à un rapport. **Intégrations** : synchroniser avec un logiciel comptable, créer une tâche externe.

<Tip>
Les actions peuvent inclure des variables dynamiques comme le nom du marchand, le montant ou l'employé pour personnaliser les notifications.
</Tip>

Configurez l'ordre des actions dans votre automatisation. Si une action échoue, vous pouvez définir le comportement : continuer, arrêter le flux ou exécuter une action de secours.
