## Qu'est-ce que l'assistant IA ?

L'assistant IA Smartbills est une interface conversationnelle intelligente intégrée au tableau de bord. Il vous permet de gérer vos opérations — dépenses, rapports, factures, transactions bancaires, catégories et plus encore — en tapant simplement des instructions en langage naturel.

L'assistant utilise des sous-agents spécialisés qui comprennent le contexte de votre entreprise et peuvent effectuer des actions en votre nom, avec une confirmation intégrée pour les opérations destructrices.

## Fonctionnalités principales

- **Contrôle en langage naturel** — Posez des questions ou d.nnez des instructions en français ou en anglais
- **Expertise multi-domaine** — Gère les dépenses, rapports, banque, paramètres, catégories, factures et plus
- **Flux de confirmation** — Les actions destructrices (suppressions, modifications) nécessitent votre approbation explicite avant exécution
- **Historique des conversations** — Les conversations passées sont stockées et accessibles pour référence
- **Diffusion en temps réel** — Les réponses sont diffusées en temps réel avec des indicateurs d'exécution d'outils

## Pour commencer

<Steps>
  <Step title="Ouvrir l'assistant">
    Cliquez sur le bouton étincelle en bas à droite du tableau de bord.
  </Step>
  <Step title="Démarrer une conversation">
    Tapez votre demande dans le champ de saisie. Par exemple : « Montre-moi mes rapports de dépenses en attente » ou « Crée une nouvelle catégorie appelée Voyage ».
  </Step>
  <Step title="Examiner les actions">
    Lorsque l'assistant doit effectuer une action destructrice (comme supprimer une dépense), il vous demandera votre confirmation avant de procéder.
  </Step>
  <Step title="Continuer la conversation">
    Vous pouvez poser des questions de suivi ou d.nner des instructions supplémentaires dans le même fil de conversation.
  </Step>
</Steps>

## Flux de confirmation

Pour toute action qui modifié des données, l'assistant présentera une bannière de confirmation affichant :

- La description de l'action (ex. : « Supprimer la dépense #123 »)
- L'outil appelé
- Les boutons **Approuver** ou **Refuser**

L'action ne sera exécutée qu'après avoir cliqué sur **Approuver**. Cliquer sur **Refuser** annule l'action et l'assistant accusera réception de l'annulation.

## Points de terminaison API

Tous les points de terminaison de l'assistant sont sous `/v1/assistants/chats`.

### Conversations

| Méthode | Point de terminaison | Description |
|---------|---------------------|-------------|
| `GET` | `/v1/assistants/chats` | Lister les conversations |
| `GET` | `/v1/assistants/chats/{id}` | Obtenir l'historique d'une conversation |
| `POST` | `/v1/assistants/chats` | Créer une nouvelle conversation |
| `PUT` | `/v1/assistants/chats/{id}/title` | Modifier le titre d'une conversation |
| `DELETE` | `/v1/assistants/chats/{id}` | Supprimer une conversation |

### Messages

| Méthode | Point de terminaison | Description |
|---------|---------------------|-------------|
| `POST` | `/v1/assistants/chats/{id}/messages` | Envoyer un message (réponse en flux SSE) |
| `POST` | `/v1/assistants/chats/confirm` | Confirmer ou refuser une action en attente |

## Utilisation du SDK

```typescript
import { SmartbillsClient } from "@smartbills/sdk";

const client = new SmartbillsClient({ accessToken: "..." });

const conversations = await client.conversations.list();

const conversation = await client.conversations.create({
  title: "Revue des dépenses de mars",
});

const history = await client.conversations.getHistory(conversation.id);

await client.conversations.confirmAction({
  threadId: "thread_abc",
  toolCallId: "call_xyz",
  approved: true,
});
```

## Événements Server-Sent (SSE)

Lors de l'envoi d'un message, la réponse est diffusée sous forme d'événements Server-Sent. Les types d'événements incluent :

| Événement | Description |
|-----------|-------------|
| `token` | Un jeton de texte de la réponse de l'assistant |
| `tool_start` | L'assistant à commencé l'exécution d'un outil |
| `tool_end` | Un outil à terminé son exécution |
| `pending_action` | Une action destructrice attend la confirmation de l'utilisateur |
| `error` | Une erreur est survenue pendant le traitement |
| `done` | Le flux est terminé |

## Architecture

L'assistant IA utilise une architecture multi-agent :

1. **Agent superviseur** — Achemine les demandes vers l'agent spécialisé approprié
2. **Agent affaires** — Gère les paramètres d'entreprise, la gestion d'équipe, les catégories
3. **Agent dépenses** — Gère les dépenses, rapports et tâches de traitement
4. **Agent bancaire** — Gère les connexions bancaires, comptes et transactions

Tous les agents communiquent via l'API principale Smartbills, qui redirige les requêtes vers le microservice d'agents tout en préservant le contexte d'authentification.
