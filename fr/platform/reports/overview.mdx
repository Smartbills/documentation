## Qu'est-ce qu'un rapport de dépenses ?

Les rapports de dépenses sont des collections de dépenses individuelles regroupées pour soumission, approbation et remboursement. Ils fournissent un moyen formel de demander un remboursement pour les dépenses professionnelles.

## Cycle de vie du rapport

<Steps>
  <Step title="Créer">
    Commencez un nouveau rapport de dépenses et donnez-lui un titre.
  </Step>
  <Step title="Ajouter des dépenses">
    Ajoutez vos dépenses au rapport depuis votre liste de dépenses.
  </Step>
  <Step title="Réviser">
    Vérifiez que toutes les dépenses sont correctes et complètes.
  </Step>
  <Step title="Soumettre">
    Soumettez le rapport pour approbation.
  </Step>
  <Step title="Approbation">
    Les approbateurs examinent et approuvent ou rejettent le rapport.
  </Step>
  <Step title="Remboursement">
    Les dépenses approuvées sont traitées pour paiement.
  </Step>
</Steps>

## Statut du rapport

| Statut | Description |
|--------|-------------|
| **Brouillon** | Rapport créé mais non soumis |
| **Soumis** | En attente d'approbation |
| **En révision** | Actuellement en cours de révision par l'approbateur |
| **Approuvé** | Toutes les approbations complétées |
| **Rejeté** | Rejeté par un approbateur |
| **Modifications demandées** | Retourné pour modifications |
| **En traitement** | En cours de traitement pour remboursement |
| **Remboursé** | Paiement complété |

## Créer un rapport

### Création rapide

1. Allez dans **Rapports de dépenses**
2. Cliquez sur **Nouveau rapport**
3. Entrez un titre de rapport (ex: "Dépenses janvier 2025")
4. Sélectionnez optionnellement une période
5. Cliquez sur **Créer**

### À partir de dépenses sélectionnées

1. Allez dans **Dépenses**
2. Sélectionnez les dépenses à inclure
3. Cliquez sur **Ajouter au rapport > Nouveau rapport**
4. Entrez les détails du rapport
5. Cliquez sur **Créer le rapport**

## Contenu du rapport

### Informations requises

| Champ | Description |
|-------|-------------|
| Titre | Nom descriptif du rapport |
| Dépenses | Au moins une dépense |
| Date de soumission | Quand le rapport est soumis |

### Informations optionnelles

| Champ | Description |
|-------|-------------|
| Description | Contexte additionnel |
| Période | Période couverte |
| Projet | Projet associé |
| Département | Département soumetteur |
| Notes | Commentaires pour l'approbateur |

## Meilleures pratiques

<Tip>
**Soumettez régulièrement** - Ne laissez pas les dépenses s'accumuler. Soumettez hebdomadairement ou bi-hebdomadairement.
</Tip>

<Tip>
**Titres clairs** - Utilisez des titres descriptifs comme "Voyage client T1 - Projet X".
</Tip>

<Tip>
**Révisez avant de soumettre** - Vérifiez tous les montants et catégories.
</Tip>

<Tip>
**Ajoutez des notes** - Expliquez les dépenses inhabituelles pour accélérer l'approbation.
</Tip>
