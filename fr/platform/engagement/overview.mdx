## Engagement Post-Achat

Smartbills transforme les reçus de simples documents transactionnels en puissants outils d'engagement. Chaque reçu est une opportunité de construire des relations, recueillir des commentaires et générer des visites répétées.

## L'opportunité d'engagement

### Reçu traditionnel

```
Reçu papier → Jeté → Oublié
```

### Reçu Smartbills

```
Reçu numérique → Consulté → Engagé → Visite de retour
```

## Avis et commentaires

### Avis intégrés au reçu

Les clients peuvent évaluer leur expérience directement sur le reçu :

```
┌─────────────────────────────────────┐
│ Comment était votre expérience ?    │
│                                     │
│ ⭐⭐⭐⭐⭐                           │
│                                     │
│ [Laisser un avis]                   │
└─────────────────────────────────────┘
```

### Avantages

- **Taux de réponse plus élevés** - 40%+ vs 5% pour les sondages par email
- **Commentaires immédiats** - Capturez le sentiment pendant qu'il est frais
- **Achats vérifiés** - Seuls les vrais clients peuvent évaluer
- **Évaluations par article** - Sachez quels produits excellent

## Marketing personnalisé

### Promotions sur le reçu

Montrez des offres pertinentes basées sur :

- Ce qu'ils viennent d'acheter
- L'historique d'achat
- Le temps depuis la dernière visite
- Le niveau de fidélité

### Exemple

Le client achète un café → Le reçu montre :

```
┌─────────────────────────────────────┐
│ 🥐 Complétez votre matin !          │
│                                     │
│ Ajoutez une pâtisserie à votre      │
│ prochaine commande et obtenez 20%   │
│ de rabais                           │
│                                     │
│ [Enregistrer l'offre]               │
└─────────────────────────────────────┘
```

```
│    coupe de cheveux ?               │
│                                     │
│ Votre dernière coupe était il y a   │
│ 6 semaines.                         │
│                                     │
│ [Réserver le même styliste]         │
│ [Voir les disponibilités]           │
└─────────────────────────────────────┘
```

### Services supportés

- Salons et spas
- Dentaire et médical
- Service auto
- Toilettage animaux
- Cours de fitness

## Fonctionnalités sociales

### Partage de l'addition

Divisez les achats avec des amis :

1. Le client ouvre le reçu
2. Appuie sur "Partager l'addition"
3. Sélectionne les articles ou le montant
4. Envoie la demande aux amis
5. Les amis paient leur part

## Meilleures pratiques

<Tip>
**Ne surchargez pas** - Choisissez 1-2 fonctionnalités d'engagement par reçu.
</Tip>

<Tip>
**Personnalisez** - Utilisez l'historique d'achat pour la pertinence.
</Tip>

<Tip>
**Bon timing** - Montrez les rappels de réservation aux intervalles appropriés.
</Tip>

<Tip>
**Testez A/B** - Expérimentez avec différentes offres et messages.
</Tip>
