---
title: "Guide de Démarrage Rapide"
description: "Commencez avec l'API Smartbills en quelques minutes"
---

Ce guide vous aidera à effectuer votre premier appel API vers Smartbills en quelques minutes. À la fin de ce guide, vous aurez créé un compte Smartbills, généré votre clé API, effectué votre premier appel et téléversé votre première dépense.

Pour commencer, vous aurez besoin d'un compte Smartbills. Inscrivez-vous gratuitement sur [app.smartbills.io](https://auth.smartbills.io/sign-up). Une fois connecté, accédez à **Paramètres** → **Développeur** → **Clés API** pour générer une clé. Stockez-la dans une variable d'environnement — elle ne sera affichée qu'une seule fois.

Utilisez votre clé API dans l'en-tête `Authorization: Bearer VOTRE_CLÉ_API` pour chaque requête. Vous pouvez tester en appelant l'endpoint `/v1/user` pour récupérer vos informations. Pour téléverser une dépense, utilisez `POST /v1/expenses/upload` avec un fichier reçu et l'identifiant de votre entreprise.

<Tip>
Utilisez les clés de test (`sk_test_`) pour le développement et les clés de production (`sk_live_`) uniquement en production.
</Tip>

Consultez la documentation d'[Authentification](/fr/authentication) pour en savoir plus sur la sécurité et les bonnes pratiques. Explorez la [Référence API](/api-reference/introduction) pour découvrir tous les endpoints disponibles.
