## Démarrage rapide

Ce guide vous aidera à commencer avec Smartbills, que vous soyez un marchand ou un consommateur.

## Pour les Marchands

### Étape 1 : Créez votre compte

1. Rendez-vous sur [app.smartbills.io](https://app.smartbills.io)
2. Cliquez sur **Créer un compte**
3. Entrez vos informations d'entreprise
4. Vérifiez votre email

### Étape 2 : Configurez votre entreprise

1. Ajoutez le logo de votre entreprise
2. Configurez vos emplacements
3. Définissez vos catégories de produits
4. Personnalisez vos reçus

### Étape 3 : Connectez votre système de caisse

Choisissez votre intégration :

| Système | Configuration |
|---------|---------------|
| Shopify | Installation en 1 clic |
| Square | OAuth automatique |
| Clover | Via Clover App Market |
| Lightspeed | Configuration guidée |
| API personnalisée | Documentation complète |

### Étape 4 : Lancez les reçus numériques

1. Testez avec une transaction
2. Vérifiez la réception du reçu
3. Activez pour tous les clients
4. Communiquez à vos clients

### Créez votre compte

1. Ouvrez l'application Smartbills
2. Inscrivez-vous avec votre email ou téléphone
3. Vérifiez votre compte

### Ajoutez vos méthodes de paiement

1. Allez dans **Paramètres > Cartes de paiement**
2. Appuyez sur **Ajouter une carte**
3. Scannez ou entrez les détails de votre carte
4. Vérifiez si nécessaire

### Commencez à recevoir vos reçus

C'est tout ! Vos reçus arriveront automatiquement après chaque achat chez un marchand Smartbills.

## Fonctionnalités clés

### Reçus automatiques

Recevez vos reçus sans rien faire :

```
Vous payez → Transaction détectée → Reçu envoyé
```

### Organisation intelligente

- **Par catégorie** - Restaurants, épicerie, transports...
- **Par marchand** - Tous vos achats chez chaque commerçant
- **Par date** - Historique complet consultable

### Partage de notes

Divisez facilement les additions :

1. Ouvrez un reçu
2. Appuyez sur **Partager**
3. Sélectionnez les articles ou montants
4. Envoyez aux participants

### Suivi des dépenses

- Visualisez vos dépenses par catégorie
- Définissez des budgets
- Recevez des alertes
- Exportez pour vos impôts
