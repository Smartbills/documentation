---
title: "Commencer"
description: "Démarrez le développement avec l'API Smartbills"
---

L'API Smartbills est une API REST qui permet d'intégrer les capacités de gestion des dépenses dans vos applications. Ce guide vous aide à démarrer rapidement avec les bases de l'API : URL de base, authentification et exécution des requêtes.

Avant de commencer, assurez-vous d'avoir un compte Smartbills, une clé API et une connaissance de base des APIs REST. L'API utilisé JSON pour les requêtes et réponses, ISO 8601 pour les dates et des codes de devise ISO 4217. L'authentification se fait par jeton Bearer dans l'en-tête `Authorization`.

Pour vos requêtes, utilisez l'URL de base `https://api.smartbills.io/v1`. Les endpoints de liste supportent la pagination via les paramètres `page` et `pageSize`. Consultez la documentation sur l'authentification, les clés API et la gestion des erreurs pour une intégration complète.
