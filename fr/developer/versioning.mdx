---
title: "Versionnage"
description: "Gestion des versions de l'API Smartbills"
---

L'API Smartbills utilise un versionnage par URL. La version actuelle est **v1**. Toutes les requêtes doivent inclure la version dans l'URL : `https://api.smartbills.io/v1/expenses`.

Nous maintenons la compatibilité ascendante au sein d'une version majeure. L'ajout de nouveaux endpoints, paramètres optionnels ou propriétés de réponse ne casse pas les intégrations existantes. Les changements majeurs (suppression d'endpoints, modification de types) entraînent une nouvelle version majeure.

Lorsqu'une nouvelle version majeure est publiée, nous donnons un préavis d'au moins 12 mois avant la dépréciation de l'ancienne version. Des guides de migration sont fournis. Consultez régulièrement le changelog pour les annonces de versions.
