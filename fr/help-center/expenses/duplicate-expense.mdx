## Aperçu

La duplication est pratique pour les dépenses récurrentes (abonnements, fournitures mensuelles). Une copie est créée avec les mêmes détails; vous modifiez ensuite la date, le montant ou d'autres champs selon les besoins.

<Steps>
  <Step title="Sélectionnez la dépense">
    Ouvrez la dépense que vous souhaitez dupliquer.
  </Step>
  <Step title="Cliquez sur Dupliquer">
    Utilisez le menu ou le bouton **Dupliquer la dépense**.
  </Step>
  <Step title="Modifiez les champs">
    La nouvelle dépense s'ouvre avec les données préremplies. Modifiez la date, le montant et les notes.
  </Step>
</Steps>

<Tip>
Pour plusieurs dépenses similaires, utilisez les [actions en lot](/fr/help-center/expenses/bulk-actions) pour gagner du temps.
</Tip>
