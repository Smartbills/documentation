---
title: "Exporter un Rapport"
description: "Comment exporter un rapport de dépenses en PDF ou Excel"
---

L'exportation d'un rapport de dépenses vous permet de le télécharger au format PDF ou Excel pour archivage, présentation ou intégration dans vos systèmes comptables externes. Les exports sont disponibles pour les rapports approuvés, soumis ou même en brouillon selon les permissions.

Depuis la page du rapport, cliquez sur **Exporter** ou sur l'icône de téléchargement. Choisissez le format (PDF ou Excel). Le PDF inclut un résumé professionnel avec les dépenses, les reçus miniaturisés et les totaux. Le format Excel contient les données structurées pour une analyse ou une importation ultérieure.

<Steps>
  <Step title="Ouvrir le rapport">
    Sélectionnez le rapport à exporter dans votre liste.
  </Step>
  <Step title="Choisir le format">
    Cliquez sur **Exporter** et sélectionnez PDF ou Excel selon vos besoins.
  </Step>
  <Step title="Télécharger">
    Le fichier sera généré et téléchargé automatiquement sur votre appareil.
  </Step>
</Steps>

<AccordionGroup>
  <Accordion title="Contenu du PDF" icon="file-pdf">
    Le PDF inclut le nom du rapport, la date, les dépenses avec reçus, les catégories et le total.
  </Accordion>
  <Accordion title="Contenu Excel" icon="file-excel">
    Le fichier Excel contient les colonnes : marchand, date, montant, catégorie, notes, etc.
  </Accordion>
</AccordionGroup>

<Tip>
Exportez régulièrement vos rapports approuvés pour vos archives fiscales et la conformité.
</Tip>
