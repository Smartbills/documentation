---
title: "Flux d'Approbation"
description: "Configurer les chaînes d'approbation pour les rapports de dépenses"
---

Le flux d'approbation définit qui doit approuver les rapports de dépenses avant qu'ils soient finalisés. Vous pouvez configurer des approbations à un ou plusieurs niveaux selon la structure de votre organisation et les montants des dépenses.

Pour configurer le flux d'approbation, allez dans **Paramètres** → **Flux d'approbation**. Définissez les seuils par montant (par exemple : jusqu'à 500 $ pour le gestionnaire, au-delà pour le directeur) et assignez les approbateurs à chaque niveau. Les règles peuvent varier par département.

<Steps>
  <Step title="Définir les seuils">
    Montants qui déclenchent chaque niveau d'approbation
  </Step>
  <Step title="Assigner les approbateurs">
    Utilisateurs ou rôles responsables de chaque niveau
  </Step>
  <Step title="Configurer par département">
    Règles optionnelles selon le département
  </Step>
</Steps>

<Note>
Les rapports sont automatiquement routés vers les bons approbateurs selon les règles configurées.
</Note>
