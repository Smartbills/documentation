## Aperçu

L'authentification à deux facteurs (2FA) ajoute une couche de sécurité supplémentaire à votre compte Smartbills. En plus de votre mot de passe, vous devrez saisir un code temporaire généré par une application d'authentification ou envoyé par SMS lors de la connexion.

<Note>
  Nous recommandons fortement d'activer la 2FA pour protéger vos données financières et vos informations professionnelles.
</Note>

## Configuration de la 2FA

<Steps>
  <Step title="Accéder aux Paramètres de Sécurité">
    Allez dans **Paramètres** → **Sécurité** → **Authentification à deux facteurs**
  </Step>

  <Step title="Activer la 2FA">
    Cliquez sur **Activer l'authentification à deux facteurs**
  </Step>

  <Step title="Scanner le Code QR">
    Utilisez une application d'authentification (Google Authenticator, Authy, 1Password) pour scanner le code QR affiché.
  </Step>

  <Step title="Saisir le Code de Vérification">
    Entrez le code à six chiffres généré par l'application pour confirmer la configuration.
  </Step>

  <Step title="Sauvegarder les Codes de Récupération">
    Téléchargez ou notez les codes de récupération en lieu sûr. Ils vous permettront d'accéder à votre compte si vous perdez l'accès à l'application.
  </Step>
</Steps>

<Warning>
  Conservez vos codes de récupération dans un endroit sûr. Sans eux et sans accès à votre application d'authentification, vous pourriez être verrouillé hors de votre compte.
</Warning>

## Applications Recommandées

- **Google Authenticator** (iOS et Android)
- **Authy** (iOS, Android et bureau)
- **1Password** (intégré au gestionnaire de mots de passe)

<Tip>
  Authy offre une sauvegarde cloud des codes, ce qui facilite la restauration sur un nouvel appareil.
</Tip>
