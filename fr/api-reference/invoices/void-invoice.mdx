---
title: "Annuler une facture"
api: "POST https://api.smartbills.io/v1/invoices/{invoiceId}/void"
description: "Annuler une facture, la marquant comme annulée et non payable"
---

## Paramètres de chemin

<ParamField path="invoiceId" type="integer" required>
  L'identifiant unique de la facture à annuler
</ParamField>

## Réponse

Retourne l'objet facture mis à jour avec `billStatus` défini sur `Void` et un horodatage `voidedAt`.

<Tip>
  L'annulation d'une facture désactive le lien de paiement et empêche tout prélèvement de paiement ultérieur. Cette action ne peut pas être annulée.
</Tip>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.smartbills.io/v1/invoices/1001/void \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json'
```

```javascript JavaScript
const invoice = await smartbills.invoices.void(1001);
```

```csharp C#
var invoice = await invoiceClient.VoidAsync(1001);
```

</RequestExample>
