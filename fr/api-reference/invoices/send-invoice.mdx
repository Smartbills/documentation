---
title: "Envoyer une facture"
api: "POST https://api.smartbills.io/v1/invoices/{invoiceId}/send"
description: "Envoyer une facture au client par courriel et générer un lien de paiement"
---

## Paramètres de chemin

<ParamField path="invoiceId" type="integer" required>
  L'identifiant unique de la facture à envoyer
</ParamField>

## Réponse

Retourne l'objet facture mis à jour avec `billStatus` défini sur `Sent`, un horodatage `sentAt` et un `paymentLinkUrl` généré.

<Tip>
  L'envoi d'une facture déclenche une notification par courriel au client avec un lien vers la page de paiement hébergée où il peut payer via Stripe.
</Tip>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.smartbills.io/v1/invoices/1001/send \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json'
```

```javascript JavaScript
const invoice = await smartbills.invoices.send(1001);
```

```csharp C#
var invoice = await invoiceClient.SendAsync(1001);
```

</RequestExample>
