---
title: "Marquer une facture comme payée"
api: "POST https://api.smartbills.io/v1/businesses/{businessId}/invoices/{invoiceId}/mark-paid"
description: "Marquer manuellement une facture comme payée sans traiter de paiement"
---

## Paramètres de chemin

<ParamField path="businessId" type="integer" required>
  L'identifiant unique de l'entreprise
</ParamField>

<ParamField path="invoiceId" type="integer" required>
  L'identifiant unique de la facture
</ParamField>

## Réponse

Retourne l'objet facture mis à jour avec le statut `MarkedPaid`.

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.smartbills.io/v1/businesses/456/invoices/1001/mark-paid \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json'
```

```javascript JavaScript
const invoice = await smartbills.invoices.markPaid(1001);
```

```csharp C#
var invoice = await invoiceClient.MarkPaidAsync(1001,
    new SBRequestOptions { BusinessId = 456 });
```

</RequestExample>

<ResponseExample>

```json Response
{
  "id": 1001,
  "invoiceNumber": "INV-2026-0001",
  "billStatus": "MarkedPaid",
  "isPaid": true,
  "paidAt": "2026-05-05T14:30:00Z",
  "total": { "amount": 1500.00, "currency": "CAD" },
  "amountDue": { "amount": 0, "currency": "CAD" },
  "createdAt": "2026-04-01T10:00:00Z",
  "updatedAt": "2026-05-05T14:30:00Z"
}
```

</ResponseExample>
