---
title: "Dupliquer une facture"
api: "POST https://api.smartbills.io/v1/businesses/{businessId}/invoices/{invoiceId}/duplicate"
description: "Créer une copie d'une facture existante avec un nouveau numéro"
---

## Paramètres de chemin

<ParamField path="businessId" type="integer" required>
  L'identifiant unique de l'entreprise
</ParamField>

<ParamField path="invoiceId" type="integer" required>
  L'identifiant unique de la facture à dupliquer
</ParamField>

## Réponse

Retourne la facture nouvellement créée en tant que `Draft` avec un nouveau numéro. Tous les éléments de ligne, frais et remises sont copiés de l'original.

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.smartbills.io/v1/businesses/456/invoices/1001/duplicate \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json'
```

```javascript JavaScript
const invoice = await smartbills.invoices.duplicate(1001);
```

```csharp C#
var invoice = await invoiceClient.DuplicateAsync(1001,
    new SBRequestOptions { BusinessId = 456 });
```

</RequestExample>
