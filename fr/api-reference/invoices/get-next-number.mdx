---
title: "Obtenir le prochain numéro de facture"
api: "GET https://api.smartbills.io/v1/businesses/{businessId}/invoices/next-number"
description: "Prévisualiser le prochain numéro de facture auto-généré, optionnellement pour un client spécifique"
---

## Paramètres de chemin

<ParamField path="businessId" type="integer" required>
  L'identifiant unique de l'entreprise
</ParamField>

## Paramètres de requête

<ParamField query="customerId" type="integer">
  Lorsque fourni, retourne le prochain numéro de facture en utilisant le préfixe du client. Si le client n'a pas de préfixe, un est auto-généré à partir du nom du client (ex. « Mobbin Pte Ltd » produit le préfixe `MOB`).
</ParamField>

## Réponse

<ResponseField name="invoiceNumber" type="string">
  Le prochain numéro de facture complet (ex. `MOB-000042`)
</ResponseField>

<ResponseField name="prefix" type="string">
  La portion préfixe du numéro de facture
</ResponseField>

<ResponseField name="sequenceNumber" type="integer">
  La portion numérique séquentielle
</ResponseField>

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.smartbills.io/v1/businesses/456/invoices/next-number?customerId=789' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
const nextNumber = await smartbills.invoices.getNextInvoiceNumber(789);
```

```csharp C#
var nextNumber = await invoiceClient.GetNextInvoiceNumberAsync(789,
    new SBRequestOptions { BusinessId = 456 });
```

</RequestExample>

<ResponseExample>

```json Response
{
  "invoiceNumber": "MOB-000001",
  "prefix": "MOB",
  "sequenceNumber": 1
}
```

</ResponseExample>
