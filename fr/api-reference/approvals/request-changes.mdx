---
title: "Demander des modifications"
description: "Demander des modifications à un rapport de dépenses soumis avant approbation"
api: "POST https://api.smartbills.io/v1/businesses/{businessId}/approbations/{reportId}/request-changes"
---

## Aperçu

Renvoyer un rapport de dépenses à l'employé avec une demande de modifications. Contrairement à un rejet, cela indique que le rapport peut être approuvé une fois les modifications spécifiques effectuées. Le statut du rapport passe à `changes_requested` et l'employé reçoit une notification avec vos commentaires.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer pour l'authentification. Format : `Bearer YOUR_API_KEY`
</ParamField>

## Paramètres de chemin

<ParamField path="businessId" type="integer" required>
  L'identifiant unique de l'entreprise
</ParamField>

<ParamField path="reportId" type="integer" required>
  L'identifiant unique du rapport de dépenses
</ParamField>

## Corps de la requête

<ParamField body="changes" type="string" required>
  Description des modifications nécessaires. Soyez précis sur les dépenses à modifier et les changements requis.
</ParamField>

## Réponse

<ResponseField name="reportId" type="integer">
  Identifiant du rapport de dépenses
</ResponseField>

<ResponseField name="status" type="string">
  Statut mis à jour du rapport : `changes_requested`
</ResponseField>

<ResponseField name="requestedBy" type="integer">
  Identifiant de l'utilisateur qui à demandé les modifications
</ResponseField>

<ResponseField name="requestedAt" type="string">
  Horodatage de la demande de modification (ISO 8601)
</ResponseField>

<ResponseField name="changes" type="string">
  Description des modifications demandées
</ResponseField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.smartbills.io/v1/businesses/456/approbations/789/request-changes \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "changes": "Please recategorize the Uber expense from Travel to Ground Transportation, and add à business purpose note to the dinner expense."
  }'
```

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 400 | REPORT_NOT_SUBMITTED | Le rapport n'a pas été soumis pour approbation |
| 400 | CHANGES_REQUIRED | La description des modifications est requise |
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | NOT_APPROVER | Vous n'êtes pas approbateur pour ce rapport |
| 404 | REPORT_NOT_FOUND | Le rapport n'existe pas |

<Tip>
  Utilisez "Demander des modifications" au lieu de "Rejeter" lorsque le rapport est presque acceptable mais nécessite des corrections mineures. Cela maintient le rapport dans un état révisable et évite de demander à l'employé de tout recommencer.
</Tip>
