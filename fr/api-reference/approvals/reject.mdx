---
title: "Rejeter un rapport"
description: "Rejeter un rapport de dépenses soumis"
api: "POST https://api.smartbills.io/v1/businesses/{businessId}/approbations/{reportId}/reject"
---

## Aperçu

Rejeter un rapport de dépenses soumis pour approbation. Un motif doit être fourni pour informer l'employé de la raison du rejet. Le statut du rapport passe à `rejected` et l'employé peut corriger les problèmes et resoumettre.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer pour l'authentification. Format : `Bearer YOUR_API_KEY`
</ParamField>

## Paramètres de chemin

<ParamField path="businessId" type="integer" required>
  L'identifiant unique de l'entreprise
</ParamField>

<ParamField path="reportId" type="integer" required>
  L'identifiant unique du rapport de dépenses à rejeter
</ParamField>

## Corps de la requête

<ParamField body="reason" type="string" required>
  Motif du rejet du rapport. Celui-ci est visible par l'employé soumetteur.
</ParamField>

## Réponse

<ResponseField name="reportId" type="integer">
  Identifiant du rapport rejeté
</ResponseField>

<ResponseField name="status" type="string">
  Statut mis à jour du rapport : `rejected`
</ResponseField>

<ResponseField name="rejectedBy" type="integer">
  Identifiant de l'utilisateur qui à rejeté le rapport
</ResponseField>

<ResponseField name="rejectedAt" type="string">
  Horodatage du rejet (ISO 8601)
</ResponseField>

<ResponseField name="reason" type="string">
  Motif du rejet
</ResponseField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.smartbills.io/v1/businesses/456/approbations/789/reject \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "reason": "Missing receipts for hotel and meal expenses. Please attach receipts and resubmit."
  }'
```

```javascript JavaScript
const result = await client.approbations.reject(789, {
  reason: "Missing receipts for hotel and meal expenses. Please attach receipts and resubmit."
});
```

```python Python
result = client.approbations.reject(
    report_id=789,
    request={
        "reason": "Missing receipts for hotel and meal expenses. Please attach receipts and resubmit."
    }
)
```

```csharp C#
var result = await client.Approbations.RejectAsync(789, new RejectRequest
{
    Reason = "Missing receipts for hotel and meal expenses. Please attach receipts and resubmit."
});
```

</RequestExample>

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 400 | REPORT_NOT_SUBMITTED | Le rapport n'a pas été soumis pour approbation |
| 400 | REASON_REQUIRED | Un motif de rejet est requis |
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | NOT_APPROVER | Vous n'êtes pas approbateur pour ce rapport |
| 404 | REPORT_NOT_FOUND | Le rapport n'existe pas |
