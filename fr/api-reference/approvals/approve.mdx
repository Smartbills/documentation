---
title: "Approuver un rapport"
description: "Approuver un rapport de dépenses soumis"
api: "POST https://api.smartbills.io/v1/businesses/{businessId}/approbations/{reportId}/approve"
---

## Aperçu

Approuver un rapport de dépenses soumis pour examen. Vous pouvez approuver le montant total ou spécifier un montant approuvé réduit. Optionnellement, approuver ou rejeter des dépenses individuelles au sein du rapport.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer pour l'authentification. Format : `Bearer YOUR_API_KEY`
</ParamField>

## Paramètres de chemin

<ParamField path="businessId" type="integer" required>
  L'identifiant unique de l'entreprise
</ParamField>

<ParamField path="reportId" type="integer" required>
  L'identifiant unique du rapport de dépenses à approuver
</ParamField>

## Corps de la requête

<ParamField body="approvedAmount" type="number">
  Montant total approuvé. Si non spécifié, le montant total du rapport est approuvé.
</ParamField>

<ParamField body="notes" type="string">
  Notes ou commentaires d'approbation visibles par le soumetteur
</ParamField>

<ParamField body="expenseApprovals" type="array">
  Décisions d'approbation par dépense pour les approbations partielles

  <Expandable title="Objet Approbation de dépense">
    <ParamField body="expenseId" type="integer" required>
      Identifiant de la dépense dans le rapport
    </ParamField>

    <ParamField body="approved" type="boolean" required>
      Indique si cette dépense spécifique est approuvée
    </ParamField>

    <ParamField body="approvedAmount" type="number">
      Montant approuvé pour cette dépense (par défaut, le montant total de la dépense si approuvée)
    </ParamField>

    <ParamField body="notes" type="string">
      Notes spécifiques à l'approbation de cette dépense
    </ParamField>
  </Expandable>
</ParamField>

## Réponse

<ResponseField name="reportId" type="integer">
  Identifiant du rapport approuvé
</ResponseField>

<ResponseField name="status" type="string">
  Statut mis à jour du rapport : `approved` ou `partially_approved`
</ResponseField>

<ResponseField name="approvedAmount" type="number">
  Montant total approuvé
</ResponseField>

<ResponseField name="approvedBy" type="integer">
  Identifiant de l'approbateur
</ResponseField>

<ResponseField name="approvedAt" type="string">
  Horodatage de l'approbation (ISO 8601)
</ResponseField>

<ResponseField name="notes" type="string">
  Notes d'approbation
</ResponseField>

<ResponseField name="expenseApprovals" type="array">
  Résultats d'approbation par dépense (si fournis)

  <Expandable title="Résultat d'approbation de dépense">
    <ResponseField name="expenseId" type="integer">
      Identifiant de la dépense
    </ResponseField>
    <ResponseField name="approved" type="boolean">
      Indique si la dépense à été approuvée
    </ResponseField>
    <ResponseField name="approvedAmount" type="number">
      Montant approuvé
    </ResponseField>
    <ResponseField name="notes" type="string">
      Notes au niveau de la dépense
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
# Approbation complète
curl --request POST \
  --url https://api.smartbills.io/v1/businesses/456/approbations/789/approve \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "notes": "Approved - all expenses are within policy"
  }'

# Approbation partielle avec décisions par dépense
curl --request POST \
  --url https://api.smartbills.io/v1/businesses/456/approbations/789/approve \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "approvedAmount": 1050.00,
    "notes": "Meal expense adjusted to per diem limit",
    "expenseApprovals": [
      { "expenseId": 12345, "approved": true },
      { "expenseId": 12346, "approved": true },
      { "expenseId": 12347, "approved": true, "approvedAmount": 75.00, "notes": "Reduced to per diem rate" }
    ]
  }'
```

});

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 400 | REPORT_NOT_SUBMITTED | Le rapport n'a pas été soumis pour approbation |
| 400 | ALREADY_APPROVED | Le rapport à déjà été approuvé |
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | NOT_APPROVER | Vous n'êtes pas approbateur pour ce rapport |
| 404 | REPORT_NOT_FOUND | Le rapport n'existe pas |
