---
title: "Obtenir un département"
description: "Récupérer un département par ID"
api: "GET https://api.smartbills.io/v1/businesses/{businessId}/departments/{departmentId}"
---

## Aperçu

Récupérer les détails complets d'un département par son identifiant unique.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer. Format : `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Identifiant d'entreprise pour le contexte multi-locataire
</ParamField>

## Paramètres de chemin

<ParamField path="businessId" type="integer" required>
  L'identifiant unique de l'entreprise
</ParamField>

<ParamField path="departmentId" type="integer" required>
  L'identifiant unique du département
</ParamField>

## Réponse

<ResponseField name="id" type="integer">
  Identifiant unique du département
</ResponseField>

<ResponseField name="name" type="string">
  Nom du département
</ResponseField>

<ResponseField name="code" type="string">
  Code du département pour référence interne
</ResponseField>

<ResponseField name="costCenter" type="string">
  Identifiant du centre de coûts pour la comptabilité
</ResponseField>

<ResponseField name="defaultApproverId" type="integer">
  ID de l'approbateur par défaut pour ce département
</ResponseField>

<ResponseField name="enabled" type="boolean">
  Indique si le département est actif
</ResponseField>

<ResponseField name="createdAt" type="string">
  Horodatage de création du département (ISO 8601)
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Horodatage de la dernière mise à jour (ISO 8601)
</ResponseField>

<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.smartbills.io/v1/businesses/456/departments/1 \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'x-tenant-id: 456'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const department = await client.departments.getById(1);

console.log(department.name);
console.log(department.costCenter);
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

department = await client.departments.get(department_id=1)

print(f"{department.name} ({department.code}) - Cost Center: {department.cost_center}")
```

</RequestExample>

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | FORBIDDEN | Permissions insuffisantes pour accéder à cette entreprise |
| 404 | DEPARTMENT_NOT_FOUND | L'identifiant du département n'existe pas |
| 404 | BUSINESS_NOT_FOUND | L'identifiant de l'entreprise n'existe pas |
| 429 | RATE_LIMIT_EXCEEDED | Trop de requêtes |
