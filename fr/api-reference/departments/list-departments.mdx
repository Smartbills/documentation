---
title: "Lister les départements"
description: "Récupérer une liste paginée de départements"
api: "GET https://api.smartbills.io/v1/businesses/{businessId}/departments"
---

## Aperçu

Récupérer une liste des départements configurés pour une entreprise. Les départements sont utilisés pour associer les dépenses à des unités organisationnelles pour le suivi des coûts et les rapports.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer. Format : `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Identifiant d'entreprise pour le contexte multi-locataire
</ParamField>

## Paramètres de chemin

<ParamField path="businessId" type="integer" required>
  L'identifiant unique de l'entreprise
</ParamField>

## Paramètres de requête

<ParamField query="page" type="integer" default="1">
  Numéro de page pour la pagination (commence à 1)
</ParamField>

<ParamField query="pageSize" type="integer" default="20">
  Nombre d'éléments par page (max : 100)
</ParamField>

<ParamField query="search" type="string">
  Rechercher des départements par nom ou code (correspondance partielle)
</ParamField>

<ParamField query="enabled" type="boolean">
  Filtrer par statut d'activation. `true` retourne uniquement les départements actifs, `false` retourne uniquement les départements désactivés. Omettre pour retourner tous les départements.
</ParamField>

## Réponse

<ResponseField name="data" type="array">
  Tableau d'objets département

  <Expandable title="Objet Département">
    <ResponseField name="id" type="integer">
      Identifiant unique du département
    </ResponseField>

    <ResponseField name="name" type="string">
      Nom du département
    </ResponseField>

    <ResponseField name="code" type="string">
      Code du département pour référence interne
    </ResponseField>

    <ResponseField name="costCenter" type="string">
      Identifiant du centre de coûts pour la comptabilité
    </ResponseField>

    <ResponseField name="defaultApproverId" type="integer">
      ID de l'approbateur par défaut pour ce département
    </ResponseField>

    <ResponseField name="enabled" type="boolean">
      Indique si le département est actif
    </ResponseField>

    <ResponseField name="createdAt" type="string">
      Horodatage de création du département (ISO 8601)
    </ResponseField>

    <ResponseField name="updatedAt" type="string">
      Horodatage de la dernière mise à jour (ISO 8601)
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="pagination" type="object">
  Métadonnées de pagination

  <Expandable title="Objet Pagination">
    <ResponseField name="page" type="integer">
      Numéro de page actuel
    </ResponseField>

    <ResponseField name="pageSize" type="integer">
      Nombre d'éléments par page
    </ResponseField>

    <ResponseField name="totalPages" type="integer">
      Nombre total de pages
    </ResponseField>

    <ResponseField name="totalCount" type="integer">
      Nombre total de départements correspondant aux filtres
    </ResponseField>

    <ResponseField name="hasNext" type="boolean">
      Indique s'il y a une page suivante
    </ResponseField>

    <ResponseField name="hasPrevious" type="boolean">
      Indique s'il y a une page précédente
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.smartbills.io/v1/businesses/456/departments?page=1&pageSize=20&enabled=true' \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'x-tenant-id: 456'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const departments = await client.departments.list({
  search: "Engineering",
  enabled: true,
  page: 1,
  pageSize: 20
});

console.log(`Found ${departments.pagination.totalCount} departments`);
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

departments = await client.departments.list()

for dept in departments.data:
    print(f"{dept.name} ({dept.code}) - Cost Center: {dept.cost_center}")
```

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 400 | INVALID_PARAMETER | Valeur de paramètre de requête invalide |
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | FORBIDDEN | Permissions insuffisantes pour accéder à cette entreprise |
| 404 | BUSINESS_NOT_FOUND | L'identifiant de l'entreprise n'existe pas |
| 429 | RATE_LIMIT_EXCEEDED | Trop de requêtes |
