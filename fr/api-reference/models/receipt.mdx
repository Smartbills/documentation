## Reçu

L'objet Reçu représente un reçu numérisé qui a été traité par OCR. Les reçus contiennent des données de transaction extraites et sont liés aux dépenses à des fins de documentation et d'audit.

## Propriétés

<ResponseField name="id" type="integer">
  Identifiant unique du reçu
</ResponseField>

<ResponseField name="businessId" type="integer">
  ID de l'entreprise à laquelle ce reçu appartient
</ResponseField>

<ResponseField name="merchant" type="string">
  Nom du marchand extrait du reçu
</ResponseField>

<ResponseField name="amount" type="number">
  Montant total extrait du reçu
</ResponseField>

<ResponseField name="currency" type="string">
  Code de devise détecté à partir du reçu (ISO 4217)
</ResponseField>

<ResponseField name="date" type="string">
  Date de la transaction extraite du reçu (`AAAA-MM-JJ`)
</ResponseField>

<ResponseField name="taxes" type="array">
  Tableau des entrées de taxe détectées sur le reçu
  <Expandable title="Entrée de taxe">
    <ResponseField name="name" type="string">
      Nom de la taxe (p. ex., "TPS", "TVQ", "TVA", "Taxe de vente")
    </ResponseField>
    <ResponseField name="amount" type="number">
      Montant de la taxe
    </ResponseField>
    <ResponseField name="rate" type="number">
      Taux de taxe en pourcentage
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="items" type="array">
  Lignes d'articles individuelles extraites du reçu
  <Expandable title="Ligne d'article">
    <ResponseField name="description" type="string">
      Description de l'article
    </ResponseField>
    <ResponseField name="quantity" type="number">
      Quantité achetée
    </ResponseField>
    <ResponseField name="unitPrice" type="number">
      Prix unitaire
    </ResponseField>
    <ResponseField name="total" type="number">
      Total pour cette ligne d'article
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="imageUrl" type="string">
  URL de l'image du reçu stockée
</ResponseField>

<ResponseField name="ocrData" type="object">
  Métadonnées brutes du traitement OCR
  <Expandable title="Données OCR">
    <ResponseField name="confidence" type="number">
      Score de confiance global de l'OCR (0.0 à 1.0)
    </ResponseField>
    <ResponseField name="rawText" type="string">
      Texte brut complet extrait du reçu
    </ResponseField>
    <ResponseField name="processingTime" type="integer">
      Temps de traitement OCR en millisecondes
    </ResponseField>
    <ResponseField name="engine" type="string">
      Moteur OCR utilisé pour le traitement
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="createdAt" type="string">
  Horodatage du traitement du reçu (ISO 8601)
</ResponseField>

## Exemple

```json
{
  "id": 8001,
  "businessId": 456,
  "merchant": "Office Depot",
  "amount": 49.99,
  "currency": "USD",
  "date": "2024-01-15",
  "taxes": [
    {
      "name": "Sales Tax",
      "amount": 4.50,
      "rate": 9.0
    }
  ],
  "items": [
    {
      "description": "Copy Paper - 10 Reams",
      "quantity": 10,
      "unitPrice": 3.99,
      "total": 39.90
    },
    {
      "description": "Stapler",
      "quantity": 1,
      "unitPrice": 6.09,
      "total": 6.09
    }
  ],
  "imageUrl": "https://cdn.smartbills.io/receipts/8001.jpg",
  "ocrData": {
    "confidence": 0.95,
    "rawText": "OFFICE DEPOT\n123 Main St...",
    "processingTime": 1200,
    "engine": "smartbills-ocr-v3"
  },
  "createdAt": "2024-01-15T14:30:00Z"
}
```
