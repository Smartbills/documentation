## Facture fournisseur

L'objet Facture fournisseur (Bill) représente une facture ou une note de fournisseur que votre entreprise doit payer. Les factures fournisseur suivent les montants dus, les dates d'échéance, les lignes d'articles et le statut de paiement.

## Propriétés

<ResponseField name="id" type="integer">
  Identifiant unique de la facture fournisseur
</ResponseField>

<ResponseField name="businessId" type="integer">
  ID de l'entreprise à laquelle cette facture fournisseur appartient
</ResponseField>

<ResponseField name="vendorId" type="integer">
  ID du fournisseur qui a émis la facture
</ResponseField>

<ResponseField name="vendor" type="object">
  Informations résumées du fournisseur
  <Expandable title="Résumé du fournisseur">
    <ResponseField name="id" type="integer">
      ID du fournisseur
    </ResponseField>
    <ResponseField name="name" type="string">
      Nom d'affichage du fournisseur
    </ResponseField>
    <ResponseField name="email" type="string">
      Courriel de contact du fournisseur
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="billNumber" type="string">
  Numéro de référence de la facture du fournisseur
</ResponseField>

<ResponseField name="amount" type="number">
  Montant total de la facture incluant les taxes
</ResponseField>

<ResponseField name="currency" type="string">
  Code de devise ISO 4217 (p. ex., `USD`, `CAD`, `EUR`)
</ResponseField>

<ResponseField name="dueDate" type="string">
  Date d'échéance du paiement (`AAAA-MM-JJ`)
</ResponseField>

<ResponseField name="issueDate" type="string">
  Date d'émission de la facture par le fournisseur (`AAAA-MM-JJ`)
</ResponseField>

<ResponseField name="status" type="string">
  Statut actuel de la facture. Valeurs possibles : `draft`, `pending`, `paid`, `overdue`, `cancelled`
</ResponseField>

<ResponseField name="notes" type="string">
  Notes ou description de la facture
</ResponseField>

<ResponseField name="lineItems" type="array">
  Lignes d'articles individuelles de la facture
  <Expandable title="Objet Ligne d'article">
    <ResponseField name="id" type="integer">
      ID de la ligne d'article
    </ResponseField>
    <ResponseField name="description" type="string">
      Description de l'article
    </ResponseField>
    <ResponseField name="quantity" type="number">
      Quantité commandée
    </ResponseField>
    <ResponseField name="unitPrice" type="number">
      Prix unitaire
    </ResponseField>
    <ResponseField name="amount" type="number">
      Total pour cette ligne d'article (quantité x prix unitaire)
    </ResponseField>
    <ResponseField name="categoryId" type="integer">
      ID de la catégorie pour cette ligne d'article
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="attachments" type="array">
  Fichiers joints (facture originale, documents justificatifs)
  <Expandable title="Objet Pièce jointe">
    <ResponseField name="id" type="integer">
      ID de la pièce jointe
    </ResponseField>
    <ResponseField name="filename" type="string">
      Nom de fichier original
    </ResponseField>
    <ResponseField name="url" type="string">
      URL de téléchargement
    </ResponseField>
    <ResponseField name="contentType" type="string">
      Type MIME
    </ResponseField>
    <ResponseField name="size" type="integer">
      Taille du fichier en octets
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="subtotal" type="number">
  Sous-total avant taxes
</ResponseField>

<ResponseField name="taxAmount" type="number">
  Montant total des taxes
</ResponseField>

<ResponseField name="paidAt" type="string">
  Horodatage du paiement de la facture (ISO 8601). `null` si impayée.
</ResponseField>

<ResponseField name="createdAt" type="string">
  Horodatage de création de la facture (ISO 8601)
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Horodatage de la dernière mise à jour de la facture (ISO 8601)
</ResponseField>

## Cycle de vie des statuts

```
draft -> pending -> paid
                 -> overdue -> paid
                            -> cancelled
      -> cancelled
```
