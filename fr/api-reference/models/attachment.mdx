## Pièce jointe

L'objet Pièce jointe représente un fichier téléversé dans Smartbills, comme une image de reçu, un PDF de facture ou un document justificatif. Les pièces jointes sont liées aux dépenses, aux factures et à d'autres entités.

## Propriétés

<ResponseField name="id" type="integer">
  Identifiant unique de la pièce jointe
</ResponseField>

<ResponseField name="filename" type="string">
  Nom de fichier original tel que téléversé (p. ex., `receipt_jan15.pdf`)
</ResponseField>

<ResponseField name="url" type="string">
  URL complète pour télécharger la pièce jointe. Les URL sont signées et expirent après 1 heure.
</ResponseField>

<ResponseField name="thumbnailUrl" type="string">
  URL pour un aperçu miniature de la pièce jointe. Disponible pour les fichiers image (JPG, PNG, HEIC). `null` pour les fichiers non-image tels que les PDF.
</ResponseField>

<ResponseField name="contentType" type="string">
  Type MIME du fichier (p. ex., `image/jpeg`, `application/pdf`, `image/png`)
</ResponseField>

<ResponseField name="size" type="integer">
  Taille du fichier en octets
</ResponseField>

<ResponseField name="createdAt" type="string">
  Horodatage du téléversement de la pièce jointe (ISO 8601)
</ResponseField>

## Types de fichiers pris en charge

| Type | Type MIME | Taille max |
|------|-----------|----------|
| JPEG | `image/jpeg` | 10 Mo |
| PNG | `image/png` | 10 Mo |
| HEIC | `image/heic` | 10 Mo |
| PDF | `application/pdf` | 25 Mo |
| TIFF | `image/tiff` | 15 Mo |

## Exemple

```json
{
  "id": 401,
  "filename": "receipt_office_depot.jpg",
  "url": "https://cdn.smartbills.io/receipts/abc123.jpg",
  "thumbnailUrl": "https://cdn.smartbills.io/receipts/abc123_thumb.jpg",
  "contentType": "image/jpeg",
  "size": 245000,
  "createdAt": "2024-01-15T14:30:00Z"
}
```

```json Pièce jointe PDF
{
  "id": 402,
  "filename": "invoice-2024-0042.pdf",
  "url": "https://cdn.smartbills.io/bills/invoice-2024-0042.pdf",
  "thumbnailUrl": null,
  "contentType": "application/pdf",
  "size": 1250000,
  "createdAt": "2024-01-20T10:00:00Z"
}
```
