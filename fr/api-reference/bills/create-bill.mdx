---
title: "Créer une facture"
description: "Créer une nouvelle facture d'un fournisseur"
api: "POST https://api.smartbills.io/v1/bills"
---

## Aperçu

Créer une nouvelle facture pour suivre une facture fournisseur. Vous pouvez inclure des éléments de ligne et joindre le document de facture original.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer pour l'authentification. Format : `Bearer YOUR_API_KEY`
</ParamField>

## Corps de la requête

<ParamField body="businessId" type="integer" required>
  Identifiant de l'entreprise à laquelle cette facture appartient
</ParamField>

<ParamField body="vendorId" type="integer" required>
  Identifiant du fournisseur émettant la facture
</ParamField>

<ParamField body="billNumber" type="string">
  Numéro de référence de facture du fournisseur
</ParamField>

<ParamField body="amount" type="number" required>
  Montant total de la facture
</ParamField>

<ParamField body="currency" type="string" required>
  Code de devise ISO 4217 (ex. : USD, CAD, EUR)
</ParamField>

<ParamField body="dueDate" type="string" required>
  Date d'échéance du paiement (format ISO 8601 : AAAA-MM-JJ)
</ParamField>

<ParamField body="issueDate" type="string">
  Date d'émission de la facture (AAAA-MM-JJ). Par défaut, aujourd'hui.
</ParamField>

<ParamField body="notes" type="string">
  Notes ou d.scription pour la facture
</ParamField>

<ParamField body="lineItems" type="array">
  Tableau des éléments de ligne de la facture
  <Expandable title="Objet Élément de ligne">
    <ParamField body="description" type="string" required>
      Description de l'article
    </ParamField>
    <ParamField body="quantity" type="number" required>
      Quantité
    </ParamField>
    <ParamField body="unitPrice" type="number" required>
      Prix unitaire
    </ParamField>
    <ParamField body="categoryId" type="integer">
      Identifiant de catégorie pour cet élément de ligne
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="taxAmount" type="number">
  Montant total des taxes
</ParamField>

<ParamField body="metadata" type="object">
  Paires clé-valeur de métadonnées personnalisées
</ParamField>

## Règles de validation

- Le `vendorId` doit référencer un fournisseur existant dans l'entreprise
- Le `amount` doit être un nombre positif
- La `dueDate` doit être une date valide
- La `quantity` et le `unitPrice` des éléments de ligne doivent être des nombres positifs

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 400 | VALIDATION_FAILED | Données de requête invalides |
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | FORBIDDEN | Permissions insuffisantes |
| 404 | VENDOR_NOT_FOUND | Le fournisseur n'existe pas |
| 404 | BUSINESS_NOT_FOUND | L'entreprise n'existe pas |
