---
title: "Obtenir une facture"
description: "Récupérer une facture spécifique par identifiant"
api: "GET https://api.smartbills.io/v1/bills/{billId}"
---

## Aperçu

Récupérer les détails complets d'une facture spécifique, y compris les éléments de ligne, les pièces jointes et les informations du fournisseur.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer pour l'authentification. Format : `Bearer YOUR_API_KEY`
</ParamField>

## Paramètres de chemin

<ParamField path="billId" type="integer" required>
  L'identifiant unique de la facture
</ParamField>

## Réponse

<ResponseField name="id" type="integer">
  Identifiant unique de la facture
</ResponseField>

<ResponseField name="businessId" type="integer">
  Identifiant de l'entreprise
</ResponseField>

<ResponseField name="vendorId" type="integer">
  Identifiant du fournisseur
</ResponseField>

<ResponseField name="vendor" type="object">
  Détails du fournisseur
  <Expandable title="Objet Fournisseur">
    <ResponseField name="id" type="integer">
      Identifiant du fournisseur
    </ResponseField>
    <ResponseField name="name" type="string">
      Nom du fournisseur
    </ResponseField>
    <ResponseField name="email" type="string">
      Courriel de contact du fournisseur
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="billNumber" type="string">
  Numéro de facture ou de référence du fournisseur
</ResponseField>

<ResponseField name="amount" type="number">
  Montant total de la facture
</ResponseField>

<ResponseField name="currency" type="string">
  Code de devise ISO 4217
</ResponseField>

<ResponseField name="dueDate" type="string">
  Date d'échéance du paiement (AAAA-MM-JJ)
</ResponseField>

<ResponseField name="issueDate" type="string">
  Date d'émission de la facture (AAAA-MM-JJ)
</ResponseField>

<ResponseField name="status" type="string">
  Statut de la facture : `draft`, `pending`, `paid`, `overdue`, `cancelled`
</ResponseField>

<ResponseField name="notes" type="string">
  Notes ou d.scription de la facture
</ResponseField>

<ResponseField name="lineItems" type="array">
  Éléments de ligne individuels de la facture
  <Expandable title="Objet Élément de ligne">
    <ResponseField name="id" type="integer">
      Identifiant de l'élément de ligne
    </ResponseField>
    <ResponseField name="description" type="string">
      Description de l'article
    </ResponseField>
    <ResponseField name="quantity" type="number">
      Quantité
    </ResponseField>
    <ResponseField name="unitPrice" type="number">
      Prix unitaire
    </ResponseField>
    <ResponseField name="amount" type="number">
      Total pour cet élément de ligne
    </ResponseField>
    <ResponseField name="categoryId" type="integer">
      Identifiant de catégorie
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="attachments" type="array">
  Fichiers joints (factures, reçus)
  <Expandable title="Objet Pièce jointe">
    <ResponseField name="id" type="integer">
      Identifiant de la pièce jointe
    </ResponseField>
    <ResponseField name="filename" type="string">
      Nom de fichier original
    </ResponseField>
    <ResponseField name="url" type="string">
      URL de téléchargement
    </ResponseField>
    <ResponseField name="contentType" type="string">
      Type MIME
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="taxAmount" type="number">
  Montant total des taxes
</ResponseField>

<ResponseField name="subtotal" type="number">
  Sous-total avant taxes
</ResponseField>

<ResponseField name="paidAt" type="string">
  Horodatage du paiement de la facture (ISO 8601, null si non payée)
</ResponseField>

<ResponseField name="createdAt" type="string">
  Horodatage de la création de la facture (ISO 8601)
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Horodatage de la dernière mise à jour (ISO 8601)
</ResponseField>

<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.smartbills.io/v1/bills/3001 \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
const bill = await client.bills.getById(3001);
```

```python Python
bill = client.bills.get_by_id(bill_id=3001)
```

```csharp C#
var bill = await client.Bills.GetByIdAsync(3001);
```

</RequestExample>

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | FORBIDDEN | Permissions insuffisantes |
| 404 | BILL_NOT_FOUND | La facture n'existe pas |
