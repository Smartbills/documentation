---

## Aperçu

Supprimer définitivement une facture. Seules les factures au statut `draft` ou `cancelled` peuvent être supprimées. Les factures payées ou en attente doivent d'abord être annulées.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer pour l'authentification. Format : `Bearer YOUR_API_KEY`
</ParamField>

## Paramètres de chemin

<ParamField path="billId" type="integer" required>
  L'identifiant unique de la facture à supprimer
</ParamField>

## Réponse

Retourne un statut `200 OK` en cas de suppression réussie.

<Warning>
  Cette action est irréversible. La facture et ses éléments de ligne associés seront définitivement supprimés. Les pièces jointes liées à la facture seront également supprimées.
</Warning>

<RequestExample>

```bash cURL
curl --request DELETE \
  --url https://api.smartbills.io/v1/bills/3001 \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
await client.bills.delete(3001);
```

```python Python
client.bills.delete(bill_id=3001)
```

```csharp C#
await client.Bills.DeleteAsync(3001);
```

</RequestExample>

<ResponseExample>

```json Response
{
  "message": "Bill deleted succèssfully"
}
```

</ResponseExample>

## Restrictions

Vous ne pouvez pas supprimer une facture si :

- Elle est au statut `pending` ou `paid` (annulez-la d'abord)
- Elle à été exportée vers votre système comptable
- Elle est liée à une transaction de paiement

Dans ces cas, vous recevrez une erreur `409 Conflict`.

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | FORBIDDEN | Permissions insuffisantes |
| 404 | BILL_NOT_FOUND | La facture n'existe pas |
| 409 | BILL_NOT_DELETABLE | La facture ne peut pas être supprimée dans son statut actuel |
