---
title: "Lister les catégories"
description: "Récupérer une liste paginée de catégories de dépenses"
api: "GET https://api.smartbills.io/v1/businesses/{businessId}/categories"
---

## Aperçu

Récupérer une liste des catégories de dépenses configurées pour une entreprise. Les catégories aident à organiser les dépenses en groupes logiques tels que Voyages, Repas ou Fournitures de bureau. Vous pouvez rechercher par nom et filtrer par statut d'activation.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer. Format : `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Identifiant d'entreprise pour le contexte multi-locataire
</ParamField>

## Paramètres de chemin

<ParamField path="businessId" type="integer" required>
  L'identifiant unique de l'entreprise
</ParamField>

## Paramètres de requête

<ParamField query="page" type="integer" default="1">
  Numéro de page pour la pagination (commence à 1)
</ParamField>

<ParamField query="pageSize" type="integer" default="20">
  Nombre d'éléments par page (max : 100)
</ParamField>

<ParamField query="search" type="string">
  Rechercher des catégories par nom (correspondance partielle)
</ParamField>

<ParamField query="enabled" type="boolean">
  Filtrer par statut d'activation. `true` retourne uniquement les catégories actives, `false` retourne uniquement les catégories désactivées. Omettre pour retourner toutes les catégories.
</ParamField>

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.smartbills.io/v1/businesses/456/categories?page=1&pageSize=20&enabled=true' \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'x-tenant-id: 456'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const categories = await client.categories.list({
  search: "Travel",
  enabled: true,
  page: 1,
  pageSize: 20
});

console.log(`Found ${categories.pagination.totalCount} categories`);
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

categories = await client.categories.list()

for category in categories.data:
    print(f"{category.name} - {category.gl_account_code}")
```

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 400 | INVALID_PARAMETER | Valeur de paramètre de requête invalide |
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | FORBIDDEN | Permissions insuffisantes pour accéder à cette entreprise |
| 404 | BUSINESS_NOT_FOUND | L'identifiant de l'entreprise n'existe pas |
| 429 | RATE_LIMIT_EXCEEDED | Trop de requêtes |
