---
title: "Obtenir une catégorie"
description: "Récupérer une catégorie de dépenses par ID"
api: "GET https://api.smartbills.io/v1/businesses/{businessId}/categories/{categoryId}"
---

## Aperçu

Récupérer les détails complets d'une catégorie de dépenses par son identifiant unique.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer. Format : `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Identifiant d'entreprise pour le contexte multi-locataire
</ParamField>

## Paramètres de chemin

<ParamField path="businessId" type="integer" required>
  L'identifiant unique de l'entreprise
</ParamField>

<ParamField path="categoryId" type="integer" required>
  L'identifiant unique de la catégorie
</ParamField>

## Réponse

<ResponseField name="id" type="integer">
  Identifiant unique de la catégorie
</ResponseField>

<ResponseField name="name" type="string">
  Nom de la catégorie
</ResponseField>

<ResponseField name="description" type="string">
  Description de la catégorie
</ResponseField>

<ResponseField name="glAccountCode" type="string">
  Code de compte du grand livre pour l'intégration comptable
</ResponseField>

<ResponseField name="color" type="string">
  Code couleur hexadécimal pour l'affichage (p. ex., `#4A90D9`)
</ResponseField>

<ResponseField name="enabled" type="boolean">
  Indique si la catégorie est active et disponible à l'utilisation
</ResponseField>

<ResponseField name="displayOrder" type="integer">
  Ordre de tri pour l'affichage dans les listes déroulantes et les listes
</ResponseField>

<ResponseField name="createdAt" type="string">
  Horodatage de création de la catégorie (ISO 8601)
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Horodatage de la dernière mise à jour (ISO 8601)
</ResponseField>

<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.smartbills.io/v1/businesses/456/categories/1 \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'x-tenant-id: 456'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const category = await client.categories.getById(1);

console.log(category.name);
console.log(category.glAccountCode);
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

category = await client.categories.get(category_id=1)

print(f"{category.name} - GL: {category.gl_account_code}")
```

</RequestExample>

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | FORBIDDEN | Permissions insuffisantes pour accéder à cette entreprise |
| 404 | CATEGORY_NOT_FOUND | L'identifiant de la catégorie n'existe pas |
| 404 | BUSINESS_NOT_FOUND | L'identifiant de l'entreprise n'existe pas |
| 429 | RATE_LIMIT_EXCEEDED | Trop de requêtes |
