---
title: "Créer une catégorie"
description: "Créer une nouvelle catégorie de dépenses"
api: "POST https://api.smartbills.io/v1/businesses/{businessId}/categories"
---

## Aperçu

Créer une nouvelle catégorie de dépenses pour une entreprise. Les catégories sont utilisées pour classer les dépenses et peuvent être associées à des codes de compte du grand livre pour l'intégration comptable.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer. Format : `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Identifiant d'entreprise pour le contexte multi-locataire
</ParamField>

## Paramètres de chemin

<ParamField path="businessId" type="integer" required>
  L'identifiant unique de l'entreprise
</ParamField>

## Corps de la requête

<ParamField body="name" type="string" required>
  Nom de la catégorie. Doit être unique au sein de l'entreprise.
</ParamField>

<ParamField body="description" type="string">
  Description des dépenses appartenant à cette catégorie
</ParamField>

<ParamField body="glAccountCode" type="string">
  Code de compte du grand livre pour l'intégration comptable (p. ex., `6200`)
</ParamField>

<ParamField body="color" type="string">
  Code couleur hexadécimal pour l'affichage dans l'interface (p. ex., `#4A90D9`)
</ParamField>

<ParamField body="enabled" type="boolean" default="true">
  Indique si la catégorie est active et disponible à l'utilisation. Par défaut : `true`.
</ParamField>

<ParamField body="displayOrder" type="integer">
  Position de tri pour l'affichage dans les listes déroulantes et les listes. Les numéros les plus bas apparaissent en premier.
</ParamField>

## Réponse

Retourne l'objet catégorie nouvellement créé.

<ResponseField name="id" type="integer">
  Identifiant unique de la catégorie
</ResponseField>

<ResponseField name="name" type="string">
  Nom de la catégorie
</ResponseField>

<ResponseField name="description" type="string">
  Description de la catégorie
</ResponseField>

<ResponseField name="glAccountCode" type="string">
  Code de compte du grand livre
</ResponseField>

<ResponseField name="color" type="string">
  Code couleur hexadécimal
</ResponseField>

<ResponseField name="enabled" type="boolean">
  Indique si la catégorie est active
</ResponseField>

<ResponseField name="displayOrder" type="integer">
  Ordre de tri pour l'affichage
</ResponseField>

<ResponseField name="createdAt" type="string">
  Horodatage de création de la catégorie (ISO 8601)
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Horodatage de la dernière mise à jour (ISO 8601)
</ResponseField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.smartbills.io/v1/businesses/456/categories \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --header 'x-tenant-id: 456' \
  --data '{
    "name": "Travel",
    "description": "Business travel expenses including flights, hotels, and ground transportation",
    "glAccountCode": "6200",
    "color": "#4A90D9",
    "enabled": true,
    "displayOrder": 1
  }'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const category = await client.categories.create({
  name: "Travel",
  description: "Business travel expenses including flights, hotels, and ground transportation",
  glAccountCode: "6200",
  color: "#4A90D9",
  displayOrder: 1
});

console.log(`Created category: ${category.id}`);
```

```python Python SDK
from smartbills import Smartbills
from smartbills.types import CategoryCreateRequest

client = Smartbills(api_key="YOUR_API_KEY")

category = await client.categories.create(
    CategoryCreateRequest(
        name="Travel",
        description="Business travel expenses including flights, hotels, and ground transportation",
        gl_account_code="6200",
        color="#4A90D9",
        display_order=1
    )
)

print(f"Created category: {category.id}")
```

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 400 | VALIDATION_ERROR | Champs requis manquants ou valeurs invalides |
| 400 | DUPLICATE_NAME | Une catégorie avec ce nom existe déjà |
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | FORBIDDEN | Permissions insuffisantes pour gérer les catégories |
| 404 | BUSINESS_NOT_FOUND | L'identifiant de l'entreprise n'existe pas |
| 429 | RATE_LIMIT_EXCEEDED | Trop de requêtes |
