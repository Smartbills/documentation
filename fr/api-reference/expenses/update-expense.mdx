---
title: "Mettre à jour une dépense"
api: "PUT https://api.smartbills.io/v1/expenses/{expenseId}"
description: "Mettre à jour une dépense existante"
---

## Paramètres de chemin

<ParamField path="expenseId" type="integer" required>
  L'identifiant unique de la dépense à mettre à jour
</ParamField>

## Corps de la requête

<ParamField body="amount" type="number">
  Montant de la dépense
</ParamField>

<ParamField body="currency" type="string">
  Code de devise ISO 4217 (ex. : USD, CAD, EUR)
</ParamField>

<ParamField body="date" type="string">
  Date de la transaction au format ISO 8601
</ParamField>

<ParamField body="merchant" type="string">
  Nom du commerçant ou du fournisseur
</ParamField>

<ParamField body="category" type="string">
  Catégorie de la dépense
</ParamField>

<ParamField body="description" type="string">
  Description ou notes de la dépense
</ParamField>

<ParamField body="tags" type="array">
  Tableau d'étiquettes à associer à la dépense
</ParamField>

<ParamField body="metadata" type="object">
  Objet de métadonnées personnalisé
</ParamField>

## Réponse

Retourne l'objet de dépense mis à jour.

<RequestExample>

```bash cURL
curl --request PUT \
  --url https://api.smartbills.io/v1/expenses/12345 \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "amount": 54.99,
    "merchant": "Office Depot Store #123",
    "description": "Updated description with more détails",
    "tags": ["office", "supplies", "urgent"]
  }'
```

```javascript JavaScript
const response = await fetch(
  'https://api.smartbills.io/v1/expenses/12345',
  {
    method: 'PUT',
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      amount: 54.99,
      merchant: 'Office Depot Store #123',
      description: 'Updated description with more détails',
      tags: ['office', 'supplies', 'urgent']
    })
  }
);

const expense = await response.json();
console.log(expense);
```

```python Python
import requests

url = 'https://api.smartbills.io/v1/expenses/12345'
headers = {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
}
data = {
    'amount': 54.99,
    'merchant': 'Office Depot Store #123',
    'description': 'Updated description with more détails',
    'tags': ['office', 'supplies', 'urgent']
}

response = requests.put(url, headers=headers, json=data)
expense = response.json()
print(expense)
```
