api: "POST https://api.smartbills.io/v1/expenses/validate"
description: "Valider les données d'une dépense avant le téléversement"
---

## Corps de la requête

Ce point de terminaison accepte `multipart/form-data` pour le téléversement de fichiers.

<ParamField body="file" type="file" required>
  Le fichier de reçu ou de facture à valider
</ParamField>

## Réponse

Retourne les résultats de validation sans créer de dépense.

<ResponseField name="valid" type="boolean">
  Indique si le fichier est valide pour le téléversement
</ResponseField>

<ResponseField name="errors" type="array">
  Tableau des erreurs de validation (le cas échéant)
</ResponseField>

<ResponseField name="warnings" type="array">
  Tableau des avertissements de validation
</ResponseField>

<ResponseField name="fileInfo" type="object">
  Informations sur le fichier téléversé
  
  <Expandable title="Informations du fichier">
    <ResponseField name="size" type="integer">
      Taille du fichier en octets
    </ResponseField>

    <ResponseField name="type" type="string">
      Type MIME
    </ResponseField>

    <ResponseField name="format" type="string">
      Format du fichier (PDF, JPG, PNG, etc.)
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.smartbills.io/v1/expenses/validate \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: multipart/form-data' \
  --form 'file=@/path/to/receipt.pdf'
```

```javascript JavaScript
const formData = new FormData();
formData.append('file', fileInput.files[0]);

const response = await fetch(
  'https://api.smartbills.io/v1/expenses/validate',
  {
    method: 'POST',
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY'
    },
    body: formData
  }
);

const validation = await response.json();
console.log(validation);
```

```python Python
import requests

url = 'https://api.smartbills.io/v1/expenses/validate'
headers = {
    'Authorization': 'Bearer YOUR_API_KEY'
}
files = {
    'file': open('/path/to/receipt.pdf', 'rb')
}

response = requests.post(url, headers=headers, files=files)
validation = response.json()
print(validation)
```
