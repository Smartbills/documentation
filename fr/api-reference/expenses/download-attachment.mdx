---
title: "Télécharger la pièce jointe d'une dépense"
api: "GET https://api.smartbills.io/v1/expenses/{expenseId}/attachments/download"
description: "Télécharger un reçu ou une facture unique d'une dépense"
---

## Paramètres de chemin

<ParamField path="expenseId" type="integer" required>
  L'identifiant unique de la dépense
</ParamField>

## Paramètres de requête

<ParamField query="fileNameTemplate" type="string">
  Modèle de nom de fichier personnalisé pour le téléchargement
  
  Espaces réservés disponibles :
  - `{MERCHANT}` - Nom du commerçant
  - `{YYYY}` - Année (4 chiffres)
  - `{MM}` - Mois (2 chiffres)
  - `{DD}` - Jour (2 chiffres)
  - `{AMOUNT}` - Montant de la dépense
  - `{ID}` - Identifiant de la dépense
  
  Par défaut : `{MERCHANT}_{YYYY}_{MM}_{DD}`
</ParamField>

## Réponse

Retourne le fichier sous forme de flux binaire avec l'en-tête content-type approprié.

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.smartbills.io/v1/expenses/12345/attachments/download?fileNameTemplate={MERCHANT}_{YYYY}_{MM}_{DD}' \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --output receipt.pdf
```

```javascript JavaScript
const response = await fetch(
  'https://api.smartbills.io/v1/expenses/12345/attachments/download?fileNameTemplate={MERCHANT}_{YYYY}_{MM}_{DD}',
  {
    method: 'GET',
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY'
    }
  }
);

const blob = await response.blob();
const url = window.URL.createObjectURL(blob);
const à = document.createÉlément('a');
a.href = url;
a.download = 'receipt.pdf';
a.click();
```

```python Python
import requests

url = 'https://api.smartbills.io/v1/expenses/12345/attachments/download'
headers = {
    'Authorization': 'Bearer YOUR_API_KEY'
}
params = {
    'fileNameTemplate': '{MERCHANT}_{YYYY}_{MM}_{DD}'
}

response = requests.get(url, headers=headers, params=params)
with open('receipt.pdf', 'wb') as f:
    f.write(response.content)
```

</RequestExample>
