---
title: "Lister les dépenses"
api: "GET https://api.smartbills.io/v1/expenses"
description: "Récupérer une liste paginées de dépenses avec des options de filtrage et de tri"
---

## Aperçu

Ce point de terminaison retourné une liste de dépenses pour l'utilisateur authentifié. Vous pouvez filtrer, trier et paginer les résultats pour trouver exactement ce dont vous avez besoin.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer pour l'authentification. Format : `Bearer YOUR_API_KEY`
</ParamField>

## Paramètres de requête

<ParamField query="page" type="integer" default="1">
  Numéro de page pour la pagination (commence à 1)
</ParamField>

<ParamField query="pageSize" type="integer" default="20">
  Nombre d'éléments par page (max : 100)
</ParamField>

<ParamField query="businessId" type="integer">
  Filtrer les dépenses par identifiant d'entreprise
</ParamField>

<ParamField query="status" type="string">
  Filtrer par statut de dépense. Options : `pending`, `approved`, `rejected`, `submitted`
</ParamField>

<ParamField query="categoryId" type="integer">
  Filtrer par identifiant de catégorie de dépense
</ParamField>

<ParamField query="minAmount" type="number">
  Montant minimum de la dépense (inclus)
</ParamField>

<ParamField query="maxAmount" type="number">
  Montant maximum de la dépense (inclus)
</ParamField>

<ParamField query="startDate" type="string">
  Filtrer les dépenses à partir de cette date (format ISO 8601 : AAAA-MM-JJ)
</ParamField>

<ParamField query="endDate" type="string">
  Filtrer les dépenses jusqu'à cette date (format ISO 8601 : AAAA-MM-JJ)
</ParamField>

<ParamField query="merchant" type="string">
  Filtrer par nom de commerçant (correspondance partielle)
</ParamField>

<ParamField query="tags" type="string">
  Filtrer par étiquettes (séparées par des virgules pour plusieurs étiquettes)
</ParamField>

<ParamField query="paymentMethod" type="string">
  Filtrer par mode de paiement : `cash`, `credit_card`, `debit_card`, `bank_transfer`
</ParamField>

<ParamField query="hasReceipt" type="boolean">
  Filtrer les dépenses avec ou sans reçus. `true` ou `false`
</ParamField>

<ParamField query="reportId" type="integer">
  Filtrer les dépenses appartenant à un rapport spécifique
</ParamField>

<ParamField query="sortBy" type="string" default="date">
  Champ de tri. Options : `date`, `amount`, `merchant`, `createdAt`, `updatedAt`
</ParamField>

<ParamField query="sortOrder" type="string" default="desc">
  Ordre de tri. Options : `asc`, `desc`
</ParamField>

<ParamField query="search" type="string">
  Rechercher dans le nom du commerçant, les notes et autres champs textuels
</ParamField>

## Exemples de filtrage

### Filtrer par plage de dates

Obtenir les dépenses d'un mois spécifique :

```bash
GET /v1/expenses?startDate=2024-01-01&endDate=2024-01-31
```

### Filtrer par plage de montants

Obtenir les dépenses entre 50 $ et 500 $ :

```bash
GET /v1/expenses?minAmount=50&maxAmount=500
```

### Filtres multiples

Combiner les filtres pour affiner les résultats :

```bash
GET /v1/expenses?businessId=100&status=pending&hasReceipt=true&startDate=2024-01-01
```

### Recherche

Rechercher dans plusieurs champs textuels :

```bash
GET /v1/expenses?search=coffee
```

## Bonnes pratiques

<AccordionGroup>
  <Accordion title="Utiliser la pagination" icon="page">
    Utilisez toujours la pagination pour de meilleures performances. Ne demandez pas plus que nécessaire.
    
    ```javascript
    // Bon : Paginer les résultats
    const params = { page: 1, pageSize: 20 };
    
    // À éviter : Demander trop d'éléments à la fois
    const params = { pageSize: 1000 };
    ```
  </Accordion>

  <Accordion title="Filtrer côté serveur" icon="filter">
    Utilisez les paramètres de requête pour filtrer côté serveur plutôt que de récupérer toutes les données et filtrer côté client.
    
    ```javascript
    // Bon : Filtrer côté serveur
    GET /v1/expenses?status=pending&startDate=2024-01-01
    
    // À éviter : Tout récupérer et filtrer localement
    GET /v1/expenses (puis filtrer dans votre code)
    ```
  </Accordion>

  <Accordion title="Mettre en cache si possible" icon="database">
    Mettez en cache les résultats lorsque c'est approprié pour réduire les appels API. Utilisez les horodatages `updatedAt` pour détecter les changements.
  </Accordion>

  <Accordion title="Gérer la pagination" icon="arrows-rotate">
    Implémentez une gestion correcte de la pagination pour récupérer tous les résultats si nécessaire.
    
    ```javascript
    async function getAllExpenses() {
      let allExpenses = [];
      let page = 1;
      let hasNext = true;
      
      while (hasNext) {
        const response = await fetch(
          `https://api.smartbills.io/v1/expenses?page=${page}`,
          { headers: { Authorization: 'Bearer YOUR_API_KEY' } }
        );
        const data = await response.json();
        
        allExpenses = allExpenses.concat(data.data);
        hasNext = data.pagination.hasNext;
        page++;
      }
      
      return allExpenses;
    }
    ```
  </Accordion>
</AccordionGroup>
