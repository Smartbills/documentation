api: "POST https://api.smartbills.io/v1/expenses/attachments/download"
description: "Télécharger plusieurs reçus de dépenses sous forme de fichier ZIP"
---

## Corps de la requête

<ParamField body="expenseIds" type="array" required>
  Tableau d'identifiants de dépenses à télécharger
</ParamField>

<ParamField body="fileNameTemplate" type="string">
  Modèle de nom de fichier personnalisé pour les fichiers individuels
  
  Espaces réservés disponibles :
  - `{MERCHANT}` - Nom du commerçant
  - `{YYYY}` - Année (4 chiffres)
  - `{MM}` - Mois (2 chiffres)
  - `{DD}` - Jour (2 chiffres)
  - `{AMOUNT}` - Montant de la dépense
  - `{ID}` - Identifiant de la dépense
</ParamField>

<ParamField body="zipFileName" type="string">
  Nom personnalisé pour le fichier ZIP (par défaut : "expenses.zip")
</ParamField>

## Réponse

Retourne un fichier ZIP contenant toutes les pièces jointes de dépenses demandées.

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.smartbills.io/v1/expenses/attachments/download \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "expenseIds": [12345, 12346, 12347],
    "fileNameTemplate": "{MERCHANT}_{YYYY}_{MM}_{DD}",
    "zipFileName": "january_expenses.zip"
  }' \
  --output expenses.zip
```

```javascript JavaScript
const response = await fetch(
  'https://api.smartbills.io/v1/expenses/attachments/download',
  {
    method: 'POST',
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      expenseIds: [12345, 12346, 12347],
      fileNameTemplate: '{MERCHANT}_{YYYY}_{MM}_{DD}',
      zipFileName: 'january_expenses.zip'
    })
  }
);

const blob = await response.blob();
const url = window.URL.createObjectURL(blob);
const à = document.createÉlément('a');
a.href = url;
a.download = 'january_expenses.zip';
a.click();
```

```python Python
import requests

url = 'https://api.smartbills.io/v1/expenses/attachments/download'
headers = {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
}
data = {
    'expenseIds': [12345, 12346, 12347],
    'fileNameTemplate': '{MERCHANT}_{YYYY}_{MM}_{DD}',
    'zipFileName': 'january_expenses.zip'
}

response = requests.post(url, headers=headers, json=data)
with open('january_expenses.zip', 'wb') as f:
    f.write(response.content)
```
