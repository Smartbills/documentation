---
title: "Mise à jour groupée des dépenses"
api: "PUT https://api.smartbills.io/v1/expenses"
description: "Mettre à jour plusieurs dépenses en une seule requête"
---

## Corps de la requête

<ParamField body="updates" type="array" required>
  Tableau de mises à jour de dépenses

  <Expandable title="Objet de mise à jour">
    <ParamField body="id" type="integer" required>
      Identifiant de la dépense à mettre à jour
    </ParamField>

    <ParamField body="amount" type="number">
      Montant mis à jour
    </ParamField>

    <ParamField body="merchant" type="string">
      Nom du commerçant mis à jour
    </ParamField>

    <ParamField body="category" type="string">
      Catégorie mise à jour
    </ParamField>

    <ParamField body="description" type="string">
      Description mise à jour
    </ParamField>

    <ParamField body="tags" type="array">
      Étiquettes mises à jour
    </ParamField>

    <ParamField body="metadata" type="object">
      Métadonnées mises à jour
    </ParamField>
  </Expandable>
</ParamField>

## Réponse

Retourne un tableau d'objets de dépenses mis à jour.

<RequestExample>

```bash cURL
curl --request PUT \
  --url https://api.smartbills.io/v1/expenses \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '[
    {
      "id": 12345,
      "category": "Office Supplies",
      "tags": ["office", "supplies"]
    },
    {
      "id": 12346,
      "category": "Software",
      "tags": ["software", "recurring"]
    }
  ]'
```

```javascript JavaScript
const response = await fetch(
  'https://api.smartbills.io/v1/expenses',
  {
    method: 'PUT',
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify([
      {
        id: 12345,
        category: 'Office Supplies',
        tags: ['office', 'supplies']
      },
      {
        id: 12346,
        category: 'Software',
        tags: ['software', 'recurring']
      }
    ])
  }
);

const expenses = await response.json();
console.log(expenses);
```

```python Python
import requests

url = 'https://api.smartbills.io/v1/expenses'
headers = {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
}
data = [
    {
        'id': 12345,
        'category': 'Office Supplies',
        'tags': ['office', 'supplies']
    },
    {
        'id': 12346,
        'category': 'Software',
        'tags': ['software', 'recurring']
    }
]

response = requests.put(url, headers=headers, json=data)
expenses = response.json()
print(expenses)
```
