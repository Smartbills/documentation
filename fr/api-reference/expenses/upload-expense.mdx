## Corps de la requête

<ParamField body="file" type="file" required>
  Le fichier de reçu ou de facture (PDF, JPG, PNG, HEIC)
  
  Taille maximale du fichier : 10 Mo
</ParamField>

<ParamField body="mergeFiles" type="boolean" default="false">
  Si vrai, fusionner plusieurs fichiers en une seule dépense
</ParamField>

## Type de contenu

Ce point de terminaison accepte `multipart/form-data` pour le téléversement de fichiers.

## Réponse

<ResponseField name="id" type="integer">
  Identifiant unique de la dépense
</ResponseField>

<ResponseField name="amount" type="number">
  Montant de la dépense extrait
</ResponseField>

    <ResponseField name="taxAmount" type="number">

```python Python
import requests

url = 'https://api.smartbills.io/v1/expenses/upload'
headers = {
    'Authorization': 'Bearer YOUR_API_KEY'
}
files = {
    'file': open('/path/to/receipt.pdf', 'rb')
}

response = requests.post(url, headers=headers, files=files)
expense = response.json()
print(expense)
```

```php PHP
<?php
$ch = curl_init();

$file = new CURLFile('/path/to/receipt.pdf');

curl_setopt($ch, CURLOPT_RETURNTRANSFER, 1);
curl_setopt($ch, CURLOPT_HTTPHEADER, array(
    'Authorization: Bearer YOUR_API_KEY'
));

$result = curl_exec($ch);
curl_close($ch);

$expense = json_décodé($result, true);

?>
```

## Types de fichiers pris en charge

- **PDF** - Portable Document Format
- **JPG/JPEG** - Joint Photographic Experts Group
- **PNG** - Portable Network Graphics
- **HEIC** - High Efficiency Image Container
- **TIFF** - Tagged Image File Format

## Traitement OCR

Smartbills extrait automatiquement les informations suivantes des reçus :

- **Montant** - Montant total de la transaction
- **Commerçant** - Nom de l'entreprise
- **Date** - Date de la transaction
- **Taxe** - Montant de la taxe (si disponible)
- **Éléments de ligne** - Articles individuels achetés
- **Mode de paiement** - Type de carte ou mode de paiement
- **Devise** - Devise de la transaction

## Conseils pour de meilleurs résultats

1. **Qualité d'image** - Utilisez des images haute résolution (minimum 300 DPI)
2. **Éclairage** - Assurez un bon éclairage sans reflets
3. **Alignement** - Gardez le reçu droit et centré
4. **Complet** - Capturez l'intégralité du reçu, y compris l'en-tête et le pied de page
5. **Format** - Les fichiers PDF offrent généralement les meilleurs résultats OCR

## Validation

Après le téléversement, vérifiez et corrigez les informations extraites si nécessaire en utilisant le point de terminaison [Mettre à jour une dépense](/api-reference/expenses/update-expense).

<Tip>
  Le score de `confidence` indique la précision de l'extraction OCR. Les scores inférieurs à 0,7 peuvent nécessiter une vérification manuelle.
</Tip>
