---
title: "Supprimer une dépense"
api: "DELETE https://api.smartbills.io/v1/expenses/{expenseId}"
description: "Supprimer une dépense"
---

## Paramètres de chemin

<ParamField path="expenseId" type="integer" required>
  L'identifiant unique de la dépense à supprimer
</ParamField>

## Réponse

Retourne un statut `200 OK` avec un corps vide en cas de suppression réussie.

<Warning>
  Cette action est irréversible. La dépense et ses pièces jointes seront définitivement supprimées.
</Warning>

<RequestExample>

```bash cURL
curl --request DELETE \
  --url https://api.smartbills.io/v1/expenses/12345 \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
const response = await fetch(
  'https://api.smartbills.io/v1/expenses/12345',
  {
    method: 'DELETE',
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY'
    }
  }
);

if (response.ok) {
  console.log('Expense deleted succèssfully');
}
```

```python Python
import requests

url = 'https://api.smartbills.io/v1/expenses/12345'
headers = {
    'Authorization': 'Bearer YOUR_API_KEY'
}

response = requests.delete(url, headers=headers)
if response.ok:
    print('Expense deleted succèssfully')
```

</RequestExample>

<ResponseExample>

```json Response
{
  "message": "Expense deleted succèssfully"
}
```

</ResponseExample>

## Restrictions

Vous ne pouvez pas supprimer une dépense si :

- Elle fait partie d'un rapport de dépenses soumis ou approuvé
- Elle à été marquée comme remboursée
- Elle à été exportée vers votre système comptable

Dans ces cas, vous recevrez une erreur `409 Conflict`.
