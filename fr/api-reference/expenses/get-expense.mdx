---
title: "Obtenir une dépense"
api: "GET https://api.smartbills.io/v1/expenses/{expenseId}"
description: "Récupérer une dépense spécifique par identifiant"
---

## Paramètres de chemin

<ParamField path="expenseId" type="integer" required>
  L'identifiant unique de la dépense
</ParamField>

## Réponse

<ResponseField name="id" type="integer">
  Identifiant unique de la dépense
</ResponseField>

<ResponseField name="amount" type="number">
  Montant de la dépense
</ResponseField>

<ResponseField name="currency" type="string">
  Code de devise ISO 4217 (ex. : USD, CAD, EUR)
</ResponseField>

<ResponseField name="date" type="string">
  Date de la transaction au format ISO 8601
</ResponseField>

<ResponseField name="merchant" type="string">
  Nom du commerçant ou du fournisseur
</ResponseField>

<ResponseField name="category" type="string">
  Catégorie de la dépense
</ResponseField>

<ResponseField name="status" type="string">
  Statut de la dépense : `pending`, `approved`, `rejected`, `reimbursed`
</ResponseField>

<ResponseField name="description" type="string">
  Description ou notes de la dépense
</ResponseField>

<ResponseField name="userId" type="integer">
  Identifiant de l'utilisateur qui à créé la dépense
</ResponseField>

<ResponseField name="businessId" type="integer">
  Identifiant de l'entreprise à laquelle cette dépense appartient
</ResponseField>

<ResponseField name="attachmentUrl" type="string">
  URL de la pièce jointe du reçu/de la facture
</ResponseField>

<ResponseField name="tags" type="array">
  Tableau des étiquettes associées à la dépense
</ResponseField>

<ResponseField name="metadata" type="object">
  Objet de métadonnées personnalisé
</ResponseField>

<ResponseField name="createdAt" type="string">
  Horodatage de création au format ISO 8601
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Horodatage de la dernière mise à jour au format ISO 8601
</ResponseField>

<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.smartbills.io/v1/expenses/12345 \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json'
```

```javascript JavaScript
const response = await fetch(
  'https://api.smartbills.io/v1/expenses/12345',
  {
    method: 'GET',
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY',
      'Content-Type': 'application/json'
    }
  }
);

const expense = await response.json();
console.log(expense);
```

```python Python
import requests

url = 'https://api.smartbills.io/v1/expenses/12345'
headers = {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
}

response = requests.get(url, headers=headers)
expense = response.json()
print(expense)
```
