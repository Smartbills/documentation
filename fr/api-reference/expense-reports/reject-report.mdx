---
title: "Rejeter un rapport de dépenses"
api: "POST https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/{reportId}/reject"
description: "Rejeter un rapport de dépenses soumis avec un motif"
---

## Aperçu

Rejeter un rapport de dépenses soumis. Le statut du rapport passe à `rejected`, et le soumetteur est notifié avec le motif fourni. Le soumetteur peut ensuite créer un nouveau rapport ou modifier et resoumettre.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer. Format : `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Identifiant d'entreprise pour le contexte multi-locataire
</ParamField>

## Paramètres de chemin

<ParamField path="businessId" type="integer" required>
  L'identifiant unique de l'entreprise
</ParamField>

<ParamField path="reportId" type="integer" required>
  L'identifiant unique du rapport de dépenses à rejeter
</ParamField>

## Corps de la requête

<ParamField body="reason" type="string" required>
  Le motif du rejet du rapport. Celui-ci sera visible par le soumetteur.

  Exemple : `"Missing receipts for hotel expenses. Policy requires receipts for all expenses over $25."`
</ParamField>

## Réponse

Retourne le rapport de dépenses mis à jour avec le statut changé en `rejected`.

<ResponseField name="id" type="integer">
  Identifiant unique du rapport de dépenses
</ResponseField>

<ResponseField name="title" type="string">
  Titre du rapport
</ResponseField>

<ResponseField name="status" type="string">
  Statut du rapport (sera `rejected`)
</ResponseField>

<ResponseField name="totalAmount" type="number">
  Montant total du rapport
</ResponseField>

<ResponseField name="reportCurrency" type="string">
  Code de devise
</ResponseField>

<ResponseField name="rejectedBy" type="integer">
  Identifiant de l'utilisateur qui à rejeté le rapport
</ResponseField>

<ResponseField name="rejectedAt" type="string">
  Horodatage du rejet du rapport (ISO 8601)
</ResponseField>

<ResponseField name="rejectionReason" type="string">
  Le motif fourni pour le rejet
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Horodatage de la dernière mise à jour (ISO 8601)
</ResponseField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.smartbills.io/v1/businesses/456/expense-reports/1001/reject \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --header 'x-tenant-id: 456' \
  --data '{
    "reason": "Missing receipts for hotel expenses. Policy requires receipts for all expenses over $25."
  }'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const report = await client.expenseReports.reject(1001, {
  reason: "Missing receipts for hotel expenses. Policy requires receipts for all expenses over $25."
});

console.log("Report rejected:", report.status);
console.log("Reason:", report.rejectionReason);
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

report = client.expense_reports.reject(1001, {
    "reason": "Missing receipts for hotel expenses. Policy requires receipts for all expenses over $25."
})

print(f"Report rejected: {report.status}")
print(f"Reason: {report.rejection_reason}")
```

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 400 | VALIDATION_FAILED | Motif de rejet manquant ou vide |
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | FORBIDDEN | L'utilisateur n'est pas autorisé à rejeter ce rapport |
| 404 | NOT_FOUND | Rapport de dépenses non trouvé |
| 409 | INVALID_STATUS | Le rapport n'est pas au statut `submitted` |
| 429 | RATE_LIMIT_EXCEEDED | Trop de requêtes |
