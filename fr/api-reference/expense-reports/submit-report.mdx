---
title: "Soumettre un rapport de dépenses"
api: "POST https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/{reportId}/submit"
description: "Soumettre un rapport de dépenses pour approbation"
---

## Aperçu

Soumettre un rapport de dépenses brouillon pour approbation. Le statut du rapport passe de `draft` à `submitted`, et les approbateurs désignés sont notifiés. Le rapport doit contenir au moins une transaction avant de pouvoir être soumis.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer. Format : `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Identifiant d'entreprise pour le contexte multi-locataire
</ParamField>

## Paramètres de chemin

<ParamField path="businessId" type="integer" required>
  L'identifiant unique de l'entreprise
</ParamField>

<ParamField path="reportId" type="integer" required>
  L'identifiant unique du rapport de dépenses à soumettre
</ParamField>

## Réponse

Retourne le rapport de dépenses mis à jour avec le statut changé en `submitted`.

<ResponseField name="id" type="integer">
  Identifiant unique du rapport de dépenses
</ResponseField>

<ResponseField name="title" type="string">
  Titre du rapport
</ResponseField>

<ResponseField name="status" type="string">
  Statut du rapport (sera `submitted`)
</ResponseField>

<ResponseField name="totalAmount" type="number">
  Montant total de toutes les transactions du rapport
</ResponseField>

<ResponseField name="reportCurrency" type="string">
  Code de devise
</ResponseField>

<ResponseField name="expenseCount" type="integer">
  Nombre de transactions dans le rapport
</ResponseField>

<ResponseField name="submittedAt" type="string">
  Horodatage de soumission du rapport (ISO 8601)
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Horodatage de la dernière mise à jour (ISO 8601)
</ResponseField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.smartbills.io/v1/businesses/456/expense-reports/1001/submit \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'x-tenant-id: 456'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const report = await client.expenseReports.submit(1001);

console.log("Report submitted:", report.status);
console.log("Submitted at:", report.submittedAt);
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

report = client.expense_reports.submit(1001)

print(f"Report submitted: {report.status}")

```

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 400 | EMPTY_REPORT | Le rapport ne contient aucune transaction et ne peut pas être soumis |
| 400 | MISSING_RECEIPTS | Un ou plusieurs transactions n'ont pas les reçus requis |
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | FORBIDDEN | Permissions insuffisantes pour soumettre ce rapport |
| 404 | NOT_FOUND | Rapport de dépenses non trouvé |
| 409 | INVALID_STATUS | Le rapport n'est pas au statut `draft` ou `changes_required` |
| 429 | RATE_LIMIT_EXCEEDED | Trop de requêtes |
