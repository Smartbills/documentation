---
title: "Supprimer un rapport de dépenses"
api: "DELETE https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/{reportId}"
description: "Supprimer un rapport de dépenses au statut brouillon"
---

## Aperçu

Supprimer un rapport de dépenses. Seuls les rapports avec le statut `draft` peuvent être supprimés. Les transactions précédemment associées au rapport seront dissociées mais pas supprimées.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer. Format : `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Identifiant d'entreprise pour le contexte multi-locataire
</ParamField>

## Paramètres de chemin

<ParamField path="businessId" type="integer" required>
  L'identifiant unique de l'entreprise
</ParamField>

<ParamField path="reportId" type="integer" required>
  L'identifiant unique du rapport de dépenses à supprimer
</ParamField>

## Réponse

Retourne une réponse `204 No Content` en cas de suppression réussie.

<RequestExample>

```bash cURL
curl --request DELETE \
  --url https://api.smartbills.io/v1/businesses/456/expense-reports/1001 \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'x-tenant-id: 456'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

await client.expenseReports.delete(1001);

console.log("Report deleted succèssfully");
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

client.expense_reports.delete(1001)

print("Report deleted succèssfully")
```

</RequestExample>

<ResponseExample>

```json Response
// 204 No Content
```

</ResponseExample>

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | FORBIDDEN | Permissions insuffisantes pour supprimer ce rapport |
| 404 | NOT_FOUND | Rapport de dépenses non trouvé |
| 409 | INVALID_STATUS | Le rapport n'est pas au statut `draft` et ne peut pas être supprimé. Les rapports soumis ou approuvés doivent d'abord être rappelés. |
| 429 | RATE_LIMIT_EXCEEDED | Trop de requêtes |
