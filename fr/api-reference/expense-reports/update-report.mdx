---
title: "Mettre à jour un rapport de dépenses"
api: "PUT https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/{reportId}"
description: "Mettre à jour les détails, la plage de dates ou les transactions d'un rapport de dépenses existant"
---

## Aperçu

Mettre à jour un rapport de dépenses existant. Vous pouvez modifier le titre, la description, l'objet commercial, la plage de dates, la liste des transactions et la devise. Seuls les rapports avec le statut `draft` ou `changes_required` peuvent être mis à jour.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer. Format : `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Identifiant d'entreprise pour le contexte multi-locataire
</ParamField>

## Paramètres de chemin

<ParamField path="businessId" type="integer" required>
  L'identifiant unique de l'entreprise
</ParamField>

<ParamField path="reportId" type="integer" required>
  L'identifiant unique du rapport de dépenses à mettre à jour
</ParamField>

## Corps de la requête

<ParamField body="title" type="string">
  Titre du rapport mis à jour
</ParamField>

<ParamField body="description" type="string">
  Description du rapport mise à jour
</ParamField>

<ParamField body="businessPurpose" type="string">
  Objet commercial mis à jour
</ParamField>

<ParamField body="startDate" type="string">
  Date de début mise à jour de la période de dépenses (format ISO 8601 : AAAA-MM-JJ)
</ParamField>

<ParamField body="endDate" type="string">
  Date de fin mise à jour de la période de dépenses (format ISO 8601 : AAAA-MM-JJ)
</ParamField>

<ParamField body="transactionIds" type="array">
  Tableau mis à jour des identifiants de transactions. Ceci remplace la liste existante de transactions.
</ParamField>

<ParamField body="reportCurrency" type="string">
  Code de devise ISO à trois lettres mis à jour pour le rapport
</ParamField>

## Réponse

Retourne l'objet de rapport de dépenses mis à jour.

<ResponseField name="title" type="string">
  Titre du rapport

  Objet commercial
</ResponseField>

</ResponseField>

<ResponseField name="totalAmount" type="number">

  Code de devise
</ResponseField>

<ResponseField name="expenseCount" type="integer">

<ResponseField name="updatedAt" type="string">

<RequestExample>

```bash cURL
curl --request PUT \
  --url https://api.smartbills.io/v1/businesses/456/expense-reports/1001 \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --header 'x-tenant-id: 456' \
  --data '{
    "title": "January 2025 Business Trip - Updated",
    "description": "Updated with additional meals expenses",
    "transactionIds": [12345, 12346, 12347, 12348],
    "endDate": "2025-01-19"
  }'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const report = await client.expenseReports.update(1001, {
  title: "January 2025 Business Trip - Updated",
  description: "Updated with additional meals expenses",
  transactionIds: [12345, 12346, 12347, 12348],
  endDate: "2025-01-19"
});

console.log("Report updated:", report.title);
console.log("New total:", report.totalAmount);
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

report = client.expense_reports.update(1001, {
    "title": "January 2025 Business Trip - Updated",
    "description": "Updated with additional meals expenses",
    "transaction_ids": [12345, 12346, 12347, 12348],
    "end_date": "2025-01-19"
})

print(f"Report updated: {report.title}")
print(f"New total: {report.total_amount}")
```

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 400 | VALIDATION_FAILED | Données de requête invalides |
| 400 | INVALID_DATE_RANGE | La date de fin est antérieure à la date de début |
| 400 | TRANSACTION_NOT_FOUND | Un ou plusieurs identifiants de transaction n'existent pas |
| 400 | TRANSACTION_ALREADY_IN_REPORT | La transaction est déjà assignée à un autre rapport |
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | FORBIDDEN | Permissions insuffisantes pour mettre à jour ce rapport |
| 404 | NOT_FOUND | Rapport de dépenses non trouvé |
| 409 | INVALID_STATUS | Le rapport n'est pas dans un statut modifiable (doit être `draft` ou `changes_required`) |
| 429 | RATE_LIMIT_EXCEEDED | Trop de requêtes |
