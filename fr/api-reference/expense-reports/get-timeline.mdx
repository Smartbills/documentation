---
title: "Chronologie du rapport"
api: "GET https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/{reportId}/timeline"
description: "Récupérer la chronologie des événements d'un rapport de dépenses"
---

## Aperçu

Récupérer la chronologie des événements d'un rapport de dépenses, montrant tous les changements de statut, commentaires et actions par ordre chronologique. Cela fournit un aperçu clair du cycle de vie du rapport, de la création à l'approbation.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer. Format : `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Identifiant d'entreprise pour le contexte multi-locataire
</ParamField>

## Paramètres de chemin

<ParamField path="businessId" type="integer" required>
  L'identifiant unique de l'entreprise
</ParamField>

<ParamField path="reportId" type="integer" required>
  L'identifiant unique du rapport de dépenses
</ParamField>

## Réponse

<ResponseField name="events" type="array">
  Tableau d'objets d'événements chronologiques par ordre chronologique

  <Expandable title="Objet Événement chronologique">
    <ResponseField name="id" type="integer">
      Identifiant unique de l'événement
    </ResponseField>

    <ResponseField name="type" type="string">
      Type d'événement : `created`, `updated`, `submitted`, `approved`, `partially_approved`, `rejected`, `changes_required`, `recalled`, `comment_added`, `expense_added`, `expense_removed`
    </ResponseField>

    <ResponseField name="userId" type="integer">
      Identifiant de l'utilisateur qui à déclenché l'événement
    </ResponseField>

    <ResponseField name="userName" type="string">
      Nom de l'utilisateur qui à déclenché l'événement
    </ResponseField>

    <ResponseField name="description" type="string">
      Description lisible de l'événement
    </ResponseField>

    <ResponseField name="metadata" type="object">
      Données supplémentaires spécifiques à l'événement (ex. : motif de rejet, notes d'approbation, texte de commentaire)
    </ResponseField>

    <ResponseField name="timestamp" type="string">
      Horodatage de l'événement (ISO 8601)
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.smartbills.io/v1/businesses/456/expense-reports/1001/timeline \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'x-tenant-id: 456'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const timeline = await client.expenseReports.getTimeline(1001);

timeline.events.forEach(event => {
  console.log(`${event.timestamp}: ${event.type} by ${event.userName}`);
});
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

timeline = client.expense_reports.get_timeline(1001)

for event in timeline.events:
    print(f"{event.timestamp}: {event.type} by {event.user_name}")
```

</RequestExample>

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | FORBIDDEN | Permissions insuffisantes pour voir la chronologie de ce rapport |
| 404 | NOT_FOUND | Rapport de dépenses non trouvé |
| 429 | RATE_LIMIT_EXCEEDED | Trop de requêtes |
