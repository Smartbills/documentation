---
title: "Créer un rapport de dépenses"
api: "POST https://api.smartbills.io/v1/businesses/{businessId}/expense-reports"
description: "Créer un nouveau rapport de dépenses pour regrouper les transactions en vue de la soumission et de l'approbation"
---

## Aperçu

Créer un nouveau rapport de dépenses pour organiser et soumettre des transactions pour approbation. Vous pouvez créer un rapport vide et ajouter des transactions ultérieurement, ou inclure des identifiants de transaction lors de la création.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer. Format : `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Identifiant d'entreprise pour le contexte multi-locataire
</ParamField>

## Paramètres de chemin

<ParamField path="businessId" type="integer" required>
  L'identifiant unique de l'entreprise
</ParamField>

## Corps de la requête

<ParamField body="title" type="string" required>
  Titre descriptif pour le rapport de dépenses

  Exemple : `"January 2025 Travel Expenses"`
</ParamField>

<ParamField body="description" type="string">
  Description détaillée de l'objet du rapport

  Exemple : `"Business trip to NYC for client meetings"`
</ParamField>

<ParamField body="businessPurpose" type="string">
  Justification commerciale des dépenses

  Exemple : `"Client acquisition and relationship building"`
</ParamField>

<ParamField body="startDate" type="string">
  Date de début de la période de dépenses (format ISO 8601 : AAAA-MM-JJ)

  Exemple : `"2025-01-15"`
</ParamField>

<ParamField body="endDate" type="string">
  Date de fin de la période de dépenses (format ISO 8601 : AAAA-MM-JJ)

  Exemple : `"2025-01-18"`
</ParamField>

<ParamField body="transactionIds" type="array">
  Tableau d'identifiants de transactions à inclure dans le rapport

  Exemple : `[12345, 12346, 12347]`
</ParamField>

<ParamField body="reportCurrency" type="string">
  Code de devise ISO à trois lettres pour le rapport (ex. : USD, CAD, EUR). Les transactions dans d'autres devises seront converties.

  Exemple : `"USD"`
</ParamField>

<ParamField body="employéeId" type="integer">
  Identifiant de l'employé pour lequel ce rapport est créé. Si omis, l'utilisateur authentifié est utilisé par défaut. Les gestionnaires peuvent créer des rapports au nom des employés en spécifiant ce champ.
</ParamField>

<RequestExample>

```bash cURL
curl --request POST \
  --url https://api.smartbills.io/v1/businesses/456/expense-reports \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'Content-Type: application/json' \
  --header 'x-tenant-id: 456' \
  --data '{
    "title": "January 2025 Travel Expenses",
    "description": "Business trip to NYC for client meetings",
    "businessPurpose": "Client acquisition",
    "startDate": "2025-01-15",
    "endDate": "2025-01-18",
    "transactionIds": [12345, 12346, 12347],
    "reportCurrency": "USD"
  }'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const report = await client.expenseReports.create({
  businessId: 456,
  title: "January 2025 Travel Expenses",
  description: "Business trip to NYC for client meetings",
  businessPurpose: "Client acquisition",
  startDate: "2025-01-15",
  endDate: "2025-01-18",
  transactionIds: [12345, 12346, 12347],
  reportCurrency: "USD"
});

console.log("Report created:", report.id);
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

report = client.expense_reports.create({
    "business_id": 456,
    "title": "January 2025 Travel Expenses",
    "description": "Business trip to NYC for client meetings",
    "business_purpose": "Client acquisition",
    "start_date": "2025-01-15",
    "end_date": "2025-01-18",
    "transaction_ids": [12345, 12346, 12347],
    "report_currency": "USD"
})

print(f"Report created: {report.id}")
```

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 400 | VALIDATION_FAILED | Données de requête invalides |
| 400 | INVALID_DATE_RANGE | La date de fin est antérieure à la date de début |
| 400 | TRANSACTION_NOT_FOUND | Un ou plusieurs identifiants de transaction n'existent pas |
| 400 | TRANSACTION_ALREADY_IN_REPORT | La transaction est déjà assignée à un autre rapport |
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | FORBIDDEN | Pas d'accès à l'entreprise spécifiée |
| 404 | BUSINESS_NOT_FOUND | L'identifiant d'entreprise n'existe pas |
| 429 | RATE_LIMIT_EXCEEDED | Trop de requêtes |
