---
title: "Lister les rapports de dépenses"
api: "GET https://api.smartbills.io/v1/businesses/{businessId}/expense-reports"
description: "Récupérer une liste paginées de rapports de dépenses avec des options de filtrage et de tri"
---

## Aperçu

Récupérer une liste de rapports de dépenses pour une entreprise. Vous pouvez filtrer par statut, employé, plage de dates et termes de recherche, et trier les résultats par différents champs.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer. Format : `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Identifiant d'entreprise pour le contexte multi-locataire
</ParamField>

## Paramètres de chemin

<ParamField path="businessId" type="integer" required>
  L'identifiant unique de l'entreprise
</ParamField>

## Paramètres de requête

<ParamField query="status" type="string">
  Filtrer par statut du rapport. Options : `draft`, `submitted`, `approved`, `partially_approved`, `rejected`, `changes_required`, `reimbursed`
</ParamField>

<ParamField query="employéeId" type="integer">
  Filtrer les rapports par identifiant d'employé (le soumetteur)
</ParamField>

<ParamField query="startDate" type="string">
  Filtrer les rapports avec une période commençant à partir de cette date (format ISO 8601 : AAAA-MM-JJ)
</ParamField>

<ParamField query="endDate" type="string">
  Filtrer les rapports avec une période se terminant avant cette date (format ISO 8601 : AAAA-MM-JJ)
</ParamField>

<ParamField query="search" type="string">
  Rechercher dans le titre, la description et l'objet commercial du rapport
</ParamField>

<ParamField query="sortBy" type="string" default="createdAt">
  Champ de tri. Options : `createdAt`, `updatedAt`, `totalAmount`, `title`, `status`
</ParamField>

<ParamField query="sortDescending" type="boolean" default="true">
  Trier par ordre décroissant quand `true`, croissant quand `false`
</ParamField>

<ParamField query="page" type="integer" default="1">
  Numéro de page pour la pagination (commence à 1)
</ParamField>

<ParamField query="pageSize" type="integer" default="20">
  Nombre d'éléments par page (max : 100)
</ParamField>

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const response = await client.expenseReports.list({
  businessId: 456,
  status: "submitted",
  sortBy: "createdAt",
  sortDescending: true,
  page: 1,
  pageSize: 20
});

console.log(`Found ${response.pagination.totalCount} reports`);
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

response = client.expense_reports.list({
    "business_id": 456,
    "status": "submitted",
    "sort_by": "createdAt",
    "sort_descending": True,
    "page": 1,
    "page_size": 20
})
```

## Exemples de filtrage

### Filtrer par statut

Obtenir tous les rapports soumis en attente d'approbation :

```bash
GET /v1/businesses/456/expense-reports?status=submitted
```

### Filtrer par employé

Obtenir tous les rapports d'un employé spécifique :

```bash
GET /v1/businesses/456/expense-reports?employéeId=789
```

### Filtrer par plage de dates

Obtenir les rapports pour une période spécifique :

```bash
GET /v1/businesses/456/expense-reports?startDate=2025-01-01&endDate=2025-03-31
```

### Rechercher des rapports

Rechercher dans les titres et descriptions des rapports :

```bash
GET /v1/businesses/456/expense-reports?search=travel
```

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 400 | INVALID_PARAMETER | Valeur de paramètre de requête invalide |
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | FORBIDDEN | Permissions insuffisantes pour accéder à cette entreprise |
| 404 | BUSINESS_NOT_FOUND | L'identifiant d'entreprise n'existe pas |
| 429 | RATE_LIMIT_EXCEEDED | Trop de requêtes |
