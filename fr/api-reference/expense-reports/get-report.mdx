---
title: "Obtenir un rapport de dépenses"
api: "GET https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/{reportId}"
description: "Récupérer un rapport de dépenses spécifique avec les détails complets incluant les transactions"
---

## Aperçu

Récupérer les informations détaillées d'un rapport de dépenses spécifique, incluant toutes les transactions associées, l'historique d'approbation et les commentaires.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer. Format : `Bearer YOUR_API_KEY`
</ParamField>

<ParamField header="x-tenant-id" type="string" required>
  Identifiant d'entreprise pour le contexte multi-locataire
</ParamField>

## Paramètres de chemin

<ParamField path="businessId" type="integer" required>
  L'identifiant unique de l'entreprise
</ParamField>

<ParamField path="reportId" type="integer" required>
  L'identifiant unique du rapport de dépenses
</ParamField>

## Paramètres de requête

<ParamField query="sortBy" type="string" default="date">
  Champ de tri des transactions. Options : `date`, `amount`, `merchant`, `createdAt`
</ParamField>

<ParamField query="sortOrder" type="string" default="desc">
  Ordre de tri des transactions. Options : `asc`, `desc`
</ParamField>

## Réponse

<ResponseField name="id" type="integer">
  Identifiant unique du rapport de dépenses
</ResponseField>

<ResponseField name="title" type="string">
  Titre du rapport
</ResponseField>

<ResponseField name="description" type="string">
  Description du rapport
</ResponseField>

<ResponseField name="businessPurpose" type="string">
  Objet commercial des dépenses
</ResponseField>

<ResponseField name="status" type="string">
  Statut du rapport : `draft`, `submitted`, `approved`, `partially_approved`, `rejected`, `changes_required`, `reimbursed`
</ResponseField>

<ResponseField name="totalAmount" type="number">
  Montant total de toutes les transactions du rapport
</ResponseField>

<ResponseField name="approvedAmount" type="number">
  Montant total approuvé (défini après approbation), null si non encore approuvé
</ResponseField>

<ResponseField name="reportCurrency" type="string">
  Code de devise ISO à trois lettres (ex. : USD, CAD, EUR)
</ResponseField>

<ResponseField name="expenseCount" type="integer">
  Nombre de transactions dans le rapport
</ResponseField>

<ResponseField name="employéeId" type="integer">
  Identifiant de l'employé propriétaire du rapport
</ResponseField>

<ResponseField name="startDate" type="string">
  Date de début de la période de dépenses (AAAA-MM-JJ)
</ResponseField>

<ResponseField name="endDate" type="string">
  Date de fin de la période de dépenses (AAAA-MM-JJ)
</ResponseField>

<ResponseField name="transactions" type="array">
  Tableau d'objets de transaction inclus dans le rapport

  <Expandable title="Objet Transaction">
    <ResponseField name="id" type="integer">
      Identifiant de la transaction
    </ResponseField>

    <ResponseField name="amount" type="number">
      Montant de la transaction
    </ResponseField>

    <ResponseField name="currency" type="string">
      Code de devise de la transaction
    </ResponseField>

    <ResponseField name="merchant" type="string">
      Nom du commerçant ou du fournisseur
    </ResponseField>

    <ResponseField name="date" type="string">
      Date de la transaction (AAAA-MM-JJ)
    </ResponseField>

    <ResponseField name="category" type="string">
      Nom de la catégorie de dépense
    </ResponseField>

    <ResponseField name="notes" type="string">
      Notes de la transaction
    </ResponseField>

    <ResponseField name="hasReceipt" type="boolean">
      Indique si un reçu est joint
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="comments" type="array">
  Tableau d'objets de commentaire sur le rapport

  <Expandable title="Objet Commentaire">
    <ResponseField name="id" type="integer">
      Identifiant du commentaire
    </ResponseField>

    <ResponseField name="userId" type="integer">
      Identifiant de l'utilisateur qui à posté le commentaire
    </ResponseField>

    <ResponseField name="userName" type="string">
      Nom de l'utilisateur qui à posté le commentaire
    </ResponseField>

    <ResponseField name="comment" type="string">
      Texte du commentaire
    </ResponseField>

    <ResponseField name="createdAt" type="string">
      Horodatage de publication du commentaire (ISO 8601)
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="submittedAt" type="string">
  Horodatage de soumission du rapport (ISO 8601), null si non soumis
</ResponseField>

<ResponseField name="approvedAt" type="string">
  Horodatage d'approbation du rapport (ISO 8601), null si non approuvé
</ResponseField>

<ResponseField name="createdAt" type="string">
  Horodatage de création du rapport (ISO 8601)
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Horodatage de la dernière mise à jour (ISO 8601)
</ResponseField>

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.smartbills.io/v1/businesses/456/expense-reports/1001?sortBy=date&sortOrder=desc' \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --header 'x-tenant-id: 456'
```

```javascript JavaScript SDK
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: "YOUR_API_KEY" });

const report = await client.expenseReports.getById(1001, {
  sortBy: "date",
  sortOrder: "desc"
});

console.log("Report:", report.title);
console.log("Total:", report.totalAmount, report.reportCurrency);
```

```python Python SDK
from smartbills import Smartbills

client = Smartbills(api_key="YOUR_API_KEY")

report = client.expense_reports.get_by_id(1001)

print(f"Report: {report.title}")
print(f"Total: {report.total_amount} {report.report_currency}")
```

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | FORBIDDEN | Permissions insuffisantes pour accéder à ce rapport |
| 404 | NOT_FOUND | Rapport de dépenses non trouvé |
| 404 | BUSINESS_NOT_FOUND | L'identifiant d'entreprise n'existe pas |
| 429 | RATE_LIMIT_EXCEEDED | Trop de requêtes |
