## Créer un webhook

Enregistrer un webhook pour recevoir des notifications d'événements.

## Requête

```bash
POST /v1/webhooks
```

### Paramètres du corps

| Paramètre | Type | Requis | Description |
|-----------|------|----------|-------------|
| `url` | string | Oui | L'URL pour recevoir les webhooks |
| `events` | array | Oui | Événements auxquels s'abonner |
| `description` | string | Non | Description du webhook |
| `enabled` | boolean | Non | Indique si le webhook est actif (par défaut : true) |

### Exemple de requête

```bash
curl -X POST https://api.smartbills.io/v1/webhooks \
  -H "Authorization: Bearer sk_live_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://your-app.com/webhooks",
    "events": ["expense.created", "report.submitted"],
    "description": "Production webhook"
  }'
```

## Réponse

```json
{
  "data": {
    "id": "wh_abc123",
    "url": "https://your-app.com/webhooks",
    "events": ["expense.created", "report.submitted"],
    "description": "Production webhook",
    "enabled": true,
    "secret": "whsec_xxxxx",
    "createdAt": "2025-01-15T10:30:00Z"
  }
}
```

<Warning>
Conservez le `secret` en lieu sûr. Il n'est retourné qu'une seule fois et est utilisé pour vérifier les signatures des webhooks.
</Warning>
