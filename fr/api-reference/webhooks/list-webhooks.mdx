## Lister les webhooks

Récupérer tous les points de terminaison webhook de votre compte.

## Requête

```bash
GET /v1/webhooks
```

### Paramètres de requête

| Paramètre | Type | Description |
|-----------|------|-------------|
| `page` | integer | Numéro de page (par défaut : 1) |
| `pageSize` | integer | Éléments par page (par défaut : 20) |

### Exemple de requête

```bash
curl https://api.smartbills.io/v1/webhooks \
  -H "Authorization: Bearer sk_live_xxxxx"
```
