## Aperçu

Créer un nouvel employé pour suivre les ventes et les interactions avec les clients. Les employés sont des membres du personnel en contact avec la clientèle qui génèrent des ventes et peuvent être associés à des reçus pour des analyses détaillées.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer pour l'authentification. Format : `Bearer YOUR_API_KEY`
</ParamField>

## Portées requises

- `employees.write`

## Corps de la requête

<ParamField body="firstName" type="string" required>
  Prénom de l'employé
</ParamField>

<ParamField body="lastName" type="string">
  Nom de famille de l'employé
</ParamField>

<ParamField body="email" type="string">
  Adresse courriel
</ParamField>

<ParamField body="locale" type="string">
  Code de langue (p. ex., "en-US", "fr-CA")
</ParamField>

<ParamField body="birthDate" type="string">
  Date de naissance au format ISO 8601 (AAAA-MM-JJ)
</ParamField>

<ParamField body="phoneNumber" type="string">
  Numéro de téléphone
</ParamField>

<ParamField body="employeeNumber" type="string">
  Numéro ou identifiant interne de l'employé
</ParamField>

<ParamField body="department" type="string">
  Nom du département
</ParamField>

<ParamField body="position" type="string">
  Poste ou titre du poste
</ParamField>

<ParamField body="hireDate" type="string">
  Date d'embauche au format ISO 8601 (AAAA-MM-JJ)
</ParamField>

<ParamField body="isActive" type="boolean" default="true">
  Indique si l'employé est actuellement actif
</ParamField>

<ParamField body="metadata" type="object">
  Paires clé-valeur de métadonnées personnalisées
</ParamField>

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 400 | INVALID_PARAMETER | Valeur de paramètre invalide |
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | FORBIDDEN | Permissions insuffisantes |
| 409 | DUPLICATE_EMPLOYEE | Un employé avec ce courriel ou ce numéro d'employé existe déjà |
| 429 | RATE_LIMIT_EXCEEDED | Trop de requêtes |
