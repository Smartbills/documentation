---
title: "Supprimer un employé"
api: "DELETE https://api.smartbills.io/v1/employees/{id}"
description: "Supprimer un employé de votre compte"
---

## Aperçu

Supprimer définitivement un employé de votre compte Smartbills. Cette action ne peut pas être annulée.

<Warning>
  **Action destructive** : La suppression d'un employé est permanente. Envisagez plutôt de le marquer comme inactif.
</Warning>

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer pour l'authentification. Format : `Bearer YOUR_API_KEY`
</ParamField>

## Portées requises

- `employees.write`

## Paramètres de chemin

<ParamField path="id" type="integer" required>
  L'identifiant unique de l'employé à supprimer
</ParamField>

<RequestExample>

```bash cURL
curl --request DELETE \
  --url https://api.smartbills.io/v1/employees/12345 \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: 'YOUR_API_KEY' });

const deletedEmployee = await client.employees.delete(12345);
console.log('Deleted employee:', deletedEmployee);
```

```python Python
from smartbills import Smartbills

client = Smartbills(api_key='YOUR_API_KEY')

deleted_employee = client.employees.delete(12345)
print('Deleted employee:', deleted_employee)
```

```csharp C#
using Smartbills.NET;

var client = new SBClient("YOUR_API_KEY");

var deletedEmployee = await client.Employees.DeleteAsync(12345);
Console.WriteLine($"Deleted employee: {deletedEmployee.Id}");
```

</RequestExample>

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | FORBIDDEN | Permissions insuffisantes |
| 404 | NOT_FOUND | Employé non trouvé |
| 409 | CONFLICT | Impossible de supprimer un employé avec des transactions actives |
| 429 | RATE_LIMIT_EXCEEDED | Trop de requêtes |

## Considérations importantes

<AccordionGroup>
  <Accordion title="Préférer la désactivation" icon="toggle-off">
    Au lieu de supprimer, envisagez de marquer l'employé comme inactif :
    
    ```javascript
    await client.employees.update(12345, {
      ...employee,
      isActive: false
    });
    ```
  </Accordion>

  <Accordion title="Données historiques" icon="clock">
    La suppression d'un employé peut affecter les rapports de ventes historiques et les analyses.
  </Accordion>

  <Accordion title="Reçus associés" icon="receipt">
    Vérifiez les reçus associés avant la suppression pour maintenir l'intégrité des données.
  </Accordion>
</AccordionGroup>
