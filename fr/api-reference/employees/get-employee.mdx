---
title: "Obtenir un employé"
api: "GET https://api.smartbills.io/v1/employees/{id}"
description: "Récupérer un employé par ID"
---

## Aperçu

Récupérer les informations détaillées d'un employé spécifique à l'aide de son identifiant unique.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer pour l'authentification. Format : `Bearer YOUR_API_KEY`
</ParamField>

## Portées requises

- `employees.read`

## Paramètres de chemin

<ParamField path="id" type="integer" required>
  L'identifiant unique de l'employé à récupérer
</ParamField>

<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.smartbills.io/v1/employees/12345 \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: 'YOUR_API_KEY' });

const employee = await client.employees.get(12345);
console.log('Employee:', employee);
```

```python Python
from smartbills import Smartbills

client = Smartbills(api_key='YOUR_API_KEY')

employee = client.employees.get(12345)
print('Employee:', employee)
```

```csharp C#
using Smartbills.NET;

var client = new SBClient("YOUR_API_KEY");

var employee = await client.Employees.GetAsync(12345);
Console.WriteLine($"Employee: {employee.FirstName} {employee.LastName}");
```

</RequestExample>

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | FORBIDDEN | Permissions insuffisantes |
| 404 | NOT_FOUND | Employé non trouvé |
| 429 | RATE_LIMIT_EXCEEDED | Trop de requêtes |
