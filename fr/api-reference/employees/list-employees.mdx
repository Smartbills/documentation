---
title: "Lister les employés"
api: "GET https://api.smartbills.io/v1/employees"
description: "Récupérer une liste paginée d'employés"
---

## Aperçu

Récupérer une liste de tous les employés de votre compte avec des options de pagination, de tri et de filtrage.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer pour l'authentification. Format : `Bearer YOUR_API_KEY`
</ParamField>

## Portées requises

- `employees.read`

## Paramètres de requête

<ParamField query="page" type="integer" default="1">
  Numéro de page pour la pagination
</ParamField>

<ParamField query="pageSize" type="integer" default="100">
  Nombre d'éléments par page (max : 100)
</ParamField>

<ParamField query="orderBy" type="string" default="createdAt">
  Champ de tri : `id`, `firstName`, `lastName`, `createdAt`, `totalSales`
</ParamField>

<ParamField query="sortOrder" type="string" default="desc">
  Ordre de tri : `asc`, `desc`
</ParamField>

<ParamField query="search" type="string">
  Rechercher par nom ou courriel
</ParamField>

<ParamField query="department" type="string">
  Filtrer par département
</ParamField>

<ParamField query="isActive" type="boolean">
  Filtrer par statut actif
</ParamField>

<ParamField query="employeeNumber" type="string">
  Filtrer par numéro d'employé
</ParamField>

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.smartbills.io/v1/employees?page=1&pageSize=20&isActive=true' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
import { SBClient } from "@smartbills/sdk";

const client = new SBClient({ apiKey: 'YOUR_API_KEY' });

const response = await client.employees.list({
  page: 1,
  pageSize: 20,
  isActive: true,
  orderBy: 'totalSales',
  sortOrder: 'desc'
});

console.log(`Found ${response.metadata.count} employees`);
```

```python Python
from smartbills import Smartbills

client = Smartbills(api_key='YOUR_API_KEY')

response = client.employees.list(
    page=1,
    page_size=20,
    is_active=True,
    order_by='totalSales',
    sort_order='desc'
)

print(f"Found {response.metadata.count} employees")
```

```csharp C#
using Smartbills.NET;

var client = new SBClient("YOUR_API_KEY");

var response = await client.Employees.ListAsync(new EmployeeListRequest
{
    Page = 1,
    PageSize = 20,
    IsActive = true,
    OrderBy = "totalSales",
    SortOrder = "desc"
});

Console.WriteLine($"Found {response.Metadata.Count} employees");
```

## Exemples de filtrage

### Obtenir les meilleurs performeurs

```bash
GET /v1/employees?orderBy=totalSales&sortOrder=desc&pageSize=10
```

### Filtrer par département

```bash
GET /v1/employees?department=Sales
```

### Employés actifs uniquement

```bash
GET /v1/employees?isActive=true
```

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 400 | INVALID_PARAMETER | Paramètre de requête invalide |
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | FORBIDDEN | Permissions insuffisantes |
| 429 | RATE_LIMIT_EXCEEDED | Trop de requêtes |
