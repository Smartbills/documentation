---
title: "Supprimer une entreprise"
api: "DELETE https://api.smartbills.io/v1/businesses/{id}"
description: "Supprimer une entreprise"
---

## Paramètres de chemin

<ParamField path="id" type="integer" required>
  Identifiant de l'entreprise
</ParamField>

<Warning>
  Cette action ne peut pas être annulée. Toutes les données associées seront définitivement supprimées.
</Warning>

<RequestExample>

```bash cURL
curl --request DELETE \
  --url https://api.smartbills.io/v1/businesses/456 \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

</RequestExample>
