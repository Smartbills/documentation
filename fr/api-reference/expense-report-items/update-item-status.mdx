title: "Modifier un élément du rapport"
description: "Modifier les détails d'une dépense dans un rapport de dépenses"
api: "PUT https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/{reportId}/expenses/{expenseId}"
---

## Aperçu

Mettre à jour le montant alloué, le taux de change, la catégorie ou les notes d'une dépense dans un rapport de dépenses. Cela modifié les propriétés au niveau du rapport de la dépense sans modifier l'enregistrement original de la dépense.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer pour l'authentification. Format : `Bearer YOUR_API_KEY`
</ParamField>

## Paramètres de chemin

<ParamField path="businessId" type="integer" required>
  L'identifiant unique de l'entreprise
</ParamField>

<ParamField path="reportId" type="integer" required>
  L'identifiant unique du rapport de dépenses
</ParamField>

<ParamField path="expenseId" type="integer" required>
  L'identifiant unique de la dépense à modifier
</ParamField>

## Corps de la requête

<ParamField body="allocatedAmount" type="number">
  Montant mis à jour à allouer de cette dépense au rapport
</ParamField>

<ParamField body="exchangeRate" type="number">
  Taux de changé mis à jour à appliquer
</ParamField>

<ParamField body="categoryId" type="integer">
  Identifiant de catégorie mis à jour pour cette dépense dans le rapport
</ParamField>

<ParamField body="notes" type="string">
  Notes spécifiques à cette dépense dans le rapport
</ParamField>

## Règles de validation

- Le rapport doit être au statut `draft`
- Le `allocatedAmount` ne peut pas dépasser le montant original de la dépense
- Le `categoryId` doit référencer une catégorie valide dans l'entreprise
- Le `exchangeRate` doit être un nombre positif

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 400 | REPORT_NOT_DRAFT | Le rapport n'est pas au statut brouillon |
| 400 | AMOUNT_EXCEEDS_EXPENSE | Le montant alloué dépasse le total de la dépense |
| 400 | INVALID_CATEGORY | La catégorie n'existe pas |
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 404 | EXPENSE_NOT_IN_REPORT | La dépense ne fait pas partie de ce rapport |
| 404 | REPORT_NOT_FOUND | Le rapport n'existe pas |
