---

## Aperçu

Ajouter une dépense existante à un rapport de dépenses. Vous pouvez optionnellement spécifier un montant alloué (pour les dépenses fractionnées), un taux de changé et une catégorie de remplacement.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer pour l'authentification. Format : `Bearer YOUR_API_KEY`
</ParamField>

## Paramètres de chemin

<ParamField path="businessId" type="integer" required>
  L'identifiant unique de l'entreprise
</ParamField>

<ParamField path="reportId" type="integer" required>
  L'identifiant unique du rapport de dépenses
</ParamField>

## Corps de la requête

<ParamField body="expenseId" type="integer" required>
  L'identifiant de la dépense à ajouter au rapport
</ParamField>

<ParamField body="allocatedAmount" type="number">
  Montant à allouer de cette dépense au rapport. Par défaut, le montant total de la dépense. Utilisez ceci pour fractionner une dépense entre plusieurs rapports.
</ParamField>

<ParamField body="exchangeRate" type="number">
  Taux de changé à appliquer lorsque la devise de la dépense diffère de la devise du rapport. Par défaut `1.0`.
</ParamField>

<ParamField body="categoryId" type="integer">
  Remplacer la catégorie de la dépense pour ce rapport. Si non fourni, la catégorie originale de la dépense est utilisée.
</ParamField>

## Règles de validation

- La dépense doit exister et appartenir à l'entreprise spécifiée
- La dépense ne doit pas être déjà entièrement allouée à un autre rapport
- Le rapport doit être au statut `draft`
- Le `allocatedAmount` ne peut pas dépasser le montant non alloué restant de la dépense
- Le `exchangeRate` doit être un nombre positif

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 400 | EXPENSE_ALREADY_IN_REPORT | La dépense est déjà dans ce rapport |
| 400 | AMOUNT_EXCEEDS_EXPENSE | Le montant alloué dépasse le total de la dépense |
| 400 | REPORT_NOT_DRAFT | Le rapport n'est pas au statut brouillon |
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 404 | EXPENSE_NOT_FOUND | La dépense n'existe pas |
| 404 | REPORT_NOT_FOUND | Le rapport n'existe pas |
