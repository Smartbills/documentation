---
title: "Lister les éléments du rapport"
description: "Lister toutes les dépenses d'un rapport de dépenses"
api: "GET https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/{reportId}/expenses"
---

## Aperçu

Récupérer toutes les dépenses ajoutées à un rapport de dépenses spécifique. La réponse inclut le montant alloué, le taux de changé et l'attribution de catégorie de chaque dépense dans le contexte du rapport.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer pour l'authentification. Format : `Bearer YOUR_API_KEY`
</ParamField>

## Paramètres de chemin

<ParamField path="businessId" type="integer" required>
  L'identifiant unique de l'entreprise
</ParamField>

<ParamField path="reportId" type="integer" required>
  L'identifiant unique du rapport de dépenses
</ParamField>

## Réponse

<ResponseField name="data" type="array">
  Tableau d'objets d'éléments de rapport de dépenses

  <Expandable title="Objet Élément de rapport de dépenses">
    <ResponseField name="id" type="integer">
      Identifiant unique de l'entrée d'élément du rapport
    </ResponseField>

    <ResponseField name="expenseId" type="integer">
      Identifiant de la dépense liée
    </ResponseField>

    <ResponseField name="reportId" type="integer">
      Identifiant du rapport de dépenses parent
    </ResponseField>

    <ResponseField name="allocatedAmount" type="number">
      Montant alloué à ce rapport (peut différer du montant original de la dépense pour les dépenses fractionnées)
    </ResponseField>

    <ResponseField name="exchangeRate" type="number">
      Taux de changé appliqué lorsque la devise de la dépense diffère de la devise du rapport
    </ResponseField>

    <ResponseField name="categoryId" type="integer">
      Identifiant de catégorie assigné à cette dépense dans le rapport
    </ResponseField>

    <ResponseField name="notes" type="string">
      Notes spécifiques à cette dépense dans le rapport
    </ResponseField>

    <ResponseField name="expense" type="object">
      L'objet de dépense complet
      <Expandable title="Objet Dépense">
        <ResponseField name="id" type="integer">
          Identifiant de la dépense
        </ResponseField>
        <ResponseField name="merchant" type="string">
          Nom du commerçant
        </ResponseField>
        <ResponseField name="amount" type="number">
          Montant original de la dépense
        </ResponseField>
        <ResponseField name="currency" type="string">
          Code de devise ISO 4217
        </ResponseField>
        <ResponseField name="date" type="string">
          Date de la transaction (AAAA-MM-JJ)
        </ResponseField>
        <ResponseField name="status" type="string">
          Statut de la dépense
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="createdAt" type="string">
      Horodatage de l'ajout de l'élément au rapport (ISO 8601)
    </ResponseField>

    <ResponseField name="updatedAt" type="string">
      Horodatage de la dernière mise à jour (ISO 8601)
    </ResponseField>
  </Expandable>
</ResponseField>

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | FORBIDDEN | Permissions insuffisantes pour cette entreprise |
| 404 | REPORT_NOT_FOUND | Le rapport de dépenses n'existe pas |
