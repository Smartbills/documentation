---
title: "Supprimer un élément du rapport"
description: "Supprimer une dépense d'un rapport de dépenses"
api: "DELETE https://api.smartbills.io/v1/businesses/{businessId}/expense-reports/{reportId}/expenses/{expenseId}"
---

## Aperçu

Supprimer une dépense d'un rapport de dépenses. La dépense elle-même n'est pas supprimée -- elle est simplement détachée du rapport et peut être ajoutée à un autre rapport.

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer pour l'authentification. Format : `Bearer YOUR_API_KEY`
</ParamField>

## Paramètres de chemin

<ParamField path="businessId" type="integer" required>
  L'identifiant unique de l'entreprise
</ParamField>

<ParamField path="reportId" type="integer" required>
  L'identifiant unique du rapport de dépenses
</ParamField>

<ParamField path="expenseId" type="integer" required>
  L'identifiant unique de la dépense à supprimer
</ParamField>

## Réponse

Retourne un statut `200 OK` en cas de suppression réussie.

<ResponseField name="message" type="string">
  Message de confirmation
</ResponseField>

<Warning>
  Vous ne pouvez supprimer des dépenses que des rapports au statut `draft`. Les rapports soumis ou approuvés ne peuvent pas être modifiés.
</Warning>

<RequestExample>

```bash cURL
curl --request DELETE \
  --url https://api.smartbills.io/v1/businesses/456/expense-reports/789/expenses/12345 \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
await client.expenseReportExpenses.remove(789, 12345);
```

```python Python
client.expense_report_expenses.remove(report_id=789, expense_id=12345)
```

```csharp C#
await client.ExpenseReportExpenses.RemoveAsync(789, 12345);
```

</RequestExample>

<ResponseExample>

```json Response
{
  "message": "Expense removed from report succèssfully"
}
```

</ResponseExample>

## Réponses d'erreur

| Code de statut | Code d'erreur | Description |
|------------|------------|-------------|
| 400 | REPORT_NOT_DRAFT | Le rapport n'est pas au statut brouillon |
| 401 | UNAUTHORIZED | Clé API manquante ou invalide |
| 403 | FORBIDDEN | Permissions insuffisantes |
| 404 | EXPENSE_NOT_IN_REPORT | La dépense ne fait pas partie de ce rapport |
| 404 | REPORT_NOT_FOUND | Le rapport n'existe pas |
