---
title: "Lister les reçus"
api: "GET https://api.smartbills.io/v1/receipts"
description: "Récupérer une liste paginée de reçus"
---

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer pour l'authentification
</ParamField>

## Portées requises

- `receipts.read`

## Paramètres de requête

<ParamField query="page" type="integer" default="1">
  Numéro de page
</ParamField>

<ParamField query="pageSize" type="integer" default="100">
  Éléments par page (max : 100)
</ParamField>

<ParamField query="merchantId" type="integer">
  Filtrer par identifiant de marchand
</ParamField>

<ParamField query="locationId" type="integer">
  Filtrer par identifiant d'emplacement
</ParamField>

<ParamField query="customerId" type="integer">
  Filtrer par identifiant de client
</ParamField>

<ParamField query="startDate" type="string">
  Filtrer les reçus à partir de cette date (ISO 8601)
</ParamField>

<ParamField query="endDate" type="string">
  Filtrer les reçus jusqu'à cette date (ISO 8601)
</ParamField>

<ParamField query="status" type="string">
  Filtrer par statut : `completed`, `pending`, `cancelled`
</ParamField>

<RequestExample>

```bash cURL
curl --request GET \
  --url 'https://api.smartbills.io/v1/receipts?page=1&pageSize=20&status=completed' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```
