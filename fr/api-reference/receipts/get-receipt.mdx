---
title: "Obtenir un reçu"
api: "GET https://api.smartbills.io/v1/receipts/{id}"
description: "Récupérer un reçu par ID"
---

## Authentification

<ParamField header="Authorization" type="string" required>
  Jeton Bearer pour l'authentification
</ParamField>

## Portées requises

- `receipts.read`

## Paramètres de chemin

<ParamField path="id" type="integer" required>
  L'identifiant unique du reçu
</ParamField>

<RequestExample>

```bash cURL
curl --request GET \
  --url https://api.smartbills.io/v1/receipts/12345 \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

```javascript JavaScript
const receipt = await client.receipts.get(12345);
```

```python Python
receipt = client.receipts.get(12345)
```

```csharp C#
var receipt = await client.Receipts.GetAsync(12345);
```

</RequestExample>
