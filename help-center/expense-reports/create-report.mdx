## Overview

Expense reports allow you to group related expenses together for easy submission, approval, and reimbursement. This guide shows you how to create reports on both web and mobile platforms.

<Note>
  **What is an expense report?** A collection of expenses submitted together for approval and reimbursement, typically organized by time period or project.
</Note>

## Web Application

### Method 1: Create from Expenses Page

1. Log in to your [Smartbills dashboard](https://app.smartbills.io)
2. Navigate to **Expenses**
3. Select expenses you want to include (click checkboxes)
4. Click **Create Report** button
5. Enter report details:
   - **Report Name** (e.g., "January 2024 Travel Expenses")
   - **Description** (optional but recommended)
   - **Period** (start and end dates)
6. Click **Create Report**

<img
  className="block"
  src="/images/help-center/expense-reports/web-create-from-expenses.png"
  alt="Create report from expenses"
/>

### Method 2: Create Empty Report

1. Navigate to **Reports** tab
2. Click **+ New Report**
3. Enter report details:
   - **Name**: Give your report a descriptive name
   - **Description**: Explain the purpose
   - **Business**: Select the business (if you have multiple)
   - **Period**: Set start and end dates
4. Click **Create**
5. Add expenses later using **Add Expenses** button

<img
  className="block"
  src="/images/help-center/expense-reports/web-new-report.png"
  alt="Create new report"
/>

<Tip>
  **Naming convention**: Use a consistent format like "Month Year - Category" for easy organization.
</Tip>

## Mobile App

### iOS

1. Open the Smartbills app
2. Tap the **Reports** tab (bottom navigation)
3. Tap the **+** button (top right)
4. Select **New Report**
5. Fill in report details:
   - **Report Name**
   - **Description** (optional)
   - **Date Range**
6. Tap **Create**
7. Tap **Add Expenses** to include expenses
8. Select expenses from the list
9. Tap **Add** (top right)

<img
  className="block"
  src="/images/help-center/expense-reports/ios-create-report.png"
  alt="iOS create report"
/>

### Android

1. Open the Smartbills app
2. Tap **Reports** (bottom navigation)
3. Tap the **+** FAB button
4. Tap **New Report**
5. Enter report information:
   - **Name**
   - **Description**
   - **Start Date**
   - **End Date**
6. Tap **Create Report**
7. Tap **+ Add Expenses**
8. Select the expenses you want to include
9. Tap the checkmark icon

## Adding Expenses to a Report

### Select Eligible Expenses

Only expenses that meet these criteria can be added:

- ✅ Status is "Pending" (not already in another report)
- ✅ Within the report's date range (or no date range set)
- ✅ Belongs to the same business
- ✅ Not already submitted
- ✅ Has all required fields completed

<img
  className="block"
  src="/images/help-center/expense-reports/eligible-expenses.png"
  alt="Eligible expenses"
/>

### Add Expenses

<Tabs>
  <Tab title="Web">
    **From Report Page:**
    1. Open your report
    2. Click **Add Expenses**
    3. Browse or search for expenses
    4. Check boxes next to expenses to add
    5. Click **Add Selected** button
    
    **Drag and Drop:**
    1. Open the report in one browser tab
    2. Open expenses list in another tab
    3. Drag expense items from list to report
  </Tab>
  
  <Tab title="Mobile">
    1. Open the report
    2. Tap **Add Expenses**
    3. Scroll through eligible expenses
    4. Tap expenses to select them (checkmark appears)
    5. Tap **Add** or checkmark icon
    
    **Quick Add:**
    - On the Expenses screen, swipe right on an expense
    - Tap **Add to Report**
    - Select the report from the list
  </Tab>
</Tabs>

### Remove Expenses

To remove an expense from a report (before submission):

<Tabs>
  <Tab title="Web">
    1. Open the report
    2. Find the expense in the list
    3. Click the **X** or **Remove** button
    4. Confirm the removal
  </Tab>
  
  <Tab title="Mobile">
    1. Open the report
    2. Swipe left on the expense
    3. Tap **Remove**
    4. Confirm if prompted
  </Tab>
</Tabs>

## Report Details

### Required Information

Every report must include:

| Field | Description | Example |
|-------|-------------|---------|
| **Name** | Descriptive title | "Q1 2024 Travel Expenses" |
| **Business** | Which business/department | "Sales Department" |
| **At least one expense** | Minimum one expense | - |

### Optional Information

Add more context with optional fields:

<AccordionGroup>
  <Accordion title="Description" icon="align-left">
    Explain the purpose of these expenses:
    - Trip details
    - Project information
    - Event name
    - Any relevant context for approvers
  </Accordion>

  <Accordion title="Date Range" icon="calendar">
    Set the period these expenses cover:
    - Helps filter eligible expenses
    - Useful for monthly or trip-based reports

  <Accordion title="Project/Cost Center" icon="folder">

  </Accordion>

  <Accordion title="Tags" icon="tags">
    Add tags for better organization:
    - Client name
    - Project code
    - Event name
    - Location
  </Accordion>

  <Accordion title="Notes for Approver" icon="message">
    Include any special instructions or context for the person reviewing your report.
  </Accordion>
</AccordionGroup>

## Report Templates

### Create a Template

Save time by creating templates for recurring reports:

1. Go to **Reports** → **Templates**
2. Click **Create Template**
3. Define template settings:
   - **Name**: Template name
   - **Auto-name format**: Pattern for report names
   - **Default period**: Weekly, monthly, etc.
   - **Auto-include rules**: Criteria for auto-adding expenses
4. Click **Save Template**

<img
  className="block"
  src="/images/help-center/expense-reports/report-template.png"
  alt="Report template"
/>

### Use a Template

1. Click **+ New Report**
2. Select **From Template**
3. Choose your template
4. Report is created with predefined settings
5. Expenses matching rules are automatically added

<Check>
  **Time saver**: Templates are perfect for monthly expense reports or recurring business travel.
</Check>

## Auto-Generated Reports

### Enable Auto-Reports

Set up automatic report creation:

1. Go to **Settings** → **Expense Reports**
2. Enable **Auto-Generate Reports**
3. Choose frequency:
   - Weekly (every Friday)
   - Monthly (last day of month)
   - Custom schedule
4. Set auto-inclusion rules
5. Click **Save**

<img
  className="block"
  src="/images/help-center/expense-reports/auto-reports.png"
  alt="Auto-generated reports"
/>

### Auto-Inclusion Rules

Define which expenses are automatically added:

- All expenses in period
- Expenses from specific categories
- Expenses with specific tags
- Expenses over a certain amount
- Personal card expenses only

<Tip>
  Auto-reports are created as drafts. You can review and modify them before submission.
</Tip>

## Review Before Submission

### Pre-Submission Checklist

Before submitting your report, verify:

<Steps>
  <Step title="All Expenses Included">
    Ensure you haven't missed any eligible expenses for the period.
  </Step>
  
  <Step title="Receipts Attached">
    Every expense should have a receipt image (per company policy).
  </Step>
  
  <Step title="Correct Categorization">
    All expenses are properly categorized.
  </Step>
  
  <Step title="Accurate Amounts">
    Double-check all amounts and currency conversions.
  </Step>
  
  <Step title="Policy Compliance">
    No out-of-policy expenses, or violations are explained.
  </Step>
  
  <Step title="Complete Information">
    All required fields are filled in for each expense.
  </Step>
</Steps>

### Report Summary

Review the report summary before submitting:

- **Total Amount**: Sum of all expenses
- **Expense Count**: Number of items
- **Date Range**: Period covered
- **Policy Violations**: Any flagged items
- **Missing Receipts**: Expenses without documentation

  className="block"
  src="/images/help-center/expense-reports/report-summary.png"

/>

<Warning>
  **Policy violations**: If your report contains policy violations, add notes explaining the circumstances.
</Warning>

## Tips for Better Reports

### Organization

- **Group by purpose**: Trip, event, or project
- **Use consistent naming**: Follow a standard format
- **Include context**: Add descriptions and notes
- **Tag appropriately**: Use tags for easy searching

### Timing

- **Submit regularly**: Don't let expenses pile up
- **Meet deadlines**: Submit before company cutoff dates
- **Plan ahead**: Create reports before quarter/month end

### Documentation

- **Attach all receipts**: Even for small amounts
- **Add notes**: Explain unusual expenses
- **Include attendees**: For meal expenses
- **Document purpose**: Business justification for each expense

## Troubleshooting

<AccordionGroup>
  <Accordion title="Can't add an expense to report" icon="circle-exclamation">
    An expense might not be available if:
    
    - Already included in another report
    - Already submitted or approved
    - Outside the report's date range
    - Missing required information
    - Belongs to a different business
    
    **Solution**: Check expense status and complete any missing information.
  </Accordion>

  <Accordion title="Report won't save" icon="floppy-disk">
    Common reasons:
    
    - Missing required fields (name, business)
    - No expenses added
    - Network connection issues
    - You don't have permission to create reports
    
    **Solution**: Fill in all required fields and ensure you have internet connection.
  </Accordion>

  <Accordion title="Can't find my report" icon="magnifying-glass">
    Try these steps:
    
    1. Check the **Status** filter (Draft, Submitted, Approved)
    2. Expand the date range filter
    3. Look in the correct business/department
    4. Use the search function
    5. Check if it was accidentally deleted (check Trash)
  </Accordion>

  <Accordion title="Policy violation warnings" icon="triangle-exclamation">
    If your report shows policy violations:
    
    1. Review each flagged expense
    2. Correct any errors
    3. Add notes explaining valid violations
    4. Remove truly out-of-policy expenses
    5. Consult with your manager if unsure
  </Accordion>
</AccordionGroup>
