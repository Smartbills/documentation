## Overview

Bulk actions let you perform operations on multiple expenses simultaneously, saving significant time when managing large volumes.

## Available Bulk Actions

| Action | Description |
|--------|-------------|
| **Assign Category** | Set the same category on multiple expenses |
| **Assign Vendor** | Link expenses to a vendor |
| **Assign Payer Type** | Mark as business or personal |
| **Add to Report** | Add multiple expenses to an expense report |
| **Set Note** | Apply the same note to selected expenses |
| **Export** | Download selected expenses as CSV or PDF |
| **Delete** | Remove multiple expenses at once |

## Web Dashboard

<Steps>
  <Step title="Select Expenses">
    In the expense list, click the checkbox next to each expense you want to include. Use **Select All** to select the entire page.
  </Step>
  <Step title="Choose Action">
    A bulk action toolbar appears at the top. Click the action you want to perform.
  </Step>
  <Step title="Configure">
    Depending on the action:
    - **Category**: Select a category from the dropdown
    - **Report**: Choose or create an expense report
    - **Export**: Choose format (CSV, PDF, or ZIP with attachments)
  </Step>
  <Step title="Confirm">
    Click **Apply** to execute the bulk action. A progress indicator shows completion status.
  </Step>
</Steps>

<Tip>
Use the search and filter options to narrow down expenses before selecting — you can filter by date range, category, vendor, or status.
</Tip>

<Warning>
Bulk delete is permanent. Make sure you've selected the correct expenses before confirming.
</Warning>
