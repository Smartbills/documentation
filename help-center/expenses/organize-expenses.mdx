## Overview

Proper expense organization makes reporting faster, ensures compliance, and provides better insights into spending. This guide covers best practices for organizing expenses in Smartbills.

## Categories

### Choosing the Right Category

Categories group similar expenses for reporting and tax purposes.

**Common Categories:**
- Travel & Transportation
- Meals & Entertainment
- Office Supplies
- Software & Subscriptions
- Marketing & Advertising
- Professional Services
- Utilities
- Equipment

**How to Categorize:**
1. Open the expense
2. Select **Category**
3. Choose from the list
4. Save

<Tip>
  Auto-categorization learns from your patterns. Review and correct initially for better accuracy later.
</Tip>

### Creating Custom Categories

**Administrators can:**
1. Go to **Settings** → **Categories**
2. Click **New Category**
3. Enter name and settings
4. Assign to departments (optional)
5. Save

See [Expense Categories](/help-center/settings/categories) for details.

## Tags

### Using Tags Effectively

Tags provide flexible organization beyond categories.

**Tag Ideas:**
- **Projects**: Project Alpha, Q1 Campaign
- **Clients**: ABC Corp, XYZ Inc
- **Billable**: Billable, Non-billable
- **Teams**: Marketing, Sales, Engineering
- **Events**: Conference 2024, Trade Show

**Adding Tags:**
1. Open expense
2. Click **Tags**
3. Select existing or create new
4. Add multiple tags as needed

### Tag Best Practices

✅ **Do:**
- Use consistent naming conventions
- Create a tag library
- Train team on standard tags
- Review tags periodically

❌ **Don't:**
- Create too many similar tags
- Use overly specific tags
- Duplicate category information in tags

## Filters

### Finding Expenses Quickly

Use filters to organize and find expenses:

**On Web:**
1. Go to **Expenses**
2. Click **Filter** button
3. Select criteria:
   - Date range
   - Category
   - Tags
   - Amount range
   - Status
   - Merchant

4. Click **Apply**

**On Mobile:**
1. Tap **Expenses**
2. Tap filter icon
3. Select filters
4. Tap **Done**

### Saved Filters

Create saved filters for common searches:

1. Configure your filters
2. Click **Save Filter**
3. Name it (e.g., "This Month - Meals")
4. Access from **Saved Filters** dropdown

**Useful Saved Filters:**
- This month's expenses
- Pending expenses
- Billable items
- High-value expenses (>$500)
- Specific projects or clients

## Expense Status

### Understanding Status

Expenses have different states:

- **Pending** - Uploaded, needs review
- **Draft** - Manually created, incomplete
- **Ready** - Complete, ready for report
- **In Report** - Added to draft report
- **Submitted** - In submitted report
- **Approved** - Report approved
- **Rejected** - Needs correction
- **Reimbursed** - Payment processed

### Status-Based Organization

Filter by status to manage workflow:

**Pending → Ready:**
1. Filter: Status = Pending
2. Review and edit
3. Mark as Ready

**Ready → In Report:**
1. Filter: Status = Ready
2. Add to expense report
3. Submit

## Best Practices

### Daily Habits

- ✅ Upload receipts immediately
- ✅ Categorize within 24 hours
- ✅ Add tags while details are fresh
- ✅ Review pending weekly

### Weekly Review

Every week:
1. Review all pending expenses
2. Ensure proper categorization
3. Add missing tags/projects
4. Delete duplicates
5. Create expense reports

### Monthly Cleanup

Once a month:
1. Review all expenses
2. Archive submitted reports
3. Check for uncategorized items
4. Update saved filters
5. Review spending patterns

## Troubleshooting

### Can't Find an Expense

**Solutions:**
1. Clear all filters
2. Expand date range
3. Search by merchant or amount
4. Check archived expenses
5. Verify correct business account

### Wrong Category Auto-Selected

**Solutions:**
1. Manually change category
2. Save correction
3. Auto-categorization learns from changes
4. Report patterns to administrator
