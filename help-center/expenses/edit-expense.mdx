## Overview

After uploading an expense, you may need to edit details like the amount, merchant, category, or add additional notes. SmartBills makes it easy to update expense information at any time before the expense is included in an approved report.

## When Can You Edit?

You can edit an expense when:
- ✅ Status is "Pending" or "Draft"
- ✅ Included in a draft expense report
- ✅ Report has been recalled

You cannot edit when:
- ❌ Included in a submitted expense report
- ❌ Report has been approved
- ❌ Marked as reimbursed

## On Mobile (iOS/Android)

### Editing Basic Information

1. **Open the Expense**
   - Go to **Expenses** tab
   - Tap the expense you want to edit

2. **Tap Edit**
   - Tap the **Edit** icon (pencil) in the top right

3. **Update Fields**
   - **Merchant**: Tap to edit merchant name
   - **Amount**: Update the expense amount
   - **Date**: Select a different date
   - **Category**: Choose from dropdown
   - **Description**: Add or edit notes

4. **Save Changes**
   - Tap **Save** when done
   - Changes are saved immediately

### Changing the Receipt Image

1. **Open the Expense**
2. **Tap the Receipt Image**
3. **Choose Option**:
   - **Replace** - Choose a different photo
   - **Add More** - Add additional pages
   - **Remove** - Delete the attachment

### Adding Tags

1. **Open the Expense**
2. **Tap Tags**
3. **Add or Remove Tags**
   - Select from existing tags
   - Or create new tags
4. **Save**

## On Web

### Editing Expense Details

1. **Navigate to Expenses**
   - Click **Expenses** in the sidebar
   - Find the expense to edit

2. **Open Expense**
   - Click on the expense row
   - Or click the **•••** menu → **Edit**

3. **Edit in Detail View**
   - Click **Edit** button
   - Update any field:
     - Merchant name
     - Amount
     - Date
     - Category
     - Description
     - Tags
     - Payment method
     - Project (if enabled)

4. **Save Changes**
   - Click **Save Changes**
   - Or press `Ctrl/Cmd + Enter`

### Quick Edit (Inline)

For faster edits:

1. **Hover Over Expense Row**
2. **Click the Field** you want to edit
3. **Type New Value**
4. **Press Enter** to save

Quick edit works for:
- Merchant
- Amount
- Category
- Date

### Bulk Edit

To edit multiple expenses at once:

1. **Select Expenses**
   - Check the box next to each expense
   - Or select all with the header checkbox

2. **Click Bulk Actions**
   - Choose **Edit Selected**

3. **Update Common Fields**
   - Category
   - Tags
   - Project
   - Custom fields

4. **Apply Changes**
   - Click **Update All**

## Editing Specific Fields

### Amount

**Mobile:**
1. Tap the amount field
2. Enter new amount
3. Decimal point auto-formats

**Web:**
1. Click the amount
2. Type new value
3. Press Enter

<Tip>
  SmartBills automatically formats amounts based on your currency settings.
</Tip>

### Merchant

**Mobile:**
1. Tap merchant field
2. Start typing
3. Select from suggestions or enter manually

**Web:**
1. Click merchant field
2. Type or select from dropdown
3. Recent merchants appear first

### Date

**Mobile:**
1. Tap the date field
2. Use the date picker
3. Tap **Done**

**Web:**
1. Click the date field
2. Select from calendar
3. Or type in format: YYYY-MM-DD

### Category

**Mobile:**
1. Tap **Category**
2. Scroll through list
3. Tap to select
4. Or search for category

**Web:**
1. Click **Category** dropdown
2. Select from list
3. Or type to search

<Note>
  Categories can be customized by your administrator. See [Expense Categories](/help-center/settings/categories).
</Note>

### Description/Notes

**Mobile:**
1. Tap **Description**
2. Type your notes
3. Tap **Done**

**Web:**
1. Click in description field
2. Type your notes
3. Click outside to save

**Best Practices:**
- Explain the business purpose
- Note who attended (for meals)
- Add project or client name
- Include any relevant details

### Tags

Tags help organize and filter expenses.

**Adding Tags:**
1. Click/Tap **Tags**
2. Select existing tags or create new
3. Multiple tags allowed

**Common Tags:**
- Project names
- Client names
- Department
- Billable/Non-billable
- Urgent

### Payment Method

**Mobile:**
1. Tap **Payment Method**
2. Select method:
   - Corporate card
   - Personal card (for reimbursement)
   - Cash
   - Other

**Web:**
1. Click **Payment Method**
2. Choose from dropdown

<Info>
  If paid with personal funds, mark as "Personal" for proper reimbursement tracking.
</Info>

### Project Assignment

If your organization uses projects:

**Mobile:**
1. Tap **Project**
2. Select from list
3. Or search for project

**Web:**
1. Click **Project** dropdown
2. Select or search

## Advanced Editing

### Splitting Expenses

To split one expense into multiple:

1. **Open the Expense**
2. **Click Split**
3. **Enter Split Amounts**
   - Amount 1: $50 - Office Supplies
   - Amount 2: $30 - Software
4. **Save**

Each split becomes a separate expense.

### Merging Expenses

To combine multiple expenses:

1. **Select Expenses** to merge
2. **Click Merge**
3. **Review Combined Details**
4. **Save Merged Expense**

### Adding Line Items

For itemized receipts:

1. **Open Expense**
2. **Click Add Line Items**
3. **Enter Each Item**:
   - Description
   - Quantity
   - Unit price
4. **Save**

## Editing Receipt Images

### Replace Receipt

1. **Open Expense**
2. **Click Receipt Image**
3. **Click Replace**
4. **Upload New Image**
5. **Confirm**

<Warning>
  Replacing a receipt will trigger OCR re-processing. Review extracted data afterward.
</Warning>

### Add More Pages

For multi-page receipts:

1. **Open Expense**
2. **Click Add Page**
3. **Upload Additional Image**
4. **Order Pages** (drag to reorder)
5. **Save**

### Rotate or Crop

**Mobile:**
1. Tap receipt image
2. Use rotate/crop tools
3. Save

**Web:**
1. Click receipt
2. Click Edit Image
3. Use tools to rotate/crop
4. Apply changes

## Custom Fields

If your organization has custom fields:

1. **Scroll to Custom Fields** section
2. **Fill in Required Fields**
3. **Save**

Common custom fields:
- Department
- Cost center
- GL code
- Approval code
- Reference number

## History & Audit Trail

View who edited an expense and when:

**Web:**
1. Open expense
2. Click **History** tab
3. See all changes with timestamps

**Mobile:**
1. Open expense
2. Scroll to bottom
3. Tap **View History**

## Troubleshooting

### Can't Edit Expense

**Problem**: Edit button is greyed out or missing

**Possible Reasons:**
- Expense is in a submitted report
- Expense is approved
- You don't have edit permissions

**Solutions:**
- Recall the report (if you submitted it)
- Ask manager to reject/recall report
- Contact your administrator

### Changes Won't Save

**Problem**: Edits don't stick

**Solutions:**
- Check internet connection
- Refresh the page/app
- Clear cache
- Try again

### OCR Re-extraction

**Problem**: Editing triggers unwanted OCR changes

**Solution:**
- Lock fields you don't want changed
- Disable auto-OCR in settings
- Edit after OCR completes

## Best Practices

### Review Before Submitting

Always review expenses before adding to reports:
- ✅ Correct amount
- ✅ Accurate merchant
- ✅ Proper category
- ✅ Business purpose noted
- ✅ Receipt image clear and complete

### Regular Maintenance

- Review pending expenses weekly
- Categorize promptly
- Add descriptions while fresh in memory
- Delete duplicates immediately

### Consistent Formatting

- Use standard merchant names
- Follow company tagging conventions
- Complete all required fields
- Add meaningful descriptions
