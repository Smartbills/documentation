## Aperçu

Créer un compte Smartbills est rapide et facile. Vous pouvez vous inscrire en utilisant l'application web, l'application iOS ou Android. Ce guide vous guidera à travers le processus sur chaque plateforme.

<Note>
  **Gratuit pour commencer**: Aucune carte de crédit requise. Commencez avec notre plan gratuit et passez à un plan supérieur quand vous êtes prêt.
</Note>

## Application Web

### Étape 1: Accédez à la page d'inscription

1. Ouvrez votre navigateur web
2. Allez sur [app.smartbills.io/register](https://auth.smartbills.io/sign-up)
3. Vous verrez le formulaire d'inscription

<img
  className="block"
  src="/images/help-center/account/web-signup-form.png"
  alt="Formulaire d'inscription web"
/>

### Étape 2: Entrez vos informations

Remplissez les champs requis:

- **Adresse courriel**: Entrez votre courriel professionnel ou personnel
- **Mot de passe**: Créez un mot de passe fort (min. 8 caractères)
- **Prénom**: Votre prénom
- **Nom**: Votre nom de famille

<Tip>
  Utilisez un mot de passe fort avec un mélange de majuscules, minuscules, chiffres et caractères spéciaux.
</Tip>

### Étape 3: Acceptez les conditions générales

- Consultez les Conditions d'utilisation
- Consultez la Politique de confidentialité
- Cochez la case pour accepter les deux

### Étape 4: Complétez l'inscription

1. Cliquez sur le bouton **Créer un compte**
2. Vous recevrez un courriel de vérification
3. Vérifiez votre boîte de réception pour un courriel de Smartbills
4. Cliquez sur le lien de vérification dans le courriel

<img
  className="block"
  src="/images/help-center/account/email-verification.png"
  alt="Vérification par courriel"
/>

### Étape 5: Complétez votre profil

Après avoir vérifié votre courriel:

1. Vous serez redirigé vers votre tableau de bord
2. Complétez la configuration de votre profil:
   - Ajoutez une photo de profil (optionnel)
   - Définissez votre fuseau horaire
   - Choisissez votre devise préférée
   - Définissez votre préférence linguistique

<Check>
  **Félicitations!** Votre compte Smartbills est maintenant actif.
</Check>

## Application mobile (iOS)

### Étape 1: Téléchargez l'application

1. Ouvrez l'**App Store** sur votre iPhone ou iPad
2. Recherchez "Smartbills"
3. Appuyez sur **Obtenir** pour télécharger
4. Installez l'application

<img
  className="block"
  src="/images/help-center/account/ios-app-store.png"
  alt="Smartbills sur l'App Store"
/>

### Étape 2: Ouvrez l'application

1. Appuyez sur l'icône Smartbills pour lancer l'application
2. Sur l'écran de bienvenue, appuyez sur **S'inscrire**

### Étape 3: Créez votre compte

<Tabs>
  <Tab title="Inscription par courriel">
    1. Appuyez sur **S'inscrire avec un courriel**
    2. Entrez votre adresse courriel
    3. Créez un mot de passe
    4. Entrez vos prénom et nom
    5. Appuyez sur **Créer un compte**
  </Tab>
  
  <Tab title="Connexion Apple">
    1. Appuyez sur **Continuer avec Apple**
    2. Authentifiez-vous avec Face ID ou Touch ID
    3. Choisissez de partager ou masquer votre courriel
    4. Complétez les champs requis supplémentaires
    5. Appuyez sur **Continuer**
  </Tab>
  
  <Tab title="Connexion Google">
    1. Appuyez sur **Continuer avec Google**
    2. Sélectionnez votre compte Google
    3. Autorisez Smartbills
    4. Complétez les champs requis supplémentaires
    5. Appuyez sur **Continuer**
  </Tab>
</Tabs>

### Étape 4: Vérifiez votre courriel

1. Vérifiez votre boîte de réception
2. Ouvrez le courriel de vérification de Smartbills
3. Appuyez sur le lien de vérification
4. Vous serez redirigé vers l'application

### Étape 5: Configurez les permissions

L'application demandera les permissions pour:

- **Appareil photo**: Pour numériser les reçus
- **Bibliothèque de photos**: Pour télécharger des photos existantes
- **Notifications**: Pour recevoir des mises à jour
- **Localisation** (optionnel): Pour les dépenses géolocalisées

<img
  className="block"
  src="/images/help-center/account/ios-permissions.png"
  alt="Demande de permissions iOS"
/>

<Tip>
  Nous recommandons d'activer toutes les permissions pour une meilleure expérience, mais vous pouvez les modifier plus tard dans les Paramètres.
</Tip>

### Étape 2: Ouvrez l'application

1. Appuyez sur **Ouvrir** depuis le Play Store, ou

3. Appuyez pour lancer l'application

### Étape 3: Créez votre compte

<Tabs>
  <Tab title="Inscription par courriel">
    1. Appuyez sur **S'inscrire avec un courriel**
    2. Entrez votre adresse courriel
    3. Créez un mot de passe fort
    4. Entrez vos prénom et nom

## Méthodes d'inscription alternatives

### Inscription avec authentification unique (SSO)

Si votre entreprise utilise le SSO, vous pouvez vous inscrire avec vos identifiants d'entreprise:

1. Sur la page d'inscription, cliquez sur **S'inscrire avec SSO**
2. Entrez le domaine de courriel de votre entreprise
3. Vous serez redirigé vers la page de connexion de votre entreprise
4. Authentifiez-vous avec vos identifiants d'entreprise
5. Autorisez Smartbills
6. Complétez votre profil

<Note>
  Le SSO est disponible pour les plans **Business** et **Entreprise**. Contactez votre administrateur si vous avez besoin d'activer le SSO.
</Note>

### Inscription via invitation

Si un collègue vous a invité à rejoindre son entreprise:

1. Vérifiez votre courriel pour l'invitation
2. Cliquez sur **Accepter l'invitation** dans le courriel
3. Vous serez dirigé vers un formulaire d'inscription pré-rempli
4. Complétez les champs restants
5. Créez votre mot de passe
6. Cliquez sur **Rejoindre l'entreprise**

## Dépannage

<AccordionGroup>
  <Accordion title="Je n'ai pas reçu le courriel de vérification" icon="envelope">
    1. Vérifiez votre dossier spam ou courrier indésirable
    2. Attendez quelques minutes (les courriels peuvent être retardés)
    3. Cliquez sur **Renvoyer le courriel de vérification** sur la page de connexion
    4. Assurez-vous d'avoir entré la bonne adresse courriel
    5. Ajoutez noreply@smartbills.io à vos contacts
    
    Si vous ne le recevez toujours pas, contactez [support@smartbills.io](mailto:support@smartbills.io)
  </Accordion>

  <Accordion title="Le lien de vérification ne fonctionne pas" icon="link-slash">
    Les liens de vérification expirent après 24 heures. Si votre lien a expiré:
    
    1. Allez sur [app.smartbills.io/login](https://app.smartbills.io/login)
    2. Entrez votre courriel
    3. Cliquez sur **Renvoyer le courriel de vérification**
    4. Utilisez le nouveau lien dans les 24 heures
  </Accordion>

  <Accordion title="Je ne peux pas créer un compte avec mon courriel" icon="circle-exclamation">
    Cela peut arriver si:
    
    - Un compte existe déjà avec ce courriel
    - Le format de votre courriel est invalide
    - Votre entreprise a des exigences SSO
    
    Essayez:
    - Utilisez le lien **Mot de passe oublié** si vous avez déjà un compte
    - Vérifiez votre adresse courriel pour les fautes de frappe
    - Contactez votre département informatique concernant les exigences SSO
  </Accordion>

  <Accordion title="L'application mobile ne s'installe pas" icon="mobile">
    **iOS:**
    - Assurez-vous d'avoir iOS version 14.0 ou ultérieure
    - Vérifiez l'espace de stockage disponible
    - Redémarrez votre appareil
    - Mettez à jour l'application App Store
    
    **Android:**
    - Assurez-vous d'avoir Android version 8.0 ou ultérieure
    - Vérifiez l'espace de stockage disponible
    - Videz le cache de Google Play Store
    - Redémarrez votre appareil
  </Accordion>

  <Accordion title="Le SSO ne fonctionne pas" icon="key">
    Si vous avez des problèmes avec le SSO:
    
    1. Vérifiez que votre domaine de courriel est enregistré
    2. Contactez votre administrateur informatique
    3. Essayez de vous connecter avec vos identifiants d'entreprise
    4. Videz les cookies de votre navigateur
    5. Contactez le support avec le nom de votre entreprise
  </Accordion>
</AccordionGroup>

## Sécurité du compte

### Conseils pour un compte sécurisé

<Steps>
  <Step title="Utilisez un mot de passe fort">
    - Au moins 12 caractères
    - Mélange de lettres majuscules et minuscules
    - Inclure des chiffres et des symboles
    - Évitez les mots courants ou informations personnelles
  </Step>
  
  <Step title="Activez l'authentification à deux facteurs">
    Ajoutez une couche de sécurité supplémentaire à votre compte. [Apprenez comment](/help-center/account/two-factor-auth)
  </Step>
  
  <Step title="Sécurisez votre courriel">
    Votre courriel est la clé de votre compte. Utilisez également un mot de passe fort pour votre courriel.
  </Step>
  
  <Step title="Vérifiez l'activité de connexion">
    Vérifiez régulièrement votre historique de connexion dans les paramètres du compte
  </Step>
</Steps>
