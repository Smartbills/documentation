## Overview

Smartbills uses a role-based access control system. Each team member is assigned a role that determines what features and data they can access.

## Available Roles

| Role | Description |
|------|-------------|
| **Administrator** | Full access to all features, settings, and data |
| **Finance Admin** | Manage expenses, reports, billing, and accounting integrations |
| **Manager** | Approve expense reports and manage their direct reports' expenses |
| **Finance Team** | View and process business expenses and reports |
| **Member** | Standard access — submit expenses and reports |
| **Employee** | Basic access — submit personal expenses only |

## Permission Matrix

| Feature | Admin | Finance Admin | Manager | Finance Team | Member | Employee |
|---------|-------|---------------|---------|--------------|--------|----------|
| View own expenses | Yes | Yes | Yes | Yes | Yes | Yes |
| Submit expense reports | Yes | Yes | Yes | Yes | Yes | Yes |
| View all business expenses | Yes | Yes | No | Yes | No | No |
| Approve expense reports | Yes | Yes | Yes | No | No | No |
| Manage team members | Yes | No | No | No | No | No |
| Business settings | Yes | Yes | No | No | No | No |
| Billing & subscription | Yes | Yes | No | No | No | No |
| Manage integrations | Yes | Yes | No | No | No | No |
| Manage categories | Yes | Yes | No | No | No | No |
| Manage departments | Yes | Yes | No | No | No | No |
| View vendor details | Yes | Yes | Yes | Yes | No | No |
| Manage vendors | Yes | Yes | No | No | No | No |
| Vault access | Yes | Yes | No | Yes | No | No |

## Changing Roles

Only **Administrators** can change team member roles. See [Manage Users](/help-center/settings/manage-users) for instructions.

<Tip>
Assign the **Manager** role to team leads who need to approve their direct reports' expenses but don't need access to all business data.
</Tip>
