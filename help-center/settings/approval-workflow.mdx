## Overview

Approval workflows define who reviews and approves expense reports before reimbursement. You can create simple or multi-level approval chains.

## How Approvals Work

1. An employee submits an expense report
2. The report is routed to the designated approver(s) based on the workflow
3. Approvers review, approve, reject, or request changes
4. Once approved, the report moves to the reimbursement stage

## Setting Up Workflows

<Steps>
  <Step title="Open Settings">
    Go to **Settings** and look for workflow or approval settings.
  </Step>
  <Step title="Define Approval Rules">
    Configure who approves reports:
    - **Direct manager** — Reports go to the employee's assigned manager
    - **Department head** — Reports go to the department's designated approver
    - **Specific user** — Reports always go to a named approver
  </Step>
  <Step title="Set Thresholds">
    Optionally set amount-based rules:
    - Reports under $500: Manager approval only
    - Reports over $500: Manager + Finance Admin approval
  </Step>
  <Step title="Save">
    Save the workflow configuration. It applies to all new report submissions.
  </Step>
</Steps>

## Assigning Managers

For manager-based approval to work, each employee needs an assigned manager:

1. Go to **Employees**
2. Click on an employee
3. Set the **Manager** field to their direct report
4. Save

<Tip>
Start with a simple single-approver workflow and add complexity as your team grows.
</Tip>
