## Overview

Categories help organize expenses for reporting and accounting. Smartbills provides default categories and lets you create custom ones.

## Managing Categories

<Steps>
  <Step title="Open Settings">
    Go to **Settings** → **Categories**.
  </Step>
  <Step title="View Existing Categories">
    Browse the list of active categories. Default categories include Travel, Meals, Office Supplies, Software, and more.
  </Step>
</Steps>

## Creating a Category

<Steps>
  <Step title="Click Create">
    Click **Create Category**.
  </Step>
  <Step title="Enter Details">
    Provide:
    - **Name** — Descriptive label (e.g., "Client Entertainment")
    - **Code** — Optional accounting code for integration with your accounting software
  </Step>
  <Step title="Save">
    Click **Create**. The category is immediately available for assigning to expenses.
  </Step>
</Steps>

## Editing a Category

1. Click on a category in the list
2. Update the name or accounting code
3. Save changes — all expenses already assigned to this category will reflect the updated name

## Deleting a Category

1. Click the options menu (⋯) next to the category
2. Select **Delete**
3. Confirm — expenses assigned to this category will become uncategorized

<Warning>
Deleting a category cannot be undone. Consider renaming or deactivating instead if expenses are already assigned.
</Warning>

## Accounting Integration

When connected to QuickBooks or Xero, categories can be mapped to your chart of accounts:

- Categories sync as expense accounts
- The accounting code links the category to the correct account
- Exported expenses use the mapped accounts automatically

<Tip>
Keep your category list focused. Too many categories makes classification harder for employees. Aim for 10-20 well-defined categories.
</Tip>
