## Platform Support

<Tabs>
  <Tab title="Web Application">
    **System Requirements:**
    - Modern browser (Chrome, Firefox, Safari, Edge)
    - JavaScript enabled
    - Stable internet connection
    
    **Access:** [app.smartbills.io](https://app.smartbills.io)
    
    **Features:**
    - Full dashboard access
    - Advanced reporting
    - Bulk operations
    - Admin settings
  </Tab>
  
  <Tab title="iOS App">
    **Requirements:**
    - iOS 14.0 or later
    - iPhone, iPad, or iPod touch
    - Camera (for receipt scanning)
    
    **Download:** [App Store](https://apps.apple.com/app/smartbills)
    
    **Features:**
    - Quick receipt scanning
    - Offline mode
    - Push notifications
    - Touch ID / Face ID
  </Tab>
  
  <Tab title="Android App">
    **Requirements:**
    - Android 8.0 or later
    - Camera (for receipt scanning)
    - 50MB free storage
    
    **Download:** [Google Play](https://play.google.com/store/apps/details?id=io.smartbills.app)
    
    **Features:**
    - Smart receipt capture
    - Offline capability
    - Push notifications
    - Fingerprint authentication
  </Tab>
</Tabs>
