## Overview

Stay informed about expense approvals, report status changes, and team activity with push notifications.

## Enabling Notifications

<Steps>
  <Step title="Open Settings">
    Go to **Menu** → **Notifications** in the app.
  </Step>
  <Step title="Allow Permissions">
    When prompted, allow Smartbills to send push notifications. You can also enable this in your device settings.
  </Step>
  <Step title="Configure Preferences">
    Choose which notifications you want to receive:
    - **Expense reports** — Submitted, approved, rejected, changes requested
    - **Expenses** — Processing complete, flagged items
    - **Team activity** — New members, invitations
    - **Reimbursements** — Payment processed
  </Step>
</Steps>

## Notification Types

| Notification | When It's Sent |
|-------------|----------------|
| Report submitted | An employee submits a report for your approval |
| Report approved | Your submitted report was approved |
| Report rejected | Your report was rejected with feedback |
| Changes requested | An approver requests modifications |
| Expense processed | An uploaded receipt finished OCR processing |
| Reimbursement sent | A reimbursement payment was processed |
| Invitation received | You're invited to join a business |

## Disabling Notifications

To disable specific notification types:
1. Go to **Menu** → **Notifications**
2. Toggle off the categories you don't want
3. Changes apply immediately

To disable all notifications, revoke permission in your device's system settings.

<Tip>
Keep approval notifications enabled if you're a manager — delayed approvals slow down the entire reimbursement process.
</Tip>
