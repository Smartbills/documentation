## Installation

### JavaScript/TypeScript

```bash
npm install @smartbills/sdk
```

### React

```bash
npm install @smartbills/react-sdk @smartbills/sdk
```

### React Native

```bash
npm install @smartbills/react-native-sdk @smartbills/sdk
```

### .NET

```bash
dotnet add package Smartbills.NET
```

## Quick Start

All SDKs follow a similar pattern for initialization:

<CodeGroup>

```typescript JavaScript
import { SBClient } from '@smartbills/sdk';

const client = new SBClient({
  apiKey: 'YOUR_API_KEY',
  environment: 'production'
});

const expenses = await client.expenses.list({ page: 1, pageSize: 20 });
```

```csharp C#
using Smartbills.NET;

var client = new SmartbillsClient("YOUR_API_KEY");

var expenses = await client.Expenses.ListAsync(new ExpenseListRequest { 
    Page = 1, 
    PageSize = 20 
});
```

</CodeGroup>

## Authentication

All SDKs support multiple authentication methods:

| Method | Use Case |
|--------|----------|
| API Key | Server-side applications |
| OAuth 2.0 | User-facing applications |
| Session Token | Embedded applications |

## Features

### Common Features Across All SDKs

- **Type Safety** - Full TypeScript/C# type definitions
- **Error Handling** - Consistent error types and messages
- **Pagination** - Built-in pagination support
- **Retry Logic** - Automatic retry for transient failures
- **Rate Limiting** - Automatic rate limit handling

### SDK-Specific Features

| Feature | JS | React | React Native | .NET |
|---------|----|----|----|----|
| Expense Upload | Yes | Yes | Yes | Yes |
| Receipt Scanning | Yes | Yes | Yes | Yes |
| Offline Mode | - | - | Yes | - |
| Camera Integration | - | - | Yes | - |
| React Hooks | - | Yes | Yes | - |
| UI Components | - | Yes | Yes | - |
