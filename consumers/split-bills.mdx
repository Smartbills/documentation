## Bill Splitting

Smartbills makes it easy to split purchases with friends, roommates, or coworkers. No more awkward math or forgetting who owes what.

## How to Split a Bill

### From a Receipt

1. Open the receipt you want to split
2. Tap **Split Bill**
3. Choose splitting method
4. Add participants
5. Send requests

### Splitting Methods

#### Split Evenly

Divide the total equally:

```
Restaurant Bill: $120

Split 4 ways = $30 each

Sarah     $30  [Send Request]
Mike      $30  [Send Request]  
Lisa      $30  [Send Request]
You       $30  ✓ Your share
```

#### Split by Items

Assign specific items:

```
Restaurant Bill: $120

Your Items:
- Pasta      $18
- Soda       $3
Total: $21

Sarah's Items:
- Steak      $32
- Wine       $12
Total: $44

[Continue to Send]
```

#### Custom Amounts

Enter exact amounts:

```
Electric Bill: $150

You         $50
Roommate 1  $50
Roommate 2  $50

Total: $150 ✓
```

## Adding Participants

### From Contacts

1. Tap **Add Person**
2. Search contacts
3. Select Smartbills users
4. Or enter phone/email

### New to Smartbills

If they don't have Smartbills:

1. Enter their email or phone
2. They receive an invite
3. Can pay via link
4. Or download the app

## Sending Requests

### Request Preview

```
┌─────────────────────────────────────┐
│ Payment Request                     │
│                                     │
│ Restaurant Dinner                   │
│ January 15, 2025                    │
│                                     │
│ Your share: $35.50                  │
│                                     │
│ [Add Note]                          │
│                                     │
│ [Send Request]                      │
└─────────────────────────────────────┘
```

### Add a Note

Include context:

- "For Sarah's birthday dinner"
- "Your half of the electric bill"
- "Coffee run - your usual order"

## Tracking Payments

### Pending Requests

See what's outstanding:

```
Pending Payments

Sarah owes you    $35.50  ⏳ Sent Jan 15
Mike owes you     $28.00  ⏳ Sent Jan 15
You owe Lisa      $42.00  📩 Received Jan 14
```

### Payment Status

| Status | Meaning |
|--------|---------|
| ⏳ Pending | Waiting for payment |
| 👀 Viewed | They've seen it |
| ✅ Paid | Payment received |
| ❌ Declined | They declined |


### Payment Options

- Pay with linked card
- Pay with Apple Pay/Google Pay
- Mark as paid externally (cash/Venmo)

## Groups

### Create a Group

For recurring splits (roommates, couples):

1. Go to **Groups**
2. Tap **Create Group**
3. Name the group
4. Add members

### Group Features

- Automatic split suggestions
- Shared expense history
- Running balances
- Settle up anytime

### Running Balance

```
Apartment Group

Running Balance:

You owe Mike     -$23.50
Sarah owes you   +$45.00
Mike owes Sarah  -$12.00

[Settle Up]
```

## Reminders

### Automatic Reminders

Smartbills can remind people:

- After 3 days
- After 1 week
- Weekly until paid

### Manual Reminder

Tap **Send Reminder** on any pending request.

## Tips

<Tip>
**Split immediately** - Do it while everyone remembers what they ordered
</Tip>

<Tip>
**Create groups** - Makes recurring splits much easier
</Tip>

<Tip>
**Use item splits** - More accurate than even splits at restaurants
</Tip>

<Tip>
**Add context** - Notes help people remember what it's for
</Tip>

## Privacy

- Only split participants see the request
- Receipt details shared only with split members
- You control what information is visible
