## Smart Receipt Scanning

The Smartbills mobile app uses advanced AI to capture and process receipts quickly and accurately.

## Capturing Receipts

### Open Camera

1. Tap the **+** button
2. Select **Scan Receipt**
3. Position receipt in frame

### Auto-Capture

The camera automatically:

- Detects receipt edges
- Adjusts for lighting
- Captures when ready
- Optimizes image

### Manual Capture

If auto-capture doesn't work:

1. Position receipt
2. Tap shutter button
3. Adjust crop if needed
4. Confirm capture

## Data Extraction

After capture, AI extracts:

| Field | Accuracy |
|-------|----------|
| Merchant | 95%+ |
| Total | 98%+ |
| Date | 95%+ |
| Tax | 90%+ |
| Line Items | 85%+ |

### Review & Edit

1. Review extracted data
2. Tap any field to edit
3. Select category
4. Add description (optional)
5. Save expense

## Multi-Page Receipts

For long receipts:

1. Scan first page
2. Tap **Add Page**
3. Scan additional pages
4. All pages combined into one expense

## Batch Scanning

Scan multiple receipts quickly:

1. Tap **Batch Mode**
2. Scan receipts one after another
3. Review all at once
4. Save or edit each

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Can't focus | Clean camera lens |
| Poor extraction | Improve lighting |
| Wrong merchant | Edit manually |
| Missing total | Scan full receipt |
