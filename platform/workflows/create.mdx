## Creating a Workflow

Build custom automations to streamline your expense management.

## Step-by-Step Guide

### Step 1: Start New Workflow

1. Go to **Settings > Workflows**
2. Click **Create Workflow**
3. Enter a name for your workflow

### Step 2: Select Trigger

Choose what starts the workflow:

| Trigger | Use When |
|---------|----------|
| Expense Created | Process new expenses |
| Report Submitted | Handle submissions |
| Status Changed | React to updates |
| Schedule | Run at specific times |

### Step 3: Add Conditions

Filter when the workflow should run:

```
IF category = "Travel"
AND amount > 500
AND department = "Sales"
```

### Step 4: Define Actions

What happens when conditions are met:

- Send notifications
- Update fields
- Assign to approvers
- Create tasks

### Step 5: Test

1. Click **Test Workflow**
2. Select sample data
3. Verify actions would execute correctly
4. Review logs

### Step 6: Activate

1. Review all settings
2. Click **Activate**
3. Workflow starts running

## Condition Builder

### Available Operators

| Operator | Use For |
|----------|---------|
| equals | Exact match |
| contains | Partial match |
| greater than | Numeric comparison |
| in list | Multiple values |
| is empty | Null check |

### Combining Conditions

- **AND** - All conditions must be true
- **OR** - Any condition can be true
- **NOT** - Exclude matches

## Action Configuration

### Notification Actions

```yaml
action: send_email
to: manager@company.com
subject: "Large expense submitted"
body: "{{employee}} submitted ${{amount}}"
```

### Field Update Actions

```yaml
action: update_field
field: category
value: "Travel"
```
