## Available Triggers

Triggers are events that start workflow execution.

## Expense Triggers

### Expense Created

Fires when a new expense is uploaded or created.

**Use cases:**
- Auto-categorization
- Duplicate detection
- Policy checking

### Expense Updated

Fires when expense data changes.

**Use cases:**
- Audit logging
- Notification on changes

## Report Triggers

### Report Submitted

Fires when an expense report is submitted.

**Use cases:**
- Notify approvers
- Start approval workflow

### Report Approved

Fires when report receives approval.

**Use cases:**
- Notify finance
- Trigger reimbursement

### Report Rejected

Fires when report is rejected.

**Use cases:**
- Notify submitter
- Log rejection reason

## Scheduled Triggers

### Time-Based

Run at specific intervals:

| Schedule | Example |
|----------|---------|
| Daily | Every day at 9 AM |
| Weekly | Mondays at 8 AM |
| Monthly | 1st of month |

**Use cases:**
- Reminder emails
- Status reports
- Cleanup tasks

## Threshold Triggers

### Amount Threshold

Fires when amount exceeds limit.

**Use cases:**
- Additional approval required
- Manager notification

## Trigger Configuration

### Basic Setup

```yaml
trigger:
  type: expense_created
  filters:
    - field: amount
      operator: greater_than
      value: 100
```

### Multiple Conditions

```yaml
trigger:
  type: expense_created
  filters:
    - field: category
      operator: equals
      value: "Travel"
    - field: amount
      operator: greater_than
      value: 500
```
