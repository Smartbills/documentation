## Available Actions

Actions are what workflows do when triggered.

## Notification Actions

### Send Email

```yaml
action: send_email
config:
  to: ["manager@company.com"]
  subject: "Expense Alert"
  body: "New expense of ${{amount}}"
```

### Send Slack Message

```yaml
action: slack_message
config:
  channel: "#expenses"
  message: "{{employee}} submitted expense"
```

### Push Notification

```yaml
action: push_notification
config:
  to: "{{approver_id}}"
  title: "Approval needed"
  body: "Review expense report"
```

## Data Actions

### Update Field

```yaml
action: update_field
config:
  field: "status"
  value: "reviewed"
```

### Add Tag

```yaml
action: add_tag
config:
  tag: "high-value"
```

### Assign Approver

```yaml
action: assign_approver
config:
  approver: "{{manager_id}}"
```

## Workflow Actions

### Start Another Workflow

```yaml
action: start_workflow
config:
  workflow_id: "approval-flow"
```

### Wait

```yaml
action: wait
config:
  duration: "2 days"
```

## Integration Actions

### Create in External System

```yaml
action: create_external
config:
  system: "quickbooks"
  type: "expense"
```

### Webhook Call

```yaml
action: webhook
config:
  url: "https://api.example.com/hook"
  method: "POST"
  body:
    expense_id: "{{expense_id}}"
```

## Action Variables

Use dynamic values:

| Variable | Description |
|----------|-------------|
| `{{expense_id}}` | Expense ID |
| `{{amount}}` | Expense amount |
| `{{employee}}` | Employee name |
| `{{category}}` | Category name |
| `{{manager_id}}` | Manager user ID |
