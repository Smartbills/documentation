## Post-Purchase Engagement

Smartbills transforms receipts from transactional documents into powerful engagement tools. Every receipt is an opportunity to build relationships, gather feedback, and drive repeat business.

## The Engagement Opportunity

### Traditional Receipt

```
Paper receipt → Thrown away → Forgotten
```

### Smartbills Receipt

```
Digital receipt → Viewed → Engaged → Return visit
```

## Reviews & Feedback

### Receipt-Embedded Reviews

Customers can rate their experience directly on the receipt:

```
┌─────────────────────────────────────┐
│ How was your experience?            │
│                                     │
│ ⭐⭐⭐⭐⭐                           │
│                                     │
│ [Leave a Review]                    │
└─────────────────────────────────────┘
```

### Benefits

- **Higher response rates** - 40%+ vs 5% for email surveys
- **Immediate feedback** - Capture sentiment while fresh
- **Verified purchases** - Only real customers can review
- **Item-level ratings** - Know which products excel

### Review Types

| Type | Use Case |
|------|----------|
| Star Rating | Quick overall satisfaction |
| NPS | Measure likelihood to recommend |
| Item Reviews | Product-specific feedback |
| Open Text | Detailed comments |

## Personalized Marketing

### On-Receipt Promotions

Show relevant offers based on:

- What they just bought
- Purchase history
- Time since last visit
- Loyalty tier

### Example

Customer buys coffee → Receipt shows:

```
┌─────────────────────────────────────┐
│ 🥐 Complete your morning!           │
│                                     │
│ Add a pastry to your next order     │
│ and get 20% off                     │
│                                     │
│ [Save Offer]                        │
└─────────────────────────────────────┘
```

### Triggered Campaigns

| Trigger | Campaign |
|---------|----------|
| First purchase | Welcome + next visit discount |
| 30 days inactive | We miss you offer |
| Birthday month | Free birthday treat |
| Tier upgrade | Congratulations + perks |

## Social Features

### Bill Splitting

Split purchases with friends:

1. Customer opens receipt
2. Taps "Split Bill"
3. Selects items or amount
4. Sends request to friends
5. Friends pay their share

### Social Sharing

- Share receipts for expense reports
- Gift purchases with digital receipts
- Recommend products to friends

## Engagement Analytics

### Metrics to Track

| Metric | Description |
|--------|-------------|
| Open Rate | % of receipts viewed |
| Engagement Rate | % who interact with features |
| Review Rate | % who leave feedback |
| Offer Redemption | % who use promotions |
| Return Rate | % who visit again |

### Attribution

Track which engagement features drive:

- Return visits
- Increased basket size
- Customer lifetime value
- Referrals

## Best Practices

<Tip>
**Don't overwhelm** - Pick 1-2 engagement features per receipt.
</Tip>

<Tip>
**Personalize** - Use purchase history for relevance.
</Tip>

<Tip>
**Time it right** - Show rebooking reminders at appropriate intervals.
</Tip>

<Tip>
**A/B test** - Experiment with different offers and messaging.
</Tip>
