## User Management

Invite team members and configure their access levels.

## Inviting Users

### Send Invitation

1. Go to **Settings > Users**
2. Click **Invite User**
3. Enter email address
4. Select role
5. Assign department (optional)
6. Click **Send Invitation**

### Bulk Invite

1. Click **Bulk Invite**
2. Upload CSV with emails and roles
3. Review and confirm
4. Send invitations

## User Roles

| Role | Capabilities |
|------|-------------|
| **Admin** | Full access, manage settings |
| **Manager** | Approve reports, view team data |
| **Employee** | Submit expenses and reports |
| **Accountant** | Export, reports, integrations |
| **Viewer** | Read-only access |

## Role Permissions

### Admin

- All capabilities
- Manage users
- Configure settings
- Access all data

### Manager

- Submit own expenses
- Approve team reports
- View team analytics
- Manage team settings

### Employee

- Submit expenses
- Create reports
- View own data
- Request reimbursement

### Accountant

- View all expenses
- Export data
- Sync with accounting
- Generate reports

## Managing Users

### Edit User

1. Click on user in list
2. Update details:
   - Role
   - Department
   - Manager
3. Save changes

### Deactivate User

1. Click on user
2. Click **Deactivate**
3. Confirm

Deactivated users:

- Cannot log in
- Historical data preserved
- Can be reactivated

### Delete User

1. Click on user
2. Click **Delete**
3. Choose data handling
4. Confirm deletion

## User Groups

Create groups for easier management:

1. Go to **Settings > Groups**
2. Create group
3. Add users
4. Apply policies to group

## Best Practices

<Tip>
**Least privilege** - Give minimum required access.
</Tip>

<Tip>
**Review regularly** - Audit user access periodically.
</Tip>

<Tip>
**Offboard promptly** - Deactivate departing employees.
</Tip>
