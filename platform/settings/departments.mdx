## Department Configuration

Set up departments to organize users and track spending by organizational unit.

## Managing Departments

### View Departments

1. Go to **Settings > Departments**
2. See department hierarchy
3. View employee count per department

### Add Department

1. Click **Add Department**
2. Enter:
   - Name
   - Code
   - Parent (for hierarchy)
   - Manager
3. Save

### Edit Department

1. Click on department
2. Update details
3. Save

## Department Properties

| Property | Description |
|----------|-------------|
| Name | Department name |
| Code | Cost center code |
| Manager | Department head |
| Parent | Parent department |
| Budget | Monthly/annual budget |

## Department Hierarchy

Create organizational structure:

```
Company
├── Engineering
│   ├── Frontend
│   ├── Backend
│   └── QA
├── Sales
│   ├── Enterprise
│   └── SMB
└── Operations
```

## Assigning Users

### Single User

1. Go to **Settings > Users**
2. Select user
3. Set primary department
4. Save

### Bulk Assignment

1. Go to **Settings > Departments**
2. Select department
3. Click **Add Members**
4. Select users
5. Confirm

## Department Budgets

### Set Budget

1. Click on department
2. Enter budget amount
3. Select period (monthly/annual)
4. Save

### Track Spending

View budget vs actual in department details.
