## Category Configuration

Set up expense categories that match your accounting structure.

## Managing Categories

### View Categories

1. Go to **Settings > Categories**
2. See all categories in list
3. Click to expand hierarchy

### Add Category

1. Click **Add Category**
2. Enter details:
   - Name
   - Code
   - GL Account
   - Parent (optional)
3. Set options
4. Save

### Edit Category

1. Click on category
2. Modify settings
3. Save changes

### Deactivate Category

1. Click on category
2. Toggle **Active** off
3. Category hidden from selection

## Category Properties

| Property | Description |
|----------|-------------|
| Name | Display name |
| Code | Short identifier |
| GL Account | Accounting code |
| Tax Treatment | Tax rules |
| Receipt Required | Minimum for receipt |
| Spending Limit | Maximum amount |

## Import Categories

### From Accounting

1. Click **Import**
2. Select connected accounting software
3. Map fields
4. Import

### From CSV

1. Click **Import > CSV**
2. Upload file
3. Map columns
4. Import

## Auto-Categorization Rules

### Create Rule

1. Go to **Category Rules**
2. Click **Add Rule**
3. Define condition:
   - Merchant contains X
   - Amount in range
4. Select category
5. Save
