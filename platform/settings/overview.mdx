## Settings

Customize Smartbills to match your business needs.

## Account Settings

### Profile

- Personal information
- Contact details
- Password and security
- Notification preferences

### Payment Settings

- Reimbursement method
- Bank account details
- Payment preferences

## Business Settings

### General

- Business name and details
- Logo and branding
- Currency and timezone
- Language preferences

### Users & Teams

- Invite employees
- Manage roles and permissions
- Set up departments
- Configure teams

### Categories

- Create expense categories
- Map to GL accounts
- Set category rules
- Import from accounting

### Expense Policies

- Spending limits
- Receipt requirements
- Approval thresholds
- Blacklisted merchants

### Approval Workflows

- Define approval chains
- Set conditions
- Configure escalation
- Manage delegations

## Integration Settings

### Connected Apps

- View connected integrations
- Add new integrations
- Configure sync settings
- Manage permissions

### API & Webhooks

- API keys
- Webhook endpoints
- Rate limits
- Access logs
