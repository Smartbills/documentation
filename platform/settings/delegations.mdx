## Delegation Configuration

Allow employees to submit expenses on behalf of others.

## What is Delegation?

Delegation allows:

- Assistants to submit expenses for executives
- Team leads to manage team expenses
- Backup approvers during absence

## Setting Up Delegation

### As Delegator

1. Go to **Settings > Delegations**
2. Click **Add Delegate**
3. Select the person who can act on your behalf
4. Set permissions
5. Set date range (optional)
6. Save

### As Admin

1. Go to **Settings > Users**
2. Select user
3. Click **Delegations**
4. Add delegates for user

## Delegation Types

| Type | Description |
|------|-------------|
| **Expense Submission** | Submit expenses on behalf |
| **Approval** | Approve reports on behalf |
| **Full Access** | All expense actions |

## Temporary Delegation

For vacations or leave:

1. Add delegation
2. Set start date
3. Set end date
4. Delegation auto-activates/expires

## Permanent Delegation

For ongoing arrangements:

1. Add delegation
2. Leave dates blank
3. Active until manually removed

## Delegation Permissions

| Permission | Allows |
|------------|--------|
| View | See expenses |
| Create | Submit new expenses |
| Edit | Modify expenses |
| Approve | Approve reports |
| Delete | Remove expenses |

## Using Delegations

### Submit as Delegate

1. Click **Submit Expense**
2. Select "On behalf of"
3. Choose the delegator
4. Submit expense

### Approve as Delegate

1. Go to Approvals
2. See reports delegated to you
3. Review and approve

## Audit Trail

All delegated actions logged:

- Who performed action
- On whose behalf
- Timestamp
- Action details

## Best Practices
