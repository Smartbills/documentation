## What is an Expense?

An expense in Smartbills represents a business-related purchase or cost that needs to be tracked, categorized, and potentially reimbursed. Every expense contains key information about the transaction and supporting documentation.

## Expense Components

### Core Data

| Component | Description | Example |
|-----------|-------------|---------|
| **Amount** | The total cost | $45.99 |
| **Currency** | Transaction currency | USD, EUR, CAD |
| **Merchant** | Where purchased | Office Depot |
| **Date** | Transaction date | 2025-01-15 |
| **Category** | Classification | Office Supplies |

### Supporting Information

| Component | Description | Purpose |
|-----------|-------------|---------|
| **Receipt** | Proof of purchase | Audit trail, verification |
| **Description** | Additional context | Explain business purpose |
| **Project** | Cost allocation | Billing, reporting |
| **Department** | Organizational unit | Budget tracking |

## Expense Types

### By Payment Source

| Type | Description | Example |
|------|-------------|---------|
| **Out-of-Pocket** | Employee paid personally | Credit card purchase |
| **Corporate Card** | Company card used | Company Amex |
| **Petty Cash** | Cash from office fund | Office supplies |
| **Prepaid** | Pre-approved advance | Travel advance |

### By Category

Common expense categories:

- **Travel** - Transportation, lodging, per diem
- **Meals & Entertainment** - Client meetings, team events
- **Equipment** - Hardware, tools, supplies
- **Services** - Subscriptions, consulting
- **Communications** - Phone, internet

## Expense Lifecycle

```
┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐
│ Created  │ →   │ Reviewed │ →   │In Report │ →   │ Approved │ →   │Reimbursed│
└──────────┘     └──────────┘     └──────────┘     └──────────┘     └──────────┘
```

### State Transitions

| From | To | Trigger |
|------|----|---------|
| Created | Reviewed | User reviews OCR data |
| Reviewed | In Report | Added to expense report |
| In Report | Submitted | Report submitted |
| Submitted | Approved | All approvals received |
| Approved | Reimbursed | Payment processed |

## Expense Properties

### Reimbursability

- **Reimbursable** - Employee will be paid back
- **Non-reimbursable** - Business paid, no reimbursement
- **Partially reimbursable** - Split between personal/business

### Billability

- **Billable** - Can be billed to client
- **Non-billable** - Internal cost only
- **Project-specific** - Allocated to specific project

## Data Extraction

When you upload a receipt, AI extracts:

| Data Point | Extraction Method |
|------------|-------------------|
| Merchant | Logo recognition, header text |
| Amount | Total line detection |
| Date | Date pattern matching |
| Tax | Tax line identification |
| Line Items | Table/item parsing |

### Extraction Accuracy

Smartbills achieves high accuracy through:

- Multiple OCR engines
- AI-powered data parsing
- Pattern recognition
- Merchant database matching

## Expense Validation

### Required Fields

- Amount (> $0)
- Date (not future)
- Merchant name
- Category

### Policy Compliance

- Amount within limits
- Appropriate category
- Receipt attached (if required)
- Valid business purpose
