## What are Approval Workflows?

Approval workflows define the process that expense reports follow from submission to final approval. They ensure proper oversight, policy compliance, and financial controls.

## Workflow Components

### Approvers

| Role | Responsibility |
|------|----------------|
| **Manager** | Direct supervisor approval |
| **Department Head** | Department-level oversight |
| **Finance** | Financial compliance check |
| **Executive** | High-value approval |

### Conditions

Workflows can have conditions based on:

- Amount thresholds
- Expense categories
- Department
- Project
- Policy violations

## Workflow Types

### Sequential Workflow

Approvals happen in order:

```
Employee → Manager → Director → Finance
```

Each approver must complete before the next receives the report.

### Parallel Workflow

Multiple approvers simultaneously:

```
           ┌─→ Manager ─────┐
Employee ──┤                ├──→ Approved
           └─→ Finance ─────┘
```

Both must approve for completion.

### Conditional Workflow

Different paths based on criteria:

```
                    ┌─ Under $500 ─→ Manager ───────────────→ Approved
Employee ───────────┤
                    └─ Over $500 ──→ Manager → Director ───→ Approved
```

## Workflow Configuration

### Basic Setup

1. Go to **Settings > Workflows**
2. Click **Create Workflow**
3. Define trigger conditions
4. Add approval stages
5. Configure each stage
6. Activate workflow

### Stage Configuration

| Setting | Options |
|---------|---------|
| Approver Type | Specific person, Role, Manager of |
| Required Action | Approve, Review, Acknowledge |
| Time Limit | Auto-escalate after X days |
| Conditions | Amount, category, etc. |

## Workflow Examples

### Small Business

Simple manager approval:

```yaml
name: Standard Approval
trigger: All expense reports
stages:
  - name: Manager Approval
    approver: Submitter's manager
    action: Approve
```

### Enterprise

Multi-level with conditions:

```yaml
name: Enterprise Approval
trigger: All expense reports
stages:
  - name: Manager
    approver: Submitter's manager
    action: Approve
    
  - name: Department Head
    approver: Department director
    condition: amount > $1000
    action: Approve
    
  - name: Finance Review
    approver: Finance team
    condition: amount > $5000
    action: Approve
    
  - name: Executive
    approver: CFO
    condition: amount > $10000
    action: Approve
```

## Approval Actions

### For Approvers

| Action | Effect |
|--------|--------|
| **Approve** | Advance to next stage |
| **Reject** | Return to submitter, closed |
| **Request Changes** | Return for modifications |
| **Delegate** | Forward to another approver |

### Automatic Actions

| Trigger | Action |
|---------|--------|
| Time limit reached | Escalate to backup |
| Policy compliant | Auto-approve |
| Small amount | Skip levels |

## Delegation

### Types of Delegation

- **Temporary** - During vacation/leave
- **Permanent** - Role change
- **Conditional** - For specific criteria

### Setting Up Delegation

1. Go to **Settings > Delegations**
2. Click **Add Delegation**
3. Select delegate
4. Set date range
5. Choose scope
6. Save

## Escalation

### Automatic Escalation

When approvals stall:

```
Day 1-3: Original approver
Day 4-5: Reminder sent
Day 6-7: Escalate to backup
Day 8+:  Escalate to manager
```

### Manual Escalation

Submitters can request escalation:

1. Open submitted report
2. Click **Request Escalation**
3. Provide reason
4. System notifies appropriate parties

## Policy Integration

### Automatic Checks

Before reaching approvers:

- Receipt verification
- Amount limits
- Category restrictions
- Duplicate detection
- Date validation

### Policy Flags

Approvers see flagged items:

- 🔴 Violation - Requires override
- 🟡 Warning - Review recommended
- 🟢 Compliant - Meets all policies
