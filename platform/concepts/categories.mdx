## What are Categories?

Categories are classifications that organize expenses by type, making it easier to track spending, generate reports, and map to accounting systems.

## Default Categories

Smartbills includes standard business expense categories:

| Category | Description | GL Code |
|----------|-------------|---------|
| Travel - Airfare | Flight tickets | 6200 |
| Travel - Lodging | Hotels, accommodation | 6210 |
| Travel - Ground | Taxis, rideshare, rental | 6220 |
| Meals & Entertainment | Business meals, events | 6400 |
| Office Supplies | Stationery, equipment | 6100 |
| Software | Subscriptions, licenses | 6300 |
| Telecommunications | Phone, internet | 6150 |
| Professional Services | Consulting, legal | 6500 |

## Category Hierarchy

Organize categories in a tree structure:

```
Travel
├── Airfare
├── Lodging
│   ├── Hotels
│   └── Short-term Rentals
├── Ground Transportation
│   ├── Rental Car
│   ├── Taxi/Rideshare
│   └── Parking
└── Per Diem
```

## Creating Categories

### Add New Category

1. Go to **Settings > Categories**
2. Click **Add Category**
3. Fill in details:
   - Name
   - GL Account Code
   - Parent (optional)
   - Description
4. Set policy options
5. Click **Save**

### Import Categories

From accounting software:

1. Go to **Settings > Categories**
2. Click **Import**
3. Select source (QuickBooks, Xero, etc.)
4. Map fields
5. Import

### Bulk Edit

1. Go to **Settings > Categories**
2. Click **Export**
3. Edit in spreadsheet
4. Click **Import**
5. Review changes
6. Confirm

## Category Rules

### Auto-Categorization

Set rules for automatic assignment:

```yaml
rules:
  - merchant_contains: "Uber"
    category: "Travel - Ground Transportation"
    
  - merchant_contains: "Hilton"
    category: "Travel - Lodging"
    
  - merchant_contains: "Office Depot"
    category: "Office Supplies"
```

### Rule Priority

When multiple rules match:

1. Most specific match wins
2. Most recent rule takes precedence
3. User selection overrides all

| Travel | Fully deductible |

## Accounting Integration

### GL Code Mapping

Map categories to your chart of accounts:

| Category | GL Account | Description |
|----------|------------|-------------|
| Travel - Airfare | 6200-100 | Travel - Air |
| Travel - Lodging | 6200-200 | Travel - Hotel |
| Meals | 6400-100 | Meals & Ent |

### Sync with Accounting

When connected to accounting software:

1. Categories sync automatically
2. New GL accounts appear
3. Changes propagate both ways

## Reporting by Category

### Spending Analysis

View expenses by category:

1. Go to **Reports > Spending**
2. Select date range
3. View category breakdown
4. Drill down for details

### Budget Comparison

| Category | Budget | Actual | Variance |
|----------|--------|--------|----------|
| Travel | $10,000 | $8,500 | -$1,500 |
| Meals | $2,000 | $2,300 | +$300 |
| Software | $5,000 | $4,800 | -$200 |
