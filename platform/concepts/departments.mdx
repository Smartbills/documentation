## What are Departments?

Departments in Smartbills represent organizational units within your business. They enable expense allocation, budget tracking, and approval routing based on organizational structure.

## Department Structure

### Hierarchy

```
Company
├── Engineering
│   ├── Frontend
│   ├── Backend
│   └── DevOps
├── Sales
│   ├── North America
│   └── Europe
├── Marketing
└── Finance
```

## Department Properties

| Property | Description |
|----------|-------------|
| Name | Department name |
| Code | Short identifier |
| Parent | Parent department |
| Manager | Department head |
| Cost Center | Accounting code |
| Budget | Monthly/annual budget |

## Creating Departments

### Add Department

1. Go to **Settings > Departments**
2. Click **Add Department**
3. Enter details:
   - Name
   - Code
   - Manager
   - Parent (optional)
4. Set budget (optional)
5. Click **Save**

### Import Structure

From HR system or CSV:

1. Go to **Settings > Departments**
2. Click **Import**
3. Upload file or connect HR system
4. Map fields
5. Import

## Employee Assignment

### Assign Employees

1. Go to **Settings > Employees**
2. Select employee
3. Set primary department
4. Optionally add secondary departments

### Multiple Departments

Employees can belong to multiple:

- Primary department (default for expenses)
- Secondary departments (for allocation)

## Expense Allocation

### Default Assignment

Expenses automatically assigned to employee's primary department.

### Manual Override

1. Open expense
2. Change department field
3. Provide reason (if required)

### Split by Department

For shared expenses:

```
Office Party: $500
├── Engineering: $200 (40%)
├── Sales: $150 (30%)
└── Marketing: $150 (30%)
```

## Department Budgets

### Setting Budgets

| Department | Annual Budget | Monthly |
|------------|---------------|---------|
| Engineering | $120,000 | $10,000 |
| Sales | $200,000 | $16,667 |
| Marketing | $80,000 | $6,667 |

### Budget Tracking

- View real-time spending vs budget
- Alerts at thresholds (80%, 100%)
- Year-to-date projections

## Approval Routing

Expenses routed by department:

```
Engineering expense → Engineering Manager → CTO
Sales expense → Sales Manager → VP Sales
```

## Reporting

### Department Spending

View expenses by department:

1. Go to **Reports > Department Spending**
2. Select date range
3. Compare departments
4. Drill into details

### Budget vs Actual

| Department | Budget | Actual | Remaining |
|------------|--------|--------|-----------|
| Engineering | $10,000 | $8,500 | $1,500 |
| Sales | $16,667 | $18,200 | -$1,533 |
