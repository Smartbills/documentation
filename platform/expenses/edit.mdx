## Editing Expenses

You can edit expenses at any time before they are approved. This guide covers how to modify expense details, update receipts, and manage expense information.

## When Can You Edit?

| Expense Status | Editable | Notes |
|----------------|----------|-------|
| Draft | Yes | Full editing capabilities |
| Pending | Yes | Full editing capabilities |
| In Report (Draft) | Yes | Can edit if report not submitted |
| Submitted | Limited | Can recall report to edit |
| Approved | No | Must request revision |
| Rejected | Yes | Edit and resubmit |
| Reimbursed | No | Contact admin for changes |

## How to Edit an Expense

### From the Dashboard

1. Go to **Expenses** in the main navigation
2. Find the expense you want to edit
3. Click on the expense to open details
4. Click the **Edit** button
5. Make your changes
6. Click **Save**

### Quick Edit

For common changes, use quick edit directly from the list:

1. Hover over an expense in the list
2. Click the pencil icon for quick actions
3. Update category, amount, or date inline
4. Press Enter to save

## Editable Fields

| Field | Description |
|-------|-------------|

### Categorization

| Field | Description |
|-------|-------------|

### Payment Details

| Field | Description |
|-------|-------------|
| Payment Method | Cash, card, etc. |
| Reimbursable | Whether employee should be reimbursed |

## Updating Receipts

### Replace Receipt

1. Open the expense details
2. Click **Edit**
3. Click **Replace Receipt** in the receipt section
4. Upload a new receipt image
5. Click **Save**

### Add Additional Receipts

Some expenses may have multiple receipts:

1. Open the expense details
2. Click **Add Attachment**
3. Upload additional documentation
4. Click **Save**

### Remove Receipt

1. Open the expense details
2. Click **Edit**
3. Hover over the receipt thumbnail
4. Click the **X** to remove
5. Add justification if required
6. Click **Save**

## Split Expenses

Split a single receipt into multiple expense entries:

### When to Split

- Meal with both personal and business items
- Receipt covering multiple projects
- Mixed category purchases

### How to Split

1. Open the expense details
2. Click **Split Expense**
3. Enter the number of splits or add line items
4. Allocate amounts to each split
5. Assign categories to each portion
6. Click **Save Split**

Example split:

| Description | Amount | Category |
|-------------|--------|----------|
| Team lunch | $50.00 | Meals & Entertainment |
| Personal items | $15.00 | Personal (non-reimbursable) |

## Merge Expenses

Combine duplicate or related expenses:

1. Select multiple expenses using checkboxes
2. Click **Merge** from the bulk actions menu
3. Choose which expense to keep as primary
4. Review the merged details
5. Click **Confirm Merge**

<Warning>
Merged expenses cannot be unmerged. Receipts from all merged expenses will be attached to the primary expense.
</Warning>

## Change History

View all changes made to an expense:

1. Open the expense details
2. Click the **History** tab
3. View a timeline of all modifications
4. See who made each change and when

## Batch Editing

Edit multiple expenses at once:

### Batch Categorize

1. Select expenses using checkboxes
2. Click **Batch Actions > Categorize**
3. Choose the category
4. Click **Apply**

### Batch Add to Report

1. Select expenses using checkboxes
2. Click **Batch Actions > Add to Report**
3. Select an existing report or create new
4. Click **Add**

### Batch Delete

1. Select expenses using checkboxes
2. Click **Batch Actions > Delete**
3. Confirm deletion

<Warning>
Deleted expenses cannot be recovered. Make sure you want to permanently remove them.
</Warning>

## Validation Rules

Expenses must meet these requirements:

<Check>Amount must be greater than zero</Check>
<Check>Date must not be in the future</Check>
<Check>Category must be selected</Check>
<Check>Merchant name is required</Check>

### Policy Violations

Your company may have additional rules:

- Maximum amount limits per category
- Required descriptions for certain categories
- Mandatory receipt attachment
- Approval required above threshold

If an expense violates policy:

1. A warning banner will appear
2. Review the policy requirement
3. Add justification if needed
4. Or correct the expense to comply

## Best Practices

<Tip>
**Edit promptly** - Make corrections as soon as you notice errors.
</Tip>

<Tip>
**Add context** - Use the description field to explain unusual expenses.
</Tip>

<Tip>
**Keep receipts** - Even if you replace a receipt, the original is archived.
</Tip>

<Tip>
**Review before submitting** - Double-check all expenses before adding to a report.
</Tip>
