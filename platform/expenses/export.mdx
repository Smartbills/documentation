## Export Options

Smartbills provides multiple ways to export your expense data for accounting, reporting, and compliance purposes.

## Export Formats

| Format | Best For | Includes Receipts |
|--------|----------|-------------------|
| **CSV** | Spreadsheet analysis, accounting import | No |
| **Excel (XLSX)** | Formatted reports, pivot tables | No |
| **PDF** | Audit documentation, expense reports | Yes (embedded) |
| **ZIP** | Bulk receipt download | Yes (separate files) |
| **JSON** | API integrations, data processing | No |

## How to Export

### Export from Expenses List

1. Go to **Expenses** in the main navigation
2. Apply filters to select the expenses you want
3. Click the **Export** button
4. Choose your format
5. Click **Download**

### Export Selected Expenses

1. Select specific expenses using checkboxes
2. Click **Bulk Actions > Export**
3. Choose your format
4. Click **Download**

### Export from Reports

1. Go to **Reports**
2. Open the desired report
3. Click **Export** in the report toolbar
4. Select format and options
5. Click **Download**

### Custom Columns

Select which columns to include:

1. Click **Export** > **CSV**
2. Click **Customize Columns**
3. Check/uncheck desired fields
4. Drag to reorder columns
5. Save as template (optional)
6. Click **Export**

## PDF Export

### Expense Detail PDF

Generates a detailed document for each expense:

- Expense metadata
- Receipt image(s)
- Approval history
- Notes and comments

### Expense Summary PDF

Tabular summary of multiple expenses:

- Grouped by category, project, or date
- Subtotals and grand total
- Charts and visualizations

### Options

| Option | Description |
|--------|-------------|
| Include receipts | Embed receipt images |
| Include history | Show approval timeline |
| Group by | Category, date, project, employee |
| Sort by | Date, amount, merchant |
| Page size | Letter, A4, Legal |

## Bulk Receipt Download

Download all receipt images and documents:

### As ZIP Archive

1. Select expenses to export
2. Click **Export > Download Receipts**
3. Choose file naming convention:
   - By expense ID: `expense_12345.jpg`
   - By date and merchant: `2025-01-15_OfficeDepot.jpg`
   - By report: `Q1-Report/expense_12345.jpg`
4. Click **Download ZIP**

### File Organization

```
receipts_export_2025-01-29/
├── Office_Supplies/
│   ├── 2025-01-15_OfficeDepot_12345.jpg
│   └── 2025-01-20_Staples_12348.jpg
├── Travel/
│   ├── 2025-01-16_Uber_12346.jpg
│   └── 2025-01-17_Hilton_12347.pdf
└── manifest.csv
```

## Scheduled Exports

Set up automatic exports:

### Create a Schedule

1. Go to **Settings > Integrations > Exports**
2. Click **Add Scheduled Export**
3. Configure:
   - Frequency: Daily, Weekly, Monthly
   - Filter criteria
   - Export format
   - Delivery method (email, SFTP, cloud storage)
4. Click **Save**

### Delivery Options

| Method | Setup |
|--------|-------|
| Email | Enter recipient addresses |
| SFTP | Configure server credentials |
| S3 | Provide bucket and credentials |
| Google Drive | Connect account |
| Dropbox | Connect account |

## API Export

Export data programmatically:

```bash
curl -X GET "https://api.smartbills.io/v1/expenses/export" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "format": "csv",
    "from_date": "2025-01-01",
    "to_date": "2025-01-31",
    "include_receipts": false
  }'
```

See [API Reference](/api-reference/expenses/export-expenses) for details.

## Data Compliance

### Audit Trail

Exports include audit information:

- Export timestamp
- User who performed export
- Filters applied
- Number of records

### Data Retention

- Exports are available for download for 7 days
- After 7 days, regenerate the export
- Historical exports logged for compliance
