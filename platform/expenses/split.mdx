## What is Expense Splitting?

Expense splitting allows you to divide a single receipt or transaction into multiple expense entries. This is useful when a single purchase contains items that should be categorized or allocated differently.

## When to Split Expenses

### Common Scenarios

| Scenario | Example |
|----------|---------|
| **Mixed categories** | Office supplies and snacks on same receipt |
| **Multiple projects** | Software subscription used by two projects |
| **Personal/Business split** | Meal with partial personal items |
| **Department allocation** | Shared equipment purchase |
| **Client billing** | Some items billable, others not |

## How to Split an Expense

### Basic Split

1. Open the expense you want to split
2. Click the **Split** button in the toolbar
3. Choose the split type:
   - **By Amount** - Manually enter amounts
   - **By Percentage** - Split by percentage
   - **By Line Item** - If line items are available
4. Enter split details
5. Click **Apply Split**

### Split by Amount

<Steps>
  <Step title="Enter first split">
    Amount: $50.00
    Category: Office Supplies
  </Step>
  <Step title="Enter second split">
    Amount: $25.00
    Category: Meals & Entertainment
  </Step>
  <Step title="Verify total">
    Ensure splits equal original amount ($75.00)
  </Step>
  <Step title="Save">
    Click Apply Split to create separate expenses
  </Step>
</Steps>

### Split by Percentage

Useful for recurring allocations:

| Split | Percentage | Amount |
|-------|------------|--------|
| Project A | 60% | $60.00 |
| Project B | 40% | $40.00 |
| **Total** | 100% | **$100.00** |

### Split by Line Item

When OCR extracts line items, you can split by selecting items:

1. Review extracted line items
2. Check items for the first split
3. Assign category/project
4. Check items for second split
5. Assign different category/project
6. Click **Apply Split**

## Split Options

### Category Split

Assign different categories to each portion:

```
Original Expense: $75.00 - Costco

Split 1: $50.00 - Office Supplies
Split 2: $25.00 - Kitchen Supplies
```

### Project Split

Allocate costs to different projects:

```
Original Expense: $100.00 - AWS Services

Split 1: $60.00 - Project Alpha
Split 2: $40.00 - Project Beta
```

### Department Split

Charge different cost centers:

```
Original Expense: $500.00 - Team Training

Split 1: $250.00 - Engineering Department
Split 2: $150.00 - Product Department
Split 3: $100.00 - Design Department
```

### Reimbursement Split

Mark portions as personal/non-reimbursable:

```
Original Expense: $45.00 - Lunch Meeting

Split 1: $30.00 - Reimbursable (Business)
Split 2: $15.00 - Non-reimbursable (Personal)
```

## Split Rules

### Amount Requirements

<Check>Splits must equal the original expense amount</Check>
<Check>Each split must be greater than $0.00</Check>
<Check>Minimum of 2 splits required</Check>

### Receipt Handling

- Original receipt is attached to all splits
- Each split can have additional attachments
- Split reference ID links related expenses

## Managing Split Expenses

### Identifying Splits

Split expenses are marked with a split icon and include:

- Split group ID
- Reference to original expense
- "Part X of Y" indicator

### Editing Splits

To modify an existing split:

1. Find any expense in the split group
2. Click **View Split**
3. Modify amounts or allocations
4. Click **Update Split**

<Warning>
Modifying one split may require adjusting others to maintain balance.
</Warning>

### Undoing a Split

To merge splits back together:

1. Select all expenses in the split group
2. Click **Unsplit** or **Merge**
3. Choose which expense to keep as primary
4. Click **Confirm**

## Split Templates

Save common split patterns for reuse:

### Create a Template

1. Go to **Settings > Split Templates**
2. Click **Add Template**
3. Define the split pattern:
   - Name: "AWS Cost Allocation"
   - Split 1: 60% - Engineering
   - Split 2: 40% - Operations
4. Click **Save**

### Apply a Template

1. Open an expense
2. Click **Split**
3. Select **Apply Template**
4. Choose your saved template
5. Adjust amounts if needed
6. Click **Apply**

## Reporting with Splits

### Spending Reports

Split expenses appear correctly in reports:

- **By Category**: Each split counted in its category
- **By Project**: Each split allocated to its project
- **By Employee**: Total original amount attributed

### Export Handling

When exporting:

| Format | Split Handling |
|--------|----------------|
| CSV | Each split as separate row |
| PDF | Grouped by original expense |
| Accounting Sync | Each split as separate entry |

## Best Practices

<Tip>
**Split at time of upload** - Easier to remember allocations when fresh.
</Tip>

<Tip>
**Use templates** - Create templates for recurring split patterns.
</Tip>

<Tip>
**Document splits** - Add notes explaining the split rationale.
</Tip>

<Tip>
**Review before submission** - Verify split allocations are correct.
</Tip>
