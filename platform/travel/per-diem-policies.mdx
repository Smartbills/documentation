## Overview

Per diem policies define the maximum daily allowance an employee can claim while traveling. Smartbills supports both flat-rate and GSA-based per diem configurations.

## Creating a policy

Navigate to **Travel > Policies** and click **Create Policy**.

### Policy settings

- **Name** — A descriptive name (e.g., "Standard Domestic Travel").
- **Default** — Mark as the default policy applied to new trips.

### Per diem rules

Each policy contains one or more per diem rules:

| Field | Description |
|---|---|
| **Default daily rate** | The flat daily allowance amount |
| **Allowance type** | `FLAT_RATE` or `GSA_RATE` |
| **GSA rate adjustment** | For GSA-based rates: `FULL`, `SEVENTY_FIVE_PERCENT`, or `FIFTY_PERCENT` |
| **Tracking categories** | Expense categories that count toward per diem (meals, incidentals, etc.) |

### GSA rates

When using GSA-based per diem, the daily rate is determined by the trip destination using U.S. General Services Administration rates. You can apply an adjustment factor to scale the rate.

## SDK usage

<CodeGroup>

```typescript JavaScript
const policies = await client.travelPolicies.list(businessId);

const policy = await client.travelPolicies.create(businessId, {
  name: "Standard Domestic",
  isDefault: true,
});
```

```csharp .NET
var policies = await travelPolicyClient.ListAsync(businessId, options);

var policy = await travelPolicyClient.CreateAsync(new TravelPolicyCreateRequest
{
    Name = "Standard Domestic",
    IsDefault = true
}, options);
```
