## Creating a trip

Navigate to **Travel** in the sidebar and click **New Trip**. Fill in:

- **Name** — A descriptive label (e.g., "Q1 Client Visit — Toronto").
- **Destination** — The primary destination city or region.
- **Traveler** — The employee taking the trip.
- **Dates** — Start and end dates for the journey.
- **Currency** — The currency for tracking trip expenses.

## Trip statuses

| Status | Description |
|---|---|
| `PLANNED` | Trip is scheduled but hasn't started |
| `ACTIVE` | Trip is currently in progress |
| `COMPLETED` | Trip has ended |

## Associating expenses

From a trip's detail page, use **Add Expense** to link existing wallet expenses. This groups all trip-related spending under one view and calculates the total trip cost automatically.

You can also associate expenses from the expense detail page by selecting the trip from the trip picker.

## Per diem summary

Each trip detail page shows a per diem summary that compares the traveler's actual spending against the applicable per diem policy. This helps identify over- or under-spending relative to the daily allowance.
