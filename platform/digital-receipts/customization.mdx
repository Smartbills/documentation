## Customize Your Receipts

Make your digital receipts an extension of your brand with custom logos, colors, messages, and interactive features.

## Branding Options

### Logo & Identity

| Element | Specifications |
|---------|---------------|
| Logo | PNG/SVG, 400x100px recommended |
| Icon | Square, 256x256px |
| Colors | Primary and secondary hex codes |
| Font | Select from available options |

## Custom Messages

### Header Messages

Add messages at the top of receipts:

- Thank you message
- Seasonal greeting
- Promotional announcement

### Footer Messages

Include at the bottom:

- Return policy
- Contact information
- Social media links
- Upcoming events

### Dynamic Content

Insert personalized content:

| Variable | Example |
|----------|---------|
| `{{customer_name}}` | "Thanks, Sarah!" |
| `{{loyalty_points}}` | "You earned 50 points" |
| `{{next_reward}}` | "10 more points for free coffee" |
| `{{visit_count}}` | "Your 5th visit this month!" |

## Interactive Elements

Add buttons for:

- Leave a review
- Join loyalty program
- Book next appointment
- Follow on social media
- Refer a friend

### Survey Questions

Embed quick surveys:

- Star rating
- NPS question
- Yes/No feedback
- Multiple choice

## Setup

### In Dashboard

1. Go to **Settings > Receipt Customization**
2. Upload your logo
3. Set brand colors
4. Configure messages
5. Enable features
6. Preview and save

### Via API

```json
{
  "branding": {
    "logo_url": "https://...",
    "primary_color": "#6366F1",
    "secondary_color": "#8B5CF6"
  },
  "messages": {
    "header": "Thank you for shopping!",
    "footer": "Returns accepted within 30 days"
  },
  "features": {
    "reviews": true,
    "loyalty": true,
    "recommendations": true
  }
}
```

</Tip>

<Tip>

<Tip>
