## Setup

### Configure Program

1. Go to **Settings > Loyalty**
2. Choose program type
3. Set earning rules
4. Define rewards
5. Customize messaging
6. Launch program

### Earning Rules

```json
{
  "type": "points",
  "earn_rate": 1,
  "earn_unit": "dollar",
  "bonus_rules": [
    {
      "condition": "category = 'premium'",
      "multiplier": 2
    },
    {
      "condition": "day_of_week = 'tuesday'",
      "multiplier": 2
    }
  ]
}
```

### Rewards Configuration

```json
{
  "rewards": [
    {
      "name": "$5 Off",
      "points_required": 500,
      "type": "discount",
      "value": 5
    },
    {
      "name": "Free Drink",
      "points_required": 100,
      "type": "free_item",
      "eligible_items": ["coffee", "tea"]
    }
  ]
}
```
