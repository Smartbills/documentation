## Uploading Bills

Add vendor invoices to Smartbills for processing and payment.

## Supported Formats

| Format | Extensions | Max Size |
|--------|------------|----------|
| PDF | .pdf | 25 MB |
| Images | .jpg, .png | 10 MB |
| Email | .eml | 10 MB |

## Upload Methods

### Drag and Drop

1. Go to **Bills**
2. Drag invoice file onto the page
3. Wait for processing
4. Review extracted data

### File Upload

1. Click **Add Bill**
2. Click **Browse** or upload area
3. Select invoice file
4. Process and review

### Email Forwarding

1. Forward invoices to your AP email address
2. Smartbills processes automatically
3. Bills appear in your inbox

### Bulk Upload

Upload multiple invoices at once:

1. Click **Add Bill > Bulk Upload**
2. Select multiple files
3. Each creates a separate bill
4. Review in queue

## Data Extraction

AI extracts:

| Field | Extraction |
|-------|------------|
| Vendor name | From header/logo |
| Invoice number | Detected from label |
| Amount due | Total identified |
| Due date | Date parsing |
| Line items | Table extraction |

## Review Process

After upload:

1. Review extracted data
2. Correct any errors
3. Assign category/GL code
4. Select vendor or create new
5. Save bill

## Best Practices

<Tip>
**Clear scans** - Ensure invoices are legible.
</Tip>

<Tip>
**Complete invoices** - Include all pages.
</Tip>

<Tip>
