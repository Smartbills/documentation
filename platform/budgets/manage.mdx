## Creating a budget

Navigate to **Budgets** in the sidebar and click **Create Budget**.

### Required fields

- **Name** — A descriptive label (e.g., "Q2 Marketing Budget").
- **Total budget** — The total amount allocated.
- **Currency** — The budget currency.
- **Start date / End date** — The budget period.

## Budget statuses

| Status | Description |
|---|---|
| `ACTIVE` | Budget is within its date range and accepting expenses |
| `DRAFT` | Budget is being prepared but not yet active |
| `CLOSED` | Budget period has ended |
| `OVER_BUDGET` | Spending has exceeded the total budget |

## Categories

Break down a budget into categories to track spending more granularly. Each category has its own allocated amount and tracks actual spending independently.

From the budget detail page, click **Add Category** and specify:
- **Name** — Category label.
- **Allocated amount** — The portion of the total budget assigned to this category.

## Utilization metrics

Each budget displays:
- **Actuals** — Total confirmed spending.
- **Committed** — Approved but not yet finalized amounts.
- **Remaining** — Budget minus actuals and committed.
- **Utilization %** — Percentage of budget consumed.

A progress bar visualizes utilization, turning amber at 75% and red at 100%.

## SDK usage

<CodeGroup>

```typescript JavaScript
const budgets = await client.budgets.list(businessId, { status: "ACTIVE" });

const budget = await client.budgets.create(businessId, {
  name: "Q2 Marketing",
  totalBudget: 50000,
  currency: "CAD",
  startDate: "2026-04-01",
  endDate: "2026-06-30",
});

await client.budgets.createCategory(businessId, budget.id, {
  name: "Advertising",
  allocatedAmount: 20000,
});
```
