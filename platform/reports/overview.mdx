## What are Expense Reports?

Expense reports are collections of individual expenses bundled together for submission, approval, and reimbursement. They provide a formal way to request reimbursement for business expenses.

## Report Lifecycle

<Steps>
  <Step title="Create">
    Start a new expense report and give it a title.
  </Step>
  <Step title="Add Expenses">
    Add your expenses to the report from your expense list.
  </Step>
  <Step title="Review">
    Verify all expenses are correct and complete.
  </Step>
  <Step title="Submit">
    Submit the report for approval.
  </Step>
  <Step title="Approval">
    Approvers review and approve or reject the report.
  </Step>
  <Step title="Reimbursement">
    Approved expenses are processed for payment.
  </Step>
</Steps>

## Report Status

| Status | Description |
|--------|-------------|
| **Draft** | Report created but not submitted |
| **Submitted** | Awaiting approval |
| **In Review** | Currently being reviewed by approver |
| **Approved** | All approvals complete |
| **Rejected** | Rejected by an approver |
| **Changes Requested** | Returned for modifications |
| **Processing** | Being processed for reimbursement |
| **Reimbursed** | Payment completed |

## Creating a Report

### Quick Create

1. Go to **Expense Reports**
2. Click **New Report**
3. Enter a report title (e.g., "January 2025 Expenses")
4. Optionally select a date range
5. Click **Create**

### From Selected Expenses

1. Go to **Expenses**
2. Select the expenses to include
3. Click **Add to Report > New Report**
4. Enter report details
5. Click **Create Report**

## Report Contents

### Required Information

| Field | Description |
|-------|-------------|
| Title | Descriptive name for the report |
| Expenses | At least one expense |
| Submission Date | When the report is submitted |

### Optional Information

| Field | Description |
|-------|-------------|
| Description | Additional context |
| Period | Date range covered |
| Project | Associated project |
| Department | Submitting department |
| Notes | Comments for approver |

## Managing Expenses in Reports

### Add Expenses

1. Open the expense report
2. Click **Add Expenses**
3. Select from available expenses
4. Click **Add Selected**

### Remove Expenses

1. Open the expense report
2. Find the expense to remove
3. Click the remove icon (X)
4. Confirm removal

<Note>
Removed expenses return to your unassigned expenses list.
</Note>

### Edit Expenses

While in a draft report, you can still edit expenses:

1. Click on an expense in the report
2. Make your changes
3. Click **Save**

## Report Summary

Each report shows a summary including:

- **Total Amount** - Sum of all expenses
- **By Category** - Breakdown by expense category
- **By Date** - Timeline of expenses
- **Receipt Status** - Which expenses have receipts

## Expense Report Views

### List View

See all your reports with status indicators:

- Filter by status, date, or amount
- Sort by date, amount, or status
- Search by title or description

### Detail View

Open a report to see:

- Complete expense list
- Receipt thumbnails
- Approval workflow status
- Comments and history

## Report Actions

| Action | Available When |
|--------|----------------|
| Edit | Draft status |
| Submit | Draft status, expenses added |
| Recall | Submitted, not yet approved |
| Duplicate | Any status |
| Delete | Draft status only |
| Export | Any status |
| Print | Any status |

## Approval Workflow

Reports follow your organization's approval workflow:

### Single Approver

1. Employee submits report
2. Manager reviews and approves/rejects
3. Report moves to reimbursement

### Multi-Level Approval

1. Employee submits report
2. Direct manager approves
3. Department head approves (if over threshold)
4. Finance approves
5. Report moves to reimbursement

### Automatic Approval

For expenses under a threshold:

- Small expenses may auto-approve
- Policy-compliant reports fast-tracked
- Configurable by admin

## Notifications

Stay informed about your reports:

| Event | Notification |
|-------|-------------|
| Report submitted | Confirmation to submitter |
| Approval needed | Alert to approvers |
| Report approved | Notification to submitter |
| Report rejected | Notification with reason |
| Changes requested | Notification with details |
| Reimbursement sent | Payment confirmation |

## Best Practices

<Tip>
**Submit regularly** - Don't let expenses pile up. Submit weekly or bi-weekly.
</Tip>

<Tip>
**Clear titles** - Use descriptive titles like "Q1 Client Travel - Project X".
</Tip>

<Tip>
**Review before submitting** - Double-check all amounts and categories.
</Tip>

<Tip>
**Add notes** - Explain any unusual expenses to speed up approval.
</Tip>

<Tip>
**Keep receipts organized** - Ensure all expenses have receipt images.
</Tip>

## Report Templates

Save time with templates:

### Create a Template

1. Go to **Settings > Report Templates**
2. Click **New Template**
3. Configure default settings:
   - Title format
   - Default categories
   - Date range logic
4. Click **Save**

### Use a Template

1. Click **New Report**
2. Select **From Template**
3. Choose your template
4. Customize as needed
5. Add expenses
