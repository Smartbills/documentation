## Submitting Your Report

Once your expense report is complete and reviewed, submit it for approval.

## Pre-Submission Checklist

Before submitting, verify:

<Check>All expenses have receipts attached</Check>
<Check>Categories are correctly assigned</Check>
<Check>Amounts are accurate</Check>
<Check>Description provides context</Check>
<Check>No policy violations exist</Check>
<Check>Report total is correct</Check>

## How to Submit

### Submit from Report Detail

1. Open your expense report
2. Review the contents one final time
3. Click the **Submit** button
4. Confirm submission in the dialog
5. Your report is sent for approval

### Submit from List View

1. Go to **Expense Reports**
2. Find your draft report
3. Click the **Submit** icon or menu
4. Confirm submission

## Submission Confirmation

After submitting, you'll see:

- Confirmation message
- Report status changes to "Submitted"
- Email confirmation sent to you
- Notification sent to approver(s)

## Approval Workflow

Your report follows the configured approval workflow:

### Understanding Your Workflow

1. Go to your submitted report
2. Click **View Workflow**
3. See the approval stages and current status

### Example Workflow

```
┌─────────────┐    ┌──────────────┐    ┌─────────────┐    ┌──────────────┐
│  Submitted  │ →  │   Manager    │ →  │   Finance   │ →  │   Approved   │
│             │    │   Approval   │    │   Review    │    │              │
└─────────────┘    └──────────────┘    └─────────────┘    └──────────────┘
```

### Approval Stages

| Stage | Approver | Criteria |
|-------|----------|----------|
| Manager | Your direct manager | All reports |
| Department Head | Department lead | Reports > $500 |
| Finance | Finance team | Reports > $2,000 |

## What Happens After Submission

### Instant Actions

- Report locked from editing
- Approvers notified via email
- Status updated in dashboard
- Shows in approver's queue

### During Review

- Approvers can add comments
- You receive notifications of activity
- Can respond to questions
- View real-time status updates

## Handling Responses

### Report Approved

When your report is approved:

1. You receive an email notification
2. Report status changes to "Approved"
3. Enters reimbursement processing
4. Payment scheduled per company policy

### Changes Requested

If changes are needed:

1. You receive notification with details
2. Report status shows "Changes Requested"
3. Review the requested changes
4. Make necessary corrections
5. Resubmit the report

### Report Rejected

If your report is rejected:

1. You receive notification with reason
2. Report status shows "Rejected"
3. Review rejection reason
4. Options:
   - Edit and resubmit
   - Create new report
   - Contact approver for clarification

## Recalling a Submission

Need to make changes after submitting?

### How to Recall

1. Open the submitted report
2. Click **Recall** button
3. Confirm recall
4. Report returns to draft status
5. Make your changes
6. Submit again

### Recall Limitations

| Scenario | Can Recall? |
|----------|-------------|
| Pending approval | Yes |
| Partially approved | Contact approver |
| Fully approved | No, contact finance |
| Processing | No |
| Reimbursed | No |

## Submission Deadlines

Your organization may have submission policies:

| Policy | Deadline |
|--------|----------|
| Monthly close | 5th of following month |
| Quarterly | Within 2 weeks of quarter end |
| Travel | Within 30 days of trip |
| Recurring | As incurred |

<Warning>
Late submissions may require additional approval or may be denied per company policy.
</Warning>

Submit from the mobile app:

3. Open your draft report
4. Review contents
5. Tap **Submit**
6. Confirm

## Email Notifications

You'll receive emails for:

| Event | Email Content |
|-------|---------------|
| Submission confirmed | Report details, next steps |
| Approval received | Approver name, timestamp |
| Questions/comments | Approver question, link to respond |
| Changes requested | Specific changes needed |
| Rejection | Reason, instructions |
| Final approval | Reimbursement timeline |
| Payment processed | Amount, method, date |

## Troubleshooting

### Can't Submit?

| Issue | Solution |
|-------|----------|
| Submit button disabled | Check for validation errors |
| Missing required fields | Complete all expenses |
| Policy violation | Add justification or fix issue |
| No approver assigned | Contact admin |

### Not Receiving Notifications?

1. Check spam/junk folder
2. Verify email settings in profile
3. Check notification preferences
4. Contact support if issue persists
