## Approving Expense Reports

As an approver, you're responsible for reviewing and approving expense reports submitted by your team.

## Accessing Pending Approvals

### Approvals Dashboard

1. Navigate to **Approvals** in the sidebar
2. View all pending reports requiring your approval
3. Filter and sort as needed

### Notification-Based

1. Click the approval notification email
2. Opens directly to the report
3. Review and take action

## Reviewing a Report

### Report Overview

When you open a report, you'll see:

- **Submitter** - Who submitted the report
- **Total Amount** - Sum of all expenses
- **Date Range** - Period covered
- **Expense Count** - Number of line items
- **Previous Approvals** - Earlier approval stages

### Detailed Review

For each expense, verify:

| Check | What to Look For |
|-------|------------------|
| Receipt | Image is legible and matches expense |
| Amount | Matches the receipt total |
| Category | Appropriate classification |
| Date | Falls within report period |
| Description | Business purpose is clear |
| Policy | Complies with expense policy |

### Receipt Verification

Click on any expense to:

1. View the full receipt image
2. Zoom and pan for details
3. Compare against entered data
4. Check for alterations

## Approval Actions

### Approve

When everything looks correct:

1. Click **Approve** button
2. Optionally add a comment
3. Confirm approval
4. Report advances to next stage or completion

### Reject

When the report cannot be approved:

1. Click **Reject** button
2. **Required**: Enter rejection reason
3. Optionally suggest corrections
4. Confirm rejection
5. Submitter is notified

### Request Changes

When minor corrections are needed:

1. Click **Request Changes**
2. Specify what needs to be fixed
3. Can mark specific expenses
4. Submit request
5. Submitter can edit and resubmit

### Add Comments

Communicate without taking action:

1. Click **Add Comment**
2. Enter your question or note
3. Click **Send**
4. Submitter receives notification
5. Continues conversation thread

## Policy Validation

### Automatic Checks

Smartbills flags potential issues:

| Flag | Description |
|------|-------------|
| 🔴 Policy Violation | Exceeds limits or rules |
| 🟡 Needs Review | Unusual but may be valid |
| 🟢 Compliant | Meets all policies |

### Common Policy Flags

- Amount exceeds category limit
- Missing receipt (above threshold)
- Duplicate expense detected
- Weekend/holiday expense
- Out-of-policy merchant

### Override Policy

When a violation is justified:

1. Review the justification note
2. Verify business need
3. If approved despite violation, add comment explaining why
4. Click **Approve with Override**

## Bulk Approval

For multiple reports:

### Select and Approve

1. Go to **Approvals** dashboard
2. Check multiple reports
3. Click **Bulk Approve**
4. Confirm action

<Warning>
Only use bulk approval when you've reviewed each report individually.
</Warning>

### Approval Thresholds

Set auto-approval rules:

| Condition | Action |
|-----------|--------|
| Under $50, single expense | Auto-approve |
| Under $200, regular submitter | Fast-track |
| Policy compliant | Priority queue |

## Delegation

### Temporary Delegation

When you'll be unavailable:

1. Go to **Settings > Delegations**
2. Click **Add Delegate**
3. Select the delegate
4. Set date range
5. Choose delegation scope:
   - All approvals
   - Specific employees
   - Amount threshold
6. Save

### Viewing Delegated Approvals

Delegates see:

- Delegated reports marked with indicator
- Original approver name
- Can approve on behalf of

## Audit Trail

### What's Tracked

Every action is logged:

- Approval/rejection with timestamp
- Comments added
- Changes requested
- Who took action
- IP address and device

### Viewing History

1. Open the expense report
2. Click **History** or **Audit Log**
3. View complete timeline
4. Export for compliance

## Mobile Approval

Approve on the go:

1. Open Smartbills app
2. Go to **Approvals** tab
3. Review report summary
4. Tap to view details
5. Approve, reject, or comment

### Quick Actions

From notification:

1. Tap the push notification
2. Opens report directly
3. Swipe to approve (configurable)
4. Or tap for full review

## Best Practices

<Tip>
**Review promptly** - Don't leave submitters waiting.
</Tip>

<Tip>
**Check receipts** - Verify images match entered data.
</Tip>

<Tip>
**Be consistent** - Apply the same standards to all submissions.
</Tip>

<Tip>
**Provide feedback** - Explain rejections clearly.
</Tip>

<Tip>
**Set up delegation** - Ensure approvals continue when you're away.
</Tip>

## Common Scenarios

### Partial Approval

When some expenses are valid but others aren't:

1. Request changes for the report
2. Specify which expenses need correction
3. Submitter can fix and resubmit
4. Or create separate report

### Unusual Expenses

For legitimate but unusual expenses:

1. Review justification carefully
2. Consider business context
3. Consult policy if needed
4. Document your decision in comments

### Late Submissions

When reports are submitted late:

1. Check company policy on late submissions
2. Review business justification
3. Approve with note if acceptable
4. Or reject per policy
