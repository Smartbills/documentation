## Creating Your First Report

Follow these steps to create an expense report for reimbursement.

## Before You Start

Ensure you have:

<Check>Expenses uploaded and categorized</Check>
<Check>All receipts attached</Check>
<Check>Categories assigned</Check>
<Check>Descriptions added for clarity</Check>

## Step-by-Step Guide

### Step 1: Start a New Report

1. Navigate to **Expense Reports** in the sidebar
2. Click the **New Report** button
3. You'll see the report creation dialog

### Step 2: Enter Report Details

Fill in the report information:

| Field | Example | Required |
|-------|---------|----------|
| Title | "January 2025 Business Travel" | Yes |
| Description | "Client meetings in NYC" | No |
| Date Range | Jan 1 - Jan 31, 2025 | No |
| Department | Engineering | No |
| Project | Project Alpha | No |

<Tip>
**Naming convention**: Use a consistent format like "[Month] [Year] - [Purpose]" for easy searching.
</Tip>

### Step 3: Add Expenses

#### Method 1: From the Report

1. Click **Add Expenses** in the report
2. Browse available expenses
3. Check the boxes for expenses to include
4. Click **Add Selected**

#### Method 2: From Expenses Page

1. Go to **Expenses**
2. Select expenses using checkboxes
3. Click **Add to Report**
4. Choose your report or create new

#### Method 3: Auto-Add by Date Range

1. In report settings, set a date range
2. Click **Auto-Add Expenses**
3. All unassigned expenses in that range are added
4. Remove any that shouldn't be included

### Step 4: Review and Organize

Review your report contents:

- **Verify amounts** - Check each expense total
- **Check categories** - Ensure proper classification
- **Review receipts** - Confirm images are attached
- **Check for duplicates** - Remove any duplicates

#### Expense Summary

The report shows an automatic summary:

```
Total Expenses: $1,245.67

By Category:
- Travel: $750.00 (60%)
- Meals: $295.67 (24%)
- Transportation: $200.00 (16%)

Expenses: 12 items
Missing Receipts: 0
```

### Step 5: Add Notes (Optional)

Include context for your approver:

- Explain the business purpose
- Clarify unusual expenses
- Note any policy exceptions
- Reference project or client

Example note:
> "Travel expenses for client meetings with Acme Corp in NYC. Included team dinner for 4 attendees from both companies."

### Step 6: Save as Draft

Click **Save Draft** to:

- Keep the report for later
- Continue adding expenses
- Review before submission

<Note>
Draft reports can be edited freely. Once submitted, changes require recalling the report.
</Note>

## Creating Reports for Specific Purposes

### Travel Report

Best practices for travel expenses:

1. Include all related expenses:
   - Flights
   - Hotels
   - Ground transportation
   - Per diem meals
   - Conference fees

2. Organize by trip:
   - One report per trip
   - Include itinerary reference
   - Note attendees if team travel

### Monthly Expense Report

For recurring submissions:

1. Set date range for the month
2. Include all business expenses
3. Group by category
4. Add month-end summary

### Project-Based Report

When billing to specific projects:

1. Select the project from dropdown
2. Only include project-related expenses
3. Note client or project code
4. Attach relevant approvals

## Report Validation

Before you can submit, the system checks:

<Check>At least one expense included</Check>
<Check>All expenses have required fields</Check>
<Check>Receipts attached (if required by policy)</Check>
<Check>No duplicate expenses</Check>
<Check>Within submission deadlines</Check>

### Common Validation Errors

| Error | Solution |
|-------|----------|
| Missing category | Categorize all expenses |
| Missing receipt | Upload receipt images |
| Over policy limit | Add justification note |
| Duplicate expense | Remove the duplicate |

## Using Templates

### Available Templates

Your organization may provide templates:

| Template | Use Case |
|----------|----------|
| Standard Monthly | Regular expense submission |
| Travel Report | Business trips |
| Conference | Events and conferences |
| Client Billable | Client-reimbursable expenses |

### Apply a Template

1. Click **New Report**
2. Select **From Template**
3. Choose the appropriate template
4. Template pre-fills settings
5. Add your expenses
6. Modify as needed

## Bulk Report Creation

For multiple reports at once:

### By Date Range

1. Go to **Reports > Bulk Create**
2. Select date range
3. Choose grouping (by week/month)
4. System creates draft reports
5. Review and adjust each

### For Team (Managers)

Managers can create reports for team members:

1. Go to **Team > Expense Reports**
2. Select team member
3. Click **Create Report For**
4. Add their expenses
5. Save and notify them
